# 패션·뷰티 시장성·상품 생성 지침 v02


기준일: 2026-09-09
적용 프로젝트: 실사 모델 제작 / 인플루언서 모델
목적: Nano Banana, GPT 계열 및 기타 이미지 생성 모델에서 한국 시장의 실제 패션·뷰티 문법을 반영한 가상 의상·상품·착장 이미지를 설계하기 위한 공통 운영 지침


## 1. 문서 역할


이 문서는 모델의 얼굴·신체 정체성을 정의하는 정본이 아니다. 승인된 MODEL의 얼굴·체형·앵커·Morphology·Body Signature를 변경하지 않고, 작업별 가변 슬롯인 패션·메이크업·상품 디자인을 선택하고 생성하는 시장성 보조 지침이다.


적용 대상은 다음과 같다.


- CASUAL: 평상복, 데일리룩, SNS, 이동·카페·거리 장면
- FASHION: 룩북, 에디토리얼, 디자이너·컨템포러리 패션
- STAGE: K-pop·공연·퍼포먼스 의상
- LIFESTYLE: 오피스, 여행, 홈, 스포츠, 일상 소비 장면
- BEAUTY: 색조 메이크업, 화장품·향수·헤어 제품, 뷰티 광고
- PRODUCT: 의상·신발·가방·액세서리·화장품의 가상 상품 단독 이미지


이 지침의 시장·트렌드 내용은 2026년 9월 기준 리서치에서 추출한 작업용 규칙이다. 유행 자체는 정본으로 고정하지 않으며, 최신성이 중요한 생성에서는 필요 시 현재 플랫폼·랭킹·기획전을 다시 확인한다.


## 2. 핵심 원칙


1. 의상이나 화장품을 아무 근거 없이 임의 조합하지 않는다.
2. 실존 브랜드나 개별 상품을 복제하지 않는다. 외부 상품은 카테고리, 실루엣, 소재, 가격 포지션, 스타일링 문법을 분석하는 자료로만 사용한다.
3. 먼저 시장에서 익숙한 기본 상품 구조를 만들고, 그 위에 트렌드 요소를 1~2개 추가한다.
4. 하나의 제품에 너무 많은 마이크로트렌드를 동시에 넣지 않는다.
5. 모든 의상은 실제 착용·봉제가 가능한 구조를 가져야 한다.
6. 신규 상품은 원칙적으로 `상품 설계 이미지 → 상품 단품 정본 → 착용샷 → 화보` 순서로 진행한다.
7. 상품 설계 이미지는 디자인을 결정하는 기획 자료이고, 상품 단품 이미지는 이후 생성에서 참조하는 제품 정본이다. 두 역할을 혼용하지 않는다.
8. 상품 단품 정본이 승인된 뒤에는 착용샷과 화보에서 프롬프트만으로 상품을 다시 설계하지 않고 승인된 단품 이미지를 우선 참조한다.
9. 모델의 신체 정체성은 의상 때문에 변형하지 않는다. 체형은 해당 MODEL의 BODY MASTER와 Body Signature를 따른다.
10. 패션·뷰티의 최신성은 ‘현재 시장에서 반복 노출되는 문법’을 우선하고, 일회성 바이럴 요소는 보조로만 쓴다.

## 7. 상품 생성 프롬프트 조립 규칙

상품 생성의 최종 영어 프롬프트 정본은 상품 생성 프롬프트 템플릿-v01.md다.

상품 프롬프트는 다음 순서로만 만든다.

1. 모드 선택: DESIGN LAYOUT / PRODUCT DESIGN / PRODUCT MASTER / FITTING MASTER / EDITORIAL DERIVED
2. 승인 정본, 사용자 지시, 참고 자료에서 슬롯값 수집
3. 카테고리별 VIEWSET 자동 선택
4. 선택한 모드 템플릿에 슬롯값 입력
5. LAYOUT CONTRACT, VIEWSET CONTRACT, STRUCTURE LOCK, BRAND LOCK, TEXT / METADATA POLICY, QUALITY, NEGATIVE / CONSTRAINT 고정 블록을 원문 그대로 삽입
6. P00~P10 검수 후 사용자 공개본 확정

매 작업마다 자연어 상품 프롬프트를 새로 작성하거나, 고정 블록을 요약·축약·재배열하지 않는다. 가변 작성 범위는 슬롯값뿐이다.

상품 설계 순서는 아래 슬롯의 누락을 막기 위한 검수 순서로 유지한다.

ITEM → SILHOUETTE → LENGTH / PROPORTION → MATERIAL → COLOR → SEAMS / PANELING → CLOSURE → POCKETS → HARDWARE / TRIMS → LINING / FINISH → SURFACE TEXTURE → PRODUCT VIEW → LIGHT → BACKGROUND → CONSTRAINTS

미확정 날짜·가격·치수·사이즈·상품 코드·출시 상태·버전은 임의로 생성하지 않는다. DESIGN LAYOUT과 PRODUCT DESIGN에서는 빈칸 또는 TBD로 두고, PRODUCT MASTER 이후 단계에서는 표시하지 않는다.

## 8. 상품 설계 이미지와 상품 단품 정본


패션·뷰티 상품 제작은 다음 세 단계를 구분한다.

1. `DESIGN LAYOUT MODE` — 상품 설계 이미지의 레이아웃 템플릿 자체를 설계·검토한다.
2. `PRODUCT DESIGN MODE` — 승인된 레이아웃을 이용해 실제 개별 상품을 설계한다.
3. `PRODUCT MASTER` — 승인된 상품 설계를 바탕으로 실제 판매 상품처럼 보이는 단품 정본을 만든다.

세 단계의 결과물은 역할이 다르며 서로 대체하지 않는다.

모든 단계의 최종 영어 프롬프트는 상품 생성 프롬프트 템플릿-v01.md에서 해당 MODE TEMPLATE를 선택해 조립한다. 이 문서의 DESIGN LAYOUT v1, 카테고리별 VIEWSET, 구조 정합성 기준은 템플릿의 고정 계약으로 삽입되며 작업별 자연어 재서술로 대체하지 않는다.


### 8.1 상품 설계 레이아웃 — DESIGN LAYOUT MODE

DESIGN LAYOUT MODE의 목적은 특정 상품을 완성하는 것이 아니라, **상품 설계 이미지 한 장에 어떤 정보가 어떤 위치와 비중으로 들어가야 하는지 검토하는 것**이다.

이 모드에서는 다음 원칙을 적용한다.

- 특정 상품의 최종 디자인을 만들지 않는다.
- 실제 모델 착용샷, 화보, 인물 포트레이트를 생성하지 않는다.
- 실존 상품이나 완성된 가상 상품을 중심 이미지로 넣지 않는다.
- 필요하면 단순한 플레이스홀더, 무채색 더미 스케치, 빈 이미지 영역, 예시 텍스처 블록을 사용할 수 있다.
- 이미지 안의 상품명·가격·사이즈·출시일 등은 실제 데이터가 아니라 레이아웃용 필드명만 표시한다. 임의의 값은 넣지 않는다.
- 목적은 정보 구획, 시선 흐름, 정보 밀도, 섹션 비율, 반복 사용성을 평가하는 것이다.
- 레이아웃 테스트 이미지는 PRODUCT MASTER, FITTING MASTER, EDITORIAL 생성의 직접 참조로 사용하지 않는다.
- 레이아웃이 승인된 뒤에만 PRODUCT DESIGN MODE로 넘어간다.

#### 8.1.1 의류용 공통 DESIGN LAYOUT v1 — APPROVED

2026-09-09 검토를 거쳐 현재 의류용 공통 상품 설계 레이아웃을 `DESIGN LAYOUT v1` 기준안으로 승인한다. 이 레이아웃은 상의·니트·셔츠·블라우스·아우터·원피스 등 의류 상품 설계 보드의 기본 템플릿으로 사용한다.

기본 화면은 **가로형**을 우선한다. 특정 종횡비는 강제하지 않으며, 정보 밀도와 가독성을 해치지 않는 범위에서 출력 매체에 맞게 조절한다. 세로형이나 정사각형이 필요한 작업은 동일 슬롯을 유지한 채 재배치할 수 있다.

레이아웃의 정보 위계는 다음 세 구역을 기본으로 한다.

- 상단 약 25%: 상품 개요 / 컨셉·무드 / 컬러 / 관리 메타데이터
- 중앙 약 45%: 디자인 스케치 / 디테일 포인트 / 소재·텍스처
- 하단 약 30%: 봉제·치수·사양 / 선택적 스타일링 방향

비율은 절대 수치가 아니라 우선순위 가이드다. **디자인 스케치가 단일 영역 중 가장 큰 비중**을 가져야 하며, 디테일·소재·사양 영역을 합친 면적이 감성 무드·카피 영역보다 작아지지 않게 한다.

##### A. PRODUCT OVERVIEW — 상품 개요

상품 자체를 빠르게 식별하기 위한 설계 요약 영역이다. 다음 슬롯을 기본으로 한다.

- Product Name / 상품명
- Category / 카테고리
- Season / 시즌
- Target / 타깃
- One-line Concept / 한 줄 컨셉
- Concept Reference / Inspiration — 선택

`Concept Reference / Inspiration` 슬롯은 **완성 상품 이미지나 PRODUCT MASTER 자리**가 아니다. 무드, 형태 언어, 소재 감각, 사용 장면 등을 설명하는 참조 영역으로만 사용한다. 실존 상품 하나를 그대로 복제하기 위한 레퍼런스로 사용하지 않는다.

##### B. CONCEPT & MOOD — 컨셉 / 무드

- 무드 이미지 또는 플레이스홀더
- 핵심 키워드 3~6개
- 스타일 방향
- 사용 상황 또는 감성 키워드 — 필요 시

감성 카피는 최소화한다. 이 영역이 기술 설계 정보를 압도하지 않게 한다.

##### C. COLOR PALETTE — 컬러 전개

기본 팔레트는 3~4개 역할색을 우선한다. 필요할 때만 확장 컬러를 추가한다.

- MAIN — 주색
- SUB — 보조색
- ACCENT — 포인트색
- OPTIONAL / VARIANT — 변형색, 필요 시

가능하면 각 스와치에는 역할명과 색상값 또는 컬러명을 연결한다. 레이아웃 테스트에서는 실제 값 대신 필드명만 둘 수 있다.

##### D. DESIGN SKETCHES — 디자인 스케치

의류용 레이아웃의 최우선 핵심 영역이다.

필수:
- FRONT
- BACK
- LEFT SIDE
- RIGHT SIDE

상품 구조에 따라 3/4, 내부 구조, 후드·칼라 개방 상태 등의 추가 스케치를 배치할 수 있다. 네 기본 뷰는 동일 비율·동일 상품 구조로 읽혀야 한다.

##### E. DETAIL POINTS — 디테일 포인트

상품 구조에 맞춰 4~8개 슬롯을 사용한다. 기본 후보는 다음과 같다.

- Collar / Neckline
- Closure
- Sleeve / Cuff
- Hem
- Pocket / Hardware
- Panel / Seam
- Lining / Interior
- Other Critical Detail

상품에 존재하지 않는 디테일 슬롯은 억지로 채우지 않고 다른 핵심 구조로 교체한다.

##### F. MATERIAL / TEXTURE — 소재 / 텍스처

- Main Fabric / 메인 원단
- Surface Texture / 표면감
- Weight / Thickness / 중량·두께
- Stretch / 신축성
- Lining / 안감 — 필요 시
- Sheerness / 비침 — 필요 시
- Seasonal Handfeel / 계절감 — 필요 시

소재 이미지는 단순 장식이 아니라 상품의 두께·광택·결·드레이프를 판단할 수 있는 크기로 배치한다.

##### G. CONSTRUCTION & MEASUREMENT SPECS — 봉제 / 치수 / 사양

기존 `CONSTRUCTION & SPEC`을 확장한 핵심 영역이다. 설계 단계에서 구조적 고정값을 기록할 수 있어야 한다.

구조 사양 기본 슬롯:
- Silhouette
- Fit
- Length
- Seams / Paneling
- Closure
- Pockets
- Lining
- Finish / Stitching
- Main Material / Composition
- Notes

의류 치수 슬롯 기본값:
- Shoulder Width
- Chest Width / Bust Width
- Body Length
- Sleeve Length
- Sleeve Width — 필요 시
- Hem Width
- Waist Width — 허리 정의 상품일 때

카테고리에 따라 필요한 치수만 남기고 다른 항목으로 교체할 수 있다. DESIGN LAYOUT MODE에서는 실제 숫자를 임의 생성하지 않고 필드명 또는 빈칸으로 유지한다. 실제 수치는 PRODUCT DESIGN MODE에서 확정한다.

##### H. PRODUCT METADATA — 상품 관리 정보

`PRODUCT OVERVIEW`와 중복되지 않도록 관리 목적의 정보만 둔다.

- Product ID / Code
- Price Tier — 필요 시
- Sales Channel — 필요 시
- Design Status / Version
- Notes

Season, Category, Target처럼 상품 개요에 이미 존재하는 필드는 여기서 반복하지 않는다.

##### I. OPTIONAL STYLING DIRECTION — 스타일링 방향

선택 영역이다. 세부 운용은 8.1.2를 따른다. 공간이 부족하면 이 영역을 가장 먼저 축소하거나 제거하고 DESIGN SKETCHES 또는 CONSTRUCTION & MEASUREMENT SPECS를 확대한다.

#### 8.1.2 스타일링 방향 영역

스타일링 방향은 기본적으로 선택 사항이다.

- 상품 구조 설계가 목적이면 생략한다.
- 어떤 착장 맥락에 사용할 상품인지 함께 검토할 필요가 있을 때만 포함한다.
- 포함하더라도 실제 모델 착용 이미지가 아니라 단순 아이콘, 플랫 스케치, 조합 슬롯 정도로 표현한다.
- FITTING 단계의 역할을 DESIGN LAYOUT MODE에서 대신하지 않는다.

#### 8.1.3 카테고리별 레이아웃 변형

공통 레이아웃을 모든 상품에 그대로 적용하지 않는다.

- 의류: 스케치·디테일·소재·봉제 영역 비중을 높인다.
- 신발: FRONT / BACK / LEFT / RIGHT / TOP / OUTSOLE 구조와 갑피·미드솔·아웃솔·끈/버클 영역을 크게 둔다.
- 가방: FRONT / BACK / SIDE / TOP / BOTTOM / INTERIOR, 스트랩·지퍼·하드웨어·내부 수납 영역을 크게 둔다.
- 뷰티 제품: 용기 FRONT / BACK / SIDE / TOP / BOTTOM, 캡·펌프·힌지·어플리케이터·제형 스와치 영역을 중심으로 재구성한다.

#### 8.1.4 DESIGN LAYOUT MODE 평가 기준

다음 항목만 평가한다.

1. 정보 구획이 직관적인가.
2. 시선 흐름이 자연스러운가.
3. 카테고리에 필요한 섹션이 빠지지 않았는가.
4. 핵심 설계 정보의 비중이 충분한가.
5. 같은 포맷을 반복 재사용하기 쉬운가.
6. 불필요한 감성 이미지·카피·인물 요소가 과도하지 않은가.
7. PRODUCT DESIGN MODE에서 실제 데이터를 채워 넣기 쉬운가.

이 단계에서는 상품 자체의 미감이나 시장성을 평가하지 않는다.


### 8.2 실제 상품 설계 이미지 — PRODUCT DESIGN MODE

승인된 DESIGN LAYOUT을 바탕으로 실제 개별 상품의 구조와 시각 언어를 확정한다. 이 단계의 결과물은 아직 제품 정본이 아니다.

- 실루엣, 비율, 소재, 색상, 절개, 여밈, 포켓, 하드웨어, 트림을 결정한다.
- 설계 레이아웃의 각 섹션에 해당 상품의 실제 설계 정보를 채운다.
- 필요한 경우 한 장의 설계 보드 안에 스케치형 정면·후면·측면, 소재 샘플, 디테일 확대, 컬러 팔레트를 함께 배치할 수 있다.
- 실제 모델 착용샷과 화보는 포함하지 않는 것을 기본값으로 한다.
- 스타일링 방향이 필요하면 실제 인물 이미지보다 플랫 조합 또는 간단한 룩 슬롯을 우선한다.
- 설계 보드의 여러 뷰가 서로 충돌하면 어느 하나도 정본으로 승격하지 않는다.
- 이미지 안의 텍스트 데이터는 실제 설계 스펙과 일치해야 하며, 생성 모델이 임의로 만든 숫자·가격·사이즈를 정본으로 사용하지 않는다.
- 특정 실존 브랜드의 제품이나 트레이드 드레스를 그대로 복제하지 않는다.
- PRODUCT DESIGN MODE TEMPLATE의 LAYOUT CONTRACT, VIEWSET CONTRACT, STRUCTURE LOCK, BRAND LOCK, TEXT / METADATA POLICY를 그대로 사용한다.

#### 8.2.1 구조 정합성 하드 게이트

복잡한 드레이프, 러칭, 랩, 플리츠, 절개, 슬릿, 지퍼, 후크 등 여러 구조 요소가 동시에 존재하는 상품은 **디테일 하나하나의 미감보다 서로의 물리적 양립 가능성**을 먼저 검수한다.

1. **여밈 위치와 고장력 디테일을 같은 구조선에 무리하게 중첩하지 않는다.**
   - 러칭, 강한 드레이프 고정점, 두꺼운 플리츠 결합부, 중첩 랩 고정점처럼 원단이 여러 겹 모이거나 장력이 집중되는 위치에는 긴 콘실 지퍼를 기본적으로 배치하지 않는다.
   - 불가피하게 같은 위치를 사용해야 하면 여밈 길이, 심 보강, 원단 두께와 봉제 가능성을 별도로 설명한다.
2. **복잡 디테일과 여밈이 충돌하면 여밈을 더 안정적인 구조선으로 이동한다.**
   - 드레스·원피스에서 한쪽 사이드 심에 러칭이나 드레이프가 집중되면 기본 대안은 `CENTER BACK CONCEALED ZIPPER`다.
   - 사이드 지퍼를 반드시 유지해야 하면 러칭·드레이프 집중부를 반대편 또는 별도 패널로 분리한다.
3. **FRONT / BACK / LEFT SIDE / RIGHT SIDE는 동일한 설계 랜드마크를 공유해야 한다.**
   - 넥라인 시작·종료점
   - 프린세스 심·다트·패널 절개선
   - 드레이프 시작점과 고정점
   - 러칭 집중점
   - 랩 오버랩의 위·아래 관계
   - 슬릿 시작 높이와 방향
   - 지퍼·후크·단추 위치
   - 안감·페이싱 경계
4. 한 뷰에서 보이는 구조선이 인접 뷰에서 이유 없이 사라지거나 새로운 선으로 바뀌면 구조 불일치로 판정한다.
5. 디테일 확대 이미지는 4방향 스케치에서 실제로 존재하는 위치만 확대한다. 확대도에서 새로운 구조를 추가하지 않는다.
6. 복잡한 상품은 `디자인 미감 → 구조 해석` 순서가 아니라 `구조 성립 → 디자인 미감` 순서로 승인한다.

#### 8.2.2 PRODUCT DESIGN 승인과 PRODUCT MASTER 전환 조건

PRODUCT DESIGN MODE의 테스트·초기 시안 단계에서는 일부 치수값을 빈칸으로 둘 수 있다. 그러나 **PRODUCT MASTER 제작으로 승격할 상품은 핵심 구조와 필요한 치수 슬롯이 확정되어야 한다.**

의류의 기본 확정 대상은 카테고리에 맞게 다음 중 필요한 항목을 선택한다.

- Shoulder Width
- Chest / Bust Width
- Waist Width 또는 Waist Circumference 기준
- Hip Width 또는 Hip Circumference 기준
- Body Length
- Sleeve Length / Sleeve Width — 소매가 있을 때
- Hem Width
- Waist Position
- Slit Height — 슬릿이 있을 때
- Drape / Ruching Anchor Position — 구조 핵심일 때
- Closure Position / Length

실제 생산용 테크팩 수준의 정밀 수치까지 요구하는 것은 아니지만, PRODUCT MASTER에서 비율이 흔들리지 않도록 **설계 비율을 잠글 수 있는 최소 치수 또는 상대적 위치 규칙**을 확정한다.

PRODUCT MASTER로 넘어가기 전에 다음을 모두 확인한다.

1. 4방향 스케치의 구조 랜드마크가 일치한다.
2. 여밈이 드레이프·러칭·랩·플리츠 등과 물리적으로 충돌하지 않는다.
3. 핵심 치수 또는 상대적 위치 규칙이 확정되어 있다.
4. 소재 두께와 장력이 설계된 구조를 실제로 구현할 수 있다.
5. 디테일 확대도가 본체 스케치와 동일 구조를 설명한다.


### 8.3 상품 단품 이미지 — PRODUCT MASTER

설계가 승인되면 같은 디자인을 실제 판매 가능한 단독 상품처럼 다시 생성한다. 이 단계의 승인 이미지는 이후 착용샷·화보·영상에서 상품 정체성을 전달하는 PRODUCT MASTER다.

- 각 시점은 **한 이미지에 한 시점**을 원칙으로 한다.
- 정면·후면·측면·위·아래 등 여러 시점을 한 장의 콜라주로 합치지 않는다.
- 모든 시점은 같은 상품 ID를 공유하며 소재, 색상, 절개, 포켓, 단추 수, 지퍼, 하드웨어, 스트랩 구조가 일치해야 한다.
- 배경과 조명은 제품 구조를 읽기 쉬운 중성 스튜디오 조건을 기본값으로 한다.
- 제품 정체성을 가리는 소품, 손, 모델, 장식 배경을 기본값으로 사용하지 않는다.
- 제품이 실제로 제작·착용·개폐 가능한 구조인지 검수한다.


### 8.4 PRODUCT MASTER 승인 조건

다음 조건을 모두 만족해야 LOCK할 수 있다.

1. 필수 시점 세트가 확보되어 있다.
2. 모든 시점에서 동일 상품으로 인식된다.
3. 절개·여밈·포켓·하드웨어의 위치와 개수가 논리적으로 이어진다.
4. 소재의 두께, 광택, 장력과 표면 질감이 시점마다 일관된다.
5. 실제 생산과 사용이 가능한 구조다.
6. 실존 브랜드 로고·문자·식별 가능한 트레이드 드레스가 없다.
7. PRODUCT DESIGN 단계에서 확정한 핵심 치수 또는 상대적 위치 규칙이 PRODUCT MASTER의 모든 시점에서 유지된다.
8. 여밈과 드레이프·러칭·랩·플리츠·슬릿 등 고장력 구조가 서로 물리적으로 충돌하지 않는다.

승인된 PRODUCT MASTER 이후의 파생 단계에서는 디자인을 다시 해석하지 않는다.


## 9. 상품군별 필수 시점 세트


`앞 / 뒤 / 옆 / 위 / 아래`를 모든 상품에 기계적으로 강제하지 않는다. 상품 구조를 이해하는 데 필요한 시점을 카테고리별로 지정한다.


### 9.1 상의·니트·셔츠·블라우스·아우터·원피스

필수:
- FRONT — 정면
- BACK — 후면
- SIDE — 측면

조건부 권장:
- 3/4 — 입체 실루엣과 라펠·칼라 구조
- NECK / COLLAR — 넥라인·칼라
- SLEEVE / CUFF — 소매·커프
- CLOSURE — 단추·지퍼·후크
- HEM — 밑단
- INSIDE — 안감·내부 구조
- MATERIAL MACRO — 원단·니트 게이지·레더 표면

의류의 TOP/BOTTOM 뷰는 구조적 의미가 있을 때만 추가한다.

PRODUCT DESIGN 보드는 DESIGN LAYOUT v1에 따라 FRONT / BACK / LEFT SIDE / RIGHT SIDE를 각각 표시한다. PRODUCT MASTER에서만 좌우가 완전히 대칭이고 서로 다른 봉제선·여밈·포켓·슬릿·드레이프·프린트·장식·하드웨어·비대칭 소재가 없다고 명시적으로 확인된 경우 SIDE 한 시점으로 LEFT SIDE와 RIGHT SIDE를 대체할 수 있다. 조건이 하나라도 불명확하면 LEFT SIDE와 RIGHT SIDE를 모두 만든다.

필수:
- FRONT
- BACK
- SIDE

## 10. 상품 LOCK과 파생 생성 파이프라인


기본 공정은 다음 순서를 따른다.

`상품 설계 이미지 → 상품 단품 시점 세트 → PRODUCT MASTER LOCK → FIT FORM 피팅 정본 → 필요 시 모델 피팅 정본 → 착용 디테일샷(선택) → 화보 → 영상/캠페인 파생`


### 10.1 PRODUCT MASTER LOCK

- 상품별 고유 `PRODUCT ID`를 부여한다.
- 한 착장 세트에는 필요 시 `LOOK ID`를 별도로 부여하고 여러 PRODUCT ID를 묶는다.
- LOCK된 상품의 색상, 소재, 절개, 버튼 수, 포켓 위치, 지퍼, 스트랩, 하드웨어는 사용자 승인 없이 변경하지 않는다.
- 색상이나 소재를 바꾸고 싶다면 기존 상품을 변형하지 말고 VARIANT 또는 새 PRODUCT ID로 관리한다.

예시:

`LOOK-002-CASUAL-FW26-001`
- `TOP-001`
- `BOTTOM-001`
- `SHOES-001`
- `BAG-001`


### 10.2 FIT FORM 피팅 정본 — 필수

착용 가능한 상품은 PRODUCT MASTER를 직접 참조하여 승인된 LUNEVA FIT FORM에 먼저 적용한다.

- 상품의 핏, 길이, 드레이프, 압박, 주름과 피팅 기준체 접촉을 검수한다.
- PRODUCT MASTER의 색상, 소재, 절개, 여밈, 하드웨어, 마감, 로고 위치와 비율을 바꾸지 않는다.
- FIT FORM의 관절, 베이스, 지지봉, 재질과 비율을 상품 때문에 바꾸지 않는다.
- FIT FORM 피팅 정본이 승인되기 전에는 모델 피팅 또는 화보 단계로 넘어가지 않는다.


### 10.3 모델 피팅 정본 — 필요 시

FIT FORM 피팅 정본을 직접 참조하여 승인된 모델에게 적용한다.

- 머리부터 발끝까지 전신이 보여야 한다.
- 상품의 핏, 길이, 드레이프, 압박, 주름과 신체 접촉을 검수한다.
- 모델의 FACE/BODY MASTER와 Body Signature가 상품 때문에 변형되지 않아야 한다.
- 상품 정체성을 바꾸는 스타일링 수정은 금지한다.
- 가방·신발·주얼리도 LOCK된 상품을 그대로 사용한다.
- 사람 모델을 쓰는 화보는 모델 피팅 정본이 승인되기 전에는 진행하지 않는다.


### 10.4 착용 디테일샷 — 선택

필요한 경우 다음을 별도 이미지로 생성한다.

- 허리선과 여밈
- 칼라·넥라인
- 소매·커프
- 가방 착용 위치와 스트랩
- 신발과 발목·양말 관계
- 소재가 신체에서 주름지는 방식


### 10.5 화보 — EDITORIAL DERIVED

화보는 FITTING MASTER 이후의 연출 단계다.

- 상품과 모델 정체성은 LOCK한다.
- 포즈, 표정, 헤어, 메이크업, 배경, 조명, 렌즈와 구도는 캠페인 목적에 따라 적극적으로 변주할 수 있다.
- 화보 생성 시 상품을 텍스트로 다시 설계하지 말고 PRODUCT MASTER와 FITTING MASTER를 우선 참조한다.
- 연출 때문에 상품 구조가 가려질 수는 있지만 보이는 부분의 구조가 정본과 충돌하면 실패다.


### 10.6 단계 간 참조 우선순위

- 상품 단품: `DESIGN → PRODUCT MASTER`
- FIT FORM 피팅: `PRODUCT MASTER + FIT FORM → FIT FORM FITTING MASTER`
- 모델 피팅: `MODEL MASTER + PRODUCT MASTER + FIT FORM FITTING MASTER → MODEL FITTING MASTER`
- 화보: `MODEL MASTER + PRODUCT MASTER + FIT FORM FITTING MASTER + 필요 시 MODEL FITTING MASTER → EDITORIAL`
- 영상: `MODEL MASTER + PRODUCT MASTER + FIT FORM FITTING MASTER + 필요 시 MODEL FITTING MASTER + MOTION 자료 → VIDEO`

프롬프트 설명은 정본 이미지를 보조하는 용도로만 사용하며, 정본과 충돌할 경우 정본 이미지가 우선한다.

각 파이프라인 단계는 상품 생성 프롬프트 템플릿-v01.md의 같은 이름의 MODE TEMPLATE를 사용한다. PRODUCT MASTER는 CURRENT_VIEW 하나만 채운 단일 시점 프롬프트를 뷰마다 별도로 조립하며, FITTING MASTER와 EDITORIAL DERIVED는 LOCK된 PRODUCT MASTER의 디자인 슬롯을 다시 해석하지 않는다.


## 11. 착장 조합 규칙


- 한 룩의 주인공 아이템은 1개로 둔다.
- 강한 실루엣과 강한 패턴을 동시에 여러 개 사용하지 않는다.
- 강한 트렌드 아이템은 최대 1~2개로 제한한다.
- 상의가 볼륨형이면 하의는 직선형 또는 단순형을 우선한다.
- 하의가 와이드·배럴·볼륨형이면 상의는 슬림하거나 구조가 명료해야 한다.
- 시어·레이스·슬립은 구조적 재킷이나 단순 하의와 조합한다.
- 액세서리는 룩의 정보량을 보완하는 용도로 사용하고, 모든 부위에 포인트를 넣지 않는다.
- CASUAL은 실제 거리에서 착용 가능한 수준을 유지한다.
- STAGE는 움직임, 춤, 조명 반사, 탈착 구조를 고려하되 실제 의상 제작이 가능한 구조를 유지한다.

## 14. 뷰티 상품 생성 규칙


뷰티 제품 역시 실제 브랜드 제품을 복제하지 않는다.


제품 설계 슬롯:


1. 제품군
2. 내용물 제형
3. 색상
4. 용기 재질
5. 용기 형태
6. 디스펜서·어플리케이터
7. 캡·힌지·펌프 구조
8. 표면 마감
9. 포인트 컬러
10. 패키징 가격 포지션
11. 내용물 스와치·드롭·스미어 표현
12. 촬영 배경
13. 조명


현재 활용 가치가 높은 시각 언어:


- 앰플·세럼: 반투명 액체, 드로퍼 또는 정밀 펌프, 임상적·미니멀한 패키지
- 쿠션: 얇은 콤팩트, 매트·세미글로시 표면, 퍼프와 힌지 구조 명료
- 블러 립: 프로스트 튜브, 무스·클라우드 매트 스와치
- 글로시 립: 투명도 높은 용기, 젤·시럽 같은 광택
- 립&치크: 포트·컴팩트, 푸딩·무스·밤 제형을 시각적으로 노출
- 향수·미스트: 프로스트 글라스 또는 투명 실린더, 분사 구조가 실제 제품처럼 작동 가능해야 함
- 두피 세럼: 뾰족 노즐, 드로퍼, 빗형 어플리케이터 등 사용 부위와 구조가 일치해야 함


## 15. 메이크업 이미지 생성 규칙


메이크업은 제품명보다 ‘보이는 결과’를 우선해 작성한다.


- 피부: natural satin, soft glow, semi-matte, controlled dewy finish
- 눈썹: straight-soft Korean brow, softly arched brow, natural individual brow hairs
- 아이: muted taupe wash, soft brown liner, defined lash roots, separated lashes, subtle aegyo-sal highlight
- 블러셔: under-eye blush, upper-cheek diffused blush, centered youthful flush, sculpted outer-cheek placement
- 립: blurred gradient lip, cloud-matte lip, glossy syrup lip, muted rose, coral-beige, mauve, burgundy accent


모델의 얼굴 구조를 메이크업으로 바꾸지 않는다. 눈 확대, 코 축소, 턱 축소 등 성형적 변화가 발생하면 실패다.


## 16. 가상 상품의 현실성 체크리스트


패션:
- 옷을 실제로 입고 벗을 수 있는가
- 단추·지퍼·후크가 실제 여밈 위치에 있는가
- 포켓이 구조적으로 사용 가능한가
- 절개선이 앞뒤에서 연결되는가
- 안감과 겉감의 두께가 맞는가
- 원단에 맞는 주름과 장력이 표현되는가
- 좌우 대칭이 필요한 부위는 대칭인가
- 비대칭 디자인은 의도된 비대칭인가
- 신발 밑창, 굽, 스트랩이 실제로 연결되는가
- 가방 손잡이·스트랩·금속 고리가 하중을 받을 수 있는 위치에 있는가


뷰티:
- 펌프·드로퍼·스포이드가 실제로 내용물을 배출할 수 있는가
- 캡과 병 입구가 연결되는가
- 콤팩트 힌지가 작동 가능한가
- 내용물의 점도와 용기 구조가 맞는가
- 화장품의 스와치와 본품 색이 일치하는가
- 유리·플라스틱·금속의 반사 특성이 자연스러운가


## 17. 금지·실패 방지


- 실존 브랜드 로고 자동 삽입
- 읽을 수 없는 가짜 브랜드명·패키지 문구
- 특정 상품의 트레이드 드레스 복제
- 미확정 날짜·가격·치수·사이즈·상품 코드·출시 상태·버전의 임의 생성
- 빈 메타데이터를 그럴듯한 숫자·문구·가짜 라벨로 채우는 행위
- 단추·지퍼·포켓 수가 뷰마다 달라지는 디자인
- 이유 없는 과잉 절개
- 패턴과 봉제선이 충돌하는 구조
- 모든 유행 요소를 한 제품에 몰아넣는 AI식 과설계
- 과도한 금속 장식·스트랩·버클 남발
- 의상 때문에 모델의 가슴·허리·골반·다리 비율이 달라지는 현상
- 저가 상품에 비현실적으로 복잡한 고급 봉제·하드웨어를 넣거나, 프리미엄 상품을 값싼 소재감으로 표현하는 가격대 불일치
- CASUAL을 무대복처럼, STAGE를 일상복처럼 만드는 목적 불일치


## 18. 모델별 적용


모델마다 동일한 유행을 반복 적용하지 않는다. 모델의 얼굴·체형·활동 이미지에 맞춰 스타일군의 비중을 달리한다.


기본 적용 방식:


- 모델 프로필과 Body Signature 확인
- 장면 목적 결정
- 계절 결정
- 스타일군 1개 선택
- 시장성 기본 아이템 1개 선택
- 모델 개성용 트렌드 요소 0~2개 추가
- 상품 설계 이미지 생성 및 구조 확정
- 카테고리별 필수 단품 시점 세트 생성
- PRODUCT MASTER LOCK
- 전신 착용샷 생성 및 FITTING MASTER 검수
- 필요 시 착용 디테일샷 생성
- 화보 파생
- 얼굴·신체·상품 정체성 최종 검수

## 20. 업데이트 원칙


- 계절 시작 전 또는 대형 패션 시즌 전후에 시장 관찰 항목을 갱신한다.
- 장기 베이직과 단기 트렌드를 분리한다.
- 오래 유지되는 항목은 CORE로 승격할 수 있다.
- 일시적 유행은 TREND로 유지하고 정본 스타일로 고정하지 않는다.
- 생성 성공 사례가 쌓이면 프롬프트 자체보다 ‘성공한 구조·속성 조합’을 데이터로 남긴다.
- 고정 프롬프트 블록의 수정이 필요하면 작업별 예외 문장을 추가하지 않고 상품 생성 프롬프트 템플릿의 새 버전을 만든다.
- 프로젝트에서 승인된 가상 상품은 이후 실제 상품 검색보다 우선하는 내부 레퍼런스로 재사용할 수 있다.


## 21. 최종 판단 기준


좋은 생성 결과는 ‘독특한 옷’이 아니라 다음 네 조건을 동시에 만족해야 한다.


1. 현재 한국 시장에서 실제 판매될 법하다.
2. 해당 MODEL의 정체성과 장면 목적에 맞는다.
3. 실제 제작·착용·사용이 가능한 구조다.
4. 다음 이미지에서도 같은 상품으로 재사용할 수 있을 만큼 디자인 정의가 명료하다.


이 네 조건 중 하나라도 크게 무너지면 상품 또는 의상 디자인을 다시 단순화하고 구조부터 재설계한다.
