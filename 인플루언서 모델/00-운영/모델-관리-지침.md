## 3. 모델 상태

### 선정 모델

- 사용자가 공식 모델로 승인한 인물만 등록한다.
- 선정 모델은 `MODEL-001`처럼 고유 ID를 부여하고 `MODEL-[ID]-[예명]` 형식의 독립 폴더를 사용한다.
- 대표 이미지와 승인된 앵커만 모델 정체성 유지용 레퍼런스로 사용한다.
- 외부 인물 이미지를 선정 모델의 동일 인물 유지용 앵커로 사용하지 않는다.
- 얼굴 골격과 신체 프로필은 승인 없이 변경하지 않는다.

### 미선정 후보

- 생성됐지만 아직 공식 모델로 승인되지 않은 인물을 보관한다.
- 미선정은 폐기나 실패를 뜻하지 않는다. 이후 재검토하여 선정할 수 있다.
- 미선정 후보 이미지는 공식 모델의 앵커로 사용하지 않는다.
- 후보가 선정되면 해당 이미지를 새 모델 폴더로 이동하고 고유 MODEL ID를 부여한다.

## 3.1 신규 모델 후보 생성 프롬프트 정본

신규 모델 후보를 생성할 때에는 `00-운영/신규 모델 생성 기본 프롬프트-v01.md`를 반드시 적용한다.

- 모든 신규 후보 프롬프트에는 `아이돌처럼 아름다운`이라는 고정 미적 기준을 포함한다.
- 이 문구는 특정 실존 아이돌·연예인·모델을 닮게 하라는 뜻이 아니라, 현대 한국 아이돌 화보 수준의 카메라 친화성·상업적 세련미·높은 미적 완성도를 의미한다.
- 후보별 얼굴형, 눈, 코, 입, 윤곽, 피부 특징은 독립적으로 설계한다.
- 인상은 얼굴 골격과 분리하여 `주 인상 1개 + 보조 인상 0~2개 + 인상 강도 1~3`으로 관리한다.
- 인상은 표정·시선·눈썹·입꼬리·헤어·메이크업·조명에 우선 반영하고, 얼굴 구조에는 필요할 때만 약하게 반영한다.
- `도도함 = 긴 눈 + 높은 코 + V라인`, `사랑스러움 = 둥근 얼굴 + 큰 눈`처럼 인상과 해부학을 고정 공식으로 연결하지 않는다.
- FACE-CORE는 외모 어휘와 미감 범위를 넓히는 분석 라이브러리이며, 개별 실존 얼굴을 복제하는 정본으로 사용하지 않는다.
- 같은 배치의 후보들은 얼굴형·눈·코·입·윤곽 중 최소 세 주요 축에서 분명한 차이를 확보한다.


## 4. 선정 모델 폴더 구성

각 선정 모델은 다음 구조를 기본으로 한다.

```text
MODEL-001-예린/
├─ 00-프로필/
├─ 01-앵커/
├─ 02-뷰티/
├─ 03-패션/
├─ 04-라이프스타일/
├─ 05-영상/
└─ 99-보관/
```

- `00-프로필`: 이름, 나이, 신체 프로필, 고정 특징, 변경 가능 요소, 금지 요소, Morphology Card, Expression Signature, Body Signature
- `01-앵커`: 전신, 9:16 흉상, 4방향 체형 보드, 표정 보드와 `ANCHOR-MANIFEST` 등 승인된 정체성·표현 기준 자료
- `02-뷰티`: 메이크업, 헤어, 뷰티 광고 파생 결과
- `03-패션`: 룩북, 화보, 의상 중심 파생 결과
- `04-라이프스타일`: SNS, 일상, 제품 사용 장면
- `05-영상`: 영상 앵커, 프레임, 움직임 테스트
- `99-보관`: 교체된 구버전과 실패 이력

## 5. 필수 앵커 세트

공식 선정 모델은 다음 세 이미지를 기본 앵커 세트로 갖는다.

1. `FULL`: 머리부터 발끝까지 보이는 세로형 전신 앵커
2. `HALF`: 얼굴과 상체 정체성을 확인하는 정확한 9:16 흉상 앵커
3. `BODY-4VIEW`: 정면, 45도 3/4, 완전 측면, 후면을 한 장에 배치한 체형 앵커

전신 앵커는 전체 인상과 대표 스타일을 확인하는 기준이다. 흉상 앵커는 얼굴 골격, 이목구비, 피부, 헤어와 표정을 확인하는 기준이다. 4방향 체형 앵커는 신체 치수, 골격, 체형과 방향별 실루엣을 확인하는 기준이다. 서로의 역할을 혼용하지 않는다.

### 5.1 앵커 역할(Role)과 상태(State)

앵커의 용도와 생명주기를 하나의 등급으로 섞지 않는다. 각 파일은 `Role`과 `State`를 별도로 가진다.

#### Role

- `MASTER`: 해당 영역의 최상위 공식 정체성 기준. 기본 MASTER는 FACE / FULL / BODY로 나눈다.
- `SUPPORT`: MASTER를 보조하는 승인된 다른 방향·구도·보조 기준 이미지. MASTER를 대체하지 않는다.
- `EXPRESSION`: 승인된 표정 범위를 정의하는 자료. 얼굴 골격의 MASTER가 아니다.
- `DERIVED`: 뷰티, 패션, 광고, 라이프스타일 등 MASTER에서 파생된 결과.
- `TEST`: 검증 중인 결과. 승인 전에는 정체성 기준으로 사용하지 않는다.

#### State

- `ACTIVE`: 현재 후속 생성에 사용할 수 있는 공식 파일.
- `DEPRECATED`: 교체, 실패, 구버전 등의 이유로 더 이상 정체성 기준으로 사용하지 않는 파일. `99-보관`으로 이동한다.

#### 기본 MASTER 대응

- FACE MASTER: `HALF`
- FULL MASTER: `FULL`
- BODY MASTER: `BODY-4VIEW`

모델별 현재 파일과 버전은 `MODEL-[ID]-ANCHOR-MANIFEST-v01.md`에서 관리한다.

표정 보드는 `EXPRESSION / ACTIVE`로 관리할 수 있지만 FACE MASTER를 대체하지 않는다. 표정 생성에서는 `FACE MASTER + 필요한 EXPRESSION 보드`를 함께 사용한다.

### 5.2 버전 감사 규칙

- 수정본은 기존 파일을 덮어쓰지 않고 버전을 올린다.
- 교체된 구버전은 `99-보관`으로 이동하고 `DEPRECATED`로 기록한다.
- 현재 활성 파일이 v02 이상인데 과거 버전이 Drive에 없을 경우, 과거 버전을 임의로 재생성하거나 현재 파일을 낮은 버전 번호로 재명명하지 않는다.
- 누락된 과거 버전은 `ANCHOR-MANIFEST`에 `미확인`으로 감사 기록을 남긴다.
- 추후 누락된 구버전이 발견되면 `99-보관`으로 편입하고 `DEPRECATED`로 기록한다.

### 5.3 Expression Signature

선정 모델은 승인된 표정 보드가 확보된 뒤 `MODEL-[ID]-EXPRESSION-SIGNATURE-v01.md`를 `00-프로필`에 작성한다.

- Expression Signature는 얼굴 골격이 아니라 **표정 행동의 정체성**을 관리한다.
- 같은 `미소`, `긴장`, `슬픔`이라도 모델마다 눈, 시선, 입, 광대, 눈썹과 고개 움직임의 우선순위가 다르게 보이도록 정의한다.
- 기본 생성 우선순위는 `FACE MASTER → Expression Signature → 장면에 필요한 EXPRESSION 보드`다.
- EXPRESSION 보드는 승인된 표정 범위의 예시이며 FACE MASTER를 대체하지 않는다.
- Signature는 특정 표정을 매번 복제하는 규칙이 아니다. 장면의 감정 강도와 상황에 따라 표정 구성요소를 변주한다.
- 동일 모델의 여러 이미지에서 기본 반미소, 동일 시선, 동일 고개 각도가 자동 반복되지 않게 한다.
- 표정 변화로 눈 크기, 입 폭, 턱과 얼굴형 자체가 바뀌지 않도록 Morphology Card와 함께 검수한다.
- 새로운 표정 보드가 공식 승인되어 기존 행동 범위를 의미 있게 넓히면 Signature 버전을 올려 갱신한다.

현재 3개 모델의 핵심 Signature는 다음과 같다.

- MODEL-001 예린: 절제되고 정돈된 표정에서 시작해 감정이 점진적으로 확장되는 타입
- MODEL-002 세아: 눈과 시선의 미세 변화가 감정을 주도하는 타입
- MODEL-003 하진: 입·볼·눈이 함께 움직이며 감정 진폭이 큰 타입


### 5.4 생성 출처 독립 원칙과 정규 데이터 승인

- 이미지 생성 도구나 서비스(ChatGPT Image, Higgsfield, ComfyUI, 기타 외부 생성기)는 **품질 등급이나 데이터 등급을 결정하지 않는다.** 생성 출처는 필요할 경우 작업 이력·메타데이터로만 남긴다.
- 선정 모델의 결과물은 어디에서 생성했는지와 무관하게 동일한 정체성 검수 기준을 적용한다. 핵심 판정축은 `FACE MASTER + Morphology Card`에 대한 얼굴 일치도와 `공식 신체 수치 + BODY MASTER + Body Signature`에 대한 신체 일치도다.
- 얼굴과 신체가 모두 승인 범위 안에 있고 해부학·촬영 오류가 없다면 해당 결과물은 용도에 맞는 폴더에서 `ACTIVE` 정규 데이터로 사용할 수 있다. 패션·뷰티·라이프스타일 결과라면 `DERIVED / ACTIVE`, 앵커 보조 기준으로 별도 승인되면 `SUPPORT / ACTIVE`로 관리한다.
- 얼굴 또는 신체 중 하나라도 정체성 기준에서 의미 있게 이탈하면 미감·의상·구도가 우수해도 정규 데이터로 승격하지 않는다. 검증 중이면 `TEST`, 실패가 확정되면 `DEPRECATED` 또는 점검/보관 자료로 분류한다.
- 의상이 신체 일부를 가리는 경우 단순 가림과 실제 체형 소실을 구분한다. 루즈핏이어도 어깨, 흉곽, 최고 돌출점에서의 드레이프, 허리·골반·다리 비율 등 보이는 범위에서 Body Signature와 모순되지 않아야 한다.
- 생성 서비스명은 정규 파일명의 핵심 분류자가 아니다. 특별한 디버깅·출처 감사 목적이 없다면 파일명에는 모델 ID, 용도, 장면·룩, 구도와 버전을 우선 기록한다.

## 6. 체형 정보 기록 규칙

모델별 신체 프로필에는 다음 항목을 기록한다.

- 키와 체중
- 바스트, 허리, 힙 치수
- 언더바스트와 브라 사이즈
- 어깨 너비와 흉곽 인상
- 상체와 하체의 길이 비율
- 허리선의 위치와 굴곡 정도
- 골반 너비와 둔부의 입체감
- 팔다리 길이와 굵기
- 근육량과 체지방의 시각적 인상
- 정면, 3/4, 측면, 후면에서 유지해야 할 고유 실루엣

수치는 프로필 장식이 아니라 실제 생성 결과를 결정하는 기준값이다. 다만 브라 컵은 독립적인 절대 크기가 아니라 언더바스트와 윗가슴 둘레의 차이를 나타내므로, 컵 문자만으로 체형을 판단하지 않는다. 언더바스트, 전체 바스트, 흉곽 너비와 측면 돌출을 함께 검수한다.

공식 치수와 승인된 체형 앵커가 함께 있으면 둘을 동시에 정본으로 사용한다. 치수와 이미지가 충돌할 경우 이미지를 임의로 평균화하지 않고, 신체 정보와 앵커 제작 과정을 재검토한다.


### 6.1 Body Signature

선정 모델은 공식 신체 수치와 BODY MASTER가 확정된 뒤 `MODEL-[ID]-BODY-SIGNATURE-v01.md`를 `00-프로필`에 작성한다.

- 공식 신체 수치는 키, 체중, 둘레 등 **크기·비율의 정본**이다.
- BODY MASTER는 정면 너비, 측면 깊이, 후면과 3/4 실루엣 등 **형태의 정본**이다.
- Body Signature는 골격, 연부조직, 의복 압박, 중력, 접촉, 자세와 움직임에 따른 **물리적 반응의 정본**이다.
- 기본 신체 생성 우선순위는 `공식 신체 수치 → BODY MASTER → Body Signature → 장면별 의상·포즈`다.
- 의상과 포즈가 만든 일시적인 외곽선 변화를 모델의 골격이나 공식 체적 변화로 역전파하지 않는다.
- 밀착복은 모든 부위를 같은 압력으로 진공 포장하지 않는다. 바스트, 허리, 골반, 둔부, 허벅지는 소재와 접촉 조건에 따라 서로 다른 장력과 변형을 보인다.
- 루즈핏 의상은 신체 최고 돌출점에서 자연스럽게 떨어지며, 숨겨진 허리나 골반을 임의로 추정해 과장하지 않는다.
- 앉기, 굽히기, 체중 이동에서는 접촉면과 압축이 달라질 수 있지만 공식 골격과 기본 체적은 유지한다.
- 새 BODY MASTER가 공식 승인되어 실루엣 정의가 바뀌면 Body Signature도 함께 재검토하고 필요시 버전을 올린다.

현재 핵심 Body Signature:

- MODEL-001 예린: 장신·긴 팔다리·좁음~중간 몸통·슬림한 하체
- MODEL-002 세아: 섬세한 골격·좁은 상체·낮은 전체 체적
- MODEL-003 하진: 175cm 장신·긴 다리·슬림한 몸통과 팔다리·중간 골반·매우 큰 자연형 바스트

하진은 추가로 다음 규칙을 고정한다.

- 키는 175cm로 관리하며, 이미지 생성에서는 항상 먼저 장신·늘씬한 인상으로 읽혀야 한다.
- 큰 특징은 바스트이며, 이를 이유로 몸통·팔·골반·허벅지를 함께 풍만하게 만들지 않는다.
- 하진을 커비형, 플러스 사이즈형, 소프트 헤비형 또는 살집 있는 체형으로 해석하지 않는다.
- 긴 다리, 긴 몸통, 슬림한 팔, 슬림하고 탄탄한 허벅지·종아리, 중간 폭 골반을 유지한다.
- 큰 바스트는 자연스러운 연부조직으로 취급하며 단단한 반구형을 기본값으로 사용하지 않는다.
- 압박 시 전체 체적이 사라지지 않는다. 전방 돌출이 줄어드는 만큼 아래·바깥·주변 면적으로 자연스럽게 재분포될 수 있다.
- 지지력이 높은 의상은 상승·고정 효과를 줄 수 있지만 이를 기본 신체 형태로 역전파하지 않는다.
- 기존 `MODEL-003-ANCHOR-BODY-4VIEW-v02.png`는 이 재정의와 충돌하므로 DEPRECATED다. 현재 `MODEL-003-ANCHOR-BODY-4VIEW-v03.png`가 ACTIVE BODY MASTER이며 `공식 신체 수치 → BODY MASTER → MODEL-003-BODY-SIGNATURE-v02.md → 장면별 의상·포즈` 순서를 사용한다.

## 7. 포즈 레퍼런스 사용 규칙

외부 POSE 자료는 모델의 얼굴이나 체형 정체성을 결정하지 않는다. 승인된 모델에 포즈를 적용할 때는 다음 우선순위를 사용한다.

`공식 신체 수치 → BODY MASTER → Body Signature → POSE 레퍼런스 → 장면별 의상·촬영`

- POSE는 체형을 바꾸는 수단이 아니라 승인된 체형을 읽기 쉽게 보여주는 가변 연출이다.
- 외부 포즈 이미지의 얼굴, 체형, 피부색, 헤어와 의상은 복제하지 않고 체중 분배, 관절 방향, 손동작, 접촉점과 움직임만 분석한다.
- 팔을 몸통에 과도하게 밀착해 실제 팔 굵기나 허리 폭을 왜곡하지 않는다. 필요한 경우 팔과 몸통 사이에 작은 공간을 만든다.
- 손은 특별한 연출 의도가 없으면 힘을 빼고 손가락 간격과 손목 굴곡을 자연스럽게 유지한다.
- 워킹 포즈는 실제 보행의 한 순간처럼 구성하고, 양발의 지지 관계와 무릎·발목 방향, 의상의 후행 움직임을 함께 검수한다.
- 앉은 포즈는 골반이 실제 좌면에 닿아 있어야 하며, 척추를 길게 유지하고 가까운 무릎이나 발이 원근 때문에 과도하게 커지지 않게 카메라 거리를 조정한다.
- 벽 기대기에서는 접촉면과 하중 방향이 일치해야 하며, 몸이 벽을 통과하거나 어깨·골반이 비현실적으로 꺾이지 않게 한다.
- 얼굴 주변 손동작은 눈, 코, 입과 고유 식별점을 불필요하게 가리지 않는다.
- 제품 제시 포즈에서는 제품의 로고 면, 형태, 색과 사용 방식이 모델의 손동작보다 우선한다. 손가락이 핵심 라벨을 가리지 않게 한다.
- 뒤돌아보기는 목, 어깨, 흉추와 골반의 회전 한계를 분리해서 표현하고 한 관절에 과도한 회전을 몰아주지 않는다.
- 표정이 포함되는 포즈에서는 Expression Signature를 함께 적용해 신체 제스처와 얼굴 감정이 충돌하지 않게 한다.
- 포즈 레퍼런스 목록과 개별 출처는 `beauty-fashion-model-reference-pack-v1.md`의 `POSE-01~10`을 정본으로 사용한다.


## 8. BEAUTY 레퍼런스 사용 규칙

외부 BEAUTY 자료는 모델의 얼굴 정체성을 결정하지 않는다. 승인된 모델에 메이크업·헤어·네일을 적용할 때는 다음 우선순위를 사용한다.

`FACE MASTER → Morphology Card → BEAUTY 레퍼런스 → 장면별 조명·촬영`

표정이 있는 결과에는 `Expression Signature`를 병행한다.

- BEAUTY는 피부 피니시, 색조 배치, 립 피니시, 헤어 질감·앞머리·업스타일과 네일 표현을 위한 가변 그루밍 자료다.
- 외부 BEAUTY 이미지의 인물 정체성, 얼굴 골격, 피부색, 체형과 전체 스타일링을 복제하지 않는다.
- 피부는 광고 사진 수준으로 정돈하되 모공, 솜털, 미세 굴곡과 자연스러운 좌우 비대칭을 완전히 제거하지 않는다.
- 컨투어와 하이라이트는 실제 얼굴 골격 위에 얹히는 광학·색조 효과다. 광대, 코, 턱 자체의 높이·폭·길이를 바꾸지 않는다.
- 아이 메이크업은 승인된 눈 크기, 눈 간격, 눈꺼풀과 눈꼬리 구조를 유지한다. 라이너·섀도·속눈썹 때문에 눈이 다른 형태로 변하지 않게 한다.
- 애굣살은 작고 자연스러운 하안검 아래 볼륨으로 제한하며 흰 선, 과도한 부종, 눈 확대 효과를 피한다.
- 블러셔는 피부 위 색의 위치와 확산 범위만 변경하며 광대뼈 구조를 바꾸지 않는다.
- 립은 색, 질감, 광택과 경계만 변경한다. 입술 폭, 상하 비율, 입술산과 입꼬리 구조를 유지한다.
- 글라스 헤어는 모발 표면의 건강한 윤기와 큐티클 정돈을 의미한다. 단일 플라스틱 반사면처럼 만들지 않는다.
- 앞머리와 업스타일은 작업 목적에 따라 변경할 수 있지만 얼굴 정체성 검수 작업에서는 눈썹, 광대, 턱선과 귀 주변을 동시에 가리지 않는다.
- 네일은 색과 디자인보다 손가락·손톱 해부학을 먼저 검수한다. 손톱 수, 큐티클 위치, 손가락 연결 오류를 허용하지 않는다.
- 모델 정체성 앵커에는 강한 BEAUTY 트렌드를 기본 적용하지 않는다. 앵커 확정 후 뷰티·패션·광고 파생 이미지에서 활용한다.
- 공통 BEAUTY 레퍼런스 목록과 개별 출처는 `beauty-fashion-model-reference-pack-v1.md`의 `BEAUTY-01~10`을 정본으로 사용한다.


### 8.1 패션·뷰티 시장성·상품 생성 지침 적용 규칙

패션·뷰티·라이프스타일 파생 이미지와 가상 상품 이미지를 설계할 때는 `00-운영/패션·뷰티-시장성-상품생성-지침-v01.md`을 시장성·제품 구조용 보조 지침으로 사용한다.

적용 우선순위는 다음과 같다.

`사용자 현재 지시 → MODEL 정체성 정본(FACE/FULL/BODY MASTER + Morphology/Signature/Manifest) → 이 모델 관리 지침 → 패션·뷰티 시장성·상품 생성 지침 → 현재 시장·플랫폼 참고자료 → 일반 생성 관행`

- 이 지침은 MODEL의 얼굴 골격, 체형 수치, Body Signature 또는 앵커 상태를 변경하지 않는다.
- CASUAL / FASHION / STAGE / LIFESTYLE / BEAUTY / PRODUCT 작업에서 의상·액세서리·메이크업·가상 상품의 종류와 구조를 정할 때 사용한다.
- 모델 착장 생성 전 디자인 확정이 필요하면 `제품 단독 이미지 → 정면/3·4/후면 → 소재·봉제 디테일 → 모델 피팅` 순으로 검증할 수 있다.
- 의상은 아이템명만 지정하지 않고 실루엣, 길이·비율, 소재, 색, 절개·봉제, 여밈, 포켓, 하드웨어·트림, 안감·마감 순으로 구조화한다.
- 가격 포지션은 장식의 양이 아니라 소재 품질, 패턴·절개 정교함, 봉제와 하드웨어 완성도로 표현한다.
- 하나의 제품에 여러 마이크로트렌드를 과도하게 혼합하지 않는다. 시장에서 익숙한 기본 구조에 트렌드 요소 1~2개를 추가하는 방식을 우선한다.
- 외부 쇼핑몰·브랜드·상품은 시장 조사와 디자인 문법 분석용이며, 실존 제품의 로고·트레이드 드레스·고유 패턴을 그대로 복제하지 않는다.
- 실제 상품 또는 브랜드가 사용자에게 지정된 경우에는 확인된 제품 정보가 우선하며, 시장성 지침은 배경·스타일링·촬영 맥락의 보조 규칙으로만 사용한다.
- 트렌드 내용은 시점 의존 정보다. 최신성이 중요한 작업에서는 현재 플랫폼의 랭킹·신상품·기획전 등 확인 가능한 자료를 다시 확인한다.
- ‘인기’, ‘베스트셀러’, ‘판매량’은 실제 근거가 있을 때만 사용한다. 노출·랭킹·검색량·리뷰 수 등 다른 지표는 판매량과 구분한다.
- 생성된 가상 상품이 실제 한국 시장 제품처럼 보이는지는 구조 현실성, 봉제 가능성, 소재 반응, 가격 포지션 일관성, 재사용 가능한 디자인 명료성으로 검수한다.


## 9. MOTION 레퍼런스 사용 규칙

외부 MOTION 자료는 모델의 정체성이나 스타일을 결정하지 않는다. 승인된 모델의 영상·연속 프레임 작업에서 **시간축의 움직임과 연속성**을 정의하는 용도로만 사용한다.

기본 적용 우선순위:

`FACE MASTER + Morphology Card → 공식 신체 수치 + BODY MASTER + Body Signature → Expression Signature → 현재 헤어·메이크업·의상 → MOTION 레퍼런스 → 장면별 카메라·조명`

- MOTION은 고개 회전, 걷기, 포즈 전환, 제품 제시, 표정 전환과 헤어 움직임의 경로·속도·관성을 정의한다.
- 외부 영상의 인물 얼굴, 체형, 피부색, 헤어 디자인, 의상과 제품 디자인은 복제하지 않는다.
- 한 동작은 시작·전환·핵심·감속·종료 프레임으로 나눠 검수한다. 시작과 끝만 맞고 중간 프레임이 무너지는 결과는 실패다.
- 프레임 사이에서 얼굴 골격, 눈 간격, 코·입·턱의 구조가 변하지 않아야 한다. 고개 회전으로 생기는 투영 변화와 정체성 변형을 구분한다.
- 신장, 몸통 길이, 어깨·허리·골반 위치와 팔다리 길이는 움직임 중에도 동일 인물의 범위에서 유지한다.
- 워킹에서는 발바닥 접촉, 무릎·골반 하중 이동, 반대팔 스윙이 실제 보행 순서로 이어져야 한다. 발 미끄러짐과 순간적 팔다리 길이 변화를 금지한다.
- 포즈 전환에서는 팔·손·골반·시선이 실제 관절 경로로 이동하며 한 프레임에서 순간이동하지 않는다.
- 제품을 들거나 제시할 때 제품 크기, 색, 로고 면, 회전 방향과 손가락 그립이 프레임마다 유지되어야 한다.
- 표정 변화는 해당 모델의 Expression Signature 안에서 진행한다. 미소가 커져도 얼굴형이나 눈 크기 자체가 바뀌지 않는다.
- 머리카락과 느슨한 의상·액세서리는 움직임에 후행하는 관성을 표현한다. 프레임마다 길이·디자인·색이 달라지지 않는다.
- 영상에서 좌우 눈의 캐치라이트, 피부 톤, 노출, 색온도와 배경 밝기는 장면 의도가 없는 한 안정적으로 유지한다.
- 카메라가 움직일 때에도 모델과 배경 사이 원근 관계가 연속적이어야 하며 프레임마다 렌즈 화각이 임의로 바뀌는 효과를 피한다.
- 영상용 생성 결과는 단일 프레임의 미감보다 **프레임 간 동일 인물성**을 우선해서 검수한다.
- 공통 MOTION 레퍼런스 목록과 개별 출처는 `beauty-fashion-model-reference-pack-v1.md`의 `MOTION-01~06`을 정본으로 사용한다.

### 영상 안정성 검수 항목

1. 얼굴 골격과 고유 특징이 전 프레임에서 같은가
2. 신장·체형·팔다리 비율이 움직임 중 변하지 않는가
3. 헤어 길이·색·가르마와 의상 디자인이 유지되는가
4. 손·발·관절이 시간축에서 자연스럽게 이어지는가
5. 제품의 모양·로고·색·그립이 유지되는가
6. 표정 전환이 Expression Signature와 일치하는가
7. 머리카락·의상·액세서리의 관성과 후행 움직임이 자연스러운가
8. 배경 오브젝트의 위치와 원근이 프레임 사이에서 튀지 않는가
9. 노출·화이트 밸런스·피부 톤·캐치라이트가 이유 없이 출렁이지 않는가
10. 시작·중간·종료 프레임 모두 동일 모델로 즉시 인식되는가

## 10. 4방향 체형 앵커 제작 규칙

### 기본 구성

- 가로형 한 장에 동일 모델을 네 번 배치한다.
- 왼쪽부터 정면, 45도 3/4, 완전 측면, 후면 순서를 고정한다.
- 네 인물은 동일한 키 비율, 확대율, 바닥선, 카메라 높이와 조명을 사용한다.
- 모든 방향에서 머리끝부터 발끝까지 잘리지 않아야 한다.
- 포즈는 척추와 골반이 중립인 피팅 모델 자세를 사용한다.
- 양발은 교차하지 않고 체중을 고르게 분산한다.
- 양팔은 허리와 옆선을 가리지 않도록 몸통에서 조금 떨어뜨린다.

### 표준 체형 확인복

- 무광 검은색의 불투명 민소매 미드사이 유니타드를 기본으로 사용한다.
- 목선은 단정한 크루넥, 어깨는 충분한 너비의 민소매로 구성한다.
- 하의 길이는 허벅지 중간 정도로 고정한다.
- 레이스, 메시, 시스루, 컷아웃, 장식 끈, 로고와 체형 보정 패드를 사용하지 않는다.
- 소재는 자연스러운 신축성과 두께를 가지며 신체를 압축하거나 부풀리지 않는다.

### 촬영 조건

- 따뜻한 흰색 또는 밝은 중성 회색 심리스 배경을 사용한다.
- 부드럽고 균일한 카탈로그 조명을 사용한다.
- 카메라는 눈높이의 정면 위치에 고정한다.
- 70~85mm 상당의 자연스러운 원근감을 사용한다.
- 낮은 시점, 광각 왜곡, S자 포즈와 과도한 골반 회전을 금지한다.
- 측면과 후면에서는 머리카락이 어깨, 등과 의상 구조를 가리지 않게 정리한다.

## 11. 체형 충실도 원칙

- 모델의 키, 골격, 어깨, 흉곽, 바스트, 허리, 골반, 둔부와 팔다리 비율을 평균 체형으로 수렴시키지 않는다.
- 큰 체형 특징은 임의로 줄이지 않고 작은 특징은 임의로 키우지 않는다.
- 의상 압박, 푸시업, 패딩, 자세와 카메라 각도로 공식 치수를 왜곡하지 않는다.
- 정면에서 확인되는 너비와 측면에서 확인되는 깊이가 공식 치수 및 승인 앵커와 함께 성립해야 한다.
- 네 방향에서 얼굴, 신장, 몸통 길이, 가슴 높이, 허리 위치와 골반 위치가 동일해야 한다.
- 패션이나 조명이 바뀌어도 신체 정체성은 유지한다.

## 12. 결과 검수

다음 항목을 모두 확인한 결과만 공식 체형 앵커로 사용한다.

1. 네 방향이 동일 인물인가
2. 얼굴과 헤어가 승인된 얼굴 앵커와 일치하는가
3. 키와 팔다리 길이의 인상이 설정과 맞는가
4. 어깨와 흉곽의 너비가 일관적인가
5. 바스트, 허리, 골반의 관계가 공식 수치와 맞는가
6. 측면에서 상체와 둔부의 깊이가 과장되거나 축소되지 않았는가
7. 후면에서 어깨, 허리, 골반과 다리 축이 자연스러운가
8. 표준 확인복이 체형을 압축하거나 확대하지 않는가
9. 손, 발, 관절과 바닥 접촉에 오류가 없는가
10. 광각, 낮은 시점 또는 포즈로 비율이 왜곡되지 않았는가

## 14.1 방향별 기준 포즈와 시선 정렬 규칙

정면·측면·후면 등 체형 확인용 기준 이미지와 BODY 계열 앵커에서는 **인물의 머리와 시선이 항상 인물 자신의 해부학적 정면 방향을 따른다.** 카메라를 보기 위해 고개나 눈동자를 돌리지 않는다.

- 정면 뷰: 몸통과 얼굴이 모두 인물의 정면을 향하고, 카메라가 정면에 있으므로 자연스럽게 카메라 방향을 본다.
- 측면 뷰: 몸을 카메라에 대해 정확히 90도로 돌린 상태에서 머리·코끝·턱·눈동자도 몸의 전방 축과 같은 방향을 유지한다. **카메라 쪽으로 얼굴을 돌리거나 눈길을 보내지 않는다.** 3/4 얼굴, over-the-shoulder look, camera-facing gaze를 사용하지 않는다.
- 후면 뷰: 몸과 머리가 모두 뒤를 향한다. 고개를 돌려 카메라를 보거나 어깨 너머로 뒤돌아보지 않는다.
- 기준 포즈에서 `본인 기준 정면`은 카메라 방향이 아니라 **흉곽·골반이 정의하는 신체의 전방 축**을 뜻한다.
- 방향별 체형 비교가 목적일 때는 머리 회전과 시선 회전을 별도의 연출 요소로 사용하지 않는다.

이 규칙은 BODY MASTER, BODY-4VIEW, 기본 피팅 전신, 방향별 체형 검수 이미지에 우선 적용한다. 화보·라이프스타일처럼 연출이 목적인 파생 이미지에서는 사용자의 명시 지시가 이 규칙보다 우선할 수 있다.

## 17. 전신 앵커 3분리 및 Seedance BASE 시트 표준

기준일: 2026-09-10
이 절은 기존의 `BODY-4VIEW` 단일 보드 규칙과 Seedance 초도 복장 해석보다 우선한다.

### 17.1 BODY MASTER는 독립 전신 3장

신규 모델과 교체 작업의 BODY MASTER는 아래 세 개의 독립 전신 앵커로 구성한다.

1. `MODEL-[ID]-ANCHOR-BODY-FRONT-v01.png`
2. `MODEL-[ID]-ANCHOR-BODY-SIDE-v01.png`
3. `MODEL-[ID]-ANCHOR-BODY-BACK-v01.png`

- 모두 머리부터 발끝까지 보이는 전신 세로 이미지다.
- 기본 프로필에는 위 전신 세 장과 별도로, 얼굴 정체성·헤어·어깨선·루네바 이너 웨어 상의를 확인하는 **정확한 9:16 비율의 정면 흉상** 세로 앵커를 포함한다. 9:16이 아닌 흉상은 ACTIVE로 승인하지 않고, 원본을 보관한 뒤 9:16 교정본으로 대체한다.
- 기본 프로필의 전신·흉상 앵커는 모두 동일한 루네바 이너 웨어를 착용한다.
- 측면 전신은 얼굴·몸통·시선이 모두 모델 자신의 왼쪽 전방 축을 향해야 하며, 카메라 쪽으로 고개나 시선을 돌리지 않는다.
- 정면·측면·후면은 같은 기본 복장, 같은 신발 또는 맨발 상태, 같은 배경·조명·카메라 거리·렌즈·바닥선으로 제작한다.
- 방향만 달라지고 신장 인상, 골격, 어깨·허리·골반·팔다리의 길이와 체적은 바뀌지 않는다.
- 이 3장을 합쳐서 `BODY MASTER`로 기록한다. `FULL`은 대표 전신 인상용 SUPPORT로 보존할 수 있으나 방향별 BODY MASTER를 대체하지 않는다.
- 기존 `BODY-4VIEW`는 교체 세트가 승인되기 전까지만 ACTIVE다. 새 3분리 세트 승인 후에는 `99-보관`으로 이동하고 DEPRECATED로 기록한다.
- 기존 모델의 교체는 모델별 승인 절차로 순차 진행하며, 이 변경만으로 기존 앵커 파일을 자동 폐기하지 않는다.

### 17.2 기본 복장 정본

- 기본 복장은 각 모델의 승인된 BODY-FRONT / BODY-SIDE / BODY-BACK에서 확인되는 상의·하의·신발 또는 맨발 상태·색·파이핑/트림·소재·핏·승인 마크로 정의한다.
- 루네바 이너 웨어의 마크 위치와 마감은 `03-브랜드/LUNEVA-MANAGEMENT/01-상품/LUNEVA-INNER-WEAR/00-PRODUCT-DEFINITION/LUNEVA-REGISTRATION-FIT-v02-PRODUCT-DESIGN-v01.png`을 따른다. 루네바 이너 웨어는 상의와 하의를 함께 소유하는 하나의 세트 상품이다. 상의 정면 원형 심볼, 상의 후면 `LUNEVA` / `MANAGEMENT` 2줄 워드마크, 하의 앞 허리 밴드 2줄 워드마크, 하의 뒤 허리 밴드 원형 심볼을 중앙에 유지한다. 상의의 목둘레·암홀·하단은 끊김 없는 검은 바인딩으로, 하의의 앞·뒤 허리 밴드와 양쪽 밑단은 끊김 없는 검은 원단 마감으로 재현한다. 마크만 맞고 이 마감이 빠진 복장은 승인하지 않는다.
- 앵커와 BASE 영상 시트에서는 이 복장을 패션 가변 슬롯처럼 임의 변형하지 않는다.
- 정확한 공식 의류 마크 자료가 존재하는 경우에만 마크를 재현한다. 자료가 없을 때는 문자처럼 보이는 임의 로고를 만들어 넣지 않는다.
- 루네바 기본 이너 웨어 착용 앵커와 표정 보드는 `03-브랜드/LUNEVA-MANAGEMENT/00-로고`의 승인 심볼이 보여야 할 의상 위치에 정상적으로 그려졌는지 육안 점검한다. 심볼이 없거나 형태가 깨진 파일은 승인 원본을 기준으로 교정본을 만들고, 교체 전 파일은 `99-보관`으로 이동한다.

### 17.3 Seedance 첫 시트는 BASE

- 모델당 최초 Seedance 2.5 3패널 시트는 `BASE` 파일명으로 만들며 승인 기본 복장을 유지한다.
- `CASUAL`, `STAGE`, `FASHION`, `PRODUCT`는 BASE 승인 뒤에 만드는 파생 시트다.
- 시트 캔버스에 텍스트·통계·브랜딩 로고·워터마크를 넣는 일은 계속 금지한다. 기본 복장 자체에 이미 승인된 마크가 있는 경우만 예외적으로 의상 일부로 유지한다.
- 상세 형식은 `seedance-2.5-3panel-reference-sheet-guide-v3.md`를 정본으로 사용한다.
