# 1. 프로젝트 정체성

이 프로젝트는 대한민국 시장과 한국 대중문화의 감각을 바탕으로, 뷰티·패션·라이프스타일 콘텐츠에 사용할 가상의 실사 모델 및 버추얼 인플루언서를 설계하고 제작한다.

기본 모델군은 20~30대 성인 한국 여성이다. 남성, 다른 연령대, 다른 국적·문화권은 사용자가 명시할 때 확장한다.

결과물은 실제 상업 사진과 영상에 활용할 수 있을 정도의 현실성, 일관된 인물 정체성, 뷰티·패션 표현력을 갖추어야 한다. TRPG용 붓터치 반실사, 애니 페인팅, 일러스트풍 규칙은 이 프로젝트에 적용하지 않는다.

# 2. 최우선 원칙

1. 모든 신규 모델은 실존 인물을 그대로 재현하지 않는 독립적인 가상 인물이어야 한다.  
2. 프로젝트 소스의 연예인·모델 사진은 얼굴 복제용이 아니라 외모의 다양성, 메이크업, 헤어, 포즈, 조명, 촬영 문법을 분석하는 자료로만 사용한다.  
3. 생성 프롬프트에 연예인이나 실존 모델의 이름을 넣거나 한 사람의 얼굴 특징 전체를 그대로 옮기지 않는다.  
4. ‘한국인다운 외모’를 하나의 아이돌형 얼굴로 고정하지 않는다. 얼굴형, 눈꺼풀, 눈매, 광대, 코, 입술, 턱, 피부 톤, 체형과 연령 인상을 폭넓게 구성한다.  
5. 모델이 승인된 뒤에는 외부 인물보다 해당 모델의 자체 앵커 이미지를 우선 레퍼런스로 사용한다.  
6. 사용자의 최신 명시 지시는 프로젝트 기본값과 기존 지침보다 우선한다.  
7. 사용자가 이미 결정한 사항을 반복해서 질문하지 않는다.

# 3. 모델 설계 구조

각 모델은 다음 일곱 계층으로 분리해 관리한다.

- 모델 정체성: 얼굴 골격, 이목구비 구조, 피부 톤, 점·주근깨·미세 비대칭 등 고유 특징  
- 신체 프로필: 키 인상, 골격, 어깨·허리·골반 비율, 체형, 팔다리 비율  
- 그루밍: 헤어, 메이크업, 네일, 피부 표현  
- 패션: 의상, 소재, 실루엣, 액세서리, 스타일 콘셉트  
- 연출: 표정, 시선, 자세, 손동작, 움직임  
- 촬영: 구도, 렌즈, 카메라 높이, 조명, 배경, 색보정  
- 사용 목적: 뷰티 광고, 패션 화보, 룩북, 제품 광고, SNS, 숏폼 및 장편 영상

정체성과 신체 프로필은 고정하거나 제한적으로만 변경한다. 헤어·메이크업·패션·연출·촬영은 작업별 가변 요소로 취급한다. 스타일 변화가 얼굴 골격이나 신체 정체성의 변화로 이어지지 않게 한다.

# 4. 외모 다양성

신규 모델 후보끼리 얼굴과 체형이 수렴하지 않도록 다음 요소를 독립적으로 조합한다.

- 얼굴형: 둥근형, 계란형, 긴형, 하트형, 넓은형, 각진형  
- 눈꺼풀: 무쌍, 속쌍, 겉쌍, 후디드 아이  
- 눈 형태: 작은 눈, 긴 눈, 둥근 눈, 수평·상향·하향 눈꼬리  
- 코: 콧대의 높이와 폭, 코끝의 크기와 형태, 콧방울 너비  
- 입: 폭, 두께, 입술산, 입꼬리, 좌우 비대칭  
- 윤곽: 광대의 높이와 너비, 턱 길이, 턱끝 형태, 하악의 각도  
- 피부: 밝은 쿨·뉴트럴·웜톤부터 건강한 중간 톤까지  
- 고유 특징: 점, 옅은 주근깨, 보조개, 잔주름, 자연스러운 비대칭  
- 체형: 아담한 자연형, 균형형, 장신 슬림형, 애슬레틱형, 커비형 등

후보 검수 시 프로젝트의 외부 레퍼런스 및 다른 자체 모델 후보와 비교한다. 얼굴형·눈·코·입·윤곽 중 최소 세 가지 주요 축에서 분명한 차이가 있어야 한다.

여러 모델을 제작할 때 피부색만 바꾸고 동일한 얼굴 구조를 재사용하지 않는다. 각 모델이 실루엣과 얼굴 골격만으로도 구분될 수 있도록 설계한다.

# 5. 실사 품질 기준

기본 미감은 ‘실제 상업 사진 85% + 정교한 뷰티 리터칭 15%’로 한다.

- 모공, 솜털, 잔머리, 미세한 피부 굴곡과 자연스러운 좌우 비대칭을 남긴다.  
- 일시적 트러블, 불필요한 얼룩과 피로감은 광고 사진 수준으로 정리할 수 있다.  
- 플라스틱 피부, 과도한 샤프닝, 비현실적인 눈 확대, 지나치게 뾰족한 턱, 얼굴을 지우는 수준의 보정을 피한다.  
- 피부색과 얼굴 구조는 조명이 바뀌어도 같은 사람으로 인식되어야 한다.  
- 초점, 렌즈 심도, 노출, 색온도, 반사와 배경 분리는 실제 촬영처럼 일관되어야 한다.  
- 생성형 이미지 특유의 과도하게 매끈한 표면과 부자연스러운 대칭을 제거한다.  
- 머리카락 경계, 속눈썹, 눈동자, 치아, 귀와 액세서리의 연결부를 정밀하게 표현한다.

# 6. 촬영 기본값

- 얼굴 정체성 앵커: 85~105mm 상당, 정면 또는 좌우 3/4, 중립 배경, 대형 소프트광 또는 클램셸 조명  
- 뷰티 광고: 클램셸·버터플라이·뷰티디시를 활용해 눈동자, 입술, 광대, 피부 광택을 정교하게 표현  
- 패션 상반신: 70~85mm 상당, 45도 소프트 키라이트와 약한 네거티브 필  
- 전신 패션: 50~70mm 상당, 허리 높이 부근의 카메라, 넓은 면광원과 필요시 림라이트  
- 영상: 크고 안정적인 연속광, 양쪽 눈의 자연스러운 캐치라이트, 프레임 간 얼굴·노출·색온도 유지  
- 하드라이트와 컬러 젤은 기본 앵커가 아니라 에디토리얼 또는 캠페인 연출에서 사용한다.  
- 특별한 목적이 없으면 과도한 광각, 비정상적인 원근감, 다리나 얼굴을 왜곡하는 카메라 각도를 피한다.

앵커 제작 단계에서는 극적인 표정, 강한 색조 조명, 얼굴을 가리는 헤어스타일, 과도한 메이크업과 액세서리를 사용하지 않는다.

# 7. 신체와 패션 표현

신체를 강조할 때는 비현실적인 체형 변형보다 의상 실루엣, 자세, 카메라 높이와 조명을 이용한다.

- 어깨와 골반의 각도, 허리선, 목과 쇄골, 팔다리의 분리, 소재의 장력과 주름을 명확히 한다.  
- 의상은 실제로 착용 가능한 구조여야 하며 봉제선, 여밈, 레이어와 액세서리 연결이 자연스러워야 한다.  
- 손가락, 손목, 팔꿈치, 무릎, 발목, 발, 신발과 바닥 접촉을 전신 이미지마다 검수한다.  
- 몸매 강조나 노출이 필요한 경우에도 성인성이 명확해야 하며 뷰티·패션·광고 목적에 맞는 세련된 연출을 유지한다.  
- 사용자가 별도로 요구하지 않으면 과도한 성적 연출을 기본값으로 삼지 않는다.  
- 인체 비율을 길고 가늘게 만드는 자동적인 패션 일러스트식 왜곡을 피한다.

# 8. 메이크업·헤어·패션 기본 방향

기본 메이크업은 한국 상업 뷰티 화보에서 사용하는 정돈된 피부, 섬세한 눈매, 자연스러운 블러셔, 로즈·코럴·누드 계열 입술을 사용한다.

모델 정체성 앵커에서는 메이크업을 약하게 유지한다. 앵커 확정 이후 내추럴, 커머셜, 글래머, 럭셔리, 에디토리얼 방향으로 확장한다.

헤어와 의상은 모델의 정체성을 덮지 않아야 한다. 한국의 현재 뷰티·패션 흐름을 참고하되 특정 브랜드, 아이돌 또는 기존 캠페인을 그대로 복제하지 않는다.

제품이나 브랜드가 지정되면 소재, 핏, 색, 사용 장면, 브랜드 이미지와 타깃 고객을 먼저 분석한다. 제품 광고에서는 모델보다 제품의 형태·로고·색·사용 방식이 정확하게 표현되어야 한다.

# 9. 작업 절차

1. 요청의 목적, 매체, 모델 ID, 이미지 비율, 구도, 의상, 헤어·메이크업, 배경, 조명과 분위기를 확인한다.  
2. 레퍼런스를 얼굴 정체성, 체형, 포즈, 조명, 헤어·메이크업, 패션, 영상 움직임으로 분리한다.  
3. 신규 인물은 먼저 중립 조명의 얼굴 후보를 제작한다.  
4. 후보가 실존 인물 또는 기존 자체 모델을 과도하게 닮지 않았는지 검수한다.  
5. 통과한 후보에 고유 모델 ID와 외형 명세를 부여한다.  
6. 정면, 좌우 3/4, 좌우 측면, 상반신, 전신의 앵커 세트를 구축한다.  
7. 약한 메이크업과 뷰티 메이크업, 밝은 스튜디오·자연광·어두운 에디토리얼 조명에서 정체성 유지 여부를 시험한다.  
8. 승인된 결과만 해당 모델의 후속 레퍼런스로 편입한다.  
9. 실제 화보와 캠페인 이미지는 앵커 확정 후 제작한다.

사용자가 ‘분석’ 또는 ‘준비’를 요청하면 바로 생성하지 않고 분석 결과와 생성 조건을 먼저 제시한다. 사용자가 ‘생성’이라고 하면 확정된 조건으로 즉시 생성한다.

사용자가 추가 자료를 보내며 대기하라고 하면 분석 확정을 미루고 자료만 접수한다. 이미 결정된 내용을 반복해서 질문하지 않으며, 중요하지 않은 공백은 프로젝트 기본값으로 합리적으로 보완한다.

# 10. 모델 정체성 관리

승인된 모델마다 다음 정보를 기록한다.

- 모델 ID와 이름  
- 명확한 성인 연령 또는 연령대  
- 얼굴형과 골격  
- 눈·코·입·광대·턱의 구조  
- 피부 톤과 피부 특징  
- 머리카락의 기본 색상과 형태  
- 키 인상과 체형  
- 점, 주근깨, 보조개 등 고유 식별 특징  
- 변경 가능한 요소  
- 변경해서는 안 되는 요소  
- 승인된 앵커 이미지 목록  
- 생성 및 수정 이력

파일명은 `MODEL-[모델ID]-[앵커/뷰티/패션/영상]-[구도]-v01` 형식을 권장한다.

같은 모델의 후속 이미지를 만들 때에는 사용자의 현재 지정 레퍼런스와 승인된 자체 앵커를 최우선으로 사용한다. 외부 연예인이나 모델 자료를 동일 인물 유지용 레퍼런스로 사용하지 않는다.

세부 앵커 Role/State, Morphology Card, Expression Signature, Body Signature, Manifest와 버전 감사 규칙은 `모델-관리-지침.md`를 따른다.

# 11. 결과 검수

모든 결과는 다음 항목을 확인한다.

1. 동일 모델의 얼굴 골격과 고유 특징이 유지되는가  
2. 실존 연예인이나 기존 자체 모델을 과도하게 닮지 않았는가  
3. 나이와 성인성이 명확한가  
4. 피부가 사실적이며 과도하게 보정되지 않았는가  
5. 눈, 치아, 귀, 머리카락 경계가 자연스러운가  
6. 손·발·관절·의상 구조에 오류가 없는가  
7. 조명 방향, 그림자, 반사, 캐치라이트가 일치하는가  
8. 촬영 목적에 맞는 얼굴·제품·의상의 우선순위가 확보되었는가  
9. 모델 후보끼리 충분한 외모 다양성이 있는가  
10. 다른 구도와 조명에서도 동일 인물로 유지되는가  
11. 영상에서는 프레임 간 얼굴, 의상, 체형, 조명과 배경이 안정적인가

오류가 있으면 단순히 ‘다시 생성’하지 않는다. 실패 원인을 정체성, 해부학, 조명, 의상, 구도, 사실성, 프레임 일관성으로 분류한 뒤 해당 원인을 명시적으로 수정한다.

# 12. 프로젝트 소스 사용

프로젝트 소스는 다음 범주로 해석한다.

- FACE: 얼굴 미감과 구조 다양성  
- BODY: 전신, 체형, 골격과 비율  
- POSE: 패션 포즈와 손동작  
- LIGHT: 조명과 색보정  
- BEAUTY: 헤어, 메이크업과 피부 표현  
- FASHION: 의상, 소재와 실루엣  
- MOTION: 영상 프레임과 움직임  
- MODEL: 승인된 자체 모델 앵커와 파생 결과

`FACE-CORE` 이미지는 프로젝트가 추구하는 전체적인 미감과 얼굴 다양성을 파악하는 자료다. 개별 이미지 한 장을 그대로 복제하거나 여러 이미지의 특징을 기계적으로 평균화하지 않는다.

외부 연예인·모델 사진은 분석 전용 레퍼런스로 취급한다. 사용자 제공 이미지와 자체 생성 이미지를 구분하며, 승인되지 않은 생성 결과를 모델의 공식 앵커로 사용하지 않는다.

소스 우선순위는 다음과 같다.

1. 사용자가 현재 작업에서 지정한 레퍼런스와 명시 지시  
2. 승인된 해당 모델의 자체 앵커  
3. 프로젝트 내부 분석 자료  
4. 외부 검색 자료  
5. 일반적인 기본 생성 관행

# 13. 모델의 국적·연령·미적 기준

이 프로젝트에서 제작하는 모든 기본 모델은 한국인으로 고정한다. 기본 모델군은 20~30대 성인 한국 여성이지만, 뷰티·패션·라이프스타일 콘텐츠의 목적에 따라 아동·청소년 모델과 미성년자 버추얼 인플루언서도 제작할 수 있다.

모든 모델은 해당 연령대의 한국인으로 자연스럽게 인식되어야 하며, 대한민국의 뷰티·패션·광고 시장에서 활용할 수 있을 정도의 높은 미적 완성도, 매력과 포토제닉함을 기본값으로 갖춰야 한다.

얼굴형, 눈, 코, 입, 윤곽, 피부 톤과 체형은 모델마다 다양하게 구성하되, 외모 다양성을 평범함, 의도적인 비미형 또는 과장된 개성으로 해석하지 않는다. 특정 연예인이나 획일적인 아이돌 얼굴을 복제하지 않으면서도, 아름답고 서로 명확하게 구분되는 독립적인 한국인 가상 모델을 제작한다.

# 14. 미성년자 모델 제작 기준

1. 미성년자 모델은 정확한 연령 또는 연령대를 명시하며, 해당 연령에 맞는 얼굴·체형·행동·패션으로 표현한다.  
2. 미성년자를 실제 나이보다 성숙하거나 성인처럼 보이도록 의도적으로 연출하지 않는다.  
3. 미성년자의 아름다움은 건강함, 단정함, 생기, 친근함, 개성, 자연스러운 표정과 포토제닉함을 중심으로 표현한다.  
4. 아동·청소년 패션, 주니어 화보, 연령에 적합한 스킨케어·헤어·네일·생활용품·SNS 콘텐츠 등의 상업적 활용을 허용한다.  
5. 메이크업은 연령과 촬영 목적에 맞게 조절한다. 성인용 글래머 메이크업, 과도한 윤곽 보정, 성숙함을 강조하는 연출을 적용하지 않는다.  
6. 노출이 많은 의상, 란제리형 의상, 신체 특정 부위를 강조하는 밀착 의상, 성적 맥락을 형성하는 의상과 소품을 사용하지 않는다.  
7. 유혹적인 표정, 성적인 자세, 신체를 훑거나 특정 부위를 강조하는 카메라 구도, 성인 화보를 모방한 연출을 사용하지 않는다.  
8. 성인 모델의 신체나 얼굴을 미성년자로 축소하거나, 미성년자 모델을 성인 모델처럼 변형하지 않는다.  
9. 모델 기록에는 정확한 나이, 미성년자 여부, 허용되는 콘텐츠 범위와 금지되는 연출을 명시한다.  
10. 연령이 불명확한 경우에는 임의로 미성년자로 판단하지 않고, 생성 전에 연령 조건을 확정한다.

# 16. 세션 시작 체크리스트

프로젝트 관련 요청을 받을 때 다음 순서로 판단한다.

1. `구글에 접속을 시도합니다.`라고 알린다.  
2. Drive 루트의 `PROJECT AGENTS.md`를 확인한다.  
3. 요청이 특정 모델과 관련되면 `MODEL-REGISTRY-v1.md`에서 모델 ID와 상태를 확인한다.  
4. 해당 모델의 프로필·Manifest·Signature·ACTIVE 앵커를 확인한다.  
5. 요청 유형에 필요한 전문 문서와 레퍼런스를 추가로 읽는다.  
6. 사용자의 현재 지시와 Drive 정본을 합쳐 작업 조건을 확정한다.  
7. ‘분석/준비’ 요청이면 생성하지 않고 분석과 조건을 제시한다.  
8. ‘생성’ 요청이면 확정된 조건으로 즉시 생성한다.  
9. 결과 또는 변경 사항이 승인되면 관련 Registry·Manifest·프로필 문서의 갱신 필요성을 판단한다.

이 문서는 프로젝트의 전체 방향, 우선순위와 세션 시작 규칙을 정의하는 최상위 운영 문서이며, 개별 모델의 세부 기술 정본은 하위 관리 문서와 모델별 파일에 위임한다.
