# 실사 모델 MODEL Registry v1

기준일: 2026-09-09

## 1. 관리 원칙

이 문서는 프로젝트에서 승인되어 지속적으로 사용하는 자체 가상 모델의 정본 레지스트리다.

- 등록된 모델만 `MODEL` 자체 모델로 취급한다.
- 모델의 얼굴 정체성과 기본 신체 프로필은 고정 요소다.
- 헤어, 메이크업, 패션, 표정, 포즈, 조명과 배경은 가변 요소다.
- 승인된 얼굴·전신 앵커를 후속 생성의 최우선 레퍼런스로 사용한다.
- 표정 보드, 패션 화보, 테스트 이미지와 파생 결과물은 얼굴 정체성의 마스터 앵커로 사용하지 않는다.
- 실패한 결과물과 폐기된 구버전은 공식 앵커에서 제외한다.
- 얼굴 구조의 세부 수치 및 형태 명세는 별도의 `Morphology Card`에서 관리한다.
- 신체 구조와 물리 반응은 별도의 `Body Signature`에서 관리한다.

하진의 바스트는 매우 크지만, 이것을 전체 체형의 풍만함으로 확장하지 않는다.

- 바스트만 매우 큰 것이 핵심이다.
- 몸통·팔·골반·허벅지는 장신 슬림 체형으로 유지한다.
- 인공적으로 단단한 반구형 형태를 피한다.
- 과도한 상방 고정이나 푸시업 형태를 기본값으로 사용하지 않는다.
- 자연스러운 중력 방향과 연부조직의 형태 변화를 표현한다.
- 의복에 눌릴 경우 체적이 사라지지 않는다.
- 압박 시 전방 돌출은 어느 정도 감소할 수 있다.
- 대신 아래쪽과 바깥쪽·접촉 주변으로 면적이 자연스럽게 분산될 수 있다.

## 8. 앵커 역할(Role)과 상태(State)

앵커의 용도와 생명주기를 한 축에 섞지 않는다. 각 파일은 `Role`과 `State`를 별도로 가진다.

### Role

- `MASTER`: 해당 영역의 최상위 공식 정체성 기준. 기본 영역은 FACE / FULL / BODY로 나눈다.
- `SUPPORT`: MASTER를 보조하는 승인된 다른 방향·구도·보조 기준 이미지. MASTER를 대체하지 않는다.
- `EXPRESSION`: 승인된 표정 범위를 정의하는 자료. 얼굴 골격의 MASTER가 아니다.
- `DERIVED`: 뷰티, 패션, 광고, 라이프스타일 등 MASTER에서 파생된 결과.
- `TEST`: 검증 중인 결과. 승인 전에는 정체성 기준으로 사용하지 않는다.

### State

- `ACTIVE`: 현재 후속 생성에 사용할 수 있는 공식 파일.
- `DEPRECATED`: 교체·실패·구버전 등의 이유로 더 이상 정체성 기준으로 사용하지 않는 파일. `99-보관`으로 이동한다.

### 기본 MASTER 세트

- FACE MASTER: `HALF`
- FULL MASTER: 레거시 모델의 전신 보조 기준. 신규 3분리 표준에서는 별도 생성하지 않는다.
- BODY MASTER: `BODY-FRONT` + `BODY-SIDE` + `BODY-BACK`

작업별 참조 우선순위는 해당 모델의 `MODEL-[ID]-ANCHOR-MANIFEST-v01.md`를 따른다. EXPRESSION 보드는 공식 자료이지만 FACE MASTER를 대체하지 않는다.

## 13. 전신 앵커 3분리 전환 및 Seedance BASE 운영

### 새 BODY MASTER 표준

향후 모든 모델의 BODY MASTER는 한 장의 `BODY-4VIEW`가 아니라 다음 세 개의 독립 전신 앵커로 구성한다.

1. `BODY-FRONT` — 정면 전신
2. `BODY-SIDE` — 정확한 측면 전신
3. `BODY-BACK` — 후면 전신

세 장은 동일한 기본 복장, 신발 또는 맨발 상태, 배경, 조명, 카메라 높이·거리·렌즈·바닥선을 공유한다. 이 세트를 합쳐서 BODY MASTER로 기록한다. 신규 BODY-4VIEW는 만들지 않는다.

MODEL-001~003의 기존 BODY-4VIEW는 3분리 대체 세트가 승인될 때까지 ACTIVE로 유지한다. 대체 승인 후에는 99-보관으로 이동하고 DEPRECATED로 기록한다. 이번 규칙 변경만으로 기존 파일을 자동 폐기하지 않는다.

MODEL-004 리안은 현재 정면 전신 + 측면 + 후면 자료를 갖추었으나, 새 표준 파일명과 3분리 BODY MASTER 정식 승인은 BASE 복장·방향별 일치도 검수 후 진행한다.

### Seedance 초도 BASE 시트

- 모델별 첫 Seedance 3패널 레퍼런스는 `MOTION-REFSHEET-BASE-v01`로 만든다.
- BASE 시트는 해당 모델의 3분리 BODY MASTER에 정의된 기본 복장을 유지한다.
- CASUAL·STAGE·FASHION·PRODUCT 시트는 BASE 승인 뒤의 파생 자산이다.
- 이전에 생성된 CASUAL/STAGE 시트는 파생 자산으로 보존할 수 있지만 BASE 기준을 충족하지 못하면 초도 영상 정체성 시트로 등록하지 않는다.
- 세부 규칙 정본은 `seedance-2.5-3panel-reference-sheet-guide-v3.md`다.
