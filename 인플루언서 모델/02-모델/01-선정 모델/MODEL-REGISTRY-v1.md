# 실사 모델 MODEL Registry v1

기준일: 2026-09-07

## 1. 관리 원칙

이 문서는 프로젝트에서 승인되어 지속적으로 사용하는 자체 가상 모델의 정본 레지스트리다.

- 등록된 모델만 `MODEL` 자체 모델로 취급한다.
- 모델의 얼굴 정체성과 기본 신체 프로필은 고정 요소다.
- 헤어, 메이크업, 패션, 표정, 포즈, 조명과 배경은 가변 요소다.
- 승인된 얼굴·전신 앵커를 후속 생성의 최우선 레퍼런스로 사용한다.
- 표정 보드, 패션 화보, 테스트 이미지와 파생 결과물은 얼굴 정체성의 마스터 앵커로 사용하지 않는다.
- 실패한 결과물과 폐기된 구버전은 공식 앵커에서 제외한다.
- 얼굴 구조의 세부 수치 및 형태 명세는 별도의 `Morphology Card`에서 관리한다.
- 신체 구조와 물리 반응은 별도의 `Body Signature`에서 관리한다.

## 6. 앵커 역할(Role)과 상태(State)

앵커의 용도와 생명주기를 한 축에 섞지 않는다. 각 파일은 `Role`과 `State`를 별도로 가진다.

### Role

- `MASTER`: 해당 영역의 최상위 공식 정체성 기준. 기본 영역은 FACE / FULL / BODY로 나눈다.
- `SUPPORT`: MASTER를 보조하는 승인된 다른 방향·구도·보조 기준 이미지. MASTER를 대체하지 않는다.
- `EXPRESSION`: 승인된 표정 범위를 정의하는 자료. 얼굴 골격의 MASTER가 아니다.
- `DERIVED`: 뷰티, 패션, 광고, 라이프스타일 등 MASTER에서 파생된 결과.
- `TEST`: 검증 중인 결과. 승인 전에는 정체성 기준으로 사용하지 않는다.

### State

- `ACTIVE`: 현재 후속 생성에 사용할 수 있는 공식 파일.
- `DEPRECATED`: 교체·실패·구버전 등의 이유로 더 이상 정체성 기준으로 사용하지 않는 파일. `99-보관`으로 이동한다.

### 기본 MASTER 세트

- FACE MASTER: `HALF`
- FULL MASTER: `FULL`
- BODY MASTER: `BODY-4VIEW`

작업별 참조 우선순위는 해당 모델의 `MODEL-[ID]-ANCHOR-MANIFEST-v01.md`를 따른다. EXPRESSION 보드는 공식 자료이지만 FACE MASTER를 대체하지 않는다.

## 7. 버전 감사 상태

- MODEL-001 / MODEL-002의 `BODY-4VIEW-v02`는 ACTIVE BODY MASTER다.
- MODEL-003의 `BODY-4VIEW-v02`는 175cm 장신 슬림 체형 재정의와 충돌하여 DEPRECATED 처리했고, `BODY-4VIEW-v03`를 새 ACTIVE BODY MASTER로 승인했다.
- 세 모델의 `BODY-4VIEW-v01`은 2026-09-07 Google Drive 전체 검색에서 확인되지 않았다.
- 누락된 과거 버전을 임의로 재생성하거나 v02를 v01로 재명명하지 않는다.
- 과거 v01이 발견되면 `99-보관`으로 이동하고 DEPRECATED로 기록한다.
- MODEL-002의 `HALF-v01`은 `99-보관`에 존재하며 DEPRECATED다. 현재 FACE MASTER는 `HALF-v02`다.

## 8. Expression Signature 상태

모델별 Expression Signature 구축을 완료했다.

- MODEL-001 차예린: 절제와 점진적 변화
- MODEL-002 백세아: 눈·시선 중심의 미세 변화
- MODEL-003 강하진: 입·볼·눈이 함께 움직이는 높은 감정 진폭
- 표정 생성 기본 우선순위: `FACE MASTER → Expression Signature → 장면에 필요한 EXPRESSION 보드`
- Expression Signature는 표정 종류를 제한하는 규칙이 아니라, 같은 감정도 모델마다 다른 방식으로 표현하기 위한 행동적 정체성 규칙이다.
- 모든 이미지에 동일한 미소나 같은 시선·고개 각도를 반복하지 않는다.

## 9. Body Signature 상태

모델별 Body Signature 구축을 완료했다.

- MODEL-001 차예린: 장신·긴 팔다리·좁음~중간 몸통·과장되지 않은 허리-골반 곡선
- MODEL-002 백세아: 섬세한 골격·좁은 상체·낮은 전체 체적·작고 정돈된 허리-골반 곡선
- MODEL-003 강하진: 175cm 장신·긴 다리·슬림한 몸통과 팔다리·중간 골반·매우 큰 자연형 바스트
- 신체 생성 기본 우선순위: `공식 신체 수치 → BODY MASTER → Body Signature → 장면별 의상·포즈`
- 수치는 크기·비율, BODY MASTER는 방향별 형태, Body Signature는 중력·압박·움직임 반응을 담당한다.
- 하진의 큰 바스트는 압박 시 소실시키지 않고 전방 돌출 감소와 주변 면적 재분포로 처리한다.
