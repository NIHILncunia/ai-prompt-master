# 인플루언서 모델 작업 지침

## 1. 문서 역할과 적용 순서

이 파일은 `인플루언서 모델` 프로젝트 루트에서 자동으로 읽히는 에이전트 작업 진입점이다.

작업을 시작할 때 다음 순서로 문서를 확인한다.

1. 이 `AGENTS.md`
2. `PROJECT AGENTS.md` 전체
3. `SESSION PROGRESS 운영 지침.md` 전체
4. 요청과 직접 관련된 모델 프로필·앵커·Manifest 및 하위 운영 문서

지침이 충돌하면 현재 대화에서 마스터가 가장 최근에 명시한 지시, 이 `AGENTS.md`, `PROJECT AGENTS.md`, 요청 대상의 승인된 정본 자료 순으로 적용한다. 현재 실행 환경에서 실제로 사용할 수 없는 Drive·도구 접근을 했다고 주장하거나, 연결을 시도했다는 안내를 출력하지 않는다.

`PROJECT AGENTS.md`는 이 프로젝트의 모델 정체성, 이미지 승인, 품질, 파일 관리 등 도메인 운영 기준의 정본이다. 이 파일은 이를 대체하지 않고, 자동 적용과 공통 응답 형식을 보장한다.

## 2. SESSION PROGRESS 강제 규칙

모든 최종 사용자 응답에는 프로젝트 루트의 `SESSION PROGRESS 운영 지침.md`를 따른 `SESSION PROGRESS`를 반드시 포함한다. 상세 정의와 상태 전환은 해당 문서가 정본이다.

- `SESSION PROGRESS` 전체는 마지막 코드블록 안의 플레인 텍스트로만 출력한다. 그 뒤에는 본문, 새 제안, 승인 요청, 링크를 덧붙이지 않는다.
- 활성 작업에는 아래 여섯 필드만 사용한다. 필드명을 `현재 단계`, `버전`, `필수 교정`, `일의 기준`, `다음 행동` 등으로 바꾸거나 추가하지 않는다.

```text
SESSION PROGRESS

- 작업: <현재 이어지는 큰 작업>
- 현재: <지금 처리 중인 최소 단위>
- 단계: <브레인스토밍 | 분석 | 설계 | 초안 작성 | 검토 | 정밀 검토 | 확정 | 문서 작성 | 수정 | 검증 등>
- 완료: <실제로 완료했거나 마스터가 확정한 범위>
- 미결: <이전 단계에서 남은 미확정 사항, 없으면 없음>
- 다음: <즉시 이어서 할 가장 가까운 작업>
```

- 값이 둘 이상인 필드는 쉼표로 나열하지 않고 순차 목록으로 작성한다.
- 버전, 모델 ID, 생성 배치, 교정 항목, 검수 결과는 독립 SESSION PROGRESS 필드가 아니다. 실제 진행 상태를 설명해야 할 때에만 `현재` 또는 `완료` 값 안에 간결하게 기록한다.
- 본문의 결과·근거·승인 요청은 SESSION PROGRESS 앞에 작성한다. SESSION PROGRESS에는 본문을 복사하거나 장기 계획을 넣지 않는다.
- `완료`에는 검증하지 않은 결과, 예정 작업, 아직 생성하지 않은 파일을 기록하지 않는다. `미결`에는 현재 검토 중인 항목이나 앞으로 할 일을 넣지 않는다.
- 진행 중인 작업이 없으면 정본의 대기형, 의도적으로 멈추면 일시 중단형, 작업을 끝내면 완료형을 그대로 사용한다.
- 마스터가 SESSION PROGRESS 생략을 명시하면 해당 지시를 우선한다.

## 3. 응답과 작업 기록 기준

- 작업 결과, 판단 근거, 확인이 필요한 선택지는 SESSION PROGRESS 이전 본문에 명확히 제시한다.
- 이미지 생성·수정 요청은 `PROJECT AGENTS.md` 및 관련 공통 승인 절차를 먼저 확인하고, 공개된 확인서와 최종 영어 프롬프트에 대한 마스터의 명시적 승인을 받은 경우에만 실행한다.
- 현재 대화의 실제 진행 상태를 매 응답에서 갱신한다. 다른 모델·이전 세션·예시 문구를 현재 작업 상태로 전용하지 않는다.
