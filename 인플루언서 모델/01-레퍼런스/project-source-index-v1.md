# 실사 모델 제작 — 프로젝트 소스 인덱스 v1

## 1. 프로젝트 범위

- 기본 대상: 20~30대 성인 한국 여성
- 주요 용도: 뷰티, 패션, 라이프스타일, 광고, SNS, 영상용 가상 모델·인플루언서
- 핵심 목표: 실사 품질, 모델별 정체성 유지, 외모 다양성, 실존 인물과의 충분한 구분
- 기준일: 2026-09-07

## 2. 소스 사용 원칙

1. 실존 연예인·모델 사진은 얼굴 복제용이 아니라 외모 어휘, 촬영법, 메이크업, 헤어와 분위기 분석에만 사용한다.
2. 외부 인물의 이름은 생성 프롬프트에 사용하지 않는다.
3. 한 인물의 얼굴형·눈·코·입·윤곽을 묶음으로 복제하지 않는다.
4. 신규 모델이 승인되면 외부 사진보다 해당 모델의 자체 앵커를 우선한다.
5. 재배포 권리가 불명확한 외부 이미지는 프로젝트에 원본을 복제하지 않고 출처 링크와 분석 노트를 보관한다.
6. 이 인덱스의 ID는 인물 식별자가 아니라 프로젝트 내부의 자료 관리 ID다.

## 4. FACE-CORE 파일 구성

`user-face-core` 폴더에 사용자 제공 얼굴 레퍼런스 20장을 관리용 파일명으로 복제했다.

| 묶음 | 파일 | 자료 역할 |
|---|---|---|
| 1차 업로드 | FACE-CORE-01.png ~ FACE-CORE-10.png | 청순·세련·클린 뷰티 계열의 얼굴 미감과 촬영 분위기 분석 |
| 2차 업로드 | FACE-CORE-11.png ~ FACE-CORE-20.png | 얼굴 인상, 메이크업, 헤어, 표정과 무대·행사 조명의 변형 범위 분석 |

이 20장은 다음 항목을 추출하는 용도로만 사용한다.

- 얼굴형과 턱선의 범위
- 눈꺼풀 구조, 눈매, 눈 간격과 눈꼬리 각도
- 콧대·코끝·콧방울의 형태 차이
- 입술 폭·두께·입술산·입꼬리
- 광대, 하악, 얼굴 길이와 너비
- 피부 톤과 상업적 리터칭 수준
- 내추럴·커머셜·글래머 메이크업의 차이
- 헤어 길이, 앞머리, 직모·웨이브, 업스타일
- 무표정과 미소 사이의 미세한 표정 연출

### 금지되는 사용

- 특정 한 장을 신규 모델의 전체 얼굴 기준으로 사용
- 실존 인물 이름을 넣어 닮은꼴 생성을 요청
- 여러 얼굴 중 한 명을 중심으로 나머지를 보조하는 방식
- 작은 얼굴, 큰 눈, 뾰족한 턱만 반복해 모든 후보를 동일한 AI 미인형으로 수렴시키는 방식

## 5. BODY·LIGHT·POSE·BEAUTY·MOTION 레퍼런스

상세 출처와 사용 목적은 `beauty-fashion-model-reference-pack-v1.md`에 기록되어 있다.

### BODY 자료에서 추출할 요소

- 키 인상, 어깨 너비, 골반 너비, 허리선
- 상체·하체 비율과 팔다리 길이
- 슬림형, 자연형, 애슬레틱형, 커비형의 실루엣
- 정면, 3/4, S커브, 워킹과 동작형 포즈
- 소재의 장력, 주름, 레이어와 바닥 접촉

### LIGHT 자료에서 추출할 요소

- 클램셸과 버터플라이 조명의 깨끗한 피부 표현
- 뷰티디시의 캐치라이트와 피부 광택
- 45도 소프트광과 네거티브 필의 입체감
- 하드라이트의 광대·턱·쇄골 강조
- 창문 자연광, 역광, 림라이트와 내추럴 글로우
- 하이키와 로우키에서 동일 인물의 정체성 유지

### POSE 자료에서 추출할 요소

- 정적 3/4 스탠딩과 한쪽 체중 지지
- 재킷·의상과 손의 자연스러운 접촉
- 정면·측면 워킹의 보폭, 팔 스윙과 하중 이동
- 벽 기대기와 의자 앉기에서의 실제 접촉점
- 얼굴 주변 손동작과 손가락 긴장도
- 스킨케어·향수 등 소형 제품을 보여주는 손-제품-얼굴 관계
- 뒤돌아보기에서 목·어깨·골반 회전의 한계

POSE는 체형 정체성 레퍼런스가 아니다. 실제 적용 시 `공식 신체 수치 → BODY MASTER → Body Signature → POSE → 장면별 의상·연출` 순서로 사용한다.

### BEAUTY 자료에서 추출할 요소

- 피부 피니시와 커버 강도
- 국소 하이라이트와 자연스러운 광택 위치
- 점막·라이너·속눈썹·애굣살 등 아이 디테일
- 블러셔 위치, 면적, 투명도와 색온도
- 립의 농도, 경계, 그라데이션과 광택
- 모발 윤기, 직모·웨이브·컬, 잔머리와 앞머리
- 업스타일의 두상 부피와 페이스라인 노출
- 네일 길이, 쉐입, 투명도와 표면 질감

BEAUTY는 얼굴 정체성 레퍼런스가 아니다. 실제 적용 시 `FACE MASTER → Morphology Card → BEAUTY → 장면별 조명·촬영` 순서로 사용하며, 표정이 있는 경우 Expression Signature를 병행한다.

### MOTION 자료에서 추출할 요소

- 고개 회전에서 정면·3/4·측면 사이 얼굴 구조의 연속성
- 워킹의 발 접촉, 하중 이동, 팔 스윙과 의상 후행 움직임
- 정지 포즈에서 다음 포즈로 이동하는 중간 관절 경로
- 제품 들기·제시에서 손가락 그립, 제품 방향과 라벨의 시간적 일관성
- 중립에서 미소 등 표정 전환의 눈·광대·입꼬리 변화 순서
- 헤어 플립에서 머리카락의 관성, 후행 움직임과 정착
- 프레임 간 얼굴·체형·의상·제품·노출·색온도의 안정성

MOTION은 시간축 연출 레퍼런스다. 얼굴·신체·그루밍 정체성을 바꾸지 않으며, 실제 적용 시 `정체성 앵커·Signature → 현재 스타일링 → MOTION → 장면별 카메라·조명` 순서로 사용한다.

외부 이미지 파일을 직접 등록할 때는 사용권을 별도로 확인한다. 확인되지 않은 자료는 링크 문서만 프로젝트 소스로 사용한다.

## 7. 자체 모델 등록 규칙

신규 모델은 다음 파일 구조를 사용한다.

`MODEL-[모델ID]-[ANCHOR/BEAUTY/FASHION/MOTION]-[FRONT/L3Q/R3Q/LEFT/RIGHT/HALF/FULL]-v01`

모델별로 다음 정보를 함께 기록한다.

- 모델 ID와 가상 이름
- 연령 및 연령 인상
- 얼굴형과 이목구비 구조
- 피부 톤과 고유 특징
- 키 인상, 골격, 체형과 신체 비율
- 고정 요소와 변경 가능한 요소
- 금지 요소 및 실패 이력
- 승인된 앵커 목록
- 생성 프롬프트와 버전
- 닮은꼴 검수 결과
