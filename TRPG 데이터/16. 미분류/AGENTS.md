# 컨셉 이미지 폴더 작업 지침

## 역할

이 폴더는 세션 진행과 직접 연관된 중요한 아이템·유물·장치·구조물 등의 디자인과 시각 설정을 장기 보관한다.

## 설정화 출력 규칙

- 모든 설정화는 가로형 16:9 또는 세로형 9:16 중 하나로 제작한다.
- 정사각형과 임의 비율은 설정화 최종본으로 사용하지 않는다.
- 좌우로 긴 무기·장치·구조는 16:9를 우선한다.
- 세로로 긴 대상이나 인물 중심 설정화는 9:16을 우선한다.
- 완성형 VTT 토큰 1:1, 캐릭터 레퍼런스 V2 고정 캔버스 등 별도의 기능 고정 계약을 가진 산출물은 이 규칙의 적용 대상이 아니다.
