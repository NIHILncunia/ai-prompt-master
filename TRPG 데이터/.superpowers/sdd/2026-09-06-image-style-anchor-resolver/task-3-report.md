## 구현 결정

- 포트레이트는 선택 스타일 계약보다 중앙 해석기를 먼저 읽는다. 붓터치 반실사의 얼굴·흉상 기본 호출은 `01 + 02 + 04`, 반신·전신 기본 호출은 `01 + 02 + 03 + 04`로 안내하되 실제 조합과 축소는 중앙 해석기가 결정한다.
- 완성형 VTT 토큰은 확정 전신 또는 업로드 기준 이미지의 기존 그림체와 캐릭터 본체를 보존하고 캐릭터 스타일 앵커로 다시 그리지 않는다.
- 캐릭터 레퍼런스 V1은 신규 생성과 명시적 변환에서 메인 흉상을 얼굴·흉상, 정면·후면 전신을 반신·전신으로 분류하여 중앙 해석기 결과를 사용한다. 최종 시트 조립에서는 별도 스타일 패스를 추가하지 않는다.
- 세션 하이라이트는 변환 지시가 없으면 호환되는 모든 제공 레퍼런스의 그림체와 마감을 보존한다. 서로 충돌하면 장면 전체의 단일 기준 그림체를 마스터에게 확인한다.
- 세션 하이라이트의 명시적 변환은 디자인 기준 이미지를 스타일 앵커보다 먼저 배정하고, 장면의 지배적 프레이밍을 얼굴 중심 또는 전신·행동 중심으로 분류한다. 참조 예산으로 제외한 모든 앵커와 사유를 기록하며 앵커의 인물·의상·팔레트·포즈·카메라·배경·장면 구성은 가져오지 않는다.
- 캐릭터 레퍼런스 V2는 얼굴·두상 소스를 얼굴·흉상 경로로, 정면·측면·후면 전신 소스를 반신·전신 경로로 판정한다. 최종 `1916 × 821 px` 합성은 생성된 소스의 그림체를 보존하며 두 번째 정식 스타일 패스를 추가하지 않는다.
- 기존 포트레이트 9:16 단계, VTT 토큰 파생 처리, V1 16:9 3표현 시트, V2 모드별 패널·무기·전체 검은 데이터 바 계약은 변경하지 않았다.

## 검증

### 브리프 지정 검색

- `rg -n '정식 스타일 호출 규칙' $characterRoots`: 종료 코드 0. 내부 기능 1·3·4·5의 대상 안내 문서에서 중앙 해석기 경로를 확인했다.
- `rg -n '제공 이미지.*그림체|그림체.*보존' $characterRoots`: 종료 코드 0. 제공 이미지 또는 기준 이미지의 그림체 보존 경로를 확인했다.
- `rg -n '핵심 얼굴 \+ 마감|중립 전신 \+ 마감|정식 3앵커|스타일 앵커는 최대 2장|정식 앵커를 최대 2장' $characterRoots`: 종료 코드 1, 출력 없음. 활성 기능 안내에서 금지된 구 조합과 최대 2장 규칙이 제거되었음을 확인했다.

### 보존 계약 검색

- 포트레이트에서 `전신 9:16 → 전신 확정 → 흉상 9:16 또는 완성형 VTT 토큰 1:1` 흐름과 토큰 비재렌더링·기존 그림체 보존 문구를 확인했다.
- V1에서 흉상/전신 소스 구도 분류와 최종 조립의 두 번째 스타일 패스 금지를 확인했다.
- 세션 하이라이트에서 호환 스타일 보존, 충돌 시 단일 기준 질문, 디자인 기준 우선, 지배적 프레이밍, 모든 제외 앵커 기록, 앵커 콘텐츠 복제 금지를 확인했다.
- V2에서 `1916 × 821 px`, 인간형·몬스터형 패널 순서, 외부 무기와 신체 무기 구분, 전체 검은색 데이터 바, 소스별 중앙 해석기 경로, 두 번째 스타일 패스 금지를 확인했다.
