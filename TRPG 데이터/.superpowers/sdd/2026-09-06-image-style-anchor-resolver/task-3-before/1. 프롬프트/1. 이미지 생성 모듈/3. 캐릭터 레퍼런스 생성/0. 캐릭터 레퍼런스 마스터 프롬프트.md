# 캐릭터 레퍼런스 마스터 프롬프트

## 고정 출력 계약

- 가로 16:9 시트
- 정확히 3개의 캐릭터 표현
  1. 좌측 소개 영역의 메인 흉상
  2. 우측 정면 전신
  3. 우측 후면 전신
- cm 단위 키 기준선을 포함한다.

## 목적

동일 캐릭터의 외형을 재사용할 수 있도록 정보 중심의 레퍼런스 시트를 만든다.

## 그림체 기준

- 사용자 제공 이미지 또는 이전 확정 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 그림체와 마감을 그대로 따른다.
- 기준 이미지가 여러 장이고 그림체가 충돌하면 임의로 혼합하지 않고 마스터에게 기준을 확인한다.
- 제공 이미지 없이 새로 만드는 경우 마스터가 지정한 화풍을 사용한다. 화풍 지정도 없으면 요구사항 확인 단계에서 확인한다.
- `애니 페인팅` 또는 `붓터치 반실사`로 변경하라는 명시가 있으면 제공 이미지는 디자인 기준으로만 사용하고 선택 스타일의 정식 앵커와 고정 영어 블록을 적용한다.
- 정식 스타일 변경 시 흉상 소스에는 `핵심 얼굴 + 마감`, 전신 소스에는 `중립 전신 + 마감` 앵커를 사용한다. 각 생성의 스타일 앵커는 최대 2장이다.

## 저장

완료된 캐릭터 레퍼런스 시트는 로컬 `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/`에 저장한다. 하위 분류는 마스터가 정하며, 기존 파일은 덮어쓰지 않는다.

## 금지

- 전투 장면
- 시네마틱 배경 장면
- 추가 상세 컷
- 3개를 초과하는 캐릭터 표현
- 정면과 후면의 복식 불일치
