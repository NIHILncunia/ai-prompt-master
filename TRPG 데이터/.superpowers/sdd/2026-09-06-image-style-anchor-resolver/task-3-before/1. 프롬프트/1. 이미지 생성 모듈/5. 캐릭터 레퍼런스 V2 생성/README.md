# 캐릭터 레퍼런스 V2 생성

`1916 × 821 px` 고정 캔버스의 프로덕션형 레퍼런스 시트를 생성한다.

## 모드

### 인간형 V2
얼굴·헤어스타일·복식 재현이 핵심인 사람형 캐릭터용 모드다.

### 몬스터형 V2
전체 실루엣·비인간 해부 구조·핵심 기관이 중요한 대형 또는 비인간 몬스터용 모드다.

세부 판정, 레이아웃, 무기, 데이터 바, 검수 규칙은 아래 문서를 따른다.

제공 이미지가 있으면 그 이미지의 그림체를 기본 보존한다. 다른 정식 스타일로 변경할 때에만 패널별 구도에 맞는 정식 앵커를 스타일 전용으로 적용한다.

- `0. 캐릭터 레퍼런스 V2 마스터 프롬프트.md`
- `1. 캐릭터 레퍼런스 V2 공통 지침.md`
- `2. 레퍼런스 시트 V2 레이아웃 규칙.md`
- `3. 텍스트 바 및 무기 패널 규칙.md`
- `4. V2 산출물 검수 규칙.md`

## 저장

- 인간형 V2: `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/`
- 몬스터형 V2: `TRPG 데이터/10. 몬스터 이미지/`의 유형별 구조
- 몬스터형의 상세 저장 분류는 `TRPG 데이터/10. 몬스터 이미지/몬스터 이미지 분류 및 저장 지침.md`를 따른다.
