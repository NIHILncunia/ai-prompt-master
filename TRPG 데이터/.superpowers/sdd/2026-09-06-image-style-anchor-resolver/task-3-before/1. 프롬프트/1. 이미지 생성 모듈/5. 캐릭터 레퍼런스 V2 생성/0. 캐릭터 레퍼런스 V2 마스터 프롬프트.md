# 캐릭터 레퍼런스 V2 마스터 프롬프트

## 목적

캐릭터 또는 몬스터의 정체성, 체형·실루엣, 방향별 구조, 복식·표면 구조, 외부 무기, 핵심 식별 구조와 마스터가 지정한 핵심 데이터를 한 장에서 재현할 수 있는 프로덕션형 레퍼런스 시트를 만든다.

## 공통 출력 계약

- 캔버스: 정확히 `1916 × 821 px`
- 상단 배경: 마스터가 별도로 지정하지 않으면 반드시 흰색 단색
- 하단 데이터 바: 반드시 전체 검은색
- 데이터는 마스터가 제공한 정보만 사용하며 임의 값·번역·보완을 추가하지 않는다.
- 기본 제작 방식은 패널별 소스 생성 후 고정 레이아웃 합성이다.
- 최종 레이아웃은 이미지 모델의 자율적인 시트 재디자인보다 기능 계약을 우선한다.
- 생성 전 요구사항 확인서에서 `인간형 V2` 또는 `몬스터형 V2` 중 선택된 모드를 반드시 명시한다.

## 그림체 기준

- 사용자 제공 이미지 또는 이전 확정 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 그림체와 마감을 모든 패널에 유지한다.
- 기준 이미지가 여러 장이고 그림체가 충돌하면 임의로 혼합하지 않고 마스터에게 기준을 확인한다.
- 제공 이미지 없이 새로 만드는 경우 마스터가 지정한 화풍을 사용한다. 화풍 지정도 없으면 요구사항 확인 단계에서 확인한다.
- `애니 페인팅` 또는 `붓터치 반실사`로 변경하라는 명시가 있으면 제공 이미지는 디자인 기준으로만 사용하고 선택 스타일의 정식 앵커와 고정 영어 블록을 적용한다.
- 패널별 소스 생성에서 얼굴·핵심 두상은 `핵심 얼굴 + 마감`, 전신 3면은 `중립 전신 + 마감` 앵커를 사용한다. 각 생성의 스타일 앵커는 최대 2장이다.

## 모드 판정

### 사용자 명시 우선

사용자가 `인간형`, `몬스터형`, `몬스터 모드` 등 모드를 직접 지정하면 자동 판정보다 우선한다.

### 인간형 V2

다음 특성이 중심이면 인간형 V2를 사용한다.

- 얼굴과 헤어스타일이 개체 식별의 핵심이다.
- 복식·방어구·착용 장비 구조가 중요하다.
- 사람형 골격을 기준으로 정면·측면·후면을 안정적으로 재현할 수 있다.
- 인간, 엘프, 드워프, 수인 등 기본적으로 인간형 체계를 따른다.

### 몬스터형 V2

다음 중 하나 이상이 강하게 해당하면 몬스터형 V2를 사용한다.

- 인간형 골격에서 크게 벗어난 체형이다.
- 머리·상체·팔다리 비율 자체가 개체 정체성이다.
- 꼬리·촉수·다족·날개·뿌리·등판 등 비인간 구조가 핵심이다.
- 얼굴보다 코어·구강·뿔·등판·기관 등 다른 부위가 더 중요한 식별 요소다.
- 전신에서 머리를 제거하면 구조 정보가 크게 손실된다.
- 대형 몬스터로서 전체 실루엣 판독이 우선된다.

### 경계 사례

오우거, 미노타우로스, 인간형 골렘, 인간형 악마, 인간형 언데드처럼 애매한 대상은 종족명이 아니라 무엇을 보존해야 하는가를 기준으로 판정한다.

- 얼굴·헤어·복식 중심 → 인간형 V2
- 전체 실루엣·해부 구조·핵심 기관 중심 → 몬스터형 V2

## 인간형 V2 고정 계약

상단 순서:
`정면 → 정확한 측면 → 후면 → (외부 무기) → 얼굴+헤어스타일 클로즈업 정면`

- 전신 3패널은 항상 동일한 너비다.
- 최종 전신 3패널에서는 머리와 얼굴을 노출하지 않는다.
- 얼굴 패널은 반드시 정면이며 우측 대형 패널의 중앙에 위치한다.
- 얼굴 패널은 흉상이 아니다. 얼굴과 헤어스타일 구조가 판독될 정도까지만 포함하는 클로즈업을 사용한다.
- 정수리·앞머리·옆머리·묶음 시작점·포니테일 베이스·주요 헤어 장식 등 헤어스타일 식별 구조가 읽혀야 한다.
- 어깨·가슴·상반신은 최소화한다.
- 인간형 상단은 한 줄짜리 공유 외곽선·구획선의 단일선 그리드를 반드시 사용한다.

## 몬스터형 V2 고정 계약

외부 무기 없음:
`정면 전체 → 정확한 측면 전체 → 후면 전체 → 핵심 디테일`

외부 무기 있음:
`정면 전체 → 정확한 측면 전체 → 후면 전체 → 외부 무기 → 핵심 디테일`

- 전신 3면은 머리부터 발끝까지 전체 실루엣을 표시한다.
- 인간형의 머리 제거 규칙을 적용하지 않는다.
- 세 방향의 전체 비율·해부 구조·기관·장식·재질·발광부·색상을 동일 개체로 유지한다.
- 상단에는 격자선·구획선·외곽선을 두지 않는다. 각 영역은 여백으로 구분한다.
- 우측 대형 패널은 얼굴 고정이 아니라 `핵심 디테일 패널`이다.
- 핵심 디테일은 사용자 지정 우선이며, 미지정 시 가장 중요한 개체 식별 구조를 자동 선택한다.
- `머리 + 흉부 코어`처럼 서로 연결된 구조를 함께 보여줄 수 있다.
- 본체와 분리 가능한 외부 무기만 독립 무기 패널을 사용한다.
- 발톱·송곳니·뿔·꼬리·촉수·독침·날개 칼날 등 신체 무기는 본체 일부로 취급한다.

## 핵심 디테일 자동 선택 우선순위

사용자 지정이 없을 때 다음 순서로 판단한다.

1. 얼굴·머리 구조
2. 코어·기관·발광부
3. 구강·눈·뿔 등 공격 또는 감각 기관
4. 날개·꼬리·촉수·등판 등 개체 식별 구조
5. 기타 가장 강한 시각적 특징

핵심 디테일은 시네마틱 연출이 아니라 구조 판독용 정본 패널이다.

## 표준 제작 절차

1. 사용자 제공 이미지 또는 이전 확정 이미지를 디자인·기본 그림체 기준 앵커로 선정한다.
2. 요구사항 확인서에서 인간형/몬스터형 모드를 판정하고 공개한다.
3. 별도 스타일 변경 여부를 판정하고, 변경이 명시되면 패널별 정식 스타일 앵커를 실제 픽셀로 확인한다.
4. 필요한 방향별 전신, 외부 무기, 인간형 얼굴 패널 또는 몬스터형 핵심 디테일 패널을 생성한다.
5. 각 소스의 방향·동일성·비율·핵심 식별 구조·그림체 일관성을 개별 검수한다.
6. 최종 `1916 × 821 px` 캔버스에 모드별 고정 계약으로 합성한다.
7. 하단 검은 데이터 바와 텍스트를 배치한다.
8. `4. V2 산출물 검수 규칙.md`의 해당 모드 체크리스트로 검수한다.

## 데이터 바

- 항상 검은색이다.
- 각 데이터는 `라벨 위 / 값 아래` 세로 쌍으로 구성한다.
- 제공된 데이터만 사용한다.
- 미제공 항목을 `불명`, `???`, 추정값으로 자동 채우지 않는다.
- 인간형은 사용자가 제공한 항목을 그대로 사용한다.
- 몬스터형 기본 후보는 `이름 / 종족·유형 / 크기 / 등급 / 소속`이지만, 후보일 뿐 자동 생성하지 않는다.

## 저장

- 인간형 V2 시트는 `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/`에 저장한다. 하위 분류는 마스터가 정하며 기존 파일은 덮어쓰지 않는다.
- 몬스터형 V2 시트는 `TRPG 데이터/10. 몬스터 이미지/`에 저장한다.
- 몬스터형 저장 위치는 `몬스터 이미지 분류 및 저장 지침.md`의 유형 → 계통·종족·집단 → 개체 구조를 따른다.
- `10. 인간형`은 적성 인간형 전용이다. 비적성 인간형 NPC는 몬스터형 저장 대상으로 보지 않는다.
- 곤충·협각류·다족류·갑각류 등 절지동물형은 이미지 관리상 `16. 곤충류`에 저장한다.
- 유형이 아직 확정되지 않은 몬스터는 임의 추정하지 않고 `커스텀`에 저장한다.

## 금지

### 공통
- 전투·액션 장면
- 시네마틱 배경
- 별도 지정이 없는 상태에서 흰색 외의 상단 배경
- 그라데이션·텍스처·패턴·환경 배경
- 임의 데이터 값 추가
- 패널 번호·불필요한 헤더·계약 밖 UI 장식

### 인간형
- 최종 전신 3면의 머리 또는 얼굴 노출
- 3/4·반측면·사선 구도
- 서로 다른 너비의 전신 3패널
- 얼굴 패널의 비정면 또는 중앙 이탈
- 헤어스타일이 판독되지 않을 정도의 과도한 얼굴 확대
- 얼굴 패널을 흉상으로 만드는 구성
- 단일선 공유 그리드 생략
- 이중선·독립 카드형 프레임·장식형 모서리 프레임

### 몬스터형
- 전신 3면에서 머리·꼬리·날개·촉수·뿌리 등 주요 구조를 잘라내는 구성
- 상단에 인간형용 격자·구획선·외곽선을 적용하는 구성
- 핵심 디테일을 단순 시네마틱 초상으로 만드는 구성
- 신체 무기를 외부 무기처럼 독립 패널로 분리하는 구성
