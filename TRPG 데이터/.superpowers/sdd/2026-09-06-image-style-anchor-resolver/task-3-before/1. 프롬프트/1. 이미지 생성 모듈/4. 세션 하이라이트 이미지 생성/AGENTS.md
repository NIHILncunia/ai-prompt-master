# 4. 세션 하이라이트 이미지 생성 AGENTS

세션 하이라이트 이미지를 담당한다.

읽기 순서:
1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 세션 하이라이트 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 세션 하이라이트 공통 지침.md`
6. 장면 유형 문서 선택

상위 모듈의 제공 이미지 그림체 보존 규칙, 정식 스타일 앵커 하드 게이트와 이미지 승인 절차를 먼저 판정한다.

핵심 계약:

- 이미지 생성은 공통 승인 절차를 적용하고 마스터의 명시적 승인을 받은 뒤에만 실행한다.
- 확인된 캐릭터 레퍼런스 이미지의 그림체를 별도 스타일 변경 지시가 없는 한 그대로 따른다.
- 여러 핵심 레퍼런스의 그림체가 충돌하면 임의로 혼합하지 않고 마스터에게 기준 그림체를 확인한다.
- 정식 스타일 변경이 명시된 경우 레퍼런스는 디자인 기준, 정식 앵커는 스타일 전용 기준으로 분리한다.
