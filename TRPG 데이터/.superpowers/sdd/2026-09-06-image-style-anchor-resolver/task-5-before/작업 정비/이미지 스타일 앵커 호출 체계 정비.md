# 이미지 스타일 앵커 호출 체계 정비

## 상태

- 상태: 진행 중
- 시작일: 2026-09-06
- 작업 유형: 이미지 생성 모듈 스타일 계약·앵커 호출 구조 후속 개편

## 목적

- 붓터치 반실사의 핵심 얼굴·나이 표현·전신·마감 4앵커를 정식 체계로 반영한다.
- 이미지 기능 1~8번이 중앙 정식 스타일 호출 규칙을 통해 동일한 기준으로 스타일을 판정하게 한다.
- 제공 이미지 그림체 보존과 기능성 이미지 예외를 유지하면서 정식 스타일 누락과 중복 정의를 방지한다.

## 확정 사항

- `04. 마감 앵커 교정본.png`을 붓터치 반실사의 정식 마감 앵커로 사용한다.
- 붓터치 반실사의 활성 앵커는 `01. 핵심 얼굴`, `02. 나이 표현`, `03. 전신`, `04. 마감`이다.
- 중앙 호출 규칙을 신설하고 각 기능은 앵커 조합을 직접 소유하지 않는다.
- 신규 인물 얼굴·흉상은 `01 + 02 + 04`, 반신·전신은 `01 + 02 + 03 + 04`를 기본으로 한다.
- 제공 이미지가 있으면 디자인 기준을 우선하고, 스타일 변경 지시가 없으면 제공 이미지의 그림체를 보존한다.
- 비인물 기능에는 얼굴·나이·전신 앵커를 자동 적용하지 않는다.
- 붓터치 반실사의 고정 영어 그림체 블록과 공통 저수분 붓터치 마감 블록을 개정한다.
- 애니 페인팅의 현재 3앵커 구조는 이번 작업에서 강제로 변경하지 않는다.

## 완료 범위

- 현재 활성 문서의 3앵커·최대 2장·구 파일명 직접 참조를 조사했다.
- 이미지 기능 1~8번의 정식 스타일 적용과 기능성 예외 경계를 분류했다.
- 중앙 스타일 호출 구조와 참조 예산 축소 순서를 마스터가 승인했다.
- 설계 정본을 `docs/superpowers/specs/2026-09-06-image-style-anchor-resolver-design.md`에 작성했다.
- 실행 계획을 `docs/superpowers/plans/2026-09-06-image-style-anchor-resolver.md`에 작성했다.
- 승인된 04번 교정본을 활성 마감 앵커로 승격하고 기존 후보를 보관했다.
- 중앙 정식 스타일 호출 규칙과 붓터치 반실사·공통 마감 영어 고정 블록을 개정했다.
