# Task 1 수정 라운드 1 재검토 패키지 — 교정본

## 패키지 교정 사유

직전 재검토 패키지의 기준 스냅샷은 구현자에게 수정 요청을 보낸 뒤에 생성되어 이미 수정된 내용을 포함했다. 따라서 그 패키지의 빈 diff는 유효한 검토 근거가 아니다.

이 교정본은 다음 두 근거를 사용한다.

- 수정 전: 최초 검토 패키지 `task-1-review-package.md`에 기록된 실제 초기 문장
- 수정 후: 현재 `정식 스타일 호출 규칙.md`의 실제 문장

## 발견 1 — 제공 이미지가 있는 세션 하이라이트 조건

### 수정 전

```text
제공 이미지를 정식 스타일로 변환하거나 캐릭터 중심 세션 하이라이트를 만들 때에는 디자인 기준 이미지를 우선하고, 남은 참조 범위 안에서 주 프레이밍에 맞는 위 조합을 적용한다. 풍경에서는 얼굴·나이·전신 앵커를 적용하지 않는다.
```

### 수정 후

```text
제공 이미지를 정식 스타일로 변환하거나, 캐릭터 중심 세션 하이라이트에서 붓터치 반실사를 명시적으로 선택한 경우에는 디자인 기준 이미지를 우선하고 남은 참조 범위 안에서 주 프레이밍에 맞는 위 조합을 적용한다. 제공 이미지가 있고 명시적 정식 스타일 변환 요청이 없는 세션 하이라이트는 `제공 이미지 그림체 보존`을 적용하며 정식 앵커 조합을 적용하지 않는다. 풍경에서는 얼굴·나이·전신 앵커를 적용하지 않는다.
```

### 적용된 판정 규칙

제공 이미지가 있고 명시적 스타일 변환이 없으면 제공 이미지의 그림체를 보존하고 정식 앵커를 적용하지 않는다. 정식 스타일 앵커는 사용자가 스타일 변환을 명시했을 때만 적용한다.

## 발견 2 — 참조 예산 한 자리 충돌

### 수정 전

```text
도구 전체 이미지 참조 한도 때문에 전체 활성 앵커를 모두 사용할 수 없으면 위 순서로 자리를 배정한다. 주 구도 앵커는 얼굴 중심일 때 핵심 얼굴 앵커, 전신 중심일 때 전신 앵커다. 연령 오차 위험이 있는 인물은 나이 표현 앵커를 우선한다. 축소하면 요구사항 확인서에 실제 사용할 앵커, 제외한 앵커, 각 제외 사유를 기록한다.
```

### 수정 후

```text
도구 전체 이미지 참조 한도 때문에 전체 활성 앵커를 모두 사용할 수 없으면 위 순서로 자리를 배정한다. 주 구도 앵커는 얼굴 중심일 때 핵심 얼굴 앵커, 전신 중심일 때 전신 앵커다. 다만 디자인 기준 이미지와 마감 앵커 뒤에 한 자리만 남고, 명시 연령이 미성년·고령이거나 연령 오차가 핵심 위험이면 3·4순위를 뒤집어 나이 표현 앵커를 우선하고 주 구도 앵커를 제외한다. 그 밖의 경우에는 주 구도 앵커를 우선한다. 축소하면 요구사항 확인서에 실제 사용할 앵커, 제외한 앵커, 각 제외 사유를 기록한다.
```

### 적용된 판정 규칙

디자인 기준 이미지와 마감 앵커 뒤에 한 자리만 남으면 미성년·고령·연령 오차 핵심 위험 대상은 나이 표현 앵커를 우선하고, 그 밖에는 주 구도 앵커를 우선한다.

## 재검토 범위

1. 위 두 최초 발견이 각각 `ADDRESSED` 또는 `NOT ADDRESSED`인지 판정한다.
2. 이번 수정 범위 밖의 새 설계 제안은 하지 않는다.
3. 직전 빈 diff 패키지는 근거로 사용하지 않는다.
