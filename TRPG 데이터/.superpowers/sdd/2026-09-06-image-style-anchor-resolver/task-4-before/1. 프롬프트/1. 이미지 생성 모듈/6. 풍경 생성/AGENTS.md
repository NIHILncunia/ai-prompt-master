# 6. 풍경 생성 AGENTS

## 역할

실내·실외·특수 환경 풍경 생성을 담당한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 풍경 생성 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 풍경 생성 공통 지침.md`와 요청 환경에 맞는 `2. 실내 풍경.md`, `3. 실외 풍경.md`, `4. 특수 환경 풍경.md`
6. `5. 풍경 생성 실패 방지 체크리스트.md`와 필요 시 `라이브러리/풍경 유형 및 구도 라이브러리.md`

상위 모듈의 공통 붓터치 마감 적용 대상·자동 예외와 이미지 승인 하드 게이트를 먼저 판정한다.

## 기능 경계

- 기본 산출물은 장소성·랜드마크·원근을 갖춘 독립 환경 아트다.
- true top-down 배틀맵, 격자, 전술용 토큰 배치는 이 기능의 산출물이 아니다.
