# 최종 종합 검토 수정 라운드 1 패키지

## 수정 전 기준

- 스냅샷: `final-fix1-before/`
- 수정 대상: 중앙 호출 규칙, 공통 요구사항 확인서 작성 규칙, 공통 프롬프트 점검 지침

## 파일별 차이

1. `final-fix1-diffs/01-정식_스타일_호출_규칙.diff`
2. `final-fix1-diffs/02-2._요구사항_확인서_작성_규칙.diff`
3. `final-fix1-diffs/03-6._이미지_생성_프롬프트_점검_및_교정_지침.diff`

## 발견별 수정

1. 애니 페인팅 중앙 조합 누락
   - 얼굴·흉상: `01 + 03`
   - 반신·전신: `02 + 03`
   - 비인물 풍경: 명시적 적용일 때 `03`만 사용
   - 독립 나이 앵커 우선 예외는 독립 나이 앵커를 선언한 스타일에만 적용
   - 애니 페인팅 02는 연령별 체형 기준을 내장하지만 독립 나이 앵커가 아님을 명시
2. 공통 마감 표기 충돌
   - 기능명 기반 무조건 적용 문장 제거
   - 중앙 `그림체 적용 방식`에 따라 정식 스타일 적용, 제공 이미지 마감 보존, 사용자 지정·기능성 예외로 분기
   - 풍경의 명시적 마감 단독 경로, 토큰 마감 보존, 배틀맵·아이콘·양피지 지도 기능 계약 우선을 명시
3. P04 상대경로 오류
   - `라이브러리/스타일/...`을 `../라이브러리/스타일/...`으로 교정
   - 공통 폴더 기준 구 경로는 존재하지 않고 새 경로는 존재함을 확인

## 재검토 요청

1. 최초 최종 검토의 Important 2건과 Minor 1건을 각각 `ADDRESSED` 또는 `NOT ADDRESSED`로 판정한다.
2. 수정으로 반실사 조합, 제공 이미지 보존, P04 8검사, 12개 스타일 통제 필드가 약화되지 않았는지 확인한다.
3. 새 Critical/Important 문제가 없으면 `Ready`라고 명시한다.
