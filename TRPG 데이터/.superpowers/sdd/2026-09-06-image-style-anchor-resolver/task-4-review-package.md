## 파일별 수정 차이

`task-4-diffs/`의 `01`부터 `12`까지 모든 `.diff` 파일이 권위 검토 범위다. 번호는 `task-4-before-manifest.json`의 파일 순서와 같다.

## 필수 기능 계약

- 배틀맵: true top-down, gridless, 전술 판독성 유지
- 게임 아이콘: 1:1과 64×64 판독성 유지
- 월드 지도: 16:9 컬러풀 양피지 지도 계약 유지
- 풍경: 환경 중심 기능성 예외, 명시 요청 때 마감 앵커와 공통 마감 블록만 허용
- 전역 진입 문서: 중앙 호출 규칙만 연결하고 구도별 조합 표를 복제하지 않음
- 루트 정책 문장: 승인된 정확한 한 문장으로 교체

## 구현자 검증 요약

- 기능 2·6·7·8에서 기능성 예외 근거 확인
- 전역 문서 4개에서 중앙 호출 규칙 연결 확인
- 구 공통 앵커 수량·최대 2장·고정 조합·구 파일명 참조 0건
- 대상 12개 문서 펜스 균형 및 줄 끝 공백 검사 통과

## 검토 요청

1. Task 4 브리프와 승인 설계를 기준으로 12개 diff와 현재 파일을 모두 검토한다.
2. 배틀맵·아이콘·월드 지도의 인물 앵커 자동 적용 금지와 기능 계약 우선이 명확한지 확인한다.
3. 풍경의 마감 단독 경로가 얼굴·나이·전신 앵커 및 캐릭터 그림체 블록을 배제하는지 확인한다.
4. 전역 문서에 중앙 경로가 정확하며 과도한 구도별 표 복제가 없는지 확인한다.
5. 기존 기능 출력 계약이 약화되지 않았는지 확인한다.
6. 문제는 `Critical`, `Important`, `Minor`로 분류하고 파일·줄·근거·수정 방향을 제시한다. 문제가 없으면 `Approved`라고 명시한다.
