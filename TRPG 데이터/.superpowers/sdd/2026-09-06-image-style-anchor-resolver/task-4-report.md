## 구현 결정

- 배틀맵·게임 아이콘·월드 지도는 `사용자 지정 스타일·기능성 예외`로 판정하고 정식 인물 스타일의 얼굴·나이·전신 앵커를 자동 호출하지 않는다. 기능 전용 판독성·시점·레이아웃 계약을 우선하며, 별도 표면 마감은 기능 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.
- 풍경은 환경 중심 기능성 예외로 유지한다. 마스터가 정식 스타일의 회화적 마감을 명시한 경우에만 선택 스타일의 마감 앵커와 공통 고정 영어 마감 블록을 사용하고, 얼굴·나이·전신 앵커 및 캐릭터 드로잉 블록은 환경 전용 프롬프트에 삽입하지 않는다.
- 배틀맵의 true top-down·gridless·전술 가독성, 게임 아이콘의 1:1·64×64 판독성·배경 계약, 월드 지도의 16:9 컬러풀 양피지·무광 검정 외곽·파란 바다·200px 여백 계약을 변경하지 않았다.
- 루트의 구 공통 3앵커 문장을 스타일별 활성 구성이 다름을 밝히는 확정 문장으로 교체했다. 붓터치 반실사는 4장, 애니 페인팅은 현재 3장임을 구분하고 실제 조합과 참조 예산 축소를 중앙 호출 규칙에 위임했다.
- 프롬프트 루트 `AGENTS.md`, 프로젝트 기본 지침, 통합 마스터에는 중앙 호출 규칙 경로와 판정 책임만 추가했다. 산출물 프레이밍별 앵커 표는 전역 문서에 복제하지 않았다.

## 검증

### 브리프 지정 검색

- `rg -n '기능성 예외|인물 스타일.*자동|얼굴·나이·전신 앵커|마감 앵커' $functionalRoots`: 종료 코드 0. 내부 기능 2·6·7·8의 각 `AGENTS.md`와 마스터 프롬프트에서 기능성 예외 또는 풍경 마감 단독 경로를 확인했다.
- `rg -n '정식 스타일 호출 규칙|붓터치 반실사.*4장|애니 페인팅.*3장' $globalDocs`: 종료 코드 0. 네 전역 진입 문서의 중앙 호출 규칙 연결과 루트의 스타일별 활성 앵커 수량 문장을 확인했다.

### 예외 계약과 보존 계약

- 배틀맵·게임 아이콘·월드 지도의 공통 예외 문장 네 개를 대상 6개 문서에서 각각 6회 확인했다.
- 풍경의 `마감 앵커와 공통 고정 영어 마감 블록만 사용`, `얼굴·나이·전신 앵커 제외`, `캐릭터 드로잉 블록 제외` 문장을 대상 2개 문서에서 각각 2회 확인했다.
- 배틀맵에서 `true top-down`, `gridless`, 격자·칸 수, 전술 가독성과 이동 가능 영역 계약을 확인했다.
- 게임 아이콘에서 1:1, 단일 핵심 개념, 64×64 식별 가능 실루엣, 비투명 추상 배경 계약을 확인했다.
- 월드 지도에서 16:9, 컬러풀 양피지, 무광 검정 외곽, 파란 바다, 약 200px 여백, 지도 판독성 계약을 확인했다.
- 풍경에서 16:9 환경 아트, 장소성, 랜드마크, 원근 계약을 확인했다.

### 구 규칙 부재와 문서 구조

- 대상 12개 문서에서 구 공통 3앵커 문장, 최대 2장 규칙, 고정 `01 + 03`·`02 + 03` 조합을 검색한 결과 종료 코드 1, 출력 없음이었다.
- 대상 12개 문서에서 붓터치 반실사의 구 `02. 중립 전신 앵커.png`·`03. 마감 앵커.png` 참조를 검색한 결과 종료 코드 1, 출력 없음이었다.
- 중앙 호출 규칙 참조는 네 전역 진입 문서에 모두 존재했고, 확정 전역 정책 문장은 루트 `AGENTS.md`에 정확히 1회 존재했다.
- 보존 매니페스트와 현재 SHA-256을 비교해 대상 12개가 모두 사전 스냅샷과 달라졌음을 확인했다.
- 대상 12개 Markdown 파일의 코드 펜스 수를 검사해 모두 짝수임을 확인했다.
- 대상 12개 문서에서 줄 끝 공백을 검색한 결과 종료 코드 1, 출력 없음이었다.
- `.superpowers/sdd/2026-09-06-image-style-anchor-resolver/task-4-before/`와 `task-4-before-manifest.json`이 모두 남아 있음을 확인했다.
