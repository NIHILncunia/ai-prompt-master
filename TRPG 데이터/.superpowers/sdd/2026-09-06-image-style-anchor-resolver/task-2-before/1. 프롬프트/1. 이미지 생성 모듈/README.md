# 이미지 생성 모듈

## 기능 성격

- 고정 계약형: 반실사 포트레이트, 캐릭터 레퍼런스, 캐릭터 레퍼런스 V2
- 준고정 계약형: 배틀맵, 풍경, 월드 지도
- 가변 계약형: 세션 하이라이트, 게임 아이콘

## 내부 기능

1. 반실사 포트레이트 — 전신·흉상·완성형 VTT 토큰
2. 배틀맵 생성
3. 캐릭터 레퍼런스 생성
4. 세션 하이라이트 이미지 생성
6. 풍경 생성
7. 게임 아이콘 생성
8. 월드 지도 생성
5. 캐릭터 레퍼런스 V2 생성

내부 5번은 캐릭터 레퍼런스 V2 생성이다.

완성형 VTT 토큰은 포트레이트 전신 확정본 또는 사용자 업로드 이미지를 기준으로 생성하며, 캐릭터가 포함된 1:1 투명 PNG 한 장만 제공한다.

## 정식 스타일 체계

- `애니 페인팅`과 `붓터치 반실사`는 각각 핵심 얼굴·중립 전신·마감의 정식 앵커 3장을 사용한다.
- 한 생성에서는 구도에 맞는 정식 스타일 앵커를 최대 2장만 사용한다.
- 스타일별 고정 영어 그림체 블록과 공통 고정 영어 마감 블록은 해당 스타일 계약이 소유한다.
- 스타일 앵커는 그림체·채색·재질 표현·마감만 참조하며 인물·의상·색상·포즈·카메라·배경·구성은 참조하지 않는다.
- 캐릭터 레퍼런스 V1·V2와 세션 하이라이트는 별도 스타일 변경 지시가 없으면 제공 이미지의 그림체를 그대로 따른다.
- 요구사항 확인서와 최종 영어 프롬프트는 `공통/6. 이미지 생성 프롬프트 점검 및 교정 지침.md`의 P01~P10을 모두 통과한 뒤에만 공개·승인할 수 있다.
