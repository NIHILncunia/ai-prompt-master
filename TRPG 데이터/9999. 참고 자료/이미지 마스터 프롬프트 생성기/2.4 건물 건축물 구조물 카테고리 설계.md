# 2.4 건물 / 건축물 / 구조물 카테고리 설계

## 개요

`건물 / 건축물 / 구조물`은 장소 전체가 아니라 **하나의 인공 대상, 건축물, 구조물, 시설, 장치, 랜드마크**가 중심인 창작 이미지 카테고리입니다.

성, 신전, 마탑 같은 건축물뿐 아니라 거대 관문, 봉인 장치, 비공정, 부유 플랫폼, 공중 요새, 구조물형 골렘, 자동 수호체 같은 대상도 포함합니다.

예를 들어 `마법 도시 전체 전경`은 C에 가깝고, `도시 중앙의 거대한 마탑 하나`는 D에 가깝습니다.  
`지하 유적 전체`는 C지만, `지하 유적의 중앙 봉인문 / 거대 제단 / 고대 관문`은 D입니다.

## 다른 카테고리와의 경계

```text
C. 풍경화 / 배경 / 장소 / 세계관
- 장소 전체, 환경, 지역, 배경 공간이 중심

D. 건물 / 건축물 / 구조물
- 하나의 인공 대상, 시설, 장치, 랜드마크, 구조물 자체가 중심

B. 몬스터 / 크리처
- 생물성, 괴물성, 위협적인 생명체성이 중심

I. 메카 / 탈것 / 기계
- 기계 설계물, 탑승체, 전투 메카, 이동 장비 자체의 메커니즘이 중심
```

예시로 보면 이렇게 나눕니다.

```text
마법 도시의 전경
→ C. 풍경화 / 배경 / 장소 / 세계관

마법 도시 중앙의 거대한 마탑
→ D. 건물 / 건축물 / 구조물

전투하는 골렘 몬스터
→ B. 몬스터 / 크리처 또는 I. 메카 / 탈것 / 기계

고대 신전을 지키는 거대한 석상형 수호 골렘 구조체
→ D. 건물 / 건축물 / 구조물 가능

파일럿이 탑승하는 전투 메카
→ I. 메카 / 탈것 / 기계

하늘에 정박한 거대한 비공정 도시형 구조물
→ D. 건물 / 건축물 / 구조물 가능
```

## D 단계 구조

```text
D-1. 카테고리
D-2. 문화권 / 양식 / 세계관
  - D-2-1. 문화권 / 미학권
  - D-2-2. 세부 장르 / 양식
D-3. 중심 대상 유형
  - D-3-1. 상위 대상 분류
  - D-3-2. 세부 대상 선택
D-4. 대상 상세 설계

D-6. 레이아웃 / 예상 결과물
```

이 흐름의 핵심은 이렇습니다.

```text

D-3에서 무엇을 만들지 정한다.
D-4에서 실제 구조와 디테일을 정한다.
```


# D-6. 레이아웃 / 예상 결과물


