# 2.10 지도 / 맵 / 배틀맵 카테고리 설계

## 개요

`지도 / 맵 / 배틀맵`은 세계, 대륙, 도시, 마을, 던전, 건물 내부, 전투 공간, 우주 / 성계 구조를 시각적으로 정리해 보여주는 카테고리입니다.

이 카테고리의 핵심은 분위기보다 **공간 구조, 위치 관계, 연결 방식, 지형 배치, 전술 공간 설계**입니다.  
즉 “멋진 풍경”이 아니라 “어디에 무엇이 있고 어떻게 연결되는가”를 보여주는 것이 중심입니다.

이 카테고리는 어디까지나 **이미지 생성용**입니다.  
별도 툴 세팅이나 시스템 데이터가 아니라, 바로 사용할 수 있는 **지도 이미지**를 만드는 방향으로 설계합니다.

이 카테고리는 다음 결과물을 모두 포함합니다.

```text
- 세계지도
- 대륙 상세 지도
- 정치 / 세력권 지도
- 지형 지도
- 도시 지도
- 마을지도
- 던전지도
- 건물 평면도
- 배틀맵
- 모듈형 던전맵
- 모듈형 전투맵
- 우주 / 성계 지도
- 참조 이미지 기반 지도 재구성
```

---

## 다른 카테고리와의 경계

```text
2.3 풍경화 / 배경 / 장소 / 세계관
- 장소를 풍경 이미지로 보여준다.
- 분위기, 조명, 공간감, 경관이 중심이다.

2.4 건물 / 건축물 / 구조물
- 단일 건물, 구조물, 시설, 랜드마크가 중심이다.

2.5 장면 / 서사 일러스트
- 사건, 갈등, 전투, 감정선, 행동이 중심이다.

2.10 지도 / 맵 / 배틀맵
- 지형, 배치, 연결, 구조, 이동 경로, 전술 공간이 중심이다.
```

예시는 이렇게 나뉩니다.

```text
안개 낀 숲 풍경
→ 2.3 풍경화 / 배경 / 장소 / 세계관

숲이 포함된 권역 구조 지도
→ 2.10 지도 / 맵 / 배틀맵

거대한 성채 외관
→ 2.4 건물 / 건축물 / 구조물

성채 내부 평면도
→ 2.10 지도 / 맵 / 배틀맵

보스와 싸우는 장면
→ 2.5 장면 / 서사 일러스트

보스전이 벌어지는 전투용 맵
→ 2.10 지도 / 맵 / 배틀맵
```

# 2.10-2. 지도 용도 / 범위

## 2.10-2-1. 지도 용도

### 질문

```text
이 지도는 어떤 용도로 사용할까요?
```

### 선택지

```text
- 세계관 설정용 지도
- 감상용 장식 지도
- 플레이어용 지도
- 마스터용 지도
- 정치 / 세력 설명용 지도
- 도시 구조 설명용 지도
- 마을 구조 설명용 지도
- 던전 구조 설명용 지도
- 건물 구조 설명용 지도
- 전투용 지도
- 모듈형 지도 세트
- 참조 이미지 기반 재구성 지도
- 직접 입력
- 자동 / 맡기기
```

### 용도별 해석

```text
세계관 설정용 지도
- 전체 구조와 분위기를 보여주는 것이 중요하다.

플레이어용 지도
- 정보량을 줄이고 비밀 요소를 최소화하는 것이 좋다.

마스터용 지도
- 비밀 통로, 숨겨진 방, 함정, 번호, 메모성 구조를 포함할 수 있다.

전투용 지도
- 실제 전투 공간, 이동 구조, 엄폐물, 장애물, 지형 요소가 중요하다.

모듈형 지도 세트
- 여러 장을 이어붙일 수 있는 구조와 연결부 정합성이 중요하다.
```

# 2.10-3. 지도 유형 / 시점 / 정보 표현

## 2.10-3-1. 지도 유형

### 질문

```text
어떤 종류의 지도 형태로 만들까요?
```

### 선택지

```text
- 세계지도
- 대륙 상세 지도
- 정치 / 세력권 지도
- 지형 지도
- 도시 지도
- 마을지도
- 던전지도
- 건물 평면도
- 배틀맵
- 모듈형 던전맵
- 모듈형 전투맵
- 우주 / 성계 지도
- 참조 이미지 기반 지도 재구성
- 직접 입력
- 자동 / 맡기기
```

### 유형별 해석

```text
세계지도
- 세계 전체 구조와 대륙 배치를 중심으로 한다.

대륙 상세 지도
- 대륙 하나 또는 대륙 일부를 자세히 보여준다.
- 자연지형, 주요 거점, 도로, 세부 권역 구조를 담는다.

정치 / 세력권 지도
- 국가, 왕국, 제국, 세력, 점령지, 영향권, 분쟁 구역을 색상이나 경계로 보여준다.

지형 지도
- 정치 요소보다 산맥, 강, 숲, 늪, 사막, 해안선 같은 자연지형을 중심으로 한다.

도시 지도
- 항구도시, 수도, 성채도시, 상업도시, 종교도시 등을 포함할 수 있다.

마을지도
- 도시보다 작은 생활권 구조를 보여준다.

던전지도
- 던전 전체 구조를 축약해서 보여준다.
- 방과 복도의 연결 관계가 핵심이다.

건물 평면도
- 성, 탑, 저택, 신전, 연구소 같은 건물 내부 구조를 보여준다.

배틀맵
- 실제 전투 공간을 상세하게 보여준다.
- 장소는 하위에서 선택한다.

모듈형 던전맵 / 모듈형 전투맵
- 여러 장을 이어붙여 사용할 수 있는 구조의 맵이다.

우주 / 성계 지도
- 성계, 항성계, 궤도, 우주 구역, 성간 관계를 보여준다.
```

## 2.10-3-3. 텍스트 / 라벨 사용 여부

### 질문

```text

```

### 선택지

```text
- 텍스트 없음
- 라벨 없음
- 라벨 자리만 표시
- 읽을 수 없는 장식 문자
- 숫자 / 기호만 사용
- 주요 지역 라벨 포함

- 직접 입력 라벨 사용
- 자동 / 맡기기
```

### 처리 규칙

```text
별도 요청이 없으면 텍스트와 라벨은 넣지 않는다.

정확한 지명, 좌표, 설명 텍스트가 필요하면 후편집 전제를 두는 것이 좋다.

장식용 지도나 감상용 지도는 라벨 없음이 안정적이다.

마스터용 지도라면 숫자, 기호, 간단한 구역 표시를 사용할 수 있다.
```

# 2.10-5. 배틀맵 / 모듈형 맵 세부 설계

## 개요

배틀맵은 던전 내부만이 아니라 숲, 늪, 광장, 도시 골목, 성 내부, 동굴, 사막, 설원 등 다양한 장소를 포함합니다.

`던전 배틀맵`과 `일반 배틀맵`은 상위에서 분리하지 않습니다.  
대신 **배틀맵을 선택한 뒤, 장소를 세부 선택**하게 합니다.
