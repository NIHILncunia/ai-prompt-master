# 2.8 메카 / 탈것 / 기계 카테고리 설계

## 개요

`메카 / 탈것 / 기계`는 이동, 탑승, 조종, 작동, 자동화, 전투, 운송, 생산, 정비, 탐사 같은 **기계적 기능**이 중심인 창작 이미지 카테고리입니다.

이 카테고리는 단순한 건물이나 소품이 아니라, **움직이는 기계**, **탑승 가능한 탈것**, **조종 가능한 메카**, **자동으로 작동하는 기계 장치**, **산업 기계**, **전쟁 병기**, **마도공학 장치**, **SF 로봇 / 드론 / 우주선** 등을 담당합니다.

중요한 점은 “크다”가 아니라 **작동성**입니다.  
작더라도 로봇, 드론, 자동 장치라면 2.8이고, 거대하더라도 주된 성격이 고정 랜드마크라면 2.4입니다.

---

## 다른 카테고리와의 경계

```text
2.4 건물 / 건축물 / 구조물
- 고정 구조물, 시설, 랜드마크, 거대 장치, 구조물형 인공체가 중심

2.6 아이템 / 무기 / 유물 / 소품
- 손에 들 수 있는 단일 소품, 작은 장치, 아이콘형 오브젝트가 중심

2.7 의상 / 장비 디자인
- 사람이 입는 의상, 갑옷, 슈트, 착용 장비가 중심

2.8 메카 / 탈것 / 기계
- 조종, 탑승, 이동, 구동, 자동화, 기계 작동성이 중심

2.2 몬스터 / 크리처
- 생물성, 괴물성, 생태, 육체 구조가 중심
```

예시로 보면 이렇게 나뉩니다.

```text
거대한 봉인 장치
→ 2.4 건물 / 건축물 / 구조물

휴대용 마도 장치
→ 2.6 아이템 / 무기 / 유물 / 소품

조종 가능한 마도공학 전투 기계
→ 2.8 메카 / 탈것 / 기계

입는 강화복
→ 2.7 의상 / 장비 디자인

탑승형 파워드 메카
→ 2.8 메카 / 탈것 / 기계

공중에 떠 있는 성
→ 2.4 또는 2.8

공중에 떠 있는 성이 움직이고 조종되는 이동 요새라면
→ 2.8 메카 / 탈것 / 기계

생물형 드래곤
→ 2.2 몬스터 / 크리처

기계 드래곤형 전투 병기
→ 2.8 메카 / 탈것 / 기계
```

경계 기준은 이렇게 둡니다.

```text
고정된 구조물인가?
→ 2.4 건물 / 건축물 / 구조물

손에 드는 소형 장치인가?
→ 2.6 아이템 / 무기 / 유물 / 소품

몸에 입는 장비인가?
→ 2.7 의상 / 장비 디자인

움직이고, 탑승하고, 조종하고, 구동되는 기계인가?
→ 2.8 메카 / 탈것 / 기계

생물 자체인가?
→ 2.2 몬스터 / 크리처
```

## 자동 처리 규칙

```text
디자인 확인이 중요하면 정면 / 측면 / 후면 턴어라운드나 3/4 시점 설정화를 우선한다.
기계 구조 설명이 중요하면 설계도, 단면도, 장비 구성품 분해도를 우선한다.
탑승감과 운용 방식이 중요하면 조종석 / 콕핏 상세화를 포함한다.
스케일이 중요하면 인물 또는 환경과의 비교 시트를 포함한다.
감상용 이미지가 필요하면 격납고 전시형 이미지, 출격 장면, 전투 장면 키아트를 우선한다.
```
