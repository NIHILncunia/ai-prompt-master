# 2.9 상징 / 문장 / 엠블럼 / 로고 카테고리 설계

## 개요

`상징 / 문장 / 엠블럼 / 로고`는 창작 세계의 집단, 장소, 권역, 대륙, 국가, 세계관, 작품, 프로젝트, 게임, 소설, 만화, 브랜드를 대표하는 시각적 표식을 설계하는 카테고리입니다.

이 카테고리는 단순히 가문 문장이나 기사단 엠블럼만 다루지 않습니다.  
왕국 문장, 제국 문장, 길드 마크, 종교 상징, 마법 문양, 지역 상징, 대륙 상징, 세계관 로고, 게임 로고, 소설 로고, 만화 / 웹툰 로고, 프로젝트 로고, 창작 브랜드 로고까지 포함합니다.

핵심은 “무엇을 대표하는가”입니다.  
대표 대상이 가문이면 가문 문장이 되고, 지역이면 지역 상징이 되며, 세계관 전체라면 세계관 로고가 됩니다.

이 카테고리는 다음 두 계열을 모두 포함합니다.

```text
문장 / 엠블럼 계열
- 가문 문장
- 국가 문장
- 기사단 문장
- 길드 마크
- 종교 상징
- 마법 문양
- 지역 / 대륙 상징

로고 / 타이틀 계열
- 세계관 로고
- 게임 로고
- 소설 로고
- 만화 / 웹툰 로고
- 프로젝트 로고
- 창작 브랜드 로고
- 타이틀 로고
```

기본적으로 텍스트는 사용하지 않는 편이 안정적입니다.  
다만 게임 로고, 소설 로고, 만화 로고, 세계관 로고처럼 제목성이 중요한 경우에는 텍스트 / 타이틀 요소를 별도로 선택할 수 있게 합니다.

정확한 글자 형태가 중요한 로고는 이미지 생성 후 별도 편집이 필요할 수 있습니다.  
따라서 이 카테고리에서 생성하는 로고는 기본적으로 **창작용 로고 콘셉트 / 타이틀 디자인 방향성**으로 다룹니다.

## 다른 카테고리와의 경계

```text
2.3 풍경화 / 배경 / 장소 / 세계관
- 장소 전체의 분위기, 공간감, 세계관 경관이 중심

2.4 건물 / 건축물 / 구조물
- 단일 건축물, 구조물, 시설, 랜드마크가 중심

2.6 아이템 / 무기 / 유물 / 소품
- 실제 물체 하나가 중심
- 예: 왕관, 성배, 인장 반지, 문장패

2.9 상징 / 문장 / 엠블럼 / 로고
- 물체가 아니라 대표 표식, 상징, 문장, 엠블럼, 로고 디자인이 중심

2.10 지도 / 맵 / 배틀맵
- 지형, 지역, 위치 정보, 이동 경로, 전술 공간이 중심
```

예시로 보면 이렇게 나눕니다.

```text
왕관 하나
→ 2.6 아이템 / 무기 / 유물 / 소품

왕가를 상징하는 사자와 왕관 문장
→ 2.9 상징 / 문장 / 엠블럼 / 로고

성문 위에 새겨진 거대한 문양 장식 구조물
→ 2.4 건물 / 건축물 / 구조물 가능

왕국 전체 지도
→ 2.10 지도 / 맵 / 배틀맵

왕국 국기 / 문장 / 인장
→ 2.9 상징 / 문장 / 엠블럼 / 로고

빙설 대륙을 대표하는 설화와 북극성 상징
→ 2.9 상징 / 문장 / 엠블럼 / 로고

세계관 전체를 대표하는 타이틀 로고
→ 2.9 상징 / 문장 / 엠블럼 / 로고
```

## 선택값

```text
상징 / 문장 / 엠블럼 / 로고
```

## 설명

```text
이 이미지는 창작 세계의 개인, 집단, 장소, 지역, 대륙, 국가, 세계관, 작품, 프로젝트, 게임, 소설, 만화, 브랜드를 대표하는 상징, 문장, 엠블럼, 인장, 문양, 로고, 타이틀 표식을 중심으로 한다.

최종 영문 프롬프트는 대표 대상, 표식 유형, 핵심 모티프, 상징 근거, 색상, 형태, 장식 수준, 텍스트 사용 여부, 사용처를 명확히 반영해야 한다.
```

조직뿐 아니라 지역, 대륙, 세계관, 작품, 프로젝트까지 포함합니다.

```text
- 왕가 / 황가
- 길드

- 용병단

- 마법 학파
- 학회 / 연구기관
- 비밀조직

- 군단 / 군대
- 상단 / 상회
- 문파 / 무림 세력
- 종족 / 부족

- 애니메이션

- 자동 / 맡기기
```

## 대표 범위별 해석

```text
개인 / 영웅
- 개인 문장, 영웅 상징, 고유 인장, 캐릭터 심볼

가문 / 왕가
- 혈통, 권위, 전통, 계승, 귀족성 강조

조직 / 길드 / 기사단
- 역할, 직능, 규율, 집단 정체성 강조

종교 / 신격
- 신성성, 교리, 신격의 권능, 신앙의 방향성 강조

도시 / 지역 / 대륙
- 지형, 기후, 문화, 역사, 특산, 지역 정체성 강조

국가 / 왕국 / 제국
- 정치 체계, 군사성, 권력, 국격, 상징 동물이나 문장 강조

세계관 전체
- 작품 전체를 대표하는 핵심 상징, 장르, 분위기, 세계 구조 강조

게임 / 소설 / 만화 / 프로젝트
- 타이틀성, 브랜딩, 장르 인식, 작품의 첫인상 강조
```

## 자동 처리 규칙

```text
대표 대상이 자동일 경우, 사용자가 입력한 세계관, 조직 성격, 장소 성격, 작품 분위기에 맞춰 적절한 대표 범위를 설정한다.

상징은 해당 대상의 정체성과 가치관을 직관적으로 드러내야 한다.
```

```text

- 텍스트 없이도 성립 가능

게임 로고
- 장르 인식, 강한 실루엣, 타이틀 가독성, 상업적 브랜딩 감각 강조

소설 로고
- 장르 분위기, 서사성, 제목의 문학적 인상, 표지 적용성 강조

만화 / 웹툰 로고
- 장르적 즉시성, 시각적 개성, 표지 / 썸네일 적용성 강조

프로젝트 / 브랜드 로고
- 재사용성, 단순성, 인식성, 다양한 매체 적용성 강조
```

```text

- 원형, 단색, 음각, 왁스 봉인 느낌이 잘 맞는다.

- 작은 크기에서도 식별 가능해야 하므로 단순한 형태와 강한 대비가 중요하다.

웹사이트 / 프로젝트 로고
- 현대적이고 단순한 벡터 스타일, 재사용성, 배경 적응성이 중요하다.

지역 / 대륙 상징
- 지형, 자연, 역사, 문화, 색상으로 정체성을 표현하는 것이 중요하다.
```

## 2.9-5-3. 텍스트 사용 여부

