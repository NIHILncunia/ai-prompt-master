# 2.6 아이템 / 무기 / 유물 / 소품 카테고리 설계

## 개요

`아이템 / 무기 / 유물 / 소품`은 손에 들 수 있거나, 장면 속 핵심 물체가 되거나, 단일 오브젝트로서 디자인 가치가 있는 대상을 중심으로 하는 카테고리입니다.

검, 창, 활, 지팡이, 마도서, 포션, 반지, 왕관, 성배, 유물, 열쇠, 부적, 가면, 기계 부품, 의식용 물건, 보석, 코어 장치 같은 대상이 포함됩니다.

이 카테고리는 단순 설정화만 담당하는 것이 아닙니다.  
**오브젝트 일러스트**, **배경 포함 아이템 연출**, **게임 아이콘**, **인벤토리 아이콘**까지 함께 다뤄야 합니다.

---

## 다른 카테고리와의 경계

```text
A. 캐릭터 / 인물
- 인물 자체가 중심

D. 건물 / 건축물 / 구조물
- 대형 구조물, 시설, 장치, 랜드마크가 중심

2.6 아이템 / 무기 / 유물 / 소품
- 단일 소형~중형 오브젝트가 중심

2.7 의상 / 장비 디자인
- 착용형 장비, 의상 세트, 전신 착장 디자인이 중심

2.8 메카 / 탈것 / 기계
- 메카닉 설계, 탑승체, 대형 기계가 중심
```

예시로 보면 이렇게 나뉩니다.

```text
전설의 검 한 자루
→ 2.6 아이템 / 무기 / 유물 / 소품

전사가 입는 갑옷 풀세트
→ 2.7 의상 / 장비 디자인

거대한 봉인 장치
→ D. 건물 / 건축물 / 구조물

마법 검의 인벤토리 아이콘
→ 2.6 아이템 / 무기 / 유물 / 소품
```

## 2.6-3-4. 아이콘 배경 방식

이 항목은 `게임 아이콘`, `인벤토리 아이콘`, `카드 / 보상형 아이콘`일 때 특히 중요합니다.

```text
- 배경 없음
- 단순 단색 배경
- 단순 그라데이션 배경
- 약한 발광 배경
- 아이템 분위기에 맞는 최소 배경
- 작은 맥락 배경 포함
- 직접 입력
- 자동 / 맡기기
```

### 해석 기준

```text
배경 없음
- 게임 아이콘 느낌을 가장 강하게 줌

단순 그라데이션 / 발광 배경
- 아이템 가독성을 해치지 않으면서 분위기 부여

작은 맥락 배경 포함
- 완전한 풍경은 아니고, 아이템 성격만 암시하는 최소 연출
```

```text

- 영웅

```

```text

프레임이 있으면 아이템의 세계관, 희귀도, 스타일에 맞는 프레임으로 연출한다.
```
