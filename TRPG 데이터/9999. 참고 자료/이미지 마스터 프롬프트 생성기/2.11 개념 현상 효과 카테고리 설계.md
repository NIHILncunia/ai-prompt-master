# 2.11 개념 / 현상 / 효과 카테고리 설계

## 개요

`개념 / 현상 / 효과`는 형체가 있는 인물, 몬스터, 장소, 건축물, 아이템, 장비, 기계, 상징, 지도보다 **비물질적인 현상, 에너지, 마법 효과, 상태, 분위기, 추상 개념의 시각화**가 중심인 창작 이미지 카테고리입니다.

이 카테고리는 불꽃, 번개, 검은 안개, 신성한 후광, 저주, 축복, 사령 기운, 차원 균열, 공간 왜곡, 시간 왜곡, 마법진, 오라, 충격파, 스킬 이펙트, 상태이상 효과, UI용 효과 아이콘, 추상 개념 아트 등을 다룹니다.

핵심은 “무엇이 존재하는가”가 아니라 **무엇이 일어나고 있는가**, 또는 **보이지 않는 개념을 어떤 시각 언어로 보여줄 것인가**입니다.

---

## 다른 카테고리와의 경계

```text
2.1 캐릭터 / 인물
- 인물의 외형, 디자인, 포즈, 캐릭터성이 중심이다.

2.2 몬스터 / 크리처
- 생물, 괴물, 크리처의 신체 구조와 위협성이 중심이다.

2.3 풍경화 / 배경 / 장소 / 세계관
- 장소 전체의 공간감, 경관, 분위기가 중심이다.

2.4 건물 / 건축물 / 구조물
- 단일 건축물, 장치, 관문, 시설, 구조물이 중심이다.

2.5 장면 / 서사 일러스트
- 사건, 행동, 갈등, 감정선, 이야기의 순간이 중심이다.

2.6 아이템 / 무기 / 유물 / 소품
- 단일 오브젝트, 무기, 유물, 소품 자체가 중심이다.

2.7 의상 / 장비 디자인
- 착용물, 의복, 방어구, 장비 세트가 중심이다.

2.8 메카 / 탈것 / 기계
- 작동성, 이동성, 탑승성, 조종성, 기계 구조가 중심이다.

2.9 상징 / 문장 / 엠블럼 / 로고
- 어떤 대상을 대표하는 표식, 문장, 로고, 상징 디자인이 중심이다.

2.10 지도 / 맵 / 배틀맵
- 위치 관계, 공간 구조, 지형 배치, 전술 공간이 중심이다.

2.11 개념 / 현상 / 효과
- 비물질적 현상, 에너지, 마법 효과, 상태, 추상 개념 자체의 시각화가 중심이다.
```

예시는 다음처럼 나뉩니다.

```text
마법사가 불꽃 주문을 적에게 발사하는 장면
→ 2.5 장면 / 서사 일러스트

불꽃 주문 효과 자체의 디자인 시트
→ 2.11 개념 / 현상 / 효과

저주받은 검 한 자루
→ 2.6 아이템 / 무기 / 유물 / 소품

검에서 흘러나오는 검은 저주 오라
→ 2.11 개념 / 현상 / 효과

성자의 초상화와 신성한 후광
→ 2.1 캐릭터 / 인물

신성한 후광 효과 자체의 시각 디자인
→ 2.11 개념 / 현상 / 효과

도시를 뒤덮은 검은 안개 속 재난 장면
→ 2.5 장면 / 서사 일러스트 또는 2.3 풍경화 / 배경 / 장소 / 세계관

검은 안개 효과 자체의 디자인
→ 2.11 개념 / 현상 / 효과

마법 문양이 들어간 길드 엠블럼
→ 2.9 상징 / 문장 / 엠블럼 / 로고

마법진이 발동하며 빛과 룬이 떠오르는 효과
→ 2.11 개념 / 현상 / 효과

거대한 차원 관문 구조물
→ 2.4 건물 / 건축물 / 구조물

허공이 찢어지는 차원 균열 현상
→ 2.11 개념 / 현상 / 효과
```

```text

- 캐릭터 외형을 새로 디자인하지 않고, 캐릭터 주변의 효과나 오라만 설계한다.

- 장면 전체를 재구성하지 않고, 장면 속 효과의 색상, 밀도, 움직임, 분위기만 참고한다.

- 구도, 단순화 수준, 색상 대비, UI 가독성을 참고한다.

- 지형 구조나 공간 배치를 바꾸지 않고, 그 위에 적용될 환경 효과나 오버레이 효과를 중심으로 한다.
```
