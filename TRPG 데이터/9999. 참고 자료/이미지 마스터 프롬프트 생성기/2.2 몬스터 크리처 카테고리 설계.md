# 2.2 몬스터 / 크리처 카테고리 설계

## 개요

`몬스터 / 크리처`는 생물 구조, 위협성, 이형성, 크기감, 서식 환경, 특수 능력이 중심인 창작 이미지 카테고리입니다.

괴수, 악마, 언데드, 용형 생물, 신화 생물, 이형 생명체, 기계 생물, 기생체, 보스 몬스터, 야생 크리처 등을 포함합니다.

인간형 외형과 캐릭터성이 중심이면 `A. 캐릭터 / 인물`로 보냅니다.  
생물성, 괴물성, 위협성, 구조 자체가 중심이면 `B. 몬스터 / 크리처`로 봅니다.

## B 단계 구조

```text
B-1. 카테고리
B-2. 장르 / 세계관
B-3. 중심 대상 / 크리처 상세 설계
B-4. 배경 / 서식지 / 무대
B-5. 분위기 / 위협감
B-6. 레이아웃 / 예상 결과물
```

B-3 안에 몬스터 전용 상세 설계 블록을 둡니다.  
단계 수는 6개로 유지하되, 필요한 생물 구조 정보는 B-3 내부에서 처리합니다.

---

# B-1. 카테고리

## 선택값

```text
몬스터 / 크리처
```

## 설명

```text
이 이미지는 몬스터, 크리처, 괴수, 이형 생물, 기계 생물, 보스급 존재, 신화 생물 등을 중심으로 한다.
최종 영문 프롬프트는 크리처의 신체 구조, 크기감, 질감, 위협성, 특수 능력, 서식 환경을 명확히 반영해야 한다.
```

```text
- 직접 입력
```

```text

장르가 자동일 경우, 크리처의 외형 특징과 위협성에 가장 잘 맞는 세계관 방향을 선택한다.

```

```text
이 몬스터 / 크리처의 분위기와 위협감은 어떤 쪽인가요?
```

# B-6. 레이아웃 / 예상 결과물

## 질문

```text
어떤 형태의 몬스터 / 크리처 이미지로 만들까요?
```

## 선택지

```text
- 전신 몬스터 컨셉아트
- 위협 연출형 몬스터 일러스트
- 보스 몬스터 키아트
- 거대 괴수 스케일 강조형
- 크리처 생태 컨셉아트
- 크리처 구조 / 해부 시트
- 크리처 변이 / 진화 단계 시트
- 크리처 턴어라운드 시트
```

## 자동 처리 규칙

```text

디자인 확인이 중요하면 전신 컨셉아트 또는 구조 시트를 우선하고, 연출이 중요하면 키아트나 위협 연출형을 우선한다.
```
