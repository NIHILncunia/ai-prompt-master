# 2.5 장면 / 서사 일러스트 카테고리 설계

## 개요

`장면 / 서사 일러스트`는 단일 인물, 몬스터, 장소, 구조물, 아이템 자체보다 **사건, 행동, 갈등, 감정선, 이야기의 한 순간**이 중심인 창작 이미지 카테고리입니다.

전투, 대치, 의식, 탐험, 발견, 재회, 배신, 희생, 도주, 승리, 몰락, 조우, 공포, 결말 같은 **서사적 순간**을 한 장의 이미지로 표현할 때 사용합니다.

이 카테고리는 인물 1명만을 전제로 하지 않습니다.  
여러 명의 인물이 등장할 수 있고, 각 인물은 서로 다른 방식으로 설정될 수 있습니다.

예를 들어 다음과 같은 구성이 가능해야 합니다.

```text
- 인물 1: 캐릭터 레퍼런스 시트 참조
- 인물 2: 캐릭터 레퍼런스 시트 참조
- 인물 3: AI가 새 인물 생성
- 배경: C 카테고리에서 만든 배경 이미지 참조
```

즉 E 카테고리는 기존에 만든 **캐릭터 레퍼런스 시트**, **배경 이미지**, **구조물 이미지**, **오브젝트 설정** 등을 조합해 새로운 장면 일러스트로 재구성할 수 있어야 합니다.

---

## 다른 카테고리와의 경계

```text
A. 캐릭터 / 인물
- 인물의 디자인, 외형, 포즈, 매력, 설정화가 중심

B. 몬스터 / 크리처
- 괴물의 생물 구조, 위협성, 형태, 생태가 중심

C. 풍경화 / 배경 / 장소 / 세계관
- 장소 전체의 공간감, 배경, 세계관 경관이 중심

D. 건물 / 건축물 / 구조물
- 단일 인공 구조물, 장치, 랜드마크, 구조물형 대상이 중심

E. 장면 / 서사 일러스트
- 사건, 행동, 갈등, 감정, 관계, 이야기의 순간이 중심
```

예시로 보면 이렇게 나뉩니다.

```text
백발 여성 검사의 전신 디자인
→ A. 캐릭터 / 인물

백발 여성 검사가 폭우 속에서 숙적과 검을 맞대는 순간
→ E. 장면 / 서사 일러스트

거대한 용의 생물 구조 설정화
→ B. 몬스터 / 크리처

용이 성벽 위로 내려앉고 병사들이 도망치는 장면
→ E. 장면 / 서사 일러스트

폐허가 된 왕국의 거리 풍경
→ C. 풍경화 / 배경 / 장소 / 세계관

폐허가 된 왕국의 거리에서 왕이 무릎 꿇는 장면
→ E. 장면 / 서사 일러스트

고대 신전의 거대한 봉인문 설정화
→ D. 건물 / 건축물 / 구조물

봉인문 앞에서 두 인물이 대치하고, 봉인이 깨지기 시작하는 장면
→ E. 장면 / 서사 일러스트
```

---

## E 단계 구조

```text
E-1. 카테고리
E-2. 장르 / 세계관
E-3. 장면 유형 / 핵심 사건
E-4. 등장 주체 / 배경 / 관계 / 행동 설계
E-5. 감정선 / 긴장감 / 분위기
E-6. 레이아웃 / 예상 결과물
```

이 흐름의 핵심은 다음과 같습니다.

```text
E-2에서 세계관을 정한다.
E-3에서 어떤 사건인지 정한다.
E-4에서 누가 등장하며, 인물과 배경을 어떻게 설정할지 정한다.
E-5에서 감정선과 긴장감을 정한다.
E-6에서 장면을 어떤 화면으로 보여줄지 정한다.
```

# E-1. 카테고리

## 선택값

```text
장면 / 서사 일러스트
```

## 설명

```text
이 이미지는 이야기 속 특정 순간, 사건, 행동, 갈등, 관계, 감정선을 중심으로 한다.
최종 영문 프롬프트는 등장 주체, 사건, 행동, 관계, 배경, 감정선, 카메라 구도, 장면의 순간성을 명확히 반영해야 한다.
```

## 질문

```text
이 장면은 어떤 장르나 세계관에 속하나요?
```

## 선택지

```text
- 정통 판타지
- 다크 판타지
- 무협
- 동양 판타지
- 현대 판타지
- 현대 현실풍
- SF / 미래 세계
- 사이버펑크
- 포스트 아포칼립스
- 신화 / 전설풍
- 고딕 호러
- 코즈믹 호러
- 초현실 / 몽환
- 스팀펑크 / 마도공학
- 전쟁 / 밀리터리풍
- 직접 입력
- 자동 / 맡기기
```

## 자동 처리 규칙

```text
장면의 핵심 사건, 등장 주체, 분위기에 어울리는 장르와 세계관을 채팅형 AI가 적절히 보완한다.
장르가 자동일 경우, 사건의 성격과 감정선에 가장 잘 맞는 세계관 방향을 선택한다.
```

# E-4. 등장 주체 / 배경 / 관계 / 행동 설계

## 질문

```text
이 장면에는 누가 등장하며, 각 인물과 배경은 어떻게 정할까요?
```

E-4는 장면의 실질적인 중심입니다.  
특히 여러 인물과 참조 시트를 다룰 수 있어야 하므로 아래처럼 세분화합니다.

```text
E-4-1. 등장 인물 수 / 그룹 구성
E-4-2. 인물별 설정 방식
E-4-3. 배경 / 장소 설정 방식
E-4-4. 관계 / 갈등 구조
E-4-5. 핵심 행동
E-4-6. 시선 / 초점
E-4-7. 장면의 순간
E-4-8. 중요 오브젝트
```

---

## E-4-1. 등장 인물 수 / 그룹 구성

### 질문

```text
이 장면에는 몇 명 정도가 등장하나요?
```

### 선택지

```text
- 인물 없음
- 1명
- 2명
- 3명
- 4~5명
- 소규모 파티
- 군중
- 대규모 집단
- 직접 입력
- 자동 / 맡기기
```

### 처리 규칙

```text
선택된 인물 수에 따라 인물 슬롯을 생성한다.

1명을 선택하면 인물 1 슬롯을 생성한다.
2명을 선택하면 인물 1, 인물 2 슬롯을 생성한다.
3명을 선택하면 인물 1, 인물 2, 인물 3 슬롯을 생성한다.

4~5명 또는 소규모 파티를 선택하면 주요 인물 슬롯과 보조 인물 슬롯을 생성한다.
군중 또는 대규모 집단을 선택하면 대표 인물 / 집단 성격 / 배치 방식 중심으로 처리한다.
```

## E-4-2. 인물별 설정 방식

각 인물은 동일한 방식으로 설정될 필요가 없습니다.  
어떤 인물은 AI가 새로 만들고, 어떤 인물은 사용자가 직접 설명하고, 어떤 인물은 캐릭터 레퍼런스 시트를 참조할 수 있습니다.

예시는 다음과 같습니다.

```text
인물 1: 캐릭터 레퍼런스 시트 참조
인물 2: 캐릭터 레퍼런스 시트 참조
인물 3: AI가 새 인물 생성
```

### 인물 슬롯별 공통 질문

```text
인물 N은 어떻게 정할까요?
```

### 인물 슬롯별 선택지

```text
- AI가 새 인물 생성
- 사용자가 직접 입력

- 자동 / 맡기기
```

```text
- 장면 내 행동
```

```text
- 주인공
```

## 인물 설정 방식별 처리 규칙

### AI가 새 인물 생성

이 선택지를 고르면, 채팅형 AI가 장면에 맞는 인물을 새로 설계합니다.

마스터 프롬프트 삽입 지시:

```text
No character reference sheet is provided for this character.
Create a new character design that fits the selected genre, event, emotional tone, relationship structure, and scene composition.
```

---

### 사용자가 직접 입력

이 선택지를 고르면, 사용자가 입력한 인물 설명을 기준으로 장면에 반영합니다.

UI 안내 메시지:

```text
이 인물의 외형, 의상, 장비, 성격, 역할, 장면 내 행동을 직접 입력해 주세요.
입력한 내용은 마스터 프롬프트에 인물 설명으로 포함됩니다.
```

마스터 프롬프트 삽입 지시:

```text
Use the user's written description as the primary reference for this character.
Preserve the described appearance, outfit, equipment, role, personality, and intended action when creating the English prompt.
```

---

### 캐릭터 레퍼런스 시트 참조

이 선택지를 고르면, 해당 인물 슬롯은 레퍼런스 시트 첨부가 필요합니다.

UI 안내 메시지:

