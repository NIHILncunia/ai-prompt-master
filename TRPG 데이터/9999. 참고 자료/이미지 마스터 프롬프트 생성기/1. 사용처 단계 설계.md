# 1. 사용처 단계 설계

## 문서 개요

이 문서는 `target_usage_step(1).json`의 내용을 바탕으로 정리한 **1번 사용처 선택 단계**의 Markdown 문서입니다.

이 단계는 사용자가 실제로 영문 프롬프트를 사용할 이미지 생성 모델, 이미지 생성 서비스, 또는 모델 계열을 선택하는 최상위 분기입니다.

---

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스키마 버전 | `0.1.0` |
| 프로젝트 | `creative_image_master_prompt_builder` |
| 단계 ID | `target_usage` |
| 단계 순서 | `1` |
| 단계 제목 | 사용처 |
| 질문 | 어느 이미지 모델에 사용할 영문 프롬프트를 만들까요? |
| 필수 여부 | `True` |
| 선택 방식 | `single` |
| 스킵 허용 | `False` |
| fallback 옵션 | `universal` |
| 직접 입력 옵션 | `custom` |
| 요약 라벨 | 사용처 |
| 프롬프트 라벨 | Target image model |
| 마스터 프롬프트 섹션 | Target Usage |

### 목적

사용자가 실제로 영문 프롬프트를 사용할 이미지 모델, 이미지 생성 서비스, 또는 모델 계열을 선택한다. 이 값은 마스터 프롬프트 안에서 채팅형 AI가 어떤 형식의 영문 프롬프트를 생성해야 하는지 결정하는 최상위 분기값이다.

### 도움말

어디에 넣을 영문 프롬프트인지 고르면, 그 사용처에 맞는 형식으로 마스터 프롬프트가 정리됩니다. 잘 모르겠다면 '모르겠음 / 범용'을 선택하면 됩니다.

### 출력 역할

채팅형 AI는 이 사용처에 맞는 최종 영문 프롬프트를 생성해야 한다.

## 2. 단계 정책

```text
1. 사용처 단계는 필수 단계이다.
2. 사용자는 하나의 사용처만 선택한다.
3. 스킵은 허용하지 않는다.
4. 사용처를 잘 모를 경우 `모르겠음 / 범용`을 선택한다.
5. 목록에 없는 모델이나 서비스는 `기타 / 직접 입력`을 선택한다.
6. 선택된 사용처는 채팅형 AI가 최종 영문 프롬프트의 형식을 결정하는 기준이 된다.
```

## 7. 마스터 프롬프트 생성 시 반영 규칙

```text
선택된 사용처는 마스터 프롬프트의 Target Usage 섹션에 반영한다.
채팅형 AI는 선택된 사용처의 prompt_style과 master_prompt_instruction을 기준으로 최종 영문 프롬프트를 작성한다.
사용처가 범용이면 특정 모델 문법에 종속되지 않는 자연어 중심 프롬프트로 작성한다.
사용처가 기타 / 직접 입력이면 사용자가 입력한 모델명이나 서비스명을 우선 반영한다.
```
