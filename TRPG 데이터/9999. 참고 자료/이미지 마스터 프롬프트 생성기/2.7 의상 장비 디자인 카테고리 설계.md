# 2.7 의상 / 장비 디자인 카테고리 설계

## 개요

`의상 / 장비 디자인`은 캐릭터가 착용하는 의복, 갑옷, 방어구, 유니폼, 예복, 로브, 전투복, 기능복, 장비 세트, 착용 액세서리 조합을 중심으로 하는 카테고리입니다.

이 카테고리의 핵심은 **캐릭터 자체**가 아니라, 캐릭터가 입거나 착용하는 **의상과 장비의 디자인**입니다.

따라서 인물이 함께 등장하더라도 얼굴, 표정, 성격보다 의상 구조, 실루엣, 소재, 배색, 장식, 기능성, 착용 방식, 세계관적 미학이 중심이 되어야 합니다.

기본 표현 방식은 **의상을 돋보이게 하는 목재 재질의 마네킹 착용**을 기준으로 합니다.  
특정 부위 의상만 설계하는 경우에는 마네킹의 해당 부위만 보여주고, 풀 착장이나 세트 의상인 경우에는 얼굴과 머리카락이 없는 목재 마네킹 전신에 의상을 입힌 형태로 보여주는 것이 좋습니다.

이 카테고리는 직업부터 고르는 방식이 아니라, 먼저 다음 흐름으로 분류합니다.

```text
현대의복 / 판타지의복
→ 남성복 / 여성복 / 유니섹스
→ 의상 부위 / 계열
→ 세부 의상 유형
→ 테마 계열
→ 문화권 / 세력 / 세계관 테마
→ 역할 / 직업 / 계층 테마
→ 상세 설계
```

`전사`, `기사`, `성기사`, `마법사`, `무협 검사`, `SF 파일럿` 같은 것은 의상 종류가 아니라 **테마 / 역할 인상**으로 처리합니다.

---

## 다른 카테고리와의 경계

```text
A. 캐릭터 / 인물
- 인물의 외형, 얼굴, 성격, 포즈, 캐릭터성 자체가 중심

2.6 아이템 / 무기 / 유물 / 소품
- 손에 드는 단일 물체, 무기, 소품, 아이콘, 유물 하나가 중심

2.7 의상 / 장비 디자인
- 캐릭터가 착용하는 복장, 갑옷, 장비 세트, 유니폼, 착장 조합이 중심

2.8 메카 / 탈것 / 기계
- 대형 기계, 탑승체, 메카닉, 차량, 기계 구조 자체가 중심
```

예시로 보면 이렇게 나눕니다.

```text
백발 남성 검사 캐릭터 전신 디자인
→ A. 캐릭터 / 인물

검 한 자루
→ 2.6 아이템 / 무기 / 유물 / 소품

검사가 입는 흑색 무복 + 장갑 + 허리띠 + 부츠 + 장비 세트
→ 2.7 의상 / 장비 디자인

왕관 하나
→ 2.6 아이템 / 무기 / 유물 / 소품

왕족 예복 전체
→ 2.7 의상 / 장비 디자인

전신 동력 강화 슈트
→ 2.7 또는 2.8 경계

탑승형 거대 메카
→ 2.8 메카 / 탈것 / 기계
```

경계 기준은 다음과 같습니다.

```text
착용자가 직접 입는 장비면 2.7
손에 드는 단일 물건이면 2.6
탑승하거나 조종하는 기계면 2.8
인물의 얼굴과 캐릭터성이 중심이면 A
```


# 2.7-2. 의복 세계 / 착용 실루엣

## 질문


---

## 2.7-2-1. 의복 세계 구분

```text
- 현대의복
- 판타지의복
- 현대 + 판타지 혼합형
- 직접 입력
- 자동 / 맡기기
```

### 현대의복

현실 기반 의복입니다.

```text
예:
셔츠, 재킷, 코트, 청바지, 작업복, 정장, 후드티, 원피스, 현대 전술복, 현대 유니폼, 현대 기능복
```

### 판타지의복

현실 복식을 기반으로 하더라도 세계관적 변형, 장식성, 의식성, 전투성, 상징성이 강한 의복입니다.

```text
예:
로브, 무복, 갑옷, 예복, 의식복, 왕실복, 모험가 복장, 사제복, 판타지 드레스, 판타지 전투복, 마법사 의상
```

### 현대 + 판타지 혼합형

현대적 의상 구조에 판타지 장식, 마법 장치, 룬, 가문 문장, 의식 요소, 비현실적 소재 등이 결합된 형태입니다.

```text
예:
현대 정장 + 마법 문양
현대 코트 + 판타지 장비 벨트
전술복 + 룬 장갑
사이버펑크 의상 + 판타지 마도 장치
```

## 2.7-2-2. 착용 성별 / 실루엣

```text
- 남성복
- 여성복
- 유니섹스 / 성별 중립
- 특정 체형 기준
- 비인간형 체형 기준
- 직접 입력
- 자동 / 맡기기
```

이 항목은 의상의 기본 패턴, 실루엣, 어깨선, 허리선, 치마 / 바지 구성, 장식 위치, 전체 비례를 결정하기 위한 것입니다.

---

## 2.7-2-3. 빠른 조합 프리셋

UI에서는 위 두 단계를 분리해도 되고, 빠른 선택 버튼으로 합쳐서 보여줄 수도 있습니다.

```text
- 현대 남성복
- 현대 여성복
- 현대 유니섹스
- 판타지 남성복
- 판타지 여성복
- 판타지 유니섹스
- 현대 + 판타지 남성복
- 현대 + 판타지 여성복
- 현대 + 판타지 유니섹스
- 직접 입력
- 자동 / 맡기기
```

내부 데이터 구조는 `의복 세계 구분`과 `착용 성별 / 실루엣`을 분리해서 저장하는 편이 좋습니다.

# 2.7-4. 세부 의상 유형

## 질문

```text
구체적으로 어떤 의상 유형인가요?
```

이 단계는 2.7의 핵심 데이터입니다.  
단순히 10개 전후의 예시를 제공하는 것이 아니라, 실제 의상 선택 사전처럼 가능한 한 많은 세부 유형을 제공합니다.

```text
속옷 / 이너웨어가 대분류라면 티팬티, 브리프, 트렁크, 브라렛, 코르셋, 슬립 등이 세부 유형이다.
갑옷 / 방어구가 대분류라면 경갑, 평갑, 중갑, 특수갑이 중간 분기이고, 그 아래에 레더 아머, 체인 셔츠, 풀 플레이트 등이 세부 유형이다.
```

속옷 / 이너웨어 계열은 패션 디자인 분류로만 다루며, 최종 이미지에서는 성인 착용자 기준의 비노골적 의상 디자인, 카탈로그식 디자인, 마네킹 착용, 플랫레이, 의상 시트 표현을 우선합니다.

### 처리 기준

```text
목재 마네킹 착용
- 기본 권장 방식이다.
- 의상이 중심이며, 착용자는 의상을 보여주기 위한 중립적 지지체로 취급한다.

특정 부위 목재 마네킹 착용
- 상의, 하의, 장갑, 신발, 머리 착용물 등 특정 부위 의상만 설계할 때 사용한다.
- 마네킹의 해당 부위만 보여주어 의상 부위를 강조한다.

전신 목재 마네킹 착용
- 풀 착장, 코디 세트, 갑옷 풀세트, 로브 풀세트 등 전체 착장을 보여줄 때 사용한다.
- 얼굴과 머리카락이 없는 목재 마네킹 전신에 의상을 입힌다.

얼굴 없는 마네킹 / 모델 착용
- 캐릭터성을 줄이고 의상 구조를 강조한다.

의상만 단독 전시
- 옷걸이, 받침대, 갑옷 거치대 등으로 표현한다.

평면 전개 / 플랫레이
- 의상을 바닥이나 시트 위에 펼쳐서 구성 요소를 보여준다.

AI가 착용 모델을 생성
- 의상에 어울리는 기본 모델을 새로 만든다.
- 단, 이 카테고리의 중심은 모델이 아니라 의상이다.

사용자가 착용자 설명 직접 입력
- 사용자가 입력한 착용자 분위기, 체형, 성별 표현, 역할을 반영한다.

기존 캐릭터 레퍼런스 시트 참조
- 특정 캐릭터에게 입힐 의상으로 설계한다.
- 단, 결과물의 중심은 캐릭터 초상화가 아니라 의상 / 장비 디자인이다.
```

## 2.7-5-5. 마네킹 표현 규칙

이 카테고리는 의상이 중심이므로, 별도 요청이 없다면 인물보다 의상이 돋보이도록 **목재 재질의 마네킹**을 기본 기준으로 사용합니다.

```text
- 마네킹은 얼굴과 머리카락이 없어야 한다.
- 마네킹은 목재 재질로 표현한다.
- 마네킹의 표정, 피부, 헤어스타일, 캐릭터성은 강조하지 않는다.
- 의상의 실루엣, 소재, 장식, 구조가 가장 잘 보이게 한다.
- 특정 부위 의상만 설계할 경우, 마네킹의 해당 부위만 보여준다.
- 전체 착장일 경우, 얼굴과 머리카락 없는 전신 목재 마네킹에 의상을 입힌다.
- 마네킹은 중립적 포즈를 취한다.
- 과도한 액션 포즈보다 정면, 3/4, 후면 등 의상 확인에 유리한 포즈를 우선한다.
```

### 특정 부위 의상 예시

```text
상의
→ 상반신 목재 마네킹에 착용

하의
→ 허리부터 다리까지의 목재 마네킹에 착용

장갑 / 손 보호구
→ 손과 팔 일부의 목재 마네킹에 착용

신발 / 부츠
→ 발과 다리 일부의 목재 마네킹에 착용

머리 / 얼굴 착용물
→ 얼굴 특징 없는 목재 두상 또는 단순 두부 마네킹에 착용

갑옷 부분 부위
→ 해당 신체 부위의 목재 마네킹 또는 갑옷 거치대에 착용
```

### 풀 착장 예시

```text
풀 착장 / 코디 세트
→ 얼굴과 머리카락 없는 전신 목재 마네킹에 전체 의상을 착용

갑옷 풀세트
→ 전신 목재 마네킹 또는 갑옷 거치대에 착용

로브 풀세트
→ 전신 목재 마네킹에 로브와 부속 장비를 착용

제복 풀세트
→ 전신 목재 마네킹에 제복 전체를 착용
```

### 마스터 프롬프트 삽입 지시

```text
The focus of this prompt is the outfit, costume, armor, or wearable equipment design, not the character's face or personality.

Unless the user explicitly requests a character model, present the outfit on a neutral wooden mannequin.

The mannequin should have no face, no hair, and no expressive character identity. It should function only as a display form for the outfit.

If the selected clothing category is a specific body part, show only the relevant wooden mannequin body section wearing that item.

If the selected clothing category is a full outfit or complete set, show a full-body wooden mannequin wearing the complete outfit.

Use neutral display poses such as front view, three-quarter view, side view, back view, or turnaround views so the outfit design remains clearly visible.
```

```text
의상 구조 확인이 중요하면 정면 / 후면 시트나 턴어라운드를 우선한다.
감상용 이미지가 필요하면 목재 마네킹 착용 시트, 전신 목재 마네킹 착용 시트, 의상 컨셉아트를 우선한다.
장비 구성이 중요하면 구성품 분해도나 장비 세트 시트를 우선한다.
특정 캐릭터용 의상이면 캐릭터 레퍼런스용 착장 시트를 우선하되, 중심은 캐릭터 초상화가 아니라 의상 디자인이어야 한다.
속옷 / 이너웨어 계열은 비노골적 패션 디자인, 목재 마네킹 착용, 플랫레이, 카탈로그형 시트 표현을 우선한다.
특정 부위 의상은 해당 부위 목재 마네킹 착용 시트를 우선한다.
풀 착장 / 코디 세트는 전신 목재 마네킹 착용 시트를 우선한다.
```
