# 2.3 풍경화 / 배경 / 장소 / 세계관 카테고리 설계

## 개요

`풍경화 / 배경 / 장소 / 세계관`은 특정 인물이나 단일 구조물보다 **장소 전체의 인상, 공간감, 분위기, 세계관성**이 중심인 창작 이미지 카테고리입니다.

자연 경관뿐 아니라 도시, 마을, 던전, 동굴, 지하 유적, 성소, 전장, 수중 공간, 차원 공간, 세계관 랜드마크 주변 환경까지 포함합니다.

단일 건물이나 구조물 자체의 디자인이 중심이면 `건물 / 건축물 / 구조물` 카테고리로 보냅니다.  
사건과 인물의 행동이 중심이면 `장면 / 서사 일러스트` 카테고리로 보내는 편이 맞습니다.

## C 단계 구조

```text
C-1. 카테고리
C-2. 장르 / 세계관
C-3. 장소 유형 / 중심 배경
C-4. 장소 상세 설계
C-5. 분위기 / 조명 / 환경 조건
C-6. 레이아웃 / 예상 결과물
```

C 카테고리는 캐릭터나 몬스터처럼 외형을 세밀하게 고르는 것이 아니라, **공간의 종류, 구조, 분위기, 광원, 환경 조건**을 정하는 것이 핵심입니다.

# C-1. 카테고리

## 선택값

```text
풍경화 / 배경 / 장소 / 세계관
```

## 설명

```text
이 이미지는 장소, 배경, 풍경, 지역, 세계관 경관을 중심으로 한다.
최종 영문 프롬프트는 장소의 유형, 공간 구조, 지형, 문명 흔적, 광원, 분위기, 세계관적 특징을 명확히 반영해야 한다.
```
