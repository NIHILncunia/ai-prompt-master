# 2. 캐릭터 / 인물 카테고리 설계

## 개요

- 본 문서는 창작 이미지 설계 단계에서 `A. 캐릭터 / 인물` 카테고리에 대한 확정안을 정리한 문서다.
- 이 카테고리는 인간형 존재를 중심으로 한 창작 이미지를 설계할 때 사용한다.
- 인간, 무협 인물, 판타지 인물, SF 인물, 신격의 화신, 수인형 인물, 악마형 인물 등을 포함한다.
- 단, 생물 구조 자체가 핵심인 경우는 `B. 몬스터 / 크리처` 카테고리로 분리하는 것을 원칙으로 한다.

## 단계 구조

```text
A. 캐릭터 / 인물

A-1. 카테고리
A-2. 장르 / 세계관
A-3. 중심 대상 / 캐릭터 상세 설계
A-4. 배경 / 무대
A-5. 분위기
A-6. 레이아웃 / 예상 결과물
```

- `A-3. 중심 대상 / 캐릭터 상세 설계` 안에 캐릭터 전용 외형 설계 블록을 포함한다.
- 단계 수는 6개를 유지하되, 필요한 상세 정보는 A-3 내부 확장 블록에서 처리한다.

---

## A-1. 카테고리

### 선택값

```text
캐릭터 / 인물
```

### 설명

- 이 이미지는 캐릭터 또는 인물형 존재를 중심으로 한다.
- 최종 영문 프롬프트는 인물의 외형, 실루엣, 의상, 장비, 표정, 시선, 포즈, 분위기를 명확히 반영해야 한다.

---

## A-2. 장르 / 세계관

### 질문

```text
이 캐릭터는 어떤 장르나 세계관에 속하나요?
```

### 선택지

```text
- 정통 판타지
- 다크 판타지
- 무협
- 동양 판타지
- 현대 판타지
- SF
- 사이버펑크
- 포스트 아포칼립스
- 신화 / 종교풍
- 고딕 / 뱀파이어풍
- 학원 / 현대 일상
- 직접 입력
- 자동 / 맡기기
```

### 자동 처리 규칙

- 캐릭터의 핵심 콘셉트와 선택된 레이아웃에 어울리는 장르와 세계관을 채팅형 AI가 적절히 보완한다.

## A-3. 중심 대상 / 캐릭터 상세 설계

### 질문

```text

```

### 강조점 선택지

```text
- 인물 1명
- 인물 2명
- 여러 명의 캐릭터
- 주인공형 인물
- 악역 / 보스형 인물
- 전사 / 기사 / 무인
- 마법사 / 주술사 / 사제
- 암살자 / 도적 / 추적자
- 왕족 / 귀족 / 지배자
- 신격 / 초월자 / 화신
- 괴이한 인물형 존재
- 의상과 장비 강조
- 얼굴과 표정 강조
- 전투 자세 강조
- 직접 입력
- 자동 / 맡기기
```

### 상세 설계 정책

- 캐릭터 상세 설계는 선택 사항이다.
- UI에서는 기본적으로 접힌 상태로 두고, 필요한 사용자만 펼쳐서 선택할 수 있게 한다.
- 각 항목은 `선택`, `직접 입력`, `없음`, `자동 / 맡기기` 중 적절한 방식을 지원한다.

### 질문

```text

```

### 선택지

```text
- 단순 배경
- 어두운 추상 배경
- 밝은 추상 배경
- 자연 배경
- 도시 배경
- 전장
- 신전 / 성소
- 성 / 궁전
- 던전 / 폐허
- 실내 공간
- 우주 / 미래 공간
- 무협풍 산문 / 객잔 / 수련장
- 직접 입력
- 자동 / 맡기기
```

### 자동 처리 규칙

- 배경은 캐릭터의 실루엣과 디자인을 방해하지 않도록 조정하되, 장르와 분위기에 어울리게 보완한다.

## A-5. 분위기

### 질문

```text
캐릭터의 분위기는 어떤 쪽인가요?
```

### 선택지

```text
- 영웅적
- 신비로운
- 어두운
- 차가운
- 고독한
- 비장한
- 우아한
- 광기 어린
- 위압적인
- 성스러운
- 음산한
- 화려한
- 귀여운
- 당당한
- 슬픈
- 직접 입력
- 자동 / 맡기기
```

### 설명

- 분위기 선택은 색감, 조명, 표정, 연출 방향에 직접 영향을 준다.
- 색감 / 조명은 별도 대단계로 분리하지 않고, 분위기 선택에 따라 자동 보정한다.

## A-6. 레이아웃 / 예상 결과물

### 질문


```text

- 흉상 / 포트레이트
- 얼굴 클로즈업
- 액션 포즈 일러스트
- 캐릭터 키아트
- 캐릭터 스플래시 아트
- 캐릭터 레퍼런스 시트
- 정면 / 측면 / 후면 턴어라운드
- 표정 시트
- 의상 / 장비 시트
- 듀오 캐릭터 일러스트
- 그룹 캐릭터 일러스트
- 표지형 캐릭터 비주얼
- 직접 입력
```

### 자동 처리 규칙

- 캐릭터의 콘셉트, 강조점, 사용처에 가장 적합한 레이아웃을 선택해 영문 프롬프트를 구성한다.
