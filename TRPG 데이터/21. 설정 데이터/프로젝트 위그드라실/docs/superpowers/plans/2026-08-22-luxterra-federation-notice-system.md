# 자유 탐사 연맹 공고 체계 개편 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 자유 탐사 연맹 공고를 공통 체계·본토 공고·라크샤라 현지 활동 공고로 재편하고 모험가 문서의 역할 경계를 정합화한다.

**Architecture:** 세계수의 적 35개 공고와 모든 공통 판정 규칙은 공고 체계 문서에서 관리한다. 본토 문서는 해결사·사냥꾼·개척자의 일반 공고 21개만, 라크샤라 문서는 해결사·사냥꾼의 현지 공고 42개만 관리한다.

**Tech Stack:** Markdown, YAML frontmatter, Obsidian wiki links, PowerShell, Git

**Spec:** `docs/superpowers/specs/2026-08-21-luxterra-federation-notice-system-design.md`

## Global Constraints

- 모든 연맹 공고는 공개한다.
- 앙그라의 안개에서 일어나는 모든 사안은 개척자 공고다.
- 문명권과 라크샤라의 사안은 해결사 또는 사냥꾼 공고다.
- 재해급 개체라는 호칭은 재해룡종에만 쓴다.
- 위험 개체는 최하·하·중·상·최상·특상의 여섯 등급을 쓴다.
- 비밀 설정 문서는 수정하지 않는다.
- 현재 사용자 지시가 없는 한 후속 커밋은 만들지 않는다.
