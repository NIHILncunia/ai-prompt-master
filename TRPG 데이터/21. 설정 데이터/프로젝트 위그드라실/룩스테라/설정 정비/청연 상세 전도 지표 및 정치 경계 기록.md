## 목적과 적용 상태

이 문서는 마스터와 논의하여 확정한 청연 상세 전도의 지표와 정치 경계 판단을 다음 세션까지 보존하는 정비 기록이다. 현재 정본, [[청연 대륙 공간 배치 기준]], 개별 국가·항구 문서에는 이 기록의 내용을 자동 반영하지 않았다.

청연의 새 상세 전도는 제작 중인 임시 지도다. 세계 전도는 세계수와 대륙의 대략적 위치만 보이는 축약도로, 청연의 지형·국가·항구·경계는 청연 상세 전도에서 다룬다. 기존 지도 도구에는 국가 경계선이 없었으므로, 기존 이미지에 경계가 없다는 사실은 새 상세 전도의 경계 부재를 뜻하지 않는다.

## 전도 제작 기준

| 항목 | 기록한 판단 | 적용 상태 |
| --- | --- | --- |
| 전도 종류 | 청연은 세계 전도와 분리한 상세 대륙 전도로 제작한다. | 확정 |
| 현재 지형도 | 마스터가 제공한 무표식 청연 대륙 지형도를 새 상세 전도의 지형 검토 기준으로 쓴다. | 임시 기준 |
| 세계 전도 | 세계수와 대륙 사이의 대략적 위치만 보이는 약도로 축약한다. | 확정 |
| 국가 경계 | 새 상세 전도에는 법적 육상 국경선과 영해 경계를 표시한다. | 확정 |
| 기존 이미지 | 과거 전도의 표식·지형·항구 방향은 검토 근거이며, 경계선이 없던 표현을 소급 수정하지 않는다. | 확정 |
| 녹색 용 도상 | 이전 전도에 있던 녹색 용 그림은 지도 장식이다. 지형·생물·거점으로 기록하거나 표기하지 않는다. | 확정 |

## 지형·수계 지표

| 지표 | 상세 전도상 상대 위치와 연결 | 상태 |
| --- | --- | --- |
| 청령 산맥 | 북서부에서 북중부까지 이어지는 연속 산맥이다. | 확정 |
| 해월 산맥 | 남서 해안 배후의 산악 지대다. | 확정 |
| 동악 산맥 | 동중부의 주 능선과 북쪽 지맥으로 이루어진 산악 축이다. 단령 막부가 산맥 전체를 포함한다. | 확정 |
| 청운림 | 청령 산맥 남쪽, 청연 내해 서쪽의 서중부 밀림이다. | 확정 |
| 해월수림 | 해월 산맥 북쪽의 남서부 수림이다. | 확정 |
| 풍영림 | 동악 산맥 남쪽, 청연 내해 동쪽의 동중부·남부 수림이다. | 확정 |
| 청연 내해 | 대륙 중앙을 남북으로 잇는 큰 수역이다. | 확정 |
| 진홍의 해협 | 청연 서쪽 외해와 서쪽 도서 지대를 포함하는 해역이다. 망서 해협을 통해 청연 내해 계통과 이어진다. `핏빛 해협`은 오기가 아니라 마스터의 착오였으므로 별칭으로 남기지 않는다. | 확정 |
| 망서 해협 | 청운림 남쪽의 서쪽 수역 진입부로, 진홍의 해협과 해월 수로를 잇는다. | 확정 |
| 해월 수로 | 망서 해협에서 남서쪽으로 굽어 청연 내해 남서부로 이어지는 수로다. 청운림 남쪽·해월수림 북쪽에 놓인다. | 확정 |
| 백류강 | 동악 산맥 남서 사면에서 단령 막부 서쪽을 지나 청연 내해 북동부로 흐른다. | 확정 |
| 연류강 | 청령 산맥 동쪽에서 운경 황국 서쪽을 지나 청연 내해 북서부로 흐른다. | 확정 |
| 청하강 | 청연 내해 남동부에서 해월 산맥 동쪽·풍영림 서쪽을 지나 남쪽 외해로 흐른다. 자연 하천이면서 운항 가능한 수운 축이다. | 확정 |

## 국가·항구·수송로 표기

| 대상 | 상세 전도에서 기록할 위치·기능 | 상태 |
| --- | --- | --- |
| 운경 황국 | 청연 내해 북안과 중북부 평야에만 법적 육지를 둔다. 외해 직접 해안은 없으며, 기존 외해 항구는 보호·공동 운영 체계로 유지한다. | 확정 |
| 해월 연방 | 남서 해안과 해월 산맥 배후지를 직접 영토로 둔다. | 확정 |
| 단령 막부 | 정치 중심은 동남부에 둔다. 동악 산맥 전체와 북동부·동부 해안 영토를 포괄한다. 과거의 `동남부 중립지대` 표기는 철회한다. | 확정 |
| 철갑진 항구 | 북서쪽 암석 해안에 둔다. | 기존 위치 유지 |
| 망서루 항구 | 망서 해협 연안의 서쪽에 둔다. | 기존 위치 유지 |
| 천문대 항구 | 동쪽 해안의 북부~중부에 둔다. | 기존 위치 유지 |
| 진명영 항구 | 남동쪽 해안에 둔다. 단령 막부 주권 영토 안의 해월 연방 조차항이며, 단령의 직할 군항으로 표기하지 않는다. 지도에는 별도 색상 영지나 부제를 붙이지 않고 항구명만 쓴다. | 확정 |
| 해월진 항구 | 남서쪽 해안에 둔다. | 기존 위치 유지 |
| 운철관도 | 운경 황국 북동부·청연 내해 북안에서 출발해 내해 북쪽을 우회하고, 동악 산맥 남서쪽 물류 지대를 지나 단령 막부의 남서 물류권으로 이어지는 공동 공인 수송로다. 내해를 가로지르지 않는 연속 육상 경로로 그린다. | 확정 |

## 법적 경계 기준

| 구간 | 경계 원리 | 상태 |
| --- | --- | --- |
| 운경 황국 ↔ 단령 막부 | 동악 산맥 서쪽 산기슭과 백류강을 따라 육상 국경을 둔다. | 확정 |
| 운경 황국 ↔ 해월 연방 | 해월 산맥 북쪽 산기슭에서 청연 내해 남서안으로 이어지는 선을 육상 국경으로 둔다. | 확정 |
| 해월 연방 ↔ 단령 막부 | 서로 맞닿는 육상 국경은 두지 않는다. | 확정 |
| 청연 내해 영해 | 인접한 연안 국가별로 나누어 표시한다. | 확정 |
| 남쪽 외해 | 해월 연방과 단령 막부의 해상 경계는 등거리선으로 둔다. | 확정 |
| 진명영 항구 | 단령 막부의 주권은 유지하고, 해월 연방은 항만 운영을 조차한다. | 확정 |

## 지도에 아직 넣지 않을 내용

- 청령 산맥 권역의 무림·산문 권위권을 비주권 음영으로 표시할지, 대표 거점만 둘지, 아예 지도에 표기하지 않을지는 아직 결정하지 않았다.
- 새 상세 전도의 실제 좌표·축척·해안선 세부선·국경선의 굴곡·항구 아이콘 좌표는 최종 지도 제작 과정에서 확정한다. 이 기록의 방위와 인접 관계를 임의의 격자 좌표로 환산하지 않는다.
- 문파 대표 거점 20개는 [[청연 기존 전도 문파 대표 거점 추정 기록]]에만 `전도 추정 / 정본 미확정`으로 보존되어 있으며, 이 상세 전도의 확정 지표가 아니다.

## 재개 순서

1. 청령 산맥 권역의 무림·산문 권위권을 상세 전도에 어떤 방식으로 표시할지 한 가지 판단을 확정한다.
2. 확정된 지표와 경계를 새 상세 전도 시안에 배치한다.
3. 최종 시안의 실제 좌표와 선형을 검증한 뒤에만 [[청연 대륙 공간 배치 기준]]과 관련 정본 반영 범위를 별도로 결정한다.

## 검증 결과

- 지형·수계 13건, 국가·항구·수송로 9건, 법적 경계 6건을 마스터의 확정 발언과 대조해 기록했다.
- `진홍의 해협`, `운철관도`, 진명영의 조차항 지위, 단령 막부의 동남부 중심·동악 산맥 전체 관할, 국가 경계선 신규 표기 원칙을 모두 누락 없이 포함했다.
- 이 문서에서 기존 정본·공간 배치 기준·개별 국가·항구·관계 문서를 수정하지 않았음을 확인했다.
