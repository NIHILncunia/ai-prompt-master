# 데이터베이스 이관 사전 작업

프로젝트 위그드라실 설정 문서를 데이터베이스로 옮기기 전에 카테고리, 범용 관계 유형, 템플릿·필드, 데이터 모델과 검토 기록을 정리하는 작업 폴더다.

## 현재 기준

- 범용 관계 유형 v1: COMMON 관계 936개, 대상 역할 2,813개 동결
- 초기 카테고리: 룩스테라 114개, 엘드로스 100개, 총 214개 확정
- 다음 단계: 카테고리 기준 문서의 전체 이름·참조 ID 규칙을 기준으로 초기 시드를 작성하고, 실제 DB 연결 환경에서 검증

## 카테고리 목록

카테고리와 서브카테고리는 [카테고리 및 서브카테고리 이관 정리](카테고리%20및%20분류%20체계/카테고리%20및%20서브카테고리%20이관%20정리.md)를 기준으로 사용한다.
