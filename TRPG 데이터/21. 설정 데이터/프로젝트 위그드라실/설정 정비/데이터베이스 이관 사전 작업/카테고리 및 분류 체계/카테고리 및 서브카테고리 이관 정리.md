# 프로젝트 위그드라실 카테고리·서브카테고리 기준

> 상태: 카테고리 이관 데이터 v1 확정. 이 문서는 초기 이관과 이후 문서 분류에 사용하는 카테고리 목록의 기준본이다. 월드별 순서·경로·수량은 [카테고리 이관 데이터 v1 최종 검토 및 동결](../검토%20및%20추적/카테고리%20이관%20데이터%20v1%20최종%20검토%20및%20동결.md)을 우선한다.

## 적용 범위

이관 대상은 `설정`, `신격`, `비밀 설정` 문서다. 세 문서군은 하나의 `documents` 모델에 이관하며, 비밀 설정은 문서 유형이 아니라 공개 범위 컬럼으로 제어한다.

- `스토리 설계`, `설정 정비`, 템플릿, 지침, 라이브러리, 인덱스는 이번 이관 대상이 아니다.
- `importance`는 문서 자체의 중요도이므로 카테고리가 아닌 문서 컬럼으로 관리한다.
- 카테고리는 월드별 독립 데이터다.

## 운영 원칙

1. 계층은 `메인 → 서브 1 → 서브 2`의 최대 3단계다.
2. 문서 하나는 카테고리 하나를 선택한다. 복수 성격·상태·속성·위계는 태그와 문서 관계로 처리한다.
3. `일반`, 빈값, `기타`는 별도 카테고리로 만들지 않고 해당 메인 카테고리에 직접 연결한다.
4. 초기 목록은 이관 기준이며, 이후 월드별 필요에 따라 확장할 수 있다.

## DB 적재 데이터 사전

이 문서의 목록은 표시용 약칭이 아니라 DB 적재용 기준값이다. 서브카테고리는 단어 하나만 쓰지 않고, 아래 목록에 적은 전체 이름을 `categories.name`에 그대로 넣는다. 예를 들어 `숲`이나 `육상:숲`이 아니라 `육상 지형 - 숲`을 사용한다.

| `categories` 컬럼 | 초기 적재값 | 필요한 참조 ID 또는 선행 조건 |
| --- | --- | --- |
| `id` | DB가 생성 | 직접 입력하지 않는다. 서브카테고리와 다른 참조 테이블은 생성된 이 값을 사용한다. |
| `worldId` | 대상 월드의 `worlds.id` | 필수. 먼저 `projects.id`로 프로젝트를 찾고, 그 프로젝트의 `worlds.id`를 조회해야 한다. 룩스테라와 엘드로스는 같은 이름의 카테고리라도 서로 다른 `worldId`를 사용한다. |
| `upperCategoryId` | 메인 카테고리는 `NULL`, 서브카테고리는 같은 월드 메인 카테고리의 `categories.id` | 필수 참조. 메인 카테고리를 먼저 적재·조회한 뒤 서브카테고리를 적재한다. |
| `templateId` | 초기 적재에서는 `NULL` | 템플릿 이관 뒤 메인 카테고리에 연결할 때만 같은 월드의 `templates.id`가 필요하다. 서브카테고리에는 넣지 않는다. |
| `name` | 아래 목록의 메인 또는 서브카테고리 전체 이름 | 필수. 축약·별칭·코드값을 넣지 않는다. |
| `level` | 메인 `1`, 서브카테고리 `2` | 초기 적재에는 3단계를 만들지 않는다. |
| `order` | 아래 목록의 작성 순서 | 같은 `worldId`와 같은 부모 안에서만 순서를 매긴다. |

문서 이관 시에는 `documents.id`와 해당 카테고리의 `categories.id`가 `documentCategories.documentId`, `documentCategories.categoryId`에 필요하다. 관계 유형의 허용 카테고리를 연결할 때에는 `worldRelationshipRoleCategories.categoryId`에 같은 `categories.id`를 사용한다.

## 기존 메타데이터 이관 규칙

1. 기존 `주요 개념` 문서는 `개념 > 주요`로 이관한다.
2. 기존 `주요`가 문서 중요도를 뜻하면 `importance` 컬럼으로 이관한다. `주요 인물`은 중요도와 별개의 배역 분류다.
3. 기존 `일반` 또는 빈 `subtype`은 해당 메인 카테고리에 직접 이관한다.
4. 기존 `도시국가`는 `도시 > 국가`로, `도시국가 / 항구`는 `도시 > 항구`로 이관한다.
5. 기존 `부족국가`는 `단체 > 부족국가`로 이관한다.
6. `용종` 개념 문서는 `개념`에 두고, 개별 용종 도감 문서는 `용종`과 해당 계통에 배정한다.
7. 현재 일반 신격은 `신격 > 정령성 신위`로, 흑린망룡은 `신격 > 용성 신위`로 이관한다.
