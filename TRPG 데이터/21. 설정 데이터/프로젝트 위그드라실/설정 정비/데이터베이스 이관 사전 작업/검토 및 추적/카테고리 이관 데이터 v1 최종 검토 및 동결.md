## 판정

초기 카테고리 이관 데이터를 확정·동결한다. `categories`는 하나의 자기참조 테이블이며, `upperCategoryId`를 사용해 최대 3단계까지만 계층을 만든다.

초기 데이터에는 메인 카테고리(1단계)와 서브카테고리(2단계)만 존재한다. 3단계 카테고리는 생성하지 않으며, 향후 실제 분류 필요성이 생길 때에만 해당 2단계 카테고리 아래에 추가한다. 빈 분류 노드나 `일반`·빈값·`기타` 카테고리는 만들지 않는다.

## 1. DB 이관 규칙

| 단계 | `level` | `upperCategoryId` | 초기 데이터 규칙 |
| --- | ---: | --- | --- |
| 메인 | 1 | `NULL` | 월드별 최상위 카테고리 |
| 서브 1 | 2 | 같은 월드의 메인 카테고리 ID | 이 문서의 모든 하위 항목 |
| 서브 2 | 3 | 같은 월드의 서브 1 카테고리 ID | 초기 생성하지 않음 |

- 상위·하위 카테고리는 반드시 같은 `worldId`를 사용한다.
- `templateId`는 초기 카테고리 시드에서 모두 `NULL`이다. 템플릿 이관 뒤 메인 카테고리에만 연결할 수 있다.
- 문서는 1단계 메인 카테고리를 반드시 하나 가지며, 2·3단계는 선택이다. 연결할 때는 하나의 연속 경로를 `documentCategories`에 모두 기록한다.
- 관계 역할의 허용 카테고리는 메인 카테고리 기준이다. 해당 메인의 모든 서브 1·서브 2 문서는 허용 범위에 포함된다.

## 2. 수량 검증

| 범위 | 메인 | 서브 1 | 서브 2 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 범용 11개 카테고리 | 11 | 86 | 0 | 97 |
| 룩스테라 용종 확장 | 1 | 16 | 0 | 17 |
| 엘드로스 클래스 확장 | 1 | 2 | 0 | 3 |
| 룩스테라 초기 시드 | 12 | 102 | 0 | 114 |
| 엘드로스 초기 시드 | 12 | 88 | 0 | 100 |

## 3. 초기 카테고리 데이터 기준

카테고리와 서브카테고리의 이름·전체 경로·`categories` 입력값·참조 ID는 [카테고리·서브카테고리 기준](../카테고리%20및%20분류%20체계/카테고리%20및%20서브카테고리%20이관%20정리.md)을 단일 기준으로 사용한다.

- 목록에 축약명, 별칭, 코드값을 쓰지 않는다.
- 서브카테고리는 해당 목록의 전체 이름을 `categories.name`에 넣는다.
- `worldId`는 대상 `worlds.id`, `upperCategoryId`는 같은 월드 메인 카테고리의 `categories.id`를 사용한다.
- 룩스테라에서는 공통 97개와 용종 확장 17개를 합쳐 114개를, 엘드로스에서는 공통 97개와 클래스 확장 3개를 합쳐 100개를 적재한다.

## 5. 기존 메타데이터의 최종 경로

| 기존 값 또는 대상 | 이관 경로 |
| --- | --- |
| 주요 개념 | 개념 > 주요 |
| 일반 또는 빈 `subtype` | 해당 메인 카테고리 |
| 도시국가 | 도시 > 국가 |
| 도시국가 / 항구 | 도시 > 항구 |
| 부족국가 | 단체 > 부족국가 |
| 용종 개념 문서 | 개념 |
| 개별 용종 도감 문서 | 용종 > 해당 계통 |
| 일반 신격 | 신격 > 정령성 신위 |
| 흑린망룡 | 신격 > 용성 신위 |

`주요`가 문서 중요도를 뜻하는 기존 메타데이터는 카테고리가 아니라 `documents.importance`로 이관한다. 인물의 `주요 인물`만 카테고리 경로다.

## 6. 확정 상태와 다음 작업

- 룩스테라 초기 카테고리: 114개 확정
- 엘드로스 초기 카테고리: 100개 확정
- 다음 작업: 이 문서의 월드별 순서·경로를 기준으로 `프로젝트 위그드라실` 프로젝트, 두 월드, 카테고리 초기 적재 쿼리를 작성한다.
