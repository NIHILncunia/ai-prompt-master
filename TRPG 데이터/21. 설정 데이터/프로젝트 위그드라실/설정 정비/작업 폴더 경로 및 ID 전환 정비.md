## 목표

활성 설정 지침과 사용자 전역 지침이 신규 TRPG 작업 폴더 ID와 Git 로컬 경로를 사용하도록 전환한다.

## 전환 대상

- 작업 폴더·프롬프트 루트·설정 관련 요청 폴더 ID
- Codex CLI의 작업 폴더 경로
- 설정 관련 요청 기능 번호
- Codex 메모리의 향후 라우팅 우선 규칙

## 보존 대상

- 설정 폴더 ID와 로컬 경로
- 과거 계획·보고서의 당시 작업 경로
- 메모리의 과거 세션 이력
- 사용자가 진행 중인 다른 설정 변경
