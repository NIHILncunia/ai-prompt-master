# 인형사의 인형

## 분류
- 유형: 주요 몬스터·인형사 진영 간부
- 소속: 공포의 의회 / 인형사 진영
- 역할: 인형사가 직접 대동하고 나타나는 간부급 전투 개체
- 관계: `인형사의 실타래`와 마찬가지로 인형사 진영의 주요 간부 개체
- 등장 시점: 향후 인형사가 직접 등장하는 장면에서 동행 예정
- 현재 세션 상태: `섬에서 전해진 바람 상편 2`에는 등장하지 않으며 현재 세션 전투 목록에도 포함하지 않는다.
- 이미지 제작: 기존 완전 로봇형 `검은 집행관 베르카스` 이미지 자산을 정본으로 전환
- 스탯 정책: 전용 스탯블록 제작 완료

## 기본 구조
- 형태: 완전한 로봇형 인간형 전투 기계
- 체격: 일반 검은 가면 기계 개체보다 한 체급 크고 넓으며, 특히 흉부와 어깨가 발달한 중장 프레임
- 자세: 낮고 안정된 중심을 유지하는 전투형 실루엣
- 소속 인상: 일반 검은 가면 병력과는 구분되는 독립적인 간부급 기계 개체

## 외형
- 외장: 광택을 죽인 흑철·검은 강철 계열 장갑으로 전신이 구성된다.
- 관절: 관절부와 장갑 틈으로 내부의 짙은 금속 구조가 드러난다.
- 가면: 얼굴 전체를 덮는 단단한 백색 가면형 페이스플레이트를 사용한다.
- 눈: 좁고 날카로운 감지 슬롯에서 붉은 광원이 보인다.
- 흉부: 흉부 중심과 장갑 틈에서 선명한 적색 마석전류가 맥동한다.
- 후면: 고출력 마석전류를 안정화하고 열을 배출하기 위한 기능성 방열·안정화 구조가 존재한다.
- 장식: 금장이나 문장 대신 체급과 기계 출력 자체가 간부급 위압감을 만든다.

## 색상
- 주색: 무광 흑철·검은 강철
- 가면: 백색
- 감지 슬롯: 적색
- 마석전류: 선명한 적색

## 마스터용 묘사

전신을 흑철 장갑으로 덮은 거대한 인간형 기계가 인형사의 곁을 지키며 움직입니다. 얼굴 전체를 덮은 백색 페이스플레이트의 좁은 감지 슬롯에서는 붉은 빛이 새고, 넓은 흉부와 장갑 틈에서는 선명한 적색 마석전류가 맥박처럼 반복해서 번뜩입니다.

장식이나 휘장은 거의 보이지 않지만 일반 전투 개체와 같은 병사로 보기에는 체급과 출력이 지나치게 큽니다. 인형사가 직접 대동하고 있다는 사실까지 더해지면, 이 기계가 단순한 병기가 아니라 실타래와 나란히 취급되는 인형사 진영의 간부급 개체라는 인상이 분명해집니다.

## 역할 및 관계
인형사의 인형은 인형사가 직접 현장에 모습을 드러낼 때 함께 등장하는 직속 간부급 전력이다. `인형사의 실타래`와 같은 진영 내 주요 개체이지만, 세부 전투 능력과 지휘 체계는 실제 등장 회차 설계에서 확정한다.

현재 단계에서는 기존 베르카스의 완전 로봇형 외형 자산만 이 개체의 정본으로 이전한다. 기존 베르카스의 아그니르 현장 지휘 역할, 에너지 워메이스, 마석전류망과 CR 7 스탯블록은 `검은 집행관 베르카스`에 남기며 이 개체로 자동 승계하지 않는다.
