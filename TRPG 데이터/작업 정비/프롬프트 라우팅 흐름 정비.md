# 프롬프트 라우팅 흐름 정비

## 상태

- 상태: 완료
- 시작일: 2026-08-23
- 작업 유형: 프롬프트 루트·기능 간 라우팅 및 진입 흐름 정비

## 목적

- 이미지 공통 승인 절차를 단일 정본으로 정렬한다.
- 재번호 이전 참조와 존재하지 않는 상대 경로를 제거한다.
- 루트부터 하위 기능까지의 필수 읽기 순서를 복구한다.

## 완료 범위

- 이미지 승인 절차의 활성 정본을 이미지 생성 모듈 공통 경로로 통일했다.
- 로그 하이라이트·로그 분석·통합 마스터의 재번호 이전 참조를 현행 기능 경로로 정리했다.
- 창작 지원 하위 제작기 3곳의 상위 문서 상대 경로와 공통 종족 자료 경로를 복구했다.
- 이미지 모듈 내부 1~8 기능이 직접 진입해도 상위 모듈 지침을 먼저 읽도록 보강했다.
