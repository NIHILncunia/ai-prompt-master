# 엔터티 자산 폴더 전환 정비

## 상태

- 상태: 완료
- 시작일: 2026-09-09
- 범위: 이미지 전용 루트·레퍼런스 시트·생성 결과·컨셉 이미지를 대상별 자산 폴더로 전환

## 확정 사항

1. 자산 루트는 `5. 신격`, `6. NPC`, `7. PC`, `8. 국가`, `9. 단체`, `10. 몬스터`, `11. 맵`, `12. 종족`, `13. 지역`, `14. 용종`, `15. 장소`, `16. 미분류`, `18. 아이템`을 사용한다.
2. 모든 대상 폴더는 `<분류>_uuid`를 가진 자산 인덱스를 두며 설정 본문은 복제하지 않는다.
3. 용종은 별도 루트를 사용하지만 몬스터 자산 규칙을 따른다.
4. 현재 컨셉 이미지 4개는 아이템으로 분류한다.

## 현재 기준선

- 이미지 전용·레퍼런스·생성 결과·컨셉·아이템 루트의 이미지: 536개
- 공용 맵: 문서 6개, 이미지 7개로 별도 완료 작업이며 재이관하지 않는다.
- 설정 폴더와 데이터베이스 이관은 이번 범위에서 동기화하지 않는다.

## 완료 결과

1. 기존 이미지 전용 루트 13개를 대상별 자산 루트 또는 `16. 미분류`로 전환했다.
2. 이미지 536개의 SHA-256 다중집합이 기준선과 일치한다.
3. 대상별 자산 인덱스 283개와 유효·고유 UUID 283개를 검증했다.
4. 활성 프롬프트·하이라이트·세션 자산 경로를 새 대상 폴더 규칙으로 갱신했다.
5. 분류 근거가 없는 이미지 43개는 `16. 미분류`에 보류했다.

## 환경 잔여

- 빈 중첩 폴더 5개는 자산이 없음을 확인했으나, 실행 환경의 삭제 정책으로 제거 명령이 차단될 수 있다. 이전 최상위 이미지 루트 13개는 모두 제거된 상태다.
