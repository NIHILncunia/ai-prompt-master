### 세션 설계·로그 분석·하이라이트 연동

- 상태: 현행 세션 정비 완료, 전역 자산 이관 보류
- 목적: 세션 설계 장면·맵을 실제 플레이 로그 분석의 Pxx/Hxx와 연결하고, 현재 `섬에서 전해진 바람 상편 2`의 4개 맵 운용 문제를 정비한다.
- 전역 구조 개편: `scene_uuid / map_uuid`, 장면 식별 정보, 구조화된 사용 맵, Pxx 실제 플레이 장면, Hxx 기본 하이라이트, 2번 하이라이트의 독립/분석 연계 모드, 이미지 모듈의 `Hxx → Pxx → scene_uuid → map_uuid` 연결까지 관련 지침에 반영 완료.
- 현행 세션 대상: `남아있는 이야기 2 / 섬에서 전해진 바람 상편 2`
- 현행 세션 상태: 장면 00~08에 `scene_uuid`, 맵 01~04에 `map_uuid`를 부여하고, 장면별 구조화된 `사용 맵` 참조를 적용했다.
- 확정 맵 흐름: `03 → 01 → 04 → 02`를 세션의 필수 공간 진행으로 사용한다. 맵 03은 도시 진입 1차 전투, 맵 01은 베르카스 2차 전투, 맵 04는 수상한 마법사 인계 뒤 `혼탁함을 먹는 돌`을 회수하는 탐색 구간, 맵 02는 왼팔 공개와 최종 갈등을 담당한다.
- 돌 확정: `혼탁함을 먹는 돌`은 사특한 기운을 흡수해 감추는 악마의 씨앗이다. 수상한 마법사가 확보했고 실타래의 명령으로 은폐에 사용했다. 한계 도달 시 악마가 태어나지만, 이번 세션에서는 태어나지 않는다.
- 장면 조정 결과: 장면 01은 맵 03의 자코 처리 1차 전투, 장면 02는 맵 01의 베르카스 2차 전투, 장면 04·05는 맵 04의 격리 조사·돌 회수·실타래 폭로, 장면 06은 맵 02의 왼팔 성소 최종 보호전을 담당한다.
- 검증: 맵 이미지 4개의 SHA-256이 작업 전후 일치하며, 맵 02는 이미지 확인 후 논리 그리드를 `30 × 30`으로 정정했다.
- 별도 후속 범위: 전역 자산 분류 이관과 단일 맵 카탈로그의 물리 이동은 아직 실행하지 않았다.
- 작업 정비: `작업 정비/세션 설계·로그 분석·하이라이트 연동 정비.md`

### 게임 스킬 아이콘 정규 스타일 이식 및 아이템 아이콘 확장

- 상태: 진행 중
- 목적: `게임 스킬 아이콘 스타일`을 정식 런타임 스타일로 운용하고, 생성 배치를 `22. 아이콘 생성` 아래에서 추적 가능하게 저장한 뒤 무기·아이템 아이콘 스타일을 후속 개발·연결한다.
- 정식 기능 대상: `TRPG 데이터/1. 프롬프트/1. 이미지 생성 모듈/7. 게임 아이콘 생성`.
- 스킬 스타일 상태: 정규 이식·앵커 확장·저장 정책 갱신 완료.
- 정식 계약: `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/스타일/게임 스킬 아이콘.md`.
- 정식 앵커: `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/견본/게임 스킬 아이콘/` 01~09. 신규 06~09도 512×512 RGB이며 승격 원본과 정식본 SHA-256 일치.
- 확정 다중 출력 계약: 3×3 슬롯 시트를 기본 단위로 생성하되 생성 도구가 반환한 원본 해상도와 셀 구성을 보존한다. 자동 슬롯 분할·크롭·512×512 정규화·1536×1536 재합성·낱개 자동 저장은 하지 않는다. 개별 추출은 마스터의 별도 명시 요청이 있을 때만 파생 작업으로 수행한다.
- 정식 저장 루트: `TRPG 데이터/22. 아이콘 생성` (`1Y_ltZ7MmfrkJI10_nCHULABzfSCHMoFz`). 하위에 `스킬 아이콘` (`1cQITInwiiK1ol1r9aCnDTBA6d6uQi346`)과 `아이템 아이콘` (`14vAZ3Lo7ZiA_YSxaLOzsHQ5jSJmidzsX`)을 사용한다.
- 배치 명명: `<YYYY MMDD> <상위 폴더명> <NN>`. 폴더 내부에는 동명 `.md`와 3×3 시트 원본을 저장한다. 시트 1장이면 동명 `.png`, 여러 장이면 `-1`, `-2` 순번을 붙인다.
- 기존 이관: 2026-09-12의 3×3 스킬 시트 3배치를 `2026 0912 스킬 아이콘 01`~`03`으로 이관하고 각 배치에 동명 MD 인덱스를 작성했다. 과거 4×3·6×6·개별 512 개발 자료와 정식 앵커는 개발/런타임 참조 자산으로 기존 위치에 유지한다.
- 유저스토리·유스케이스: 공통 정본에 `US-I06` 및 `UC-I30`~`UC-I36`을 추가해 원본 시트 보존, 배치 번호, 다중 시트 접미사, MD 인덱스, 개별 추출 파생 작업을 회귀 검증 대상으로 등록했다.
- 검증: 새 22번 폴더 구조, 스킬 배치 01~03의 동명 MD+PNG 구성, 출력 규칙의 비분할 정책, 유스케이스 ID 중복 없음과 신규 케이스 존재를 확인했다.
