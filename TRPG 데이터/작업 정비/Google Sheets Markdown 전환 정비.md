# Google Sheets Markdown 전환 정비

## 목적

작업 폴더에 남은 Google Sheets 4개의 실제 내용을 Markdown으로 안전하게 전환하고 원본 삭제와 검증 결과를 추적한다.

## 상태

- 상태: 완료
- 시작일: 2026-09-06
- 완료일: 2026-09-06
- 설계: `docs/superpowers/specs/2026-09-06-google-sheets-markdown-migration-design.md`
- 실행 계획: `docs/superpowers/plans/2026-09-06-google-sheets-markdown-migration.md`
- 검증 보고서: `docs/superpowers/reports/2026-09-06-google-sheets-markdown-migration-verification.md`

## 원본 기준선

| 대상 | 탭 | 사용 범위 | 데이터 행 |
| --- | --- | --- | ---: |
| 클래스 / 서브클래스 한글화 매핑 | `시트1` | `A1:E341` | 341 |
| D&D 5.5E 추가 주문 모음 | `시트1` | `A1:D135` | 135 |
| D&D 5.5E 추가 주문 상세 데이터 | `시트1` | `A1:G479` | 479 |
| FVTT 룰북 검증 및 갱신 현황 | `룰북 검증 현황` | `A1:D150` | 150 |

## 진행

- 네 원본의 Drive ID, 부모 폴더, 단일 탭 구조를 확인했다.
- 표시값 기준 실제 사용 범위를 전량 읽었다.
- 추가 주문 모음의 B~D열에 2~126행까지 반복 수식 375개가 있고 127~135행은 수동 입력값임을 확인했다.
- FVTT 시트와 같은 이름의 최신 Markdown 정본이 이미 있음을 확인했다. 시트 149개 데이터 행 중 정본과 키가 겹치는 행은 146개지만 값이 다른 행이 132개이고, 이전 분할 파일 기준 행 3개는 정본에 없어 시트 내용을 별도 이전 스냅샷으로 보존하기로 했다.

## 완료

- Google Sheets 4개의 표시값을 341행·135행·479행·150행 Markdown으로 전환했다.
- 업로드한 네 Markdown을 다시 읽어 원본 행렬과 전량 일치함을 확인했다.
- 추가 주문 모음의 수식 375개는 계산된 표시값과 수식 패턴으로 보존했다.
- 기존 FVTT Markdown 정본은 유지하고 시트 내용을 별도 이전 스냅샷으로 보존했다.
- 검증을 통과한 Google Sheets 원본 4개를 영구 삭제했다.
- 전체 작업 폴더의 `.gsheet` 잔여 수가 0개임을 확인했다.
