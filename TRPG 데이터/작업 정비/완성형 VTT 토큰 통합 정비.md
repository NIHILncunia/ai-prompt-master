# 완성형 VTT 토큰 통합 정비

## 상태

- 상태: 완료
- 시작일: 2026-09-01
- 작업 유형: 이미지 생성 모듈 기능 제거·토큰 생성 체계 통합

## 목적

독립 5번 토큰 프레임 기능을 제거하고, 포트레이트 전신 기반 및 사용자 업로드 이미지 기반의 완성형 VTT 토큰 생성으로 통합한다.

## 확정 사항

- 독립 5번 토큰 프레임 기능을 완전히 제거한다.
- 5번은 결번으로 유지한다. 기존 6·7·8번은 재번호하지 않는다.
- 산출물은 프레임 PNG 없이 캐릭터가 포함된 완성형 VTT 토큰 PNG 1장이다.
- 포트레이트 전신 확정본과 사용자 업로드 이미지가 각각 독립적으로 토큰 생성에 진입한다.
- 토큰 계열 프로필은 기준 완성형 토큰과 Markdown으로 관리하며, 대상 유형·설정·역할에 따라 자동 적용한다.
- 등급은 일반·엘리트·보스로 나눈다. 프레임 두께는 공통이며 장식 밀도와 보스 표적성으로 구분한다.
- 보스·표적 정보가 없으면 일반 토큰으로 처리한다.

## 현재 위치

- 포트레이트 전신·업로드 이미지의 두 입력 경로, 자동 계열, 일반·엘리트·보스 규칙을 반영했다.
- 독립 5번 기능 폴더를 제거하고 활성 번호를 `1·2·3·4·6·7·8`로 검증했다.
