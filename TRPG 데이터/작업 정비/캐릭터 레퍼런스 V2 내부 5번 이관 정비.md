## 상태

- 상태: 완료

- 작업 유형: 이미지 생성 모듈 번호 이관·활성 라우팅 동기화

## 확정 사항

- 내부 5번은 캐릭터 레퍼런스 V2 생성으로 사용한다.
- 기존 내부 9번 V2 폴더를 5번으로 이관하고 9번은 제거한다.
- 과거 토큰 프레임 기능은 복원하지 않으며 완성형 VTT 토큰은 내부 1번에 둔다.
- V1 내부 3번과 V2 내부 5번은 모두 캐릭터 레퍼런스 이미지 경로에 저장한다.
