# 클래스 제작 프롬프트 개선 정비

## 목적

D&D 5e 2024 Player’s Handbook의 12개 기본 클래스를 레퍼런스로 분석하여 미세단위 제작 모듈의 클래스 제작 프롬프트와 클래스 데이터 양식을 개선한다.

## 기준 자료

- D&D 5e 2024 Player’s Handbook PDF
- 클래스 제작 관련 기존 프롬프트 및 템플릿

## 룰북 열람 원칙

- 2024 Player’s Handbook 분석은 PDF 원문만 직접 열람한다.
- Markdown 변환본은 클래스 분석 근거로 사용하지 않는다.
- PDF에 실제 수록된 성장표, 클래스 피처, 서브클래스, 자원 구조, 설명 형식을 근거로 분석한다.
- 원문에서 확인되지 않은 내용은 기억이나 외부 지식으로 보충하지 않는다.

## 분석 원칙

각 기본 클래스는 동일한 항목으로 분석한다.

1. 클래스 정체성과 역할
2. PHB의 클래스 문서 구조
3. 기본 클래스 정보와 성장표 구조
4. 1~20레벨 성장 구조
5. 공통 클래스 피처 배치
6. 서브클래스 개방 및 서브클래스 피처 배치
7. 클래스 고유 자원과 성장 방식
8. 반복 강화 피처와 신규 피처의 비율
9. 전투·탐험·사회 기능의 배치
10. 중레벨·고레벨 성장 곡선과 파워 스파이크
11. 20레벨 최종 피처의 역할
12. 클래스 피처 설명문의 작성 구조
13. 클래스 제작 프롬프트에 반영할 설계 규칙
14. 클래스 데이터 양식에 반영할 형식 규칙

## 진행 상태

- 현재: 02. Bard 분석 준비
- 완료: 분석 체계 및 작업 정비 구조 확립, PDF 열람 기준 확정, 01. Barbarian PDF 기반 재분석
- 미결: Bard~Wizard 11개 클래스 분석 및 12개 클래스 횡단 비교

## 후속 단계

12개 클래스 개별 분석 완료 후 다음 순서로 진행한다.

1. 12개 클래스 횡단 비교
2. 공통 설계 패턴 추출
3. 클래스 제작 프롬프트의 문제점 분석
4. 클래스 제작 규칙 재설계
5. 클래스 양식의 PHB 기반 재설계
6. 클래스 제작 마스터 프롬프트 및 하위 지침 갱신
7. 전체 검증
8. Superpowers 완료 보고서 및 레지스트리 완료 처리
9. 정령기사 클래스 제작 재개
