# 이미지 스타일 앵커 체계 정비

## 상태

- 상태: 완료
- 시작일: 2026-09-06
- 작업 유형: 이미지 생성 모듈 스타일 계약·시각 앵커 구조 개편

## 목적

- `애니 페인팅`과 `붓터치 반실사`의 그림체와 디지털 페인팅 마감을 고정한다.
- 캐릭터 디자인·포즈·카메라·배경과 스타일 참조의 책임을 분리한다.
- 캐릭터 레퍼런스와 세션 하이라이트에서 제공 이미지의 그림체를 기본 보존한다.

## 확정 사항

- 각 스타일은 핵심 얼굴·중립 전신·마감의 정식 앵커 3장을 사용한다.
- 03번 마감 앵커는 재질 표본판이 아니라 단일 완성 일러스트의 채색·명암·경계·붓터치·재질 표현·최종 표면 처리 기준이다.
- 정식 앵커 파일명에서는 시안·버전 뒷번호를 제거한다.
- 기존 견본은 삭제하지 않고 비활성 보관 폴더로 이동한다.
- 한 생성에서 스타일 앵커는 최대 2장만 사용한다.
- 앵커의 인물·의상·팔레트·포즈·카메라·배경·구성은 참조하지 않는다.
- 별도 스타일 변경 지시가 없는 V1·V2·세션 하이라이트는 제공 이미지의 그림체를 따른다.

## 완료 범위

- 마스터가 애니 페인팅 핵심 얼굴·연령별 체형 전신·완성 일러스트 마감 앵커와 붓터치 반실사 3장을 순차 확정했다.
- 정식 저장본에서 뒷번호를 제거하는 파일명 규칙을 확정했다.
- 정식 앵커 6장을 활성 폴더에 설치하고 원본 시안과 SHA-256 일치를 확인했다.
- 기존 애니 앵커 11장과 반실사 견본 6장을 비활성 보관 폴더로 이동했다.
- 교체된 애니 페인팅 1차 정식 앵커 3장을 별도 비활성 보관 폴더로 이동했다.
- 두 스타일의 고정 영어 그림체 블록과 공통 고정 영어 마감 블록을 작성했다.
- 스타일 앵커의 콘텐츠·구성 복제 금지와 최대 2장 선택 규칙을 반영했다.
- 포트레이트, 캐릭터 레퍼런스 V1·V2, 세션 하이라이트와 전역 라우터를 동기화했다.
- 정적 검증에서 해시 불일치·구 참조·후행 공백·필수 규칙 누락이 모두 0건임을 확인했다.
- 애니 페인팅 고정 영어 그림체 블록을 확정된 세장형 얼굴선, 절제된 눈, 리본형 머리카락 선묘와 연령별 비례 기준으로 개정했다.
- 재확정 검증 보고서를 `docs/superpowers/reports/2026-09-06-image-style-anchor-restoration-verification.md`에 작성했다.
