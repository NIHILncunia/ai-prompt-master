# 공용 맵 카탈로그 전환 정비

## 상태

- 상태: 완료
- 시작일: 2026-09-09
- 범위: `11. 맵 이미지`와 세션 패키지의 맵 문서·이미지를 `11. 맵` 공용 카탈로그로 통합

## 확정 결정

1. 모든 맵은 재사용 여부와 무관하게 `11. 맵` 공용 카탈로그에만 둔다.
2. 환경 분류 폴더 아래에 맵 문서·풍경·전술맵을 함께 둔다.
3. `map_uuid`는 영구 유지하고, `map_code`와 파일명은 변경할 수 있다.
4. 공용 맵 이름에서는 특정 지역명을 제외한다.
5. 공용 맵 문서는 공간 고유 정보를, 세션 장면 문서는 사건·토큰·배치를 소유한다.
6. 맵 상태는 `초안`, `사용 가능`, `사용 중지`만 사용하고, 사용 이력은 세션의 `map_uuid` 참조로 추적한다.
7. 초기 이관 대상은 6개 맵 항목과 7개 이미지 파일이다.

## 확정 원장

- 비공정: `M_AIRSHIP001` 오리진 비공정, 신규 `map_uuid`, 초안
- 동굴: `M_CAVE001` 수정 동굴, 신규 `map_uuid`, 초안
- 도시: `M_CITY001` 도시 전투 구역, 기존 `map_uuid`, 사용 가능
- 도시: `M_CITY002` 도시 외곽 진입로, 기존 `map_uuid`, 사용 가능
- 성소: `M_SHRINE001` 검은 사수의 왼팔 성소, 기존 `map_uuid`, 사용 가능
- 성소: `M_SHRINE002` 성소 외곽 회랑 및 격리 구역, 기존 `map_uuid`, 사용 가능

## 실행 전 확인

1. 파일별 원본과 목표 경로, SHA-256을 실행 계획에 고정한다.
2. 세션 맵 문서의 공간 정보와 장면 전용 운용 정보를 분리할 위치를 행 단위로 정한다.
3. 활성 세션 문서의 이전 물리 경로 참조만 갱신 대상으로 확정한다.

## 실행 결과

1. 공용 맵 문서 6개와 이미지 7개를 `11. 맵`으로 이관했다.
2. 세션 폴더에는 `맵/00. 맵 목록.md`만 남기고, 장면 01~07이 토큰·사건 운용을 소유하게 했다.
3. 이미지 SHA-256 7개, 공용 UUID 6개, 활성 이전 경로 참조 0건을 확인했다.
4. 이전 폴더의 `desktop.ini`를 제거했고, 항목 수 0의 빈 폴더만 남았다. 실행 환경의 삭제 정책이 폴더 제거를 차단했으나 실제 자산·참조·운영 영향은 없다.
