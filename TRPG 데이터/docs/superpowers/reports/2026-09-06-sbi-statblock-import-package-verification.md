## 요청과 근거

마스터가 인계 자료의 방향에 맞춰 스탯블록 지침을 개선하라고 요청했다. 인계 ZIP의 `07_Import_Package_규격.md`는 참고 자료로 읽었으며, 그 안의 향후 후보를 이번 사용자 요청과 [2026-09-05 실환경 시험](<2026-09-05-fvtt-sbi-ko-live-test.md>) 결과를 근거로 현행 출력 규격에 반영했다.

## 변경 결과

- 메인 스탯블록의 기본 출력을 `===STATBLOCK===`와 `===LOCALIZATION===`를 포함하는 단일 `text` 코드블록으로 바꿨다. 패키지 하나가 임포트 대상 몬스터 한 마리를 담는다.
- 별도 FVTT 한국어 번역을 LOCALIZATION JSON으로 통합했다. 기존 일반 한국어 번역과 창작/조정의 기반 몬스터 원본 제공은 유지했다.
- Item 영문 키, 한글 이름, 전체 설명 대체, JSON 이스케이프, 중복 이름, 인라인 명령·Item 참조 보존 규칙을 추가했다.
- 미확인 매칭·설명과 미검증 자동화는 패키지 밖의 `적용 확인`에 적도록 했다. 안전한 설명 교체가 불가능한 경우 description 생략으로 생성 설명을 보존하는 예외를 명시했다.

## 검증 결과

| 검증 | 결과 |
| --- | --- |
| 예시 JSON | 템플릿 내부 JSON과 부분 예시 2개 파싱 통과 |
| 데이터 형식 | actorName/items 객체·문자열 필드·중복 키·정규화 키 충돌 검사 통과 |
| 번역 대응 | 템플릿 8개 Item 키와 STATBLOCK·일반 번역 대응 확인 |
| 이름 참조 | 부분 예시의 `[[/item 장궁]]`과 최종 한글 이름 일치 |
| 입력 파서 | 기존 수정 매크로에서 추출한 parseImportPackage가 새 자리표시자 패키지와 이전 구체 시험 입력을 모두 해석 |
| 인라인 보존 | 기존 toDescriptionHtml 처리 후 토큰 유지 및 단순 Item 이름 치환 확인 |
| 기존 기준 보존 | 기본 원칙·창작/조정 기준의 본문, 원본 데이터 템플릿, 메인 영문 스탯블록 템플릿이 백업과 동일 |
| Markdown | 대상 파일의 코드펜스 닫힘·상대 링크 존재·문자 인코딩 확인 |
| 공백 | 기존 파일은 `git diff --no-index --check`, 신규 파일은 행말 공백 검사 통과 |
| 관련 문서 | 상위 4개 문서와 6번 FVTT 기능을 검색했으며 기존 별도 FVTT 번역 의무와 충돌하는 규칙 없음 |

작업 폴더는 Git 저장소가 아니므로 백업과 파일별 diff로 검사했다. `git diff --no-index --check`의 차이 있음 반환 코드 1은 공백 오류 출력과 구분했다. 신규 테스트를 제품이나 프롬프트 체계에 추가하지 않았으며 검증 스크립트는 Drive 밖 작업 폴더에 두었다.

## 검증의 한계

이번에는 서버에 재접속하지 않았다. 로컬 검증은 JSON·패키지 해석·번역 대응·문서 일관성 검사이며, 자리표시자 템플릿을 SBI에서 실행한 결과가 아니다. 이전 실환경 결과를 이번에 다시 시험했다고 표현하지 않는다.

주문·Cast Activity·실제 주문 UUID, 내용이 있는 Active Effect, 전설·신화·소굴 비용, 복수 피해·Activity, 복잡한 인라인 참조, 실제 전투 내성·피해 적용·자원 회복은 기존의 별도 시험 대상으로 남는다. 지침 개선을 완료했으며 이 시험들은 본 작업의 미완료 항목으로 확대하지 않는다.
