## 적용 결과

- `준비`, `준비.`는 현재 활성 1~8 기능을 설명형 목록으로 안내한다.
- 이미지 생성 모듈은 내부 1~8 기능을 줄바꿈 불릿으로 표시하고, 요구사항 확인서 → 최종 영어 프롬프트 → 마스터 명시적 승인 → 생성 또는 수정 실행의 공통 절차를 함께 설명한다.
- 비이미지 기능에는 이미지 승인 절차를 표시하지 않고 필요한 연결 관계만 안내한다.
- `준비 ?번`, `준비. ?번`은 프로세스 안내만 하며 실행을 시작하지 않는다.
- SESSION PROGRESS는 모든 실질 응답의 본문 뒤 최하단에 표시하며, 활성형·중단형·대기형과 사용자 표시 생략 예외를 적용한다.
