# 완성형 VTT 토큰 통합 검증 보고서

## 판정

통과. 독립 5번 토큰 프레임 기능을 제거하고, 포트레이트 전신 확정본·사용자 업로드 이미지 기반의 완성형 VTT 토큰 계약으로 통합했다.

## 확인 결과

- `1. 이미지 생성 모듈/5. 토큰 프레임 생성/` 폴더와 하위 문서 12개를 제거했다.
- 활성 내부 기능 폴더는 `1·2·3·4·6·7·8`이며 5번은 결번이다.
- 포트레이트 전신 확정본과 사용자 업로드 이미지의 두 진입 경로가 포트레이트·공통 승인·상위 라우터에서 확인된다.
- 토큰 계열 자동 선택, 일반·엘리트·보스 구분, 보스 표적성, 캐릭터 포함 1:1 투명 PNG 한 장 계약이 확인된다.
- 독립 프레임 경로, `Inner Mask`, 빈 프레임 계약은 0건이다.
- `#FFFFFF` 중앙 원형 표현은 완성형 토큰 지침과 공통 승인 절차의 금지 규칙에만 남아 있다.
- 작업 폴더는 Git 저장소가 아니어서 `git diff --check`와 커밋은 실행하지 못했다.

## 검사 명령

```powershell
rg -n --glob '*.md' '5\. 토큰 프레임 생성|토큰 프레임|중앙.*#FFFFFF|Inner Mask' 'AGENTS.md' '1. 프롬프트'
rg -l --glob '*.md' '포트레이트 전신 확정본|사용자 업로드 이미지' '1. 프롬프트'
Get-ChildItem -LiteralPath '1. 프롬프트/1. 이미지 생성 모듈' -Directory
```
