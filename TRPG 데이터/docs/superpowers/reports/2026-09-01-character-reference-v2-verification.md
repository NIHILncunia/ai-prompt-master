# 캐릭터 레퍼런스 V2 검증 보고서

## 검증 결과

- 이미지 생성 모듈 내부 `9. 캐릭터 레퍼런스 V2 생성` 폴더 생성 확인.
- 기능 폴더 내 `README.md`, `AGENTS.md`, 마스터 프롬프트, 1~4번 세부 지침의 총 7개 Markdown 파일 존재 확인.
- V2 마스터 계약에 `1916 × 821 px`, 목 위 없는 정면·측면·후면, 우측 대형 정면 두상, 두상 중앙 정렬, 조건부 독립 무기 패널, 검은색 데이터 바가 포함됨을 확인.
- 레이아웃 규칙에 전신 3패널 동일 너비와 무기 미존재 시 공간 균등 재분배 규칙이 포함됨을 확인.
- 텍스트 바 규칙에 마스터가 제공한 데이터만 사용하고 임의 필드·값·번역·보완을 추가하지 않는 계약이 포함됨을 확인.
- 이미지 모듈 `AGENTS.md`, 마스터 프롬프트, `README.md`에 내부 9번 등록 완료.
- 공통 이미지 승인 절차의 활성 기능 목록을 `1·2·3·4·6·7·8·9`로 갱신 완료.
- 프로젝트 기본 지침과 통합 마스터 프롬프트에 내부 9번 기능 및 V2 명시 라우팅을 반영 완료.
- 기존 내부 3번 V1 계약은 삭제하거나 덮어쓰지 않고 유지함.
- Superpowers 설계·실행 계획·검증 보고서 업로드 및 작업 레지스트리 완료 상태 기록 완료.
