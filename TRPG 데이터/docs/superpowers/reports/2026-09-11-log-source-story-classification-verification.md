# 로그 원본 스토리 분류 및 진행자 메타데이터 검증

## 검증 범위

- `2. 로그/원본` 최상위 폴더 구조
- `1. 프롬프트/3. 로그 분석 프롬프트`의 `AGENTS.md`, 마스터 프롬프트, 세션 분석 지침, 스토리 정리 지침, README
- 설계·실행 계획 문서

## 구조 검증

- 정규 스토리 원본 폴더: `스토리 1 - 에리디안의 잔향`, `스토리 1 시퀄 - 남아있는 이야기`
- 외전 원본 폴더: `외전 - 마키나즈`, `외전 - 사신`, `외전 - 어두운 시대`, `외전 - 프로즌 서바이버`
- 정규 스토리 판별: 최상위 폴더명에 `스토리 <번호>` 표기가 있는지 확인
- 외전 판별: 위 조건을 충족하지 않는 모든 최상위 원본 폴더

## 진행자 검증

- 마키나즈·사신·프로즌 서바이버: 시어하트어택
- 어두운 시대: 마르도스
- 정규 스토리: 마스터
- 등록된 진행자 이름은 다른 로그에서 PC 이름으로도 사용될 수 있으므로, 이름만으로 발화를 일괄 제외하지 않고 선택한 원본 로그의 진행 맥락을 확인한다.

## 문서 규칙 검증

- `story_type`: `정규 스토리` 또는 `외전`
- `game_master`: 마스터, 등록된 진행자명, 원본 로그에서 확인한 진행자명 또는 `미확인`
- 기존 `룩스테라=메인`, 그 외 스토리=사이드의 자동 판별과 `로그/원본/룩스테라/` 원본 경로 규칙은 제거했다.
- 세션 번호만 지정해 후보가 여러 개인 경우, 정규 스토리를 임의 우선하지 않고 마스터에게 원본 폴더 또는 스토리명을 확인한다.
- 기존 분석본·스토리 정리 문서는 이동하거나 이름을 바꾸지 않는다.
