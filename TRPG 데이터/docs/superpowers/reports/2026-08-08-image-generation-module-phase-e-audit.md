# 이미지 생성 모듈 Phase E 부속 자료 전수 이관 감사

## 작업 ID

`2026-08-08-image-generation-module`

## 목적

기존 이미지 기능 8개 폴더의 직속 문서, 라이브러리, 템플릿, 견본을 전수 확인하고 `이관 / 통합 / 공통 승격 / 폐기 / 보관`으로 판정한다.

## 공통 판정 원칙

- 신규 모듈에서 이미 재작성된 AGENTS/README/마스터/기본 지침은 구 파일을 폐기 후보로 둔다.
- 비어 있는 라이브러리/템플릿 폴더는 이관하지 않는다.
- 구 스타일과 충돌하는 문서는 원본 복사를 금지하고 의미 자산만 재작성한다.
- 예시 프롬프트는 실행 정본이 아니라 `개발 자료/예시`로 보관한다.
- 실제 데이터 라이브러리와 템플릿은 기능 하위에 이관한다.
