## 2. 데이터베이스 정규화 판정

원본 `keyword_management_system.xlsx`는 읽기 전용으로 유지하고, 원본 키워드와 원본 경로를 보존한 Markdown 파생 데이터베이스를 새로 만들었다.

| 데이터 | 활성 항목 수 | 선택 단위 | 검증 |
| --- | ---: | --- | --- |
| 장르 | 344 | 장르 1개 | GEN ID·계층·상태·원본 근거 확인 |
| 주제 | 2,702 | 주제 1개 | THE ID·주제 축·상태·원본 근거 확인 |
| 장면 소재 | 3,208 | 내부 조합 소재 | SCN ID·장면 축·상태·원본 근거 확인 |

원본의 중복 키워드는 표기 단위로 통합하고, 파생 데이터의 각 항목에는 원본 근거 또는 `신규 보강` 표기를 남겼다. 이 데이터는 소설 과제에서 장르·주제만 공개하고, 장면 묘사 과제에서는 내부 소재를 노출하지 않는 계약을 따른다.
