# 이미지 스타일 앵커 재확정 검증 보고서

## 검증 목적

마스터가 재확정한 애니 페인팅 핵심 얼굴·연령별 체형 전신·완성 일러스트 마감 앵커를 정식 경로에 설치하고, 두 정식 스타일의 03번 역할을 재질 표본판이 아닌 마감 앵커로 통일했는지 검증한다.

## 최종 정본 구조

두 스타일의 활성 폴더에는 다음 파일만 존재한다.

1. `01. 핵심 얼굴 앵커.png`
2. `02. 중립 전신 앵커.png`
3. `03. 마감 앵커.png`

03번은 완성된 단일 일러스트가 보여주는 채색층·명암·경계·붓터치·재질 표현·최종 표면 처리 기준이다. 재질별 견본을 나열한 표본판으로 사용하지 않는다.
