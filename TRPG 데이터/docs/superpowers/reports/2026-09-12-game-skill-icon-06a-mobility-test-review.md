# 2026-09-12 게임 스킬 아이콘 06A 물리 기동 보완 테스트 검수

## 1. 목적

정식 `게임 스킬 아이콘` 스타일에서 부족했던 `06A 기동·대시·회피` 계열의 범용 앵커 후보를 찾는다. 직전 테스트의 두 실패 원인인 `투사체화`와 `전신 캐릭터 의존`을 제거하고, 64×64에서도 물리적 위치 이동이 읽히는지 검증한다.

## 2. 원시 출력 및 정규화

- 원시 이미지: 1254×1254
- 열 경계: 0 / 418 / 836 / 1254
- 실제 행 경계: 0 / 393 / 785 / 1254
- 원시 행 높이: 393 / 392 / 469
- 원시 셀은 정사각 균등분할이 아니므로 단순 418×418 등분 금지
- 실제 시각 경계로 분할 후 각 슬롯을 512×512로 정규화
- 최종 시트: 1536×1536
- 64×64 축소 접촉 시트로 판독성 재검수
- 초기 균등분할본은 오분할로 폐기하고 Drive 파일을 동일 ID로 교체

## 3. 개별 판정

| 번호 | 개념 | 판정 | 근거 |
| --- | --- | --- | --- |
| 01 | Dash | 강한 통과 | 단일 부츠 + 후방 속도 폭발로 전진이 명확하고 투사체로 변하지 않음 |
| 02 | Dodge | 강한 통과 | 부츠 위치 이탈과 곡선 잔상으로 회피 이동이 읽힘 |
| 03 | Sidestep | 통과 | 두 발 위치와 수평 이동 흔적으로 횡이동이 읽힘. 64px에서는 Dodge와 일부 수렴 |
| 04 | Leap | 통과 | 위쪽으로 솟는 부츠와 하부 압력으로 도약이 읽힘 |
| 05 | Backstep | 부분 통과 | 이동 자체는 명확하나 정지 이미지에서 전진/후퇴 방향의 절대 판정은 약함 |
| 06 | Afterimage Movement | 최우수 후보 | 단일 실제 부츠 + 제한된 위치 잔상으로 이동·속도·연속 변위가 동시에 읽히며 범용성이 가장 높음 |
| 07 | Burst Acceleration | 부분 통과 | 강한 가속감은 있으나 폭발성 표현 때문에 발차기/착지 충격으로도 읽힐 수 있음 |
| 08 | Sharp Turn | 강한 통과 | 발 + 곡선 궤적으로 급선회가 명확하고 투사체화가 없음 |
| 09 | Breakthrough Movement | 실패 | 부츠가 장벽을 깨는 공격/킥으로 읽혀 이동 스킬보다 타격 스킬에 가까움 |

## 4. 64×64 검수

- 9종 모두 부츠/발놀림 계열의 대형 실루엣과 주색이 유지된다.
- 01, 02, 06, 08은 축소 후에도 이동성의 차이가 비교적 잘 남는다.
- 03과 05는 축소 시 일반적인 발놀림 계열로 수렴한다.
- 07과 09는 축소 시 `이동`보다 `충격/타격` 인상이 강해진다.
- 따라서 06A 앵커는 세부 기동 종류를 모두 표현하는 이미지보다 `범용 물리 이동 문법`을 대표해야 한다.

## 5. 결론

`06_afterimage_movement_512.png`를 06A 정식 앵커의 **최우수 후보**로 판정한다.

이유:
1. 전신 캐릭터가 없다.
2. 투사체처럼 보이지 않는다.
3. 64×64에서도 이동이 즉시 읽힌다.
4. 대시·회피·질주·재배치·기동 등 다양한 물리 이동에 재사용 가능한 범용 문법이다.
5. 부츠 하나와 제한된 위치 잔상이라는 구조가 너무 특정한 스킬 이름이나 세계관에 종속되지 않는다.

`01_dash_512.png`, `02_dodge_512.png`, `08_sharp_turn_512.png`는 보조 후보로 유지한다. 다만 기본 정식 앵커 수를 늘리지 않기 위해 06A는 우선 06번 한 장만 승격 후보로 둔다.
