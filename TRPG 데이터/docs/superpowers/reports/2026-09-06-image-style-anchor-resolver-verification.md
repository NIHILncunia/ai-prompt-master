## 실행 판정 기록

1. 비-Git 작업공간에서는 작업 전 스냅샷, SHA-256 해시, `git diff --no-index`를 검토 증거로 사용했다. Git 이력보다 롤백과 검토 증거 확인이 불편할 수 있으므로 작업별 스냅샷과 해시 목록, no-index diff 결과를 함께 보존했다.
2. Bash helper가 한국어 `G:` 경로에서 실패하여 PowerShell의 fence-aware Task brief 추출을 사용했다. Task 경계를 잘못 추출할 위험은 대상 heading, 다음 heading, 추출 line count를 함께 검증하여 완화했다.
3. Task 1 재검토 시점의 늦은 snapshot은 변경 전 증거로 무효이므로, 초기 검토 패키지의 pre-fix 문장과 현재 문장을 직접 비교했다. 실제 누락을 은폐할 위험은 old/new 원문과 재판정 결과를 함께 보존하여 완화했다.
4. 애니 페인팅 3앵커 조합은 얼굴·흉상에 01+03, 반신·전신에 02+03을 사용하고, 독립 나이 앵커 우선 예외는 별도 나이 앵커를 선언한 스타일로 제한했다. 참조 예산이 빡빡한 연령 핵심 애니 얼굴에는 별도 승인 앵커가 필요할 수 있다.
5. 구 계약을 찾는 첫 regex는 같은 줄의 애니 페인팅 절을 오탐했다. raw 결과를 보존하고 `애니 페인팅` 경계를 둔 PCRE2로 재검증했으며, 실제 구 반실사 문장을 놓칠 위험은 raw match와 실행 명령을 함께 보존하여 완화했다.
