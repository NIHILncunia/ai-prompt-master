# 이미지 생성 모듈 통합 현행 규칙 1차 감사

## 목적

`2026-08-08-image-generation-module`의 첫 실행 단계로서, 기존 이미지 생성 기능 8개의 현행 규칙을 `보존`, `공통 승격`, `폐기`, `재작성`으로 분류한다.

## 확인 범위

- 기존 1번 포트레이트
- 기존 2번 배틀맵
- 기존 3번 캐릭터 레퍼런스 시트
- 기존 5번 세션 하이라이트 이미지
- 기존 10번 토큰 프레임
- 기존 12번 풍경 일러스트
- 기존 13번 게임 아이콘
- 기존 14번 월드 지도
- `공통/1. 이미지 생성 공통 승인 절차.md`

## 공통 분류

| 규칙 | 처리 | 근거 |
| --- | --- | --- |
| 요구사항 확인서와 최종 영어 프롬프트 공개 후 명시적 승인 | 공통 승격 | 8개 이미지 기능 모두 같은 승인 하드 게이트를 반복한다. |
| 후속 시안의 재승인 | 공통 승격 | 컨셉·대상·출력 형식·색감이 바뀌면 이전 승인을 재사용하지 않는 규칙이 반복된다. |
| 기능별 산출물 계약 | 보존 | 승인 절차는 공통이지만 단일 인물, 시트, 맵, 아이콘의 출력 구조는 기능별로 다르다. |
| 기능별 세부 렌더링 문구 | 기능별 재작성 | 공통 문서에 복제하지 않고 스타일 또는 기능 전용 규칙으로 분리한다. |

## 기능별 분류

### 기존 1번 포트레이트 → 신규 내부 1번 반실사 포트레이트

- 보존: 단일 대상, 세로 9:16, 전신과 두상·흉상·상반신의 별도 출력 경계, 종족 시각 자료 확인, 사용자 이미지 보존 규칙.
- 공통 승격: 승인·재승인·요구사항 확인서.
- 폐기: `photorealistic cinematic 3D CGI`, `AAA game cinematic`, `3D-only` 강제 규칙. 8월 8일 명세의 붓터치 반실사 방향과 충돌한다.
- 재작성: 붓터치 반실사 스타일 계약, 전신/흉상 문서의 관계, 공통 대상 라이브러리 참조 방식.

### 기존 2번 배틀맵 → 신규 내부 2번 배틀맵 생성

- 보존: `사전 풍경 → scenic_prompt.yml → 격자·방향 확정 → true top-down Foundry VTT 배틀맵` 파이프라인, 기본 gridless, 탑뷰·전술 가독성, 독립 풍경 기능과의 경계.
- 공통 승격: 승인·재승인.
- 폐기: 공통 승인 문구와 상위 운영 문서의 반복 전문.
- 재작성: 공통 규칙 참조로 축약하고, 실내/실외·지형·격자 문서를 새 내부 구조에 맞게 분리한다.

### 기존 3번 캐릭터 레퍼런스 시트 → 신규 내부 3번 캐릭터 레퍼런스 생성

- 보존: 가로 16:9, 좌측 소개·메인 흉상, 우측 정면 전신·후면 전신·cm 키 기준선, 정확히 3개의 캐릭터 표현, 장면형·전투형·상세 컷 금지.
- 공통 승격: 승인·재승인, 종족 공통 데이터의 외형 사실 참조 원칙.
- 폐기: 공통 승인 전문의 중복.
- 재작성: 고정 시트 계약을 단일 전용 지침으로 정리하고, 대상 라이브러리는 신체 구조 해석에만 사용한다.

### 기존 5번 세션 하이라이트 → 신규 내부 4번 세션 하이라이트 이미지 생성

- 보존: Character Reference·Highlight Card·풍경 이미지·scenic_prompt.yml 결합, 캐릭터 외형/사건/배경의 출처 우선순위, 기본 시네마틱 장면, 중심 인물 1~3명, 배틀맵 오염 방지.
- 공통 승격: 승인·재승인.
- 폐기: 공통 승인·운영 진입점의 반복 전문.
- 재작성: 단일 장면·인물 중심·단체 장면·정보 포함형의 가변 레이아웃 선택 구조로 재구성한다.

### 기존 10번 토큰 프레임 → 신규 내부 5번 토큰 프레임 생성

- 보존: 1:1 캔버스, 큰 `#FFFFFF` 완전 원형 중앙 마스크, 중앙 침범 금지, 5레이어 구조, 부착 오브젝트 왜곡 금지, 평면 디지털 에셋 방향, 실패 방지 검수.
- 공통 승격: 승인·재승인.
- 폐기: 공통 승인과 상위 동기화 규칙의 반복 전문.
- 재작성: 프레임 유형 규칙과 입력 모드를 분리하면서 전용 템플릿·개념 라이브러리를 유지한다.

### 기존 12번 풍경 → 신규 내부 6번 풍경 생성

- 보존: 독립 환경 아트의 정체성, 기본 16:9 시네마틱 와이드, 장소성·랜드마크·원근·시간대·날씨, 탑뷰/배틀맵/아이소메트릭 제외.
- 공통 승격: 승인·재승인.
- 폐기: 공통 승인 전문과 다른 기능의 경계 설명 중복.
- 재작성: 실내·실외·특수 환경 분기로 재구성한다.

### 기존 13번 게임 아이콘 → 신규 내부 7번 게임 아이콘 생성

- 보존: 1:1, 단일 핵심 개념, 64×64 판독성, 프레임 없음, 단순 검정·차콜·회색 배경, 컷아웃 친화적 가장자리, 다중 아이콘의 스타일 잠금.
- 공통 승격: 승인·재승인.
- 폐기: 여러 아이콘을 반드시 별도 이미지로만 생성한다는 고정 규칙. 신규 설계의 단일·개별 세트·격자 시트·스프라이트 시트 선택 계약과 충돌한다.
- 재작성: 아이콘 스타일과 출력 구성(레이아웃)을 조립하되, 단일 아이콘은 레이아웃을 참조하지 않도록 한다.

### 기존 14번 월드 지도 → 신규 내부 8번 월드 지도 생성

- 보존: 랜덤/사용자 지정 세계 전도·대륙 지도 4모드, 16:9, 컬러풀 양피지, 종이 바깥 무광 검정, 종이 안쪽 파란 바다, 상하좌우 약 200픽셀 바다 여백, 지도 판독 우선.
- 공통 승격: 승인·재승인, 사용자 제공 이미지 보존의 일반 원칙.
- 폐기: 공통 승인 전문의 반복.
- 재작성: 전도/지역도 분기와 라벨링·양피지 규칙을 전용 문서로 재조립한다.

## 구현 전 결정 필요 사항

### 포트레이트 산출물 계약 충돌

현행 최상위 지침과 공통 승인 절차는 전신과 초상화를 서로 독립된 요청·확인서·승인·생성으로 고정하고, 전신 생성 뒤 초상화를 자동 실행하지 않도록 규정한다.

반면 이미지 생성 모듈 상세 실행 명세와 인계 문서는 `전신 9:16 1장 → 전신 확정 → 확정 전신 기반 흉상 9:16 1장`을 신규 고정 계약으로 제시한다.

이는 단순 문구 변경이 아니라 승인 단위와 기능 동작을 바꾸는 충돌이다. 신규 모듈 골격을 작성하기 전에 어느 계약을 정본으로 할지 확정해야 한다.

### 누락된 선행 문서

레지스트리와 인계 문서가 지정한 아래 파일은 현재 존재하지 않는다.

- `specs/2026-08-08-image-generation-module-design.md`
- `plans/2026-08-08-image-generation-module-plan.md`

현재는 상세 실행 명세와 인계 문서로 분석을 진행했다. 새 구조 작성 전에는 누락 문서를 복원하거나, 레지스트리와 인계 문서의 참조를 현존 문서로 정정해야 한다.
