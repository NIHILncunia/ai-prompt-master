## 잔재 범위

활성 문서에서 구 번호 표현을 확인했다.

- `8번 기능`, `8번에서`: 설정 기능 의미로 다수 잔존
- `9번`: 31건. FVTT 기능 의미 및 과거 19번 개발 자료 포함
- `10번`, `12번`, `13번`, `14번`: 토큰 프레임·풍경·아이콘·월드 지도 기능 의미로 잔존
- 세션 제작의 `개발 자료`에는 과거 19번 등록 지침이 남아 있으며, 활성 기능 문서와 분리되지 않았다.

## 결론

상위 루트 라우터의 기본 호출은 대체로 현행 구조를 안내하지만, 각 기능을 직접 진입하거나 복합 요청을 처리하는 경로는 이전 번호 체계가 남아 있어 정상으로 판정할 수 없다. 활성 운영 체계의 최종 판정은 실패이며, 먼저 구 번호와 공통 승인 절차 연결을 정비한 뒤 같은 시나리오 매트릭스를 재실행해야 한다.
