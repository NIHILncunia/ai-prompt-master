## 제한 사항

이 작업 폴더는 Git 저장소가 아니므로 `git diff --check`와 커밋 검증은 수행할 수 없다. Markdown 지침 변경의 특성에 맞춰 파일 존재성·정적 문자열·실제 디렉터리 구조 검증으로 대체했다.
