# 프롬프트 라우팅 결함 수정 검증 보고서

## 검증 대상

- 이미지 생성 모듈 내부 1~8번의 직접 진입 계약
- 설정·룰북·FVTT·창작 지원·세션 제작의 현행 번호 라우팅
- 활성 Markdown의 상대 링크
- 세션 제작에 남아 있던 구 개발 자료의 활성 경로 포함 여부

## 수정 결과

1. 이미지 생성 모듈 내부 1~4번 `AGENTS.md`에 공통 승인 절차 읽기 경로와 승인 후 실행 계약을 추가했다.
2. 공식 룰북 참조는 4번, 설정 정본 참조는 5번, FVTT 참조는 6번으로 문맥별 정정했다.
3. 토큰 프레임·풍경·게임 아이콘·월드 지도 참조는 이미지 생성 모듈 내부 5·6·7·8번으로 정정했다.
4. 창작 지원의 준비 호출은 `준비 7번` 및 `7번 <제작기명> 준비.`로 통일했다.
5. 세션 제작의 구 개발 자료는 `1. 프롬프트/보관/2026-08-08-세션 제작 구 개발 자료/`로 이동해 활성 라우팅에서 분리했다.

## 판정

활성 프롬프트 체계는 현재 1번 이미지 생성 모듈과 2~8번 기능 체계로 일관되게 라우팅된다. 이미지 생성은 내부 기능 어디로 직접 진입해도 공통 승인 절차를 먼저 적용하며, 비이미지 기능은 이미지 승인 절차를 요구하지 않는다. 보관 문서의 과거 번호는 이력 보존 대상이므로 활성 라우팅 판정에서 제외한다.
