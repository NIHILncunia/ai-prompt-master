# TRPG 프롬프트 표준화 시범 이관 검증 보고서

## 적용 범위

- 상위 표준 규약: 루트 AGENTS, 프롬프트 루트 AGENTS, 프로젝트 기본 지침, 통합 마스터, 구조 개편 설계서
- 시범 기능: 7번 룰북 관련 요청, 19번 세션 제작

## 7번 결과

- `README.md`와 빈 `라이브러리/`을 추가했다.
- 기존 `템플릿/`을 유지했다.
- 실행 문서는 0·1·2·3이며, `9999. D&D 룰북 소유 리스트.md`는 조건부 색인 예외로 유지했다.
- 스탯블록 템플릿의 `text` 코드블록은 3개이며, FVTT 임포트 레이아웃을 변경하지 않았다.

## 19번 결과

- `README.md`, 빈 `라이브러리/`, `개발 자료/`를 추가했다.
- `8. 세션 제작 예시 라이브러리.md`를 `8. 세션 제작 예시.md`로 이름만 변경했다.
- `검증 보고서.md`와 `상위 문서 등록 및 동기화 수정 지침.md`를 내용 변경 없이 `개발 자료/`로 이관했다.
- 실행 문서는 0번부터 8번까지 연속 번호를 유지한다.
- 템플릿은 단일 세션, 세션 아크 개요, 연속 세션 회차로 조건부 선택하도록 등록했다.

## 검증 결과

- 7번 필수 구조: AGENTS, README, 0번 마스터, 라이브러리, 템플릿 존재
- 19번 필수 구조: AGENTS, README, 0번 마스터, 라이브러리, 템플릿, 개발 자료 존재
- 7번 이전 루트 지침 경로: 0건
- 19번 이전 예시·비정규 파일 경로: 0건
- 19번 이관 파일 SHA-256: 이동 전과 동일
- 활성 프롬프트 Markdown의 과거 `TRPG 데이터/프롬프트/` 경로: 0건 (44개 문서를 `TRPG 데이터/1. 프롬프트/`로 정규화)
- 스탯블록 템플릿은 줄 시작 ` ```text ` 코드블록 3개를 확인했으며, 설명 문구의 인라인 표기는 코드블록 수에서 제외했다.

## 다음 기능군 이관 체크리스트

1. 이동 전 파일·폴더·직접 참조를 목록화한다.
2. 0번 마스터와 실행 문서의 번호 연속성을 확인한다.
3. README·라이브러리·템플릿을 만들고 각 책임을 기록한다.
4. 예시와 검수는 실행 문서로, 재사용 자료는 라이브러리로, 출력 구조는 템플릿으로 분리한다.
5. 비정규 파일은 삭제하지 않고 `개발 자료/`로 보존한다.
6. 기능 AGENTS와 0번 마스터의 조건부 읽기 순서를 갱신한다.
7. 이전 경로, 새 경로, 번호, 링크, 코드 펜스를 검증한다.

## 보류 항목

- 공통 라이브러리에는 실제 공유가 입증된 운영 자료만 이관한다.
- 프로젝트 위그드라실의 설정 정본은 공통 라이브러리에 복제하지 않는다.
- 1번과 11번의 0번 마스터 정규화는 후속 기능군 이관에서 처리한다.
