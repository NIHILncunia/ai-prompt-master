## 요약

루트·프롬프트 라우터에서 활성 1~8 기능을 안내하는 기본 흐름은 정상이다. 최상위 8개와 이미지 모듈 내부 8개의 AGENTS·README·0번 마스터도 모두 존재하며, 활성 Markdown에서 추출한 전체 프롬프트 경로 84건은 모두 실경로로 확인됐다.

그러나 기능 폴더를 직접 진입하거나 설정·FVTT·창작 지원·세션 제작·대륙 지도 같은 복합 요청을 처리하는 시나리오에서는 이전 기능 번호가 남아 있다. 따라서 현재 체계가 모든 루트 탐색에서 자연스럽게 작동한다고 판정할 수 없다.

## 우선 수정 대상

1. 이미지 모듈 내부 1~4번 AGENTS와 마스터에 공통 승인 절차 직접 참조를 추가한다.
2. 5번 설정 관련 요청 및 공통 종족 데이터의 구 7·8·14번 의미를 현행 4·5·이미지 모듈 내부 8번으로 전환한다.
3. 6번 FVTT 관련 요청의 구 7·8·9·10·13번 의미를 현행 4·5·6·이미지 모듈 내부 5·7번으로 전환한다.
4. 7번 창작 지원 하위 제작기의 구 7·8·9·13번 의미를 현행 4·5·6·이미지 모듈 내부 7번으로 전환한다.
5. 8번 세션 제작의 구 9·12·13·14번 의미를 현행 6번·이미지 모듈 내부 6·7·8번으로 전환한다.
6. `공통/` 및 활성 기능 폴더 안의 과거 19번 개발 자료를 보관으로 이동하거나, 현행 운영 대상이 아님을 명시적으로 분리한다.

## 재검증 조건

- 이미지 내부 1~8의 AGENTS·0번 마스터 모두에 공통 승인 절차 경로가 확인된다.
- 활성 운영 문서에서 구 기능 번호가 현행 기능 의미로 쓰이는 사례가 0건이다.
- `준비.`·설정·FVTT·창작 지원·세션 제작·지도 복합 요청의 라우팅 시나리오가 모두 현행 1~8 구조로 통과한다.
