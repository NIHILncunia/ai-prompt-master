# PNG-WebP 이미지 포맷 정규화 설계

## 목적

`TRPG 데이터`와 모든 하위 폴더의 실제 PNG 자산을 lossless WebP로 전환하고, 현재 로컬 자산 참조와 활성 이미지 생성 규칙을 WebP 기준으로 통일한다. 이미지의 해상도, 크롭, 색상, 투명도, 캐릭터 디자인과 디렉터리 구조는 바꾸지 않는다.

## 실행 범위

- 실제 작업 루트: `C:\Users\nihil\coding\ai\ai-data-master\TRPG 데이터`
- 현재 존재하는 대소문자 무관 `*.png` 파일 전수
- Git에서 이미 삭제되고 같은 stem의 신규 WebP가 존재하는 선행 미커밋 변환본
- 실제 변환 자산을 가리키는 로컬 텍스트 참조
- 신규 이미지 출력 형식을 정하는 현재 활성 지침
- PNG 작업이 끝난 뒤 수행하는 활성 로컬 저장소 경로의 `ai-data-master` 전환

## 보존 범위

- 기존 사용자 미커밋 변경
- 외부 URL의 `.png`
- 당시 PNG 산출 사실을 기록한 역사 문장
- PNG 형식 자체를 설명하는 기술 문장
- 기존 폴더 구조와 각 파일의 stem

## 변환 계약

- Pillow의 lossless WebP 인코딩을 사용한다.
- 원본 width와 height를 유지한다.
- 원본 PNG와 WebP를 RGBA로 디코딩하여 alpha 전체와 alpha가 0보다 큰 픽셀의 RGB를 비교한다.
- 완전 투명 픽셀의 숨은 RGB 차이만 허용한다.
- ICC, EXIF, XMP는 Pillow가 읽어 제공하는 값을 가능한 범위에서 전달한다.
- APNG는 자동 변환하지 않고 충돌 목록으로 분리한다.
- 동일 stem WebP가 있으면 디코딩 비교 후 동일본 유지, 정본 교체, 보류 중 하나로 판정한다.
- 원본 PNG는 WebP 생성·재오픈·픽셀·alpha·참조 검증이 끝난 항목만 삭제한다.

## 충돌 보호

- 사전 Git 상태를 기준선으로 보존한다.
- 이미 수정된 문서의 기존 내용은 유지하고 필요한 최소 참조·활성 규칙만 추가 수정한다.
- 기존 변경과 같은 문장을 서로 다르게 바꿔야 하는 경우 자동 선택하지 않고 충돌로 남긴다.
- `TRPG 데이터` 밖의 형제 폴더는 변경하지 않는다.

## 완료 조건

1. 보류된 APNG나 미해결 충돌을 제외한 실제 PNG 파일이 0개다.
2. 신규·선행 WebP가 모두 열리고 원본과 해상도·가시 픽셀·alpha가 일치한다.
3. 변환 매니페스트의 현재 로컬 PNG 참조가 0건이다.
4. `.png` 잔존 문자열의 수정 누락 분류가 0건이다.
5. 활성 이미지 생성 규칙이 WebP와 WebP alpha를 기본 출력으로 사용한다.
6. 활성 로컬 저장소 경로가 `ai-data-master`를 가리킨다.
7. 대표 자산 유형을 직접 열어 시각적으로 확인한다.
8. `git diff --check`, `git status`, `git diff --stat`, `git diff` 검토를 마친다.
