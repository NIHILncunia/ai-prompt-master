# 루트 지침 체계 정합성 정정 설계

## 목적

`TRPG 데이터` 루트에서 하위 프롬프트·기능 문서까지 이어지는 활성 지침의 경로, 번호, 라우팅, 상태 기록을 현재 실제 구조와 일치시킨다.

## 범위

1. `준비` 호출의 활성 기능 체계를 최상위 1~8로, 이미지 모듈 내부 기능 집합을 `1·2·3·4·6·7·8`로 분리해 표기한다.
2. 실제 파일로 해석되지 않는 상대 Markdown 참조 5건을 정정한다.
3. 활성 문서의 구 번호 `16번`과 모호한 `2번` 라우팅을 현재 기능 경로로 바꾼다.
4. 완성형 VTT 토큰 통합의 작업 정비 현황을 공식 레지스트리의 완료 상태와 일치시킨다.

## 비범위

- 이미지 생성 계약, 토큰의 두 입력 경로, 출력 형식, 승인 절차의 제품 규칙은 변경하지 않는다.
- 과거 Superpowers 설계·계획·검증 보고서의 당시 기록은 역사 자료로 보존한다.
- 설정 정본과 룰북 데이터의 내용은 변경하지 않는다.

## 정정 원칙

- 최상위 기능 번호는 `1~8`을 유지한다.
- 이미지 모듈 내부 번호는 결번 5를 포함한 범위 표기 대신 실제 집합 `1·2·3·4·6·7·8`로 쓴다.
- 활성 라우팅은 숫자만 쓰지 않고 필요한 경우 `1번 이미지 생성 모듈 내부 2번`처럼 소속을 함께 적는다.
- 상대 경로는 문서가 있는 디렉터리를 기준으로 실제 존재하는 정본 파일만 가리킨다.
- 작업 상태의 정본은 `SUPERPOWERS WORK REGISTRY.md`이며, 작업 정비 현황은 이를 반영한다.

## 대상 파일

- 루트 및 상위 라우터: `AGENTS.md`, `1. 프롬프트/AGENTS.md`, `1. 프롬프트/00. TRPG 세션 매니저 프로젝트 기본 지침.md`, `1. 프롬프트/0. TRPG 데이터 프롬프트 통합 마스터 프롬프트.md`
- 상대 경로: `공통/종족 데이터/AGENTS.md`, `7. 창작 지원 프롬프트/특성 제작/라이브러리/크리처 유형 대분류-중분류 인덱스.md`, `7. 창작 지원 프롬프트/아이템 제작/템플릿/아이템 템플릿.md`, `1. 이미지 생성 모듈/1. 반실사 포트레이트/4. 품질 및 금지 규칙.md`
- 라우팅: `8. 세션 제작 프롬프트/3. NPC 설계 지침.md`
- 상태 기록: `작업 정비/작업 정비 현황.md`

## 검증 기준

- 활성 프롬프트 전체에서 실제 상대 Markdown 참조의 누락이 0건이다.
- 활성 문서에서 `16번은 NPC 이미지 생성` 표현이 0건이다.
- 이미지 모듈 내부 활성 기능을 `1~8`로 범위 표기한 문장이 0건이며, 실제 7개 폴더와 표기가 일치한다.
- `완성형 VTT 토큰 통합`은 레지스트리·개별 정비 문서·작업 정비 현황 모두 완료 상태와 후속 작업 없음으로 일치한다.
- 상위 라우터에서 배틀맵 및 `scenic_prompt.yml`은 이미지 모듈 내부 2번으로 명시된다.
