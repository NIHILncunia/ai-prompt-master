# 캐릭터 레퍼런스 V2 설계

## 목표
기존 내부 3번 캐릭터 레퍼런스 기능을 유지한 채, 최신형 프로덕션 레퍼런스 시트 계약을 별도 내부 9번 기능으로 추가한다.

## 확정 설계
- 기능 번호: 이미지 생성 모듈 내부 9번
- 폴더명: `9. 캐릭터 레퍼런스 V2 생성`
- 해상도: `1916 × 821 px` 고정
- 기본 시각 요소: 목 위 없는 정면·측면·후면 전신 3면 + 우측 대형 정면 두상
- 전신 3패널: 항상 동일 너비
- 두상: 가장 큰 핵심 영역, 정면, 패널 중앙, 강한 클로즈업
- 배경: 완전한 단색만 허용
- 무기: 존재할 때만 독립 패널, 전신에서는 제거
- 무기 없음: 무기 패널 자체를 제거하고 전신 3패널에 공간 균등 재배분
- 하단 데이터 바: 검은색 고정, 마스터 제공 데이터만 그대로 사용
- 저장: `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/`

## 라우팅
- 명시적 `V2`, `버전 2`, `캐릭터 레퍼런스 V2` 요청은 내부 9번으로 라우팅한다.
- 기존 일반 레퍼런스 시트 계약은 내부 3번에 보존한다.
