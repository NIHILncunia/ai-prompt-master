# 7번 룰북 프롬프트 Markdown 정리 설계

## 목적

루트에 남아 있는 룰북 관련 Markdown을 `1. 프롬프트/7. 룰북 관련 요청 프롬프트`로 이관하고, 처리 규칙과 산출물 레이아웃을 분리한다.

## 대상 구조

```text
7. 룰북 관련 요청 프롬프트/
├─ AGENTS.md
├─ 0. 룰북 관련 요청 마스터 프롬프트.md
├─ 1. 룰북 관련 요청 지침서.md
├─ 2. 몬스터 스탯블록 지침.md
├─ 3. 룰북 몬스터 리스트업 지침.md
├─ 9999. D&D 룰북 소유 리스트.md
└─ 템플릿/
   ├─ 몬스터 스탯블록 출력 템플릿.md
   └─ 룰북 몬스터 리스트업 출력 템플릿.md
```

## 책임 분리

- 2번 문서는 공식/커스텀 분기, 기반 몬스터 확인, 명중 보정, 번역, 검수 규칙을 맡는다.
- 3번 문서는 룰북 탐색, 수록 여부 판정, 출처 표기 규칙을 맡는다.
- 템플릿 폴더는 최종 산출물의 레이아웃만 맡는다.
- 9999번 문서는 룰북 보유 여부와 유형을 확인하는 색인이다.

## 보존 규칙

- FVTT 임포트에 사용하는 몬스터 스탯블록 `text` 코드블록의 필드 순서, 공백, 영문 표기, 섹션 구성, 번역 블록 형식은 변경하지 않는다.
- 마스터와 일반 지침서는 요청 유형에 따라 필요한 지침 및 템플릿만 조건부로 읽는다.
- 이동된 파일을 참조하는 문서의 경로와 파일명은 새 구조에 맞게 갱신한다.

## 범위 제외

- Google Drive의 파일·폴더·문서는 수정하지 않는다.
- 드라켄하임 오염 규칙 문서의 이동은 이번 작업에서 보류한다.
- 19번 기능의 상위 등록 정합성은 별도 정리 작업으로 남긴다.
