# Superpowers 자동 추적 및 작업 정비 정식화 설계

## 목적
모든 실질 작업에서 Superpowers 문서와 완료 상태 추적을 자동 수행하고, `TRPG 데이터/작업 정비`를 작업 폴더의 정식 장기 작업 추적 체계로 등록한다.

## 설계
- 전역 지침 3종과 Superpowers 문서 운영 규칙에 자동 문서화·자동 레지스트리 갱신을 명시한다.
- 작업 정비는 설정 정비와 역할을 분리한다. 설정 정비는 설정 정본, 작업 정비는 작업 폴더 내부 장기 작업을 담당한다.
- 장기 작업은 `docs/superpowers`와 `작업 정비`를 병행 기록한다.
- 작업 정비 운영 지침을 별도 정본으로 생성한다.

## 완료 조건
1. 전역 지침 3종 반영
2. Superpowers 문서 운영 규칙 반영
3. 작업 정비 운영 지침 생성
4. 설계·계획·검증 보고서 생성 및 Drive 존재 확인
5. 레지스트리 완료 처리
