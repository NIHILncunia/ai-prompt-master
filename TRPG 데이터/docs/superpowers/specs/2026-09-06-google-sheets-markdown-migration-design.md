# Google Sheets Markdown 전환 설계

## 목적

작업 폴더에 남아 있는 Google Sheets 4개의 실제 사용 범위를 전량 읽고, 현재 표시값과 문서 구조를 보존한 Markdown으로 전환한 뒤 원본 시트를 정리한다.

## 대상

1. `4. 한글화/클래스   서브클래스 한글화 매핑.gsheet`
2. `D&D 5.5E 추가 주문 모음.gsheet`
3. `D&D 5.5E 추가 주문 상세 데이터.gsheet`
4. `작업 정비/룰북 인덱싱 및 FVTT 컴펜디움 이관 체계/FVTT 룰북 검증 및 갱신 현황.gsheet`

## 확정 구조

- 각 원본은 단일 탭이며 실제 사용 범위만 Markdown으로 옮긴다.
- 한글화 매핑은 원본의 출신 룰북 구분 행을 Markdown 하위 제목으로 바꾸고 동일한 5열 표를 구간별로 유지한다.
- 추가 주문 모음은 4열 전체를 보존한다. B~D열의 반복 수식은 현재 표시값으로 고정하고 수식 패턴과 적용 범위를 문서에 기록한다.
- 추가 주문 상세 데이터는 원본 헤더와 행 순서를 그대로 유지한 Markdown 표로 옮긴다.
- FVTT 룰북 검증 현황은 같은 이름의 최신 Markdown 정본을 덮어쓰지 않는다. Google Sheets의 150행은 `FVTT 룰북 검증 및 갱신 현황 - Google Sheets 전환 보존본.md`로 분리하고, 현행 집계 입력이 아닌 이전 스냅샷임을 명시한다.
- 빈 셀은 빈 표 셀로 보존하고, 셀 안의 Markdown 예약 문자와 줄바꿈은 표 구조를 깨지 않도록 이스케이프한다.

## 안전 게이트

- 변환본은 Drive 밖 임시 폴더에서 만든다.
- 각 Markdown은 원본과 같은 Drive 부모 폴더에 업로드한다.
- 업로드본을 다시 읽어 행·열·셀 값을 원본과 대조하기 전에는 원본 Google Sheets를 삭제하지 않는다.
- 원본 삭제 뒤 전체 작업 폴더의 `.gsheet` 잔여 수와 대상 ID의 `NOT_FOUND` 상태를 확인한다.
- 삭제 내역과 데이터량은 작업 정비 현황 및 검증 보고서에 누적한다.

## 삭제 성격

Google Drive 커넥터의 삭제는 영구 삭제다. 검증을 통과한 네 원본 시트만 삭제 대상으로 삼는다.
