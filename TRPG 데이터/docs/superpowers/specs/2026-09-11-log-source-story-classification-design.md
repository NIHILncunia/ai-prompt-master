# 로그 원본 스토리 분류 및 진행자 메타데이터 설계

## 목적

원본 로그 최상위 폴더의 명명 규칙으로 정규 스토리와 외전을 판별하고, 알려진 외전의 진행자를 로그 분석 맥락에 보존한다.

## 확정 규칙

- 최상위 원본 폴더명에 `스토리 <번호>` 표기가 있으면 정규 스토리다.
- 정규 스토리는 마스터가 진행한다.
- `스토리 <번호>` 표기가 없는 최상위 원본 폴더는 외전이다.
- 외전 진행자는 원본 로그 또는 등록된 담당 정보로 확인하며, 확인되지 않은 외전의 진행자를 추정하지 않는다.
- `마키나즈`, `사신`, `프로즌 서바이버`의 진행자는 시어하트어택이며, `어두운 시대`의 진행자는 마르도스다.

## 경계

- 이 변경은 원본 로그의 분류·진행자 맥락과 이후 분석 문서의 메타데이터만 다룬다.
- 기존 원본 로그·분석본·스토리 정리 문서의 이동·재분류·재작성은 포함하지 않는다.
- 정규 스토리와 외전의 세계관 연결 여부, `스토리 <번호>`와 시퀄의 병합 여부는 이 규칙만으로 확정하지 않는다.
