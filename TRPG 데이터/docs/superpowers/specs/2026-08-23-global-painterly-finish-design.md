# 전역 붓터치 마감 기본값 설계

## 목적

- 이미지 생성 모듈의 향후 시각 산출물에 은은한 붓터치 기반 디지털 페인팅 마감을 기본 적용한다.
- 포트레이트 전용인 `붓터치 반실사` 계약을 다른 기능에 무리하게 확장하지 않고, 장르와 대상에 독립적인 공통 마감 규칙을 추가한다.

## 적용 범위

- 기본 적용 대상은 포트레이트, 캐릭터 레퍼런스, 풍경, 세션 하이라이트, 아이템, 비공정·건축·기계 등 설정화·컨셉 아트 계열이다.
- 기능 계약이 판독성·기능성을 우선하는 true top-down 배틀맵, 토큰 프레임, 게임 아이콘, 양피지 지도에는 자동 적용하지 않는다.
- 사용자가 특정 화풍을 명시하면 사용자 지시가 공통 기본값보다 우선한다.

## 설계

### 새 공통 스타일 계약

- `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/스타일/공통 붓터치 마감 규칙.md`를 새 정본으로 만든다.
- 이 문서는 인체·얼굴·피부·장비처럼 포트레이트에만 적용되는 규칙을 포함하지 않는다.
- 기본 프롬프트 표현은 `high-end digital painting`, `subtle painterly brush texture`, `painterly material rendering`, `clear readable forms`로 고정한다.
- 붓터치는 재질 경계, 빛, 구름, 자연물, 넓은 금속·목재 표면에 은은하게 보이는 디지털 페인팅 마감으로 한정하며, 구조·장비·공간의 판독성을 흐리는 거친 유화 질감은 금지한다.
- 사진풍·매끈한 CGI·기계적 렌더링으로 흐르지 않게 하되, 선택 기능의 평면·전술·투명·아이콘 계약을 침범하지 않는다.

### 연결 문서

- 이미지 생성 모듈 `AGENTS.md`는 공통 붓터치 마감 규칙을 기본 참조 자료로 명시한다.
- 이미지 생성 모듈 마스터는 기능 고정 계약을 확인한 뒤, 예외가 아닌 경우 공통 붓터치 마감 규칙을 조립하도록 한다.
- 공통 `2. 요구사항 확인서 작성 규칙.md`에는 스타일 필드에서 공통 마감 적용 또는 예외를 명시하도록 추가한다.
- 기존 `라이브러리/스타일/붓터치 반실사.md`는 포트레이트 전용 세부 계약으로 유지하고, 새 공통 규칙을 상속하는 관계만 명시한다.

- 수정: `1. 프롬프트/1. 이미지 생성 모듈/AGENTS.md`
- 수정: `1. 프롬프트/1. 이미지 생성 모듈/0. 이미지 생성 모듈 마스터 프롬프트.md`
- 수정: `1. 프롬프트/1. 이미지 생성 모듈/공통/2. 요구사항 확인서 작성 규칙.md`
- 수정: `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/스타일/붓터치 반실사.md`

## 비변경 범위

- `TRPG 데이터/AGENTS.md`, 프롬프트 루트 `AGENTS.md`, 프로젝트 기본 지침, 통합 마스터는 이미지 모듈의 세부 화풍 정본이 아니므로 변경하지 않는다.
- 기존 기능별 마스터에는 같은 규칙을 복제하지 않는다.

## 검증 기준

- 이미지 모듈 진입 문서와 마스터에서 공통 스타일 계약을 찾을 수 있다.
- 요구사항 확인서에 공통 마감 적용 여부를 기록할 수 있다.
- 포트레이트 계약은 공통 마감과의 관계를 명시하되 기존 전신·흉상 산출물 계약을 변경하지 않는다.
- 배틀맵·토큰 프레임·게임 아이콘·양피지 지도 계약에는 자동 적용 예외가 명확히 남는다.
