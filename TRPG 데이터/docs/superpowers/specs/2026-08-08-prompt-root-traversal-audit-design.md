# 프롬프트 루트 탐색 심층 점검 설계

- 상태: 마스터 승인 범위 반영
- 대상: `TRPG 데이터/AGENTS.md`, `TRPG 데이터/1. 프롬프트`, 활성 1~8 기능, 이미지 모듈 내부 1~8 기능, 공통 절차

## 점검 순서

### 1. 활성 운영 경로 전수 점검

각 활성 기능에서 다음 경로가 실제로 존재하고 순서대로 도달 가능한지 검사한다.

`루트 AGENTS → 프롬프트 루트 AGENTS → 기능 AGENTS → 0번 마스터 → 필수 공통 절차 또는 실행 문서`

- 상위 1~8 기능마다 AGENTS·README·0번 마스터를 확인한다.
- 이미지 모듈은 내부 1~8 기능마다 같은 진입점 계약을 확인한다.
- 이미지 기능은 공통 승인 절차 경로와 기능별 마스터의 연결을 확인한다.
- 문서 내 `TRPG 데이터/1. 프롬프트/...` 전체 경로를 추출해 실경로 존재 여부를 검사한다.
- 보관·과거 Superpowers 기록은 활성 라우팅 오류 판정에서 제외한다.

### 2. 호출 시나리오 점검

각 요청을 루트에서 시작해 예상 기능으로 라우팅할 수 있는지 문서상 대조한다.

- `준비.`, `준비 1번`, `준비 4번`, `준비 7번`, `준비 8번`
- 이미지 모듈 내부 1~8 요청
- 로그 하이라이트·로그 분석·룰북·설정·FVTT·창작 지원·세션 제작 요청
- 이미지 승인 전 생성 요구, 프롬프트만 요청, 이미지와 비이미지의 복합 요청
- 이미지 모듈 내부 기능과 최상위 2~8 비이미지 기능의 번호 혼동 방지

## 결함 판정

- 필수 진입 문서 또는 참조 경로가 없으면 결함이다.
- 활성 문서가 구 폴더·구 번호·보관 경로로 라우팅하면 결함이다.
- 이미지 요청이 승인 절차를 우회하거나 비이미지 요청에 승인 절차를 강제하면 결함이다.
- 보관·역사 문서의 과거 기록은 활성 문서에서 참조되지 않는 한 결함이 아니다.

## 산출물

- 시나리오별 예상 경로·실제 증거·판정을 담은 검증 보고서
- 결함이 있으면 원인과 최소 수정 범위
- 결함이 없으면 최종 정상 판정
