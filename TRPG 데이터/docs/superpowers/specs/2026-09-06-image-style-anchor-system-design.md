# 이미지 스타일 앵커 체계 정비 설계

## 목적

이미지 생성 모듈의 `애니 페인팅`과 `붓터치 반실사`를 재현 가능한 고정 스타일로 정의한다. 스타일의 그림체와 마감은 고정하되, 캐릭터 디자인·포즈·카메라·배경·장면 구성은 사용자 입력과 기능 목적에 따라 바뀔 수 있게 분리한다.

## 확정 사항

1. 정식 스타일은 `애니 페인팅`과 `붓터치 반실사` 두 가지다.
2. 두 스타일은 각각 `핵심 얼굴`, `중립 전신`, `마감`의 정식 앵커 3장을 사용한다. `마감` 앵커는 재질 표본판이 아니라 완성된 단일 일러스트의 채색·명암·경계·붓터치·재질 표현·최종 표면 처리를 고정한다.
3. 정식 앵커 파일명은 앞 번호만 유지하고 시안·버전 뒷번호를 제거한다.
4. 기존 앵커와 기존 반실사 견본은 삭제하지 않고 비활성 보관 폴더로 이동한다.
5. 스타일 앵커는 얼굴·인체의 그림체, 선 처리, 형태 단순화 수준, 채색, 재질 분리, 붓터치 마감만 참조한다.
6. 스타일 앵커의 인물 정체성, 의상, 장신구, 색상 팔레트, 포즈, 카메라, 배경, 장면 구성은 새 이미지에 복제하지 않는다.
7. 한 번의 생성에 사용하는 스타일 앵커는 최대 2장이다.
8. 흉상·얼굴 중심은 `핵심 얼굴 + 마감`, 전신은 `중립 전신 + 마감`을 기본으로 한다.
9. 사용자 제공 이미지가 있으면 해당 이미지를 디자인 기준으로 우선하며, 명시적인 스타일 변경 요청일 때만 선택 스타일로 재해석한다.
10. 캐릭터 레퍼런스 V1·V2와 세션 하이라이트는 별도 화풍 지정이 없으면 제공된 기준 이미지의 그림체를 그대로 따른다.
11. 두 스타일은 공통으로 수채화 번짐·종이결이 아닌, 불투명한 레이어와 통제된 붓터치의 고급 디지털 페인팅 마감을 사용한다.

## 활성 앵커 구조

```text
라이브러리/견본/
├─ 애니 페인팅/
│  ├─ 01. 핵심 얼굴 앵커.png
│  ├─ 02. 중립 전신 앵커.png
│  └─ 03. 마감 앵커.png
├─ 붓터치 반실사/
│  ├─ 01. 핵심 얼굴 앵커.png
│  ├─ 02. 중립 전신 앵커.png
│  └─ 03. 마감 앵커.png
└─ 보관/
   ├─ 애니 페인팅 기존 앵커/
   ├─ 애니 페인팅 1차 정식 앵커/
   └─ 붓터치 반실사 기존 견본/
```

## 프롬프트 소유권

- 스타일별 고정 영문 그림체 블록은 각 스타일 계약 문서가 소유한다.
- 공통 고정 영문 마감 블록은 `공통 붓터치 마감 규칙.md`가 소유한다.
- 기능별 프롬프트는 대상·디자인·행동·포즈·카메라·배경·출력 규격만 조립한다.
- 사용자가 명시하지 않은 포즈·카메라·배경은 기능 목적에 맞게 결정할 수 있으나 스타일 블록을 변형하는 근거가 되지 않는다.

## 검증 기준

- 활성 스타일 폴더마다 PNG가 정확히 3장 존재한다.
- 정식 파일명에 `시안` 또는 파일명 끝의 버전 번호가 없다.
- 정식 앵커의 SHA-256이 선택된 원본 시안과 일치한다.
- 기존 애니 앵커 11장, 교체된 애니 1차 정식 앵커 3장과 반실사 견본 6장이 보관 폴더에 존재한다.
- 활성 문서가 구 앵커 파일명을 참조하지 않는다.
- 두 스타일의 고정 영문 블록과 공통 마감 블록이 단일 정본에 존재한다.
- V1·V2·세션 하이라이트 문서에 기준 이미지 그림체 기본 보존 규칙이 존재한다.
