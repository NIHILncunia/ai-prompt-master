# 클래스 제작 레퍼런스 분석 설계

## 목적
D&D 5e 2024 Player’s Handbook의 12개 기본 클래스를 동일한 분석 틀로 해부하여, 미세제작 모듈의 클래스 제작 프롬프트와 클래스 데이터 양식을 룰북 기반으로 재설계한다.

## 분석 축
- 클래스 판타지와 역할
- 기본 클래스 정보 블록
- 1~20레벨 진행표
- 공통 클래스 피처 배치
- 3레벨 서브클래스 개방과 이후 서브클래스 피처 배치
- 클래스 고유 자원과 성장 방식
- 저·중·고레벨 성장 곡선
- 최종 피처의 역할
- 룰북 클래스 문서의 정보 배열과 설명 양식

## 작업 구조
1. 12개 기본 클래스 개별 분석
2. 클래스 간 횡단 비교
3. 공통 설계 패턴·예외 패턴 추출
4. 클래스 제작 규칙 재설계
5. 클래스 데이터 양식 재설계
6. 기존 클래스 제작 프롬프트 수정 및 검증
