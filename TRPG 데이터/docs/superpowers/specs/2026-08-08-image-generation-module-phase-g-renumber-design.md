# 이미지 생성 모듈 Phase G 기능 재번호 설계

## 목적

구 이미지 기능 폴더 제거 후 프롬프트 루트의 활성 기능 번호를 연속적으로 재배치한다.

## 현재 활성 비이미지 기능

- 4. 로그 하이라이트 추출 프롬프트
- 6. 로그 분석 프롬프트
- 7. 룰북 관련 요청 프롬프트
- 8. 설정 관련 요청 프롬프트
- 9. FVTT 관련 요청 프롬프트
- 11. 창작 지원 프롬프트
- 15. 세션 제작 프롬프트

`11. 창작 지원 프롬프트`는 현재 Drive 구조상 통합 모듈이며 내부에 아이템 제작, 특성 제작, 능력 제작, 클래스 제작, 인물 제작 등이 존재한다.

## 실행 순서

1. Phase F hotfix 반영 및 운영 구 경로 0건 재검증
2. 구 이미지 기능 8개 폴더 삭제
3. 비이미지 기능 폴더를 최종 번호로 이름 변경
4. 각 기능 내부 AGENTS/README/마스터의 번호·경로 수정
5. 상위 AGENTS/기본 지침/통합 마스터의 라우팅표 수정
6. 기능 간 상호 참조 전역 치환
7. `준비 ?번` 라우팅 검증
8. 최종 Drive 루트에서 1~8 연속 구조 확인

## 주의

- 과거 Superpowers 설계·감사·마이그레이션 문서의 과거 번호는 역사 기록이므로 변경하지 않는다.
- 현재 운영 문서와 현재 기능 폴더만 재번호한다.
- 폴더 삭제는 hotfix 반영 및 전역 재검증 이후에만 수행한다.
