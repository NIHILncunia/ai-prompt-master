# 작업 폴더 Drive ID 일괄 이관 설계

## 목표

신규 작업 폴더의 지침 문서가 기존 작업 폴더의 하위 폴더 ID를 참조하지 않도록, 동일 상대 경로를 가진 신규 폴더 ID로 일괄 교체한다.

## 범위

- 기존·신규 작업 폴더의 모든 하위 폴더를 재귀 조회한다.
- 두 트리의 루트를 포함한 폴더 267개를 상대 경로 기준으로 대응시킨다.
- 신규 작업 폴더 내부 Markdown 589개를 전수 검사하고 활성 지침의 기존 폴더 ID 사용처만 교체한다.
- 설정 폴더 ID `1Wjo6z5YfZDTjzfwNNVhR4ubZ2CVhH6oj`는 기존과 동일하므로 보존한다.
- 폴더 ID가 아닌 파일 ID와 외부 폴더 ID는 변경하지 않는다.
- `.superpowers/sdd` 백업과 완료 검증 보고서는 당시 상태의 증거이므로 치환하지 않는다.

## 매핑 규칙

1. 각 트리에서 루트 기준 상대 경로와 폴더 ID를 수집한다.
2. 동일 상대 경로가 양쪽에 정확히 하나씩 있을 때만 매핑을 확정한다.
3. 중복 경로, 한쪽에만 존재하는 경로, 동일 ID 재사용이 있으면 문서 변경을 중단한다.
4. 확정된 기존 ID 문자열과 정확히 일치하는 사용처만 신규 ID로 교체한다.

## 검증 기준

- 기존·신규 폴더 수가 각각 267개여야 한다.
- 상대 경로 누락·중복·충돌이 0건이어야 한다.
- 확인된 활성 지침 17개 문서의 175개 기존 ID 사용처가 모두 교체되어야 한다.
- 활성 지침에서 기존 작업 폴더 하위 ID 잔여가 0건이어야 한다.
- 보존 대상 6개 문서의 역사적 기존 ID 136건은 변경하지 않는다.
- 활성 지침의 설정 폴더 ID 사용처는 교체 전후 동일하게 17건이어야 한다.
- 각 치환 결과의 신규 ID가 실제 신규 트리의 대응 상대 경로와 일치해야 한다.
