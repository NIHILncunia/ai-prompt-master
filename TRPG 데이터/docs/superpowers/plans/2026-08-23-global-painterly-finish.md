# 공통 붓터치 마감 기본값 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이미지 생성 모듈의 기본 시각 마감에 절제된 붓터치 질감을 추가하되, 기능성 이미지의 가독성과 기존 반실사 포트레이트 스타일의 역할을 보존한다.

**Architecture:** 새 공통 스타일 문서를 단일 정본으로 두고, 이미지 모듈 진입 문서와 요구사항 확인서에서 이를 참조한다. 기존 `붓터치 반실사` 문서는 포트레이트 전용 스타일로 유지하며 공통 규칙과의 관계만 명시한다.

**Tech Stack:** Markdown, 로컬 동기화 TRPG 데이터 문서 체계

**Spec:** [`2026-08-23-global-painterly-finish-design.md`](../specs/2026-08-23-global-painterly-finish-design.md)

## Global Constraints

- 기본값은 인물·레퍼런스·풍경·세션 하이라이트·아이템·탈것·건축 콘셉트 이미지에 적용한다.
- 탑다운 배틀맵, 토큰 프레임, 게임 아이콘, 양피지 지도는 사용자가 별도로 요청하지 않는 한 적용 대상에서 제외한다.
- 붓터치는 형태·소재·조명 표현을 보강하는 마감이며, 과도한 추상화·유화 덩어리화·가독성 저하를 유발하지 않는다.
- 사용자의 이번 이미지별 스타일 지시가 공통 기본값보다 우선한다.
- 기존 `붓터치 반실사`의 인물 해부·얼굴·피부·의상 묘사 규칙을 다른 이미지 유형으로 확장하지 않는다.
