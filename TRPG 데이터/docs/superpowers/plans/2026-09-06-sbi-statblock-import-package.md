# SBI 스탯블록 Import Package 지침 반영 계획

- 작업 ID: 2026-09-06-sbi-statblock-import-package
- 요청: 인계 자료에 적힌 개선 방향을 현행 스탯블록 지침에 반영한다.
- 근거: 인계 ZIP의 `07_Import_Package_규격.md`와 [실환경 검증 보고서](<../reports/2026-09-05-fvtt-sbi-ko-live-test.md>).
- 적용: 사용자가 요청한 지침 개선 범위에서 동기화된 로컬 Markdown을 직접 수정한다.
- Superpowers 적용: 기존 방향을 실행하고 verification-before-completion으로 완료 근거를 확인한다. Git 저장소가 아닌 문서 폴더이므로 원본 백업과 파일별 비교를 사용한다.

## 반영 기준

1. 메인 스탯블록은 `===STATBLOCK===`와 `===LOCALIZATION===`를 포함한 단일 `text` 코드블록으로 제공한다.
2. SBI 입력은 영어로 유지하고 한글 Actor·Item 이름과 설명은 LOCALIZATION JSON에 둔다. 기존 몬스터 이름의 한글 허용은 유지한다.
3. 기존 일반 한국어 번역과 기반 몬스터 원본 제공 규칙을 유지한다. 별도 FVTT 한국어 번역은 LOCALIZATION으로 통합한다.
4. 확인한 매크로 동작에 맞춰 키 매칭, JSON 형식, 인라인 명령·참조 보존, 예외 처리 기준을 명시한다.
5. 주문·복수 Activity 등 미검증 범위를 완료로 확대하지 않는다. 지침 적용을 이유로 서버에 재접속하지 않는다.

## 작업 순서

1. 스탯블록 지침·템플릿과 기능 진입점 4종을 원본 백업 후 수정한다.
2. 관련 상위·FVTT 라우팅 문서에서 기존 출력 규칙과의 충돌을 검색한다.
3. 예시 JSON을 파싱하고 키 중복·참조·언어 경계·번역 대응을 확인한다. 변경 파일의 공백·코드블록·링크·원본 대비 차이를 검사한다.
4. 검증 보고서를 생성하고 두 작업 레지스트리와 정비 기록을 완료로 갱신한다.

## 완료 기준

- 6개 기능 문서가 동일한 패키지 출력 규칙을 안내한다.
- 템플릿의 LOCALIZATION이 유효한 JSON이고 원본 데이터가 패키지에 중복 포함되지 않는다.
- 기존 룰북 근거·CR·명중 기준이 보존된다.
- 검증 결과와 실환경 미검증 범위가 구분되며 추적 문서가 실제 존재한다.
