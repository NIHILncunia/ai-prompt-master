# 이미지 생성 모듈 Phase G 기능 재번호 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구 이미지 기능 8개 폴더를 제거하고 남은 활성 기능을 1~8번 연속 체계로 재번호한다.

**Architecture:** 신규 `1. 이미지 생성 모듈`은 유지하고, 비이미지 활성 기능 7개를 2~8번으로 앞당긴다. 폴더명 변경 후 각 기능 내부 번호/경로 참조와 상위 라우팅 문서를 동기화하고, 과거 Superpowers 이력 문서는 역사 기록으로 유지한다.

**Tech Stack:** Google Drive 동기화 폴더, Markdown, ZIP 수동 반영

## Global Constraints

- Google Drive 구현 파일은 사용자가 직접 반영할 수 있도록 ZIP 또는 명시적 변경표로 제공한다.
- 기존 파일 수정 시 파일명은 유지한다.
- 과거 Superpowers 설계/감사/마이그레이션 문서의 과거 번호는 변경하지 않는다.
- Phase F hotfix가 실제 Drive에 반영되어 운영 구 이미지 경로가 0건임을 확인한 뒤 삭제 단계에 진입한다.
- `보관` 및 `공통` 폴더는 번호 재배치 대상이 아니다.
