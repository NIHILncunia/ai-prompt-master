# 섬에서 전해진 바람 상편 2 장면·맵 재설계 및 식별자 승격 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `섬에서 전해진 바람 상편 2`의 네 맵이 각각 필수 플레이 국면을 맡도록 장면 흐름을 재구성하고, 모든 장면·맵 문서에 영구 식별자와 구조화된 맵 참조를 부여한다.

**Architecture:** 세션 패키지 내부의 시나리오, 장면 목록, 개별 장면, 개별 맵 문서를 같은 사실 관계로 갱신한다. 장면은 `03 → 01 → 04 → 02`의 필수 공간 흐름을 따르며, 장면 문서는 `scene_uuid`, 맵 문서는 `map_uuid`를 가진다. 작업 시작 전 기존 더티 변경의 소유·겹침을 확인하고, 이미지 파일은 읽기·해시 검증만 하며 수정하지 않는다.

**Tech Stack:** Markdown, PowerShell, ripgrep, Git 읽기 전용 상태·diff 검사

**Spec:** `docs/superpowers/specs/2026-09-09-asset-map-session-adjustment-design.md`

## Global Constraints

- 이 계획은 `섬에서 전해진 바람 상편 2` 세션 문서의 내용·식별자·참조 정비만 수행한다. 전역 자산 폴더 이관, `16. 컨셉 이미지` 이름 변경, 공용 맵 카탈로그로의 물리 이동은 별도 계획과 대상 목록 승인 뒤에 수행한다.
- 현재 더티 작업 트리의 기존 변경을 덮어쓰거나 되돌리지 않는다. 이 계획의 편집 범위와 겹치는 기존 diff가 있으면 파일별 충돌 내용을 기록하고 마스터의 지시를 받기 전에는 그 파일을 수정하지 않는다.
- 모든 산출물은 Markdown으로 유지한다. Google Drive, GitHub, 세션 맵 이미지, 이미지 생성 결과는 직접 변경하지 않는다.
- `scene_uuid`와 `map_uuid`는 소문자 표준 UUID 값이다. 번호·제목·향후 맵 코드가 바뀌어도 이 값은 바꾸지 않는다.
- 모든 본편 장면은 `## 장면 식별 정보`와 `## 사용 맵`을 가지며, 사용 맵은 이름만 쓰지 않고 `map_uuid`, 맵명, 사용 방식, 공간적 목적을 함께 기록한다. 맵 없는 경계 장면은 `없음`을 명시한다.
- 장면 흐름은 `맵 03 도시 진입 1차 전투 → 맵 01 베르카스 2차 전투·도시 방어 → 맵 04 수상한 마법사 격리·혼탁함을 먹는 돌 회수·실타래 추적 → 맵 02 왼팔 성소 최종 갈등`으로 고정한다.
- `혼탁함을 먹는 돌`은 악마의 씨앗이며 혼탁·사특한 기운을 먹어 숨긴다. 포화하면 악마가 태어날 위험이 있으나, 이번 세션에서는 악마가 태어나지 않는다.
- 맵 03과 맵 04를 `필요 시`, `선택`, `보조` 공간으로 기술하지 않는다. 장면 06은 맵 02만 사용하며 맵 04로 전투가 확장되지 않는다.
- 맵 논리 그리드는 가로·세로 모두 5의 배수다. 기존 맵 02의 `28 × 28` 표기는 이미지의 실제 사용 가능 영역 검토를 통과한 경우에만 `30 × 30`으로 정정한다. 검토가 불가능하거나 이미지와 맞지 않으면 이미지를 임의로 확대·잘라내지 않고 마스터에게 판단을 요청한다.
- 커밋은 더티 트리 전체를 포함하지 않는다. 마스터가 요청하고 이 계획의 파일만 명시적으로 stage한 뒤에만 `yyyy MMdd docs: ...` 형식으로 커밋한다.
