# 엔터티 자산 폴더 전환 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이미지 전용 루트를 대상별 자산 인덱스·자산 동거 구조로 전환하고 모든 활성 저장 참조를 갱신한다.

**Architecture:** 기존 자산의 SHA-256과 원본 경로를 기준선으로 먼저 고정한다. 그 뒤 기존 분류와 파일명으로 확정 가능한 대상은 새 대상 폴더로 이동하고, 대상이 확정되지 않는 파일만 미분류로 보존한다. 설정 폴더 문서는 복사하지 않으며 자산 인덱스가 작업 폴더의 연결 지점이 된다.

**Tech Stack:** Markdown, PowerShell, SHA-256, Git 정적 검사

**Spec:** `docs/superpowers/specs/2026-09-09-entity-asset-folder-migration-design.md`

## Global Constraints

- 기존 설정 문서는 이관·복제하지 않는다.
- 이미지 픽셀을 재생성·변환·덮어쓰지 않는다.
- 원본 파일은 SHA-256 검증 전 삭제하지 않는다.
- 구 경로의 활성 Markdown 참조는 새 경로로 갱신한다.
- 용종은 별도 루트로 보관하되 몬스터 자산 규칙을 사용한다.
- 모호한 자산은 `16. 미분류`로 옮기며 억지 분류하지 않는다.
- 기존 더티 워크트리의 다른 변경을 수정·스테이징·커밋하지 않는다.

### Task 2: 대상 폴더와 자산 인덱스 생성

**Files:**
- Create: 대상별 `<대상명>.md` 자산 인덱스
- Create: `15. 장소/`, `16. 미분류/`

**Interfaces:**
- Consumes: Task 1 기준선과 분류 계약
- Produces: 영구 `<분류>_uuid`를 가진 대상 폴더

- [x] **Step 1: 기존 명시 분류를 보존해 NPC·PC·신격·국가·단체·몬스터·종족·지역·용종·아이템 대상 폴더를 만든다.**

기존 하위 종족·만신전·몬스터 유형·용종 유형은 탐색 보조 계층으로 보존하고, 최하위 대상 폴더에 자산을 둔다.

- [x] **Step 2: 공용 레퍼런스 시트를 해당 NPC·PC·몬스터·종족 대상 폴더로 이관한다.**

동일 대상의 레퍼런스 시트는 `V1`부터 차례대로 부여한다. 원본 파일명만으로 대상이 확정되지 않으면 미분류에 보존한다.

### Task 3: 개별 자산 이관과 결과 루트 해소

**Files:**
- Move: 기존 이미지 루트의 확정 분류 자산
- Move: `16. 컨셉 이미지`의 4개 아이템 자산
- Move: `15. 이미지 생성 결과`의 확정 분류 자산

**Interfaces:**
- Consumes: Task 1 해시, Task 2 대상 폴더
- Produces: 대상별 자산 동거와 `16. 미분류`의 명시적 보류 자산

- [x] **Step 1: 기존 이미지 전용 루트를 분류명 루트로 전환하고, 대상별로 자산을 개별 이동한다.**

인물 자산은 전신·초상화·토큰·레퍼런스·시안을 동일 대상 폴더에 둔다. 기존 이미지의 역할이 명백할 때만 표준 파일명으로 바꾸며, 역할이 명백하지 않은 기존 파일은 원본명을 유지한다.

- [x] **Step 2: 컨셉 이미지의 4개 자산을 아이템 대상 폴더로 이동한다.**

`검은 사수의 석궁`, `검은 사수의 오른 팔`, `검은 사수의 왼팔`, `혼탁함을 먹는 돌`을 각각 `18. 아이템/<대상>/`으로 이동한다. 같은 이름의 기존 아이템 이미지와 SHA-256이 일치하면 하나로 통합하고, 다르면 둘 다 `시안/`에 보존한다.

- [x] **Step 3: 이미지 생성 결과를 대상별 폴더 또는 미분류로 해소한다.**

비공정·구조물은 `15. 장소`, 아이콘·명시 아이템은 `18. 아이템`, 식별 가능한 인물은 NPC·PC·몬스터로 옮긴다. 앵커 시험·정체 불명·판별 불가 자산은 `16. 미분류/이미지 생성 결과/`에 원본명을 유지한다.

### Placeholder scan

각 작업은 대상 루트, 이동 기준, 검증 조건을 명시한다. 대상 식별이 불가능한 자산은 미분류로 보존하는 명시적 처리 규칙을 사용한다.

### Interface consistency

모든 자산 인덱스는 `<분류>_uuid` 형식으로 식별하고, 설정 본문은 설정 폴더에 유지한다. 공용 맵은 `map_uuid` 계약을 유지한다.
