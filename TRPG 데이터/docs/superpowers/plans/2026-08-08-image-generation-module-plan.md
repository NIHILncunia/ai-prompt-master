# 이미지 생성 모듈 통합 실행 계획

## 1. 목적

이 문서는 `1. 이미지 생성 모듈` 통합 설계를 실제 문서 구조와 프롬프트 체계로 이행하기 위한 실행 계획이다.

---

## 2. 작업 목표

- 기존 분산 이미지 기능을 `1. 이미지 생성 모듈` 아래로 재편한다.
- `1. 반실사 포트레이트`를 내부 대표 기능으로 재작성한다.
- 나머지 이미지 기능도 기능별 특성을 반영한 구조로 재편한다.
- 공통 규칙과 라이브러리를 분리한다.
- 이미지 기능 통합에 맞춰 전체 번호 재설계의 기반을 만든다.

---

## 3. 작업 범위

### 포함

- 이미지 생성 모듈 상위 구조 설계
- 하위 8개 기능 구조 재설계
- 공통 문서 설계
- 라이브러리 문서 설계
- 기존 기능과 신규 구조의 매핑

### 제외

- 비이미지 기능의 최종 재번호 확정
- 실제 이미지 샘플 생성 테스트
- 각 하위 기능의 세부 프롬프트 문안 최종 확정

---

## 4. 실행 단계

### 단계 1. 이미지 기능 현행 매핑표 작성

목표:
- 기존 이미지 기능과 신규 하위 기능 대응표를 확정한다.

작업:
- 기존 1, 2, 3, 5, 10, 12, 13, 14번을 신규 내부 번호에 매핑
- 보존할 규칙 / 폐기할 규칙 / 신규 작성할 규칙 분류

산출물:
- 이미지 기능 매핑표

---

### 단계 2. 상위 이미지 생성 모듈 골격 작성

목표:
- 상위 진입 구조를 만든다.

작업:
- `AGENTS.md`
- `README.md`
- `0. 이미지 생성 모듈 마스터 프롬프트.md`
- `공통/`
- `라이브러리/`

산출물:
- 이미지 생성 모듈 상위 골격

---

### 단계 3. 반실사 포트레이트 우선 재작성

목표:
- 가장 핵심인 1번 하위 기능을 먼저 정비한다.

작업:
- 포트레이트 마스터 작성
- 공통 지침 작성
- 전신 생성 지침 작성
- 흉상 생성 지침 작성
- 붓터치 반실사 스타일 규칙 연결

산출물:
- `1. 반실사 포트레이트/` 완성 초안

---

### 단계 4. 나머지 하위 기능 골격 작성

목표:
- 2~8번 하위 기능의 기본 골격을 만든다.

작업:
- 배틀맵
- 캐릭터 레퍼런스
- 세션 하이라이트
- 토큰 프레임
- 풍경
- 게임 아이콘
- 월드 지도

각 기능마다:
- AGENTS
- README
- 0번 마스터
- 공통 지침
- 전용 세부 지침
- 개발 자료 폴더 정책

산출물:
- 2~8번 하위 기능 초안

---

### 단계 5. 라이브러리 계층 작성

목표:
- 조립식 구조를 실제로 사용할 수 있게 만든다.

작업:
- 스타일 라이브러리 초안
- 대상 라이브러리 초안
- 레이아웃 라이브러리 초안
- 견본 운용 규칙 초안

산출물:
- `라이브러리/` 초안

---

### 단계 6. 공통 절차 연결

목표:
- 이미지 요청이 상위에서 하위로 자연스럽게 라우팅되도록 한다.

작업:
- 공통 승인 절차 연결
- 요구사항 확인서 연결
- 이미지 수정 규칙 연결
- 다중 이미지 일관성 규칙 연결

산출물:
- `공통/` 초안

---

### 단계 7. 번호 개편 후속 설계 연결

목표:
- 이미지 모듈 통합안을 전체 기능 번호 개편 설계와 연결한다.

작업:
- 이미지 모듈을 신규 1번으로 확정
- 기존 이미지 기능 번호 폐기 처리 방안 작성
- 비이미지 기능 신규 번호 부여 기준 초안 작성

산출물:
- 전체 기능 재번호 설계의 기반 자료

---

## 5. 검증 기준

다음 항목을 만족해야 한다.

- 상위 1번이 이미지 생성 모듈로 정의됨
- 내부 1번이 반실사 포트레이트로 정의됨
- 포트레이트가 `전신 9:16 → 흉상 9:16` 고정 계약을 명시함
- 고정 계약형 기능과 가변 계약형 기능이 구분됨
- 레이아웃이 필수 축이 아니라 선택형 참조 모듈로 정의됨
- 스타일, 대상, 레이아웃, 견본이 라이브러리로 분리됨

---

## 6. 후속 작업

이 계획 완료 후 바로 이어질 후속 작업은 다음과 같다.

1. 실제 `1. 이미지 생성 모듈` 문서 골격 생성
2. `1. 반실사 포트레이트` 문서 전면 재작성
3. `2~8번` 하위 기능 골격 작성
4. 이미지 기능 통합 완료 후 전체 기능 신규 번호표 설계

---

## 7. 결론

이번 계획의 기본 방침은 다음과 같다.

- 포트레이트는 고정 계약형으로 운영한다.
- 아이콘, 하이라이트 등은 필요 시 레이아웃을 참조하는 가변 계약형으로 운영한다.
- 이미지 모듈 내부 기능은 동일한 폴더 모양을 강제하지 않되, 역할 단위는 표준화한다.
- 실제 작성은 `반실사 포트레이트 → 나머지 하위 기능 → 라이브러리 → 공통` 순으로 진행하는 것이 안정적이다.
