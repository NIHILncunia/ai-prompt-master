# 집필 데이터 체크 기능 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 장르·주제·장면 소재를 근거로 집필 과제를 발급하고, 제출 원문을 보존하며, 매 제출마다 문체 프로필을 갱신하는 Drive 정본 기능을 구축한다.

**Architecture:** `9. 집필 데이터 체크 프롬프트`는 호출어와 절차를, `19. 집필 데이터`는 과제 풀·이력·원문·문체 프로필을 소유한다. keyword_management_system.xlsx는 수정하지 않는 원본 후보 자료로 사용하고, 정규화된 Markdown 데이터베이스가 과제 선택의 유일한 실행 근거가 된다.

**Tech Stack:** Google Drive Markdown 파일·폴더, 기존 `keyword_management_system.xlsx`의 읽기 전용 추출 데이터, Google Drive 직접 업로드·갱신·재조회.

**Spec:** `TRPG 데이터/docs/superpowers/specs/2026-09-09-집필-데이터-체크-기능-설계.md`

## Global Constraints

- 실행·자료 구조·저장 결과는 Google Drive 최신 정본을 기준으로 한다.
- 신규·수정 Markdown 데이터는 생성·수정 직후 Drive에 반영하고 재조회한다.
- Drive 실패 때만 같은 상대 경로를 보존한 ZIP을 제공한다.
- 프로젝트 소스 사본과 keyword_management_system.xlsx 원본은 수정하지 않는다.
- 소설 과제는 장르와 주제만 제시하며, 마스터의 제출 원문은 5,000자 이상이다.
- 장면 묘사 과제는 한 장면을 간결하게 제시한다.
