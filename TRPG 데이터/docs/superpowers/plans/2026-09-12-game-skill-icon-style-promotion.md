# 게임 스킬 아이콘 정규 스타일 이식 및 아이템 아이콘 확장 실행 계획

1. 최신 프로젝트 에이전트, SESSION PROGRESS, 작업 정비, 이미지 모듈·게임 아이콘 정본을 확인한다.
2. 현재 Git 변경과 개발 패키지를 보존한 상태로 승격 후보 5장의 규격을 검증한다.
3. 개발 앵커 01~05를 확정하고 승격 체크리스트·계약·프롬프트 블록을 최종화한다.
4. `게임 스킬 아이콘.md` 정식 계약과 정식 앵커 01~05를 설치한다.
5. 중앙 `정식 스타일 호출 규칙.md`에 기능 전용 정식 스타일의 호출 경계를 등록한다.
6. 게임 아이콘 AGENTS·마스터·공통·스타일·출력·분기·QA·시각 언어 문서를 정식 계약으로 동기화한다.
7. 개발 경로 의존, 구형 검정/회색 비아이템 배경, 패키징 충돌을 정적 검색한다.
8. 앵커 해시·크기·불투명성, 1·5·9·11 패키징 계산, Markdown 참조를 검증한다.
9. 검증 보고서와 작업 정비·Superpowers 레지스트리를 갱신한다.
10. 스킬 스타일 승격 완료 후 무기 아이콘 개발 계약을 시작하되 신규 이미지 생성 전 승인 게이트에서 멈춘다.
