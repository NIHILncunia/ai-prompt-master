# 스토리 정리 공통 지침 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 로그 분석 기능 안에 장기 스토리 정리 전용 작성·품질 지침을 추가하고 기존 라우팅 문서와 충돌 없이 연결한다.

**Architecture:** `2. 스토리 정리 작성 지침.md`가 장기 스토리 정리의 산문·문단·사실 보존·품질 게이트를 소유한다. 기존 `1. 로그 분석 지침서.md`는 세션 단위 분석 규칙을 유지하고 목록 강제 규칙의 예외만 명시하며, `AGENTS.md`와 마스터는 조건부 라우팅만 담당한다.

**Tech Stack:** Markdown, Google Drive raw file update

**Spec:** `docs/superpowers/specs/2026-09-01-스토리-정리-공통-지침-설계.md`

## Global Constraints

- 기존 Markdown 파일 ID와 파일명을 유지한다.
- 신규 지침 외 기존 파일은 최소 변경한다.
- 설정 폴더를 스토리 정리 실행의 필수 의존성으로 만들지 않는다.
- 원본 로그를 확정 사실의 최종 근거로 유지한다.
- 기존 정보흐름분석의 비순차 목록 규칙은 유지하되 스토리 정리만 명시적 예외로 둔다.
