# 00. 블록 조립 규칙 — 승격 확정

## 1. 조립 순서

기능 계약 → 생성 모드 → 입력 분석 → 콘셉트 목록 → 역할별 스타일 블록 → 세트 일관성 → 3×3 패키징 → 제외 조건.

## 2. 생성 모드

- `single`: 하나의 핵심 개념만 생성한다.
- `multi-topic`: 상위 주제에서 의미적으로 직접 연결되는 독립 아이콘을 파생한다.
- `multi-image-derived`: 기준 이미지에서 의미·기능 키워드를 추출하되, 사용자가 스타일 복제를 명시하지 않으면 원본 화풍을 복제하지 않는다.

## 3. 다중 세트 계약

- 사용자가 수량을 지정하면 그 수량을 따른다.
- 수량 미지정 자동 다중 생성은 6·8·10·12 중 하나를 선택한다.
- 최종 패키징은 수량과 무관하게 3×3 시트 단위다.
- 각 슬롯은 512×512, 각 시트는 1536×1536이다.
- 실제 아이콘은 좌상단부터 행 우선으로 채운다.
- 빈 슬롯만 순수 검정으로 채운다.
- 실제 슬롯은 유색 비투명 추상 배경으로 끝까지 채운다.
- 실제 슬롯의 검정·거의 검정·차콜 기본 배경을 금지한다.
- 거터·패딩·외곽 마진은 0px이며 1픽셀도 허용하지 않는다.
- 9개를 초과하면 다음 3×3 시트를 추가한다.

## 4. 최종 후처리

`원시 생성 → 픽셀·슬롯 검증 → 정확 분할 → 512×512 정규화 → 1536×1536 무여백 재합성 → 128/64 축소 검수 → 실제 슬롯 낱개 저장`

원시 생성본이 다른 크기인 것은 후처리로 정규화한다. 시각적 실패의 재생성은 공통 이미지 승인 게이트를 다시 거친다.

## 5. 우선순위

1. 게임 아이콘 기능 계약
2. 단일 핵심 의미
3. 64×64 판독성
4. 역할별 실루엣·운동
5. 세트 일관성
6. 스타일 렌더링
7. 장식
