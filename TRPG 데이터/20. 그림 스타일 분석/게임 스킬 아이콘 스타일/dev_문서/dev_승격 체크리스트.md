# dev_게임 스킬 아이콘 스타일 승격 체크리스트

정식 승격 판정: 통과

- [x] 1:1 기능 계약을 위반하지 않는다.
- [x] 64×64 축소본에서 핵심 의미가 유지된다.
- [x] 단일 핵심 개념이 즉시 읽힌다.
- [x] 배경이 장소·풍경으로 변하지 않는다.
- [x] 실제 슬롯은 유색 비투명 추상 배경을 사용하고 검정·차콜 기본 배경을 사용하지 않는다.
- [x] 스타일 블록이 대상·스킬 내용을 임의로 결정하지 않는다.
- [x] 속성색은 의미 분류를 돕지만 특정 팔레트를 강제하지 않는다.
- [x] glow·rim light가 형태 분리를 돕고 전역 bloom으로 흐려지지 않는다.
- [x] `dev_앵커`가 01~05 연속 번호이며 역할이 구분된다.
- [x] 실패 시안이 정식 앵커에 섞이지 않는다.
- [x] 공격·투사체·방어·지원·원소 등 서로 다른 유형에서 스타일 일관성이 검증됐다.
- [x] 나무 계열 12종에서 11/12, 91.7%의 다중 재현성을 확인했다.
- [x] 3×3 / 512 / 1536 / 0px 패키징 계약을 확정했다.
- [x] 5개 및 11개 패키징 대표 케이스가 최종 3×3 정책과 양립한다.
- [x] 게임 아이콘 기능의 실패 방지 체크리스트와 배경 규칙 충돌을 정리한다.
- [x] 공통 붓터치 마감 미적용을 명시했다.
- [x] 고정 영어 스타일 블록을 확정했다.
- [x] 정식 스타일 계약 및 정식 앵커 경로를 확정했다.
- [x] 마스터가 정규 스타일 이식 작업의 계속 진행을 확정했다.
