# dev_게임 스킬 아이콘 스타일 최종 분석

상태: 분석 완료 / 정식 승격 반영

## 1. 최종 스타일 정의

현대 판타지 RPG 스킬 아이콘의 즉시 판독성을 우선한다. 하나의 큰 핵심 실루엣과 명확한 운동 또는 중심 효과를 먼저 읽히게 하고, 고채도 속성색·강한 명암·선택적 림라이트·국소 글로우·제한적 페인터리 재질로 보강한다.

## 2. 정보 계층

1. 핵심 실루엣
2. 행동 방향 또는 중심 효과
3. 속성색·발광
4. 재질·표면 특징
5. 보조 파티클

1~3은 64×64에서도 유지되어야 한다. 4~5가 축소 후 약해져도 핵심 의미는 남아야 한다.

## 3. 구도

- 정적 중앙형: 방어, 버프, 치유, 룬, 상태
- 동적 방향형: 베기, 타격, 돌진, 투사체, 원소 공격
- 장축 투사체는 끝점과 축을 별도로 분명히 한다.

## 4. 배경

- 실제 슬롯은 피사체의 속성·주색·명도·발광과 조화되는 유색 비투명 추상 배경을 사용한다.
- 순수 검정·거의 검정·검정/차콜 기본 배경을 실제 슬롯에 사용하지 않는다.
- 같은 색 계열이면 명도·채도·림라이트로 분리한다.
- 장소·풍경·실내·바닥 등 환경 맥락은 사용하지 않는다.
- 빈 3×3 슬롯만 순수 검정으로 채운다.

## 5. 렌더링

- 페인터리와 그래픽의 중간 밀도
- 형태를 살리는 하드 에지와 선택적 림라이트
- 재질은 축소 후 남는 특징만 묘사
- 전역 bloom과 미세 텍스처 과다 금지
- 신성·광휘는 백색 과노출을 피하고 내부 형태선을 유지

## 6. 패키징

- 3×3 고정
- 슬롯 512×512
- 시트 1536×1536
- 행 우선
- 0px 거터·패딩·외곽 마진
- 9개 초과 시 추가 시트
- 실제 슬롯만 512×512 낱개 저장

## 7. 검증 근거

- 1차 6종: 전체 사용 권고, 5종 강한 통과, 장축 투사체 1종 보완점 확인
- 나무 12종: 11/12, 91.7%
- 화염·폭발 및 다속성 테스트: 세트 색언어와 재현성 확인
- 6×6 고밀도 테스트: 원시 셀 해상도 한계 확인 후 3×3 고정 정책으로 전환
- 5개: 5 실제 슬롯 + 4 빈 검정 슬롯
- 11개: 9 + 2의 2시트 구조

## 8. 최종 판정

정식 승격 가능 수준이다. 정식 런타임은 개발 레퍼런스를 직접 읽지 않고 `게임 스킬 아이콘.md`와 정식 앵커 01~05를 사용한다.
