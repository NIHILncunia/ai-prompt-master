# 게임 스킬 아이콘 스타일 — 개발·승격 기록

상태: 정식 승격 완료 소스 (`dev_` 기록 보존)

이 폴더는 `게임 스킬 아이콘` 정식 스타일의 분석·시험·승격 근거를 보존한다. 정식 런타임은 이 폴더를 직접 참조하지 않는다.

정식 계약:
- `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/스타일/게임 스킬 아이콘.md`
- 정식 앵커: `1. 프롬프트/1. 이미지 생성 모듈/라이브러리/견본/게임 스킬 아이콘/`

최종 기능 기준:
- 개별 1:1
- 다중 최종 패키징 3×3 고정
- 슬롯 512×512
- 시트 1536×1536
- 행 우선 배치
- 실제 슬롯은 유색 비투명 추상 배경, 검정·차콜 기본 배경 금지
- 빈 슬롯만 순수 검정
- 거터·패딩·외곽 마진 0px
- 9개 초과 시 3×3 시트 추가
- 원시 생성본은 정규화 전 임시본
- 최종 낱개는 실제 슬롯만 512×512 저장

개발 폴더의 분석·시안·프롬프트 블록은 승격 근거로만 보존한다. 신규 런타임 생성은 정식 계약과 정식 앵커를 사용한다.
