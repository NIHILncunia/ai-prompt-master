# 게임 아이템 아이콘 스타일 — dev 스타일 계약

- 상태: 개발 중
- 기준일: 2026-09-12
- 현재 검증 축: 무기

## 1. 목적

`게임 아이템 아이콘 스타일`은 문서·재료·소모품·도구·무기·장비·장신구 등 아이템 계열을 하나의 공통 시각 언어로 묶는 상위 개발 스타일이다. 현재는 무기 분기를 먼저 검증한다.

별도의 정식 `무기 아이콘 스타일`을 병렬 생성하지 않는다. 무기·장비·재료·소모품은 상위 `게임 아이템 아이콘 스타일` 내부의 검증 축과 조건부 분기로 다룬다.

## 2. 공통 우선순위

`아이템 종류 실루엣 → 실제 구조 → 재질 → 조건부 특수 성질 → 희귀도 장식 → 배경/효과`

- 한 슬롯에는 중심 아이템 하나를 둔다.
- 64×64에서 아이템 종류가 먼저 읽혀야 한다.
- 사람·손·착용자는 기본적으로 사용하지 않는다.
- 프레임·배지 림·토큰 링을 사용하지 않는다.
- 풍경·바닥·방·탁자 같은 환경 장면을 배경으로 사용하지 않는다.

## 3. 무기 분기

### 3.1 일반 무기 — 기본값

속성·마법·희귀도·특수 효과가 명시되지 않은 무기는 일반 무기로 해석한다.

- 화염·냉기·번개·암흑 오라·거대한 마력 소용돌이·과도한 발광을 자동 추가하지 않는다.
- 철·강철·목재·가죽·뼈 등 실제 구조와 재질을 우선한다.
- **회색조(grayscale) 비투명 추상 배경을 고정한다.** 회색의 명도 변화는 허용하지만 청색·갈색·녹색·보라색 등 배경 색조는 금지한다.
- 순수 검정 배경은 기본값으로 사용하지 않는다.
- 어두운 무기는 회색조 배경과의 명도 차, 제한적인 림라이트로 분리한다.
- 효과가 없는 일반 무기도 사실적인 제품 사진풍으로 낮추지 않는다. 참고 무기 아이콘과 같은 **선명한 판타지 RPG 게임 인벤토리 아이콘 그림체, 과감한 실루엣, 장식적 디자인, 그래픽-페인터리 채색**을 유지한다.

### 3.2 효과가 존재하는 무기 — 조건부

다음이 명시된 경우에만 활성화한다.

1. 화염·냉기·번개·독·신성·암흑·비전 등 속성
2. 마법 무기·저주받은 무기·유물·전설급 등 마법/희귀도 성질
3. 사용자 또는 테스트 명세가 요구하는 특수 효과

- **회색조 배경을 사용하지 않는다.** 명시된 효과와 조화되는 비회색 유색 배경·룬·보석·마석·국소 발광·원소 효과를 사용할 수 있다.
- 본체 그림체와 디자인 밀도는 일반 무기와 동일하게 유지하고, 차이는 배경색과 조건부 효과에서 만든다.
- 효과는 검날·룬·보석·총구·지팡이 머리 등 발생 지점 근처에 제한한다.
- 효과가 무기 외곽선·손잡이·날·활대·총열·장축 끝점을 가리면 실패다.
- 희귀도는 슬롯 테두리 색으로 표현하지 않는다.

## 4. 구조 판독 계약

- 한손검·단검·도끼: 전체 실루엣과 손잡이/날 비율 유지
- 대검: 전체 길이와 넓은 검신 폭을 함께 유지
- 창·폴암: 날끝부터 자루 끝까지 장축 구조 유지
- 활: 양쪽 활대와 시위가 함께 읽힘
- 석궁: 활대·본체·방아쇠 구조가 함께 읽힘
- 총기: 총열과 개머리판 또는 손잡이가 함께 읽힘
- 지팡이: 장축과 머리 장식/마력 핵이 함께 읽힘
- 사슬무기: 손잡이와 유연한 연결부, 타격부가 구분됨

## 5. 1차 테스트 판정

1차 3×3 두 장 테스트는 무기 종류 다양성은 확인했으나 대부분의 아이콘이 고채도 원소 효과·광휘·소용돌이 배경을 사용해 일반 무기와 마법 무기 구분이 무너졌다.

따라서 1차 결과는 정식 앵커 승격 후보로 사용하지 않고, `모든 무기의 자동 마법화 금지`를 확인한 실패/교정 기준으로 유지한다.

## 6. 2차 비교 테스트 계약

같은 논리 배치에서 두 장을 생성한다.

- 시트 A: 일반 무기 3×3 1장 — 회색조 배경, 효과 없음
- 시트 B: 효과가 존재하는 무기 3×3 1장 — 비회색 유색 배경, 명시 효과 있음

두 시트는 `22. 아이콘 생성/아이템 아이콘`의 하나의 배치 폴더에 함께 저장하며 이미지 파일명은 `-1`, `-2`를 사용한다.

### 시트 A 목표

무기 종류·구조·재질이 효과 없이도 충분히 매력적이고 판독 가능해야 하며, **효과만 제거한 동일 게임 아이템 그림체**로 보여야 한다.

### 시트 B 목표

동일한 아이템 스타일 안에서 비회색 속성 배경과 효과를 더하되 본체 구조·재질·그림체를 훼손하지 않아야 한다.

## 7. 승격 전 체크

- 일반 무기 기본값이 안정적으로 재현되는가
- 중성 배경이 밋밋함이 아니라 구조·재질 가독성으로 작동하는가
- 속성/마법 효과가 조건부로만 활성화되는가
- 장축·활·석궁·총기 구조가 64×64에서 구분되는가
- 일반/마법 두 분기가 한 게임의 같은 아이템 세트처럼 보이는가
