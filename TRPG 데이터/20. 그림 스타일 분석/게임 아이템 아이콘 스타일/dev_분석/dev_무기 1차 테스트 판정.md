# 게임 아이템 아이콘 스타일 — 무기 1차 테스트 판정

- 기준일: 2026-09-12
- 결과: 부분 실패 / 교정 필요

## 확인된 장점

- 검·대검·창·도끼·활·석궁·단검·지팡이·사슬무기 등 형태 다양성은 확보했다.
- 대형 실루엣과 재질 렌더링 자체는 게임 아이콘 문법에 맞았다.

## 핵심 실패

대부분의 무기가 강한 원소 배경, 광휘, 룬, 보석, 에너지 소용돌이를 사용하여 **속성 설명이 없는 일반 무기까지 마법 무기처럼 보였다.**

아이템 인벤토리에서는 이것이 의미 손실이다. 일반 무기, 희귀 무기, 속성 무기가 시각적으로 같은 효과 밀도에 수렴하면 아이콘의 정보 계층이 무너진다.

## 교정

- 속성·마법 설명 없음 → 일반 무기
- 일반 무기 → 중성 저채도 배경, 구조/재질 우선, 자동 발광 금지
- 속성·마법 무기 → 유색 배경/국소 효과 허용, 본체 우선
- 희귀도 → 프레임 색이 아니라 구조·보조 재질·룬·보석·제한적 발광

## 다음 검증

일반 무기 3×3 1장과 속성·마법 무기 3×3 1장을 동일 배치에서 비교한다.
