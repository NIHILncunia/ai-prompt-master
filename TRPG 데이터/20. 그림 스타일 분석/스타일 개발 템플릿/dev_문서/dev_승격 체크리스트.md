# dev_승격 체크리스트

- [ ] 스타일명과 영문 내부명이 확정됨
- [ ] 스타일 소유 범위와 비소유 범위가 명확함
- [ ] 핵심 고정 영어 스타일 블록 확정
- [ ] 공통 붓터치 마감 적용 여부 확정
- [ ] 프롬프트 블록별 역할 중복 제거
- [ ] 핵심 앵커와 조건부 앵커 구분
- [ ] dev_앵커 번호가 연속 정렬됨
- [ ] 실패 시안이 dev_앵커에 남아 있지 않음
- [ ] 인물 표현 검증 완료
- [ ] 환경 표현 검증 완료 또는 해당 없음 판정
- [ ] 기능성 예외 충돌 검토 완료
- [ ] 중앙 호출 규칙 등록용 최소 조합 확정
- [ ] 정식 경로 복사 후 `dev_` 자산 자동 호출 금지 확인
