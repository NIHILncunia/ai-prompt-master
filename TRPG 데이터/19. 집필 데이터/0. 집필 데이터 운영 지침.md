# 집필 데이터 운영 지침

## 정본 범위

이 폴더는 집필 데이터 체크 기능의 과제 데이터베이스, 과제 이력, 원문, 문체 프로필의 정본이다. 실행 규칙은 `1. 프롬프트/9. 집필 데이터 체크 프롬프트`에서 소유한다.

## 파일 책임

| 항목 | 책임 |
| --- | --- |
| 장르 데이터베이스 | 소설 과제의 장르 후보 |
| 주제 데이터베이스 | 소설 과제의 주제 후보 |
| 장면 소재 데이터베이스 | 장면 묘사 과제의 내부 조합 후보 |
| 과제 이력 | 발급·제출 상태와 선택 이력 |
| 원문 | 마스터가 제출한 무변형 원문 |
| 문체 프로필 | 원문 근거가 있는 누적 문체 관찰 |

## 저장 정책

- 모든 과제 발급, 원문 제출, 프로필 갱신은 발생 직후 Drive에 반영한다.
- 원문은 삭제·수정·재구성하지 않는다.
- 데이터베이스 항목은 원본 키워드 근거 또는 `신규 보강` 근거를 유지한다.
- 자동 선택의 편의를 위해 원본 근거를 지우거나 여러 의미를 하나의 항목으로 축약하지 않는다.
