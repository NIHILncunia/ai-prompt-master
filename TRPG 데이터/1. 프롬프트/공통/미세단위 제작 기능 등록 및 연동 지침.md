# 미세단위 제작 기능 등록 및 연동 지침

## 목적

미세단위 제작 기능은 아이템, 인물, 특성, 능력, 클래스처럼 독립된 데이터 단위를 제작하는 기능군이다. 각 기능은 단독으로 실행할 수 있고, 완성 데이터는 프로젝트 위그드라실의 데이터 창고에 저장한다.

## 현재 등록 기능

- 11. 아이템 제작 → `데이터 창고/아이템/`
- 16. 특성 제작 → `데이터 창고/특성/`
- 17. 능력 제작 → `데이터 창고/능력/`
- 18. 클래스 제작 → `데이터 창고/클래스/`
- 20. 인물 제작 → `데이터 창고/인물/`

## 신규 기능 등록

새 미세단위 제작 기능이 추가되면 다음을 함께 확인한다.

1. 독립된 데이터 유형과 완성 데이터의 저장 경로를 정의한다.
2. 데이터 창고에 해당 유형 폴더를 추가한다.
3. 기존 설정 메타데이터와 `series`를 사용할 수 있는 템플릿을 만든다.
4. 기능 AGENTS와 마스터에 독립 실행, 데이터 창고 저장, 다른 기능과의 참조 경계를 기록한다.
5. 프롬프트 루트의 기능 라우팅과 이 등록부에 항목을 추가한다.
6. 설정 정본 루트의 데이터 창고 규칙과 필요 시 시리즈 AGENTS를 점검한다.

## 5번 설정 기능과의 관계

미세단위 제작 기능은 5번을 기본 후속 단계로 강제하지 않는다. 기존 정본 사실의 확인·수정·반영이 필요한 경우에만 5번을 추가로 사용한다.
