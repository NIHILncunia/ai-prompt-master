# 1. 종족 설정 문서 작성 지침서

## 목적

이 지침서는 종족을 세계관 설정 문서로 작성할 때 사용하는 공용 작성 규칙이다.

종족 문서는 외형 목록이 아니라, 해당 존재가 어떻게 살아가고 무엇을 두려워하며 다른 문명과 어떤 긴장을 만드는지 설명해야 한다.

## 작성 전 확인

- 어느 세계에 속하는가
- 공식 룰북 종족인가, 세계관 고유 종족인가
- 플레이 가능한가
- 지성체인가
- 자연종, 창조종, 변이종, 기계 생명, 정령, 언데드 중 무엇인가
- 최신 정본 자료가 어디에 있는가
- 기존 문서가 있는가
- 시각 표현 데이터가 별도로 존재하는가

## 설정 정본과의 관계

프로젝트 위그드라실 공통 설정과 각 시리즈의 종족 정본은 5번 기능을 통해 `프로젝트 위그드라실` 루트에서 확인한다.

공식 D&D 종족은 4번 기능에서 소유 룰북과 공식 데이터를 확인한다.

공통 종족 데이터는 확인된 정보를 공용 종족 문서 구조에 맞게 정리한다. 정본에 없는 항목을 자동으로 사실화하지 않는다.

## 필수 구성

`템플릿/설정_종족 템플릿.md`를 기준으로 하되, 존재하지 않는 항목은 삭제할 수 있다.

반드시 검토할 축:

- 핵심 정체성
- 기원과 역사
- 기본 해부학
- 생리와 생애
- 능력과 한계
- 형태 변화
- 의복·갑주·도구
- 생활 방식
- 문화
- 사회 구조
- 신앙과 세계관
- 대외 관계
- 분포
- 현재 동향
- 플레이어·NPC·시나리오 활용

## 문체

- 요약형 항목 나열보다 설명형 문단을 우선한다.
- 각 섹션은 원인, 구조, 결과가 연결되어야 한다.
- 강점만 쓰지 않고 제약과 대가를 함께 쓴다.
- 외부의 편견과 실제 모습을 구분한다.
- 종족 전체의 경향과 개체차를 구분한다.
- 세계관의 현재 시점에서 어떤 변화가 진행 중인지 포함한다.

## 설정 문서와 시각 데이터 연결

설정 문서의 프론트매터에 `visual_profile`을 둘 수 있다.

```yaml
visual_profile: '종족 데이터/<분류>/<종족명>.md'
```

설정 본문에는 독자가 이해할 정도의 외형을 적되, 이미지 생성용 세부 해부학과 금지 해석은 시각 표현 데이터에 둔다.

## 복수 형태

형태 변화가 있는 종족은 다음을 구분한다.

- 종족 전체가 사용하는 형태
- 특정 혈통만 사용하는 형태
- 마법이나 기술로 획득하는 형태
- 개별 캐릭터만 가진 변신
- 일시적 전투 상태
- 타락이나 질병으로 생기는 비정상 형태

개체 고유 변신은 종족 공통 설정으로 일반화하지 않는다.

## 미확정 처리

자료가 부족한 항목은 다음 중 하나로 표시한다.

- 미확정
- 지역에 따라 다름
- 개체차가 큼
- 특정 혈통에만 해당
- 설정상 알려지지 않음
- GM 전용 정보 필요

빈칸을 임의의 상식으로 채우지 않는다.
