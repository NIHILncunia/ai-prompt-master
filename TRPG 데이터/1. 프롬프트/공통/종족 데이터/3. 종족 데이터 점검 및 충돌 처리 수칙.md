# 3. 종족 데이터 점검 및 충돌 처리 수칙

## 점검 목적

종족 설정 문서와 시각 표현 데이터가 서로 충돌하거나 이미지 기능별로 분기되는 것을 방지한다.

## 필수 점검표

### 정체성

- 한 문장으로 종족의 핵심 정체성을 설명할 수 있는가
- 인간형 장식 종족과 실제 비인간 종족이 구분되는가
- 종족 전체의 특징과 개체 고유 특징이 구분되는가

### 해부학

- 팔, 다리, 날개, 꼬리, 촉수 등 기관 수가 명확한가
- 기관 연결 위치가 명확한가
- 서로 양립할 수 없는 해부학 옵션이 동시에 필수로 적혀 있지 않은가
- 전신 이미지에서 반드시 보여야 할 기관이 지정되어 있는가

### 표면과 재질

- 피부, 털, 깃털, 비늘, 금속 등 표면이 구분되는가
- 재질 전환 부위가 설명되어 있는가
- 의복과 신체 표면이 혼동되지 않는가

### 장비

- 인간용 장비를 그대로 착용할 수 없는 부위가 반영됐는가
- 날개, 꼬리, 관절, 체급을 방해하는 구조가 없는가
- 직업 장비가 종족 해부학과 양립하는가

### 복수 형태

- 각 형태의 해부학이 독립적으로 정의됐는가
- 한 형태의 기관이 다른 형태로 무단 유출되지 않는가
- 공유 정체성 앵커가 지정되어 있는가
- 종족 공통 변신과 개체 고유 변신이 구분되는가

### 스타일 중립성

공용 데이터에 다음이 박혀 있지 않은가.

- 반실사·포토리얼리즘 강제
- 애니·치비 강제
- 특정 렌즈와 카메라
- 특정 이미지 모델
- 게임 키아트·디지털 페인팅 강제

스타일 문구는 1번, 3번 등 소비 기능에 둔다.

### 출처와 최신성

- 룰북 기반 정보는 4번에서 확인됐는가
- 세계관 정본 정보는 5번에서 확인됐는가
- 오래된 중복 파일이 단일 원천보다 우선하고 있지 않은가
- 사용자의 최신 지시가 반영됐는가

## 충돌 처리

충돌 시 다음 우선순위를 사용한다.

1. 사용자 최신 지시
2. 참고 이미지와 사용자 수정
3. 최신 세계관 정본 또는 공식 룰북 근거
4. 공통 종족 데이터
5. 범용 템플릿

충돌을 조용히 섞지 않는다. 어느 항목이 왜 선택됐는지 변경사항에 기록한다.

## 중복 방지

다음 위치에 종족별 전용 데이터를 중복 보관하지 않는다.

이미지 생성 모듈의 하위 기능 폴더에 종족별 전용 데이터 저장소를 만들지 않는다.

전용 종족 데이터는 다음 위치에만 둔다.

```text
공통/종족 데이터/데이터/
```
