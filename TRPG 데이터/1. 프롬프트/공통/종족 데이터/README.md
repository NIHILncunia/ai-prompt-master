# 공통 종족 데이터

이 폴더는 프로젝트 전체가 공유하는 종족 설정과 시각 표현 데이터의 단일 원천입니다. 독립 제작 기능이 아니며, 종족을 새로 창작하지 않습니다.

## 핵심 원칙

- 종족 데이터는 스타일 중립적으로 작성합니다.
- 반실사, 애니, 레퍼런스 시트 등 최종 화풍은 소비 기능이 결정합니다.
- 공식 룰북 정보는 4번에서 확인합니다.
- 룩스테라·엘드로스 정본은 5번에서 확인합니다.
- 전용 종족 파일은 이 폴더에만 보관합니다.
- 1번의 기존 `데이터/` 폴더는 폐기합니다.
- 사용자의 최신 지시와 참고 이미지가 가장 높은 우선순위를 가집니다.

## 문서 종류

- `템플릿/설정_종족 템플릿.md`: 세계관 설정 문서
- `템플릿/종족 시각 표현 데이터 템플릿.md`: 이미지 생성 공용 데이터
- `데이터/`: 실제 종족별 시각 표현 데이터

## 경로 예시

```text
데이터/DND/Aarakocra.md
데이터/룩스테라/엘-드로이드.md
데이터/룩스테라/드래곤.md
데이터/엘드로스/<종족명>.md
데이터/공용/<범용 종족명>.md
```

## 파일명

가능하면 설정 정본에서 사용하는 종족명을 유지합니다.

영문 공식 종족은 공식 영문명을 사용할 수 있습니다. 같은 종족을 한글명과 영문명으로 중복 생성하지 않습니다.
