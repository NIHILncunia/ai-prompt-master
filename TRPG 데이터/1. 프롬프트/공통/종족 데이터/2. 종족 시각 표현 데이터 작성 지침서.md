# 2. 종족 시각 표현 데이터 작성 지침서

## 목적

이 지침서는 포트레이트, 캐릭터 레퍼런스 시트, 하이라이트 이미지 등에서 공용으로 사용할 종족 시각 데이터를 작성한다.

공용 데이터는 화풍이 아니라 구조를 고정한다.

## 스타일 중립 작성법

다음처럼 작성한다.

- 실제 부리 구조
- 네 개의 팔
- 등에서 시작되는 두 날개
- 작은 비늘이 관절을 덮음
- 목과 어깨가 분리되지 않는 덩어리형 구조
- 판금이 날개 뿌리를 피하도록 분할됨

다음처럼 특정 화풍을 공용 데이터에 고정하지 않는다.

- 포토리얼리스틱
- 반실사 레벨 5
- 일본 애니 작화
- 치비 비율
- 게임 카드 렌더링
- 화가풍 브러시

## 데이터 우선순위

1. 사용자 최신 설명
2. 사용자 참고 이미지
3. 세계관 정본
4. 전용 종족 데이터
5. 범용 종족 표현 규칙

## 필수 필드

전용 종족 파일은 가능한 범위에서 다음을 정의한다.

- 정식 명칭과 별칭
- 분류와 세계
- 적용 범위
- 한 문장의 핵심 시각 정체성
- 해부학 위상
- 기관 수
- 기관 연결 위치
- 머리와 얼굴
- 체형과 자세
- 표면 재질
- 성장 단계
- 성별 차이 또는 차이 없음
- 필수 시각 앵커
- 선택 변형
- 금지되는 기본 오해
- 의복·갑주·장비 적응
- 움직임과 자세
- 복수 형태
- 형태 간 공유 정체성
- 스타일 중립 자동 보강 문장

## 해부학 위상

기관의 존재만 적지 말고 연결 구조를 적는다.

나쁜 예:

```text
날개가 있다.
```

좋은 예:

```text
한 쌍의 기능성 날개가 견갑골 뒤쪽의 별도 관절에서 시작되며, 두 팔과 분리된다.
```

팔과 날개가 통합된 종족이라면 이를 별도로 명시한다.

## 표면 재질

피부, 털, 깃털, 비늘, 키틴, 금속, 석재, 결정, 목재, 연기, 액체 등 표면을 구분한다.

표면이 몸 전체에서 동일하지 않다면 부위별로 적는다.

## 필수·선택·금지 구분

### 필수

종족으로 인식되기 위해 항상 유지해야 한다.

### 선택

지역형, 혈통형, 성별, 직업, 나이, 개체차에 따라 달라질 수 있다.

### 금지

모델이 자주 만드는 오해 또는 설정과 충돌하는 표현이다.

## 장비 적응

인간형 장비를 그대로 복사하지 않는다.

- 날개 뿌리
- 꼬리
- 역관절 다리
- 다족 구조
- 촉수
- 큰 뿔
- 등껍질
- 기계 관절
- 비정상 체급

이런 요소가 장비 구조에 어떤 영향을 주는지 설명한다.

## 복수 형태

각 형태는 다음 구조를 사용한다.

```yaml
forms:
  - id: true_form
    name_ko: 본래 형태
    enabled: true
  - id: humanoid_polymorph
    name_ko: 인간형 폴리모프
    enabled: true
```

본문에서는 형태마다 다음을 독립적으로 작성한다.

- 해부학
- 체형
- 머리와 얼굴
- 표면
- 의복·갑주
- 필수 요소
- 금지 요소

형태 사이에는 공유 앵커를 둔다.

- 눈 색
- 색상 체계
- 문장
- 흉터
- 장신구
- 특정 표정
- 갑주 모티프
- 마력 반응
- 음영이나 광택 특성

## 소비 기능의 책임

공통 종족 데이터 데이터는 구조만 제공한다.

- 1번은 현실에 가까운 반실사로 변환한다.
- 3번은 외형 고정용 레퍼런스 시트 구조에 배치한다.

소비 기능은 종족의 필수 해부학을 바꾸면 안 되며, 화풍과 표현 밀도만 조정한다.

## 개체 데이터와의 관계

종족 데이터는 종족의 허용 범위를 정의한다.

개별 캐릭터의 얼굴, 색상, 체격, 흉터, 직업 장비, 변신 형태는 캐릭터 데이터가 우선한다. 단, 종족의 필수 해부학과 충돌하면 사용자에게 충돌을 명확히 알린다.
