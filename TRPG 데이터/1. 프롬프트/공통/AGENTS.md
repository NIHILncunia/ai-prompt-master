## 산출물 계약 책임 분리

공통 폴더는 공용 데이터 접근 절차를 관리한다. 승인 상태는 이미지 생성 모듈 공통 폴더의 승인 정본이 관리한다.

출력 수, 단일 뷰·다중 뷰, 스프라이트, 시트 구성 여부는 각 기능 마스터가 결정한다. 공통 규칙을 이유로 레퍼런스 시트나 아이콘 스프라이트의 고유 레이아웃을 금지하지 않는다.

이미지 모듈 내부 1번 반실사 포트레이트의 전신·초상화 분리는 해당 로컬 마스터와 실행 파일이 정의한다. 공통 승인 절차는 각 모드의 승인을 분리하고 완료 후 승인 상태를 소모하는 역할만 담당한다.

## 동기화 원칙

- 이미지 승인 정본의 위치는 `../1. 이미지 생성 모듈/공통/1. 이미지 생성 공통 승인 절차.md`다. 이 폴더의 동명 문서는 기존 참조를 위한 안내 문서이며 활성 정책을 소유하지 않는다.
- 승인 상태·첫 응답·재승인·공통 확인 양식이 바뀌면 이미지 생성 모듈 공통 문서와 모든 적용 기능의 `AGENTS.md`와 마스터 프롬프트를 점검한다.

- 전역 응답 규칙이나 파일 정책이 바뀌면 TRPG 데이터 루트·프롬프트 루트 `AGENTS.md`, 프로젝트 기본 지침, 통합 마스터도 함께 갱신한다.
