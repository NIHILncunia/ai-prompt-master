# 이미지 생성 공통 승인 절차 안내

이 문서는 과거 `1. 프롬프트/공통` 경로를 참조한 요청을 위한 안내 문서다. 이미지 생성·수정의 승인 상태, 요구사항 확인서, 최종 영어 프롬프트, 명시적 승인, 결과 저장 규칙의 활성 정본은 이 문서가 아니다.

## 활성 정본

모든 이미지 생성·수정 요청은 아래 문서를 먼저 읽고 따른다.

```text
TRPG 데이터/1. 프롬프트/1. 이미지 생성 모듈/공통/1. 이미지 생성 공통 승인 절차.md
```

## 적용 원칙

- 이 문서는 승인 규칙을 별도로 정의하거나 활성 정본과 다른 규칙을 추가하지 않는다.
- 이미지 생성 모듈 내부 활성 기능 `1·2·3·4·5·6·7·8`은 활성 정본과 각 기능의 AGENTS·마스터를 따른다. 내부 5번은 캐릭터 레퍼런스 V2 생성이다.
- 공용 태그와 종족 시각 자료가 필요한 경우에는 이 폴더의 `AGENTS.md`, `라이브러리/공용 태그 사전.md`, `종족 데이터/AGENTS.md`를 조건부로 추가 참조한다.
