# 공용 태그 사전

## 목적

이 문서는 특성 종류·크리처 유형·능력 데이터·클래스 데이터에 공통으로 사용하는 표준 태그를 정의한다.

태그는 특성의 `종류·대분류·소분류` 또는 크리처의 `유형 대분류·중분류`를 대신하지 않는다. 분류 경로만으로 표현하기 어려운 발동, 작동, 기원, 외형, 존재 기반, 지성, 사회, 역할, 속성, 서사와 위상 정보를 검색 가능한 형태로 보완한다.

## 공용 사용 원칙

- 크리처 특성·효과 특성·로어 특성은 모두 같은 태그를 사용할 수 있다.
- 이형체·야수·천상체·구조체·천룡종·정령·요정·악마·거인·인간형·괴수·점액괴물·식물·언데드·용종도 모두 같은 태그를 사용할 수 있다.
- 7번 창작 지원의 능력 제작기 데이터와 7번 창작 지원의 클래스 제작기 데이터도 속성·서사·대상·역할·위상 검색을 위해 같은 태그 사전을 사용한다.
- 능력의 층위·표현 권역·원천·작동 계통·발현 형태·결과 효과와 클래스의 성격·핵심 수행 유형·기술 원천·포지션은 전용 구조 필드이므로 태그로 반복하지 않는다.
- 태그 그룹은 관리 편의를 위한 색인일 뿐 사용 제한이 아니다.
- 한 특성 또는 개체에 필요한 태그를 복수로 적용할 수 있다.
- 같은 의미의 동의어 태그를 새로 만들지 않고 이 문서의 표준 표기를 우선한다.
- 태그가 없더라도 의미가 명확하면 필드를 비울 수 있다. 분류를 채우기 위해 의미 없는 태그를 추가하지 않는다.

## 표준 출력

```text
태그: 조건부 / 강화 / 이로운 / 화염 / 구조체 / 수호
```

태그는 `/`로 구분한다. 관리 데이터에서 그룹을 병기해야 할 때만 다음처럼 보조 표기를 사용할 수 있다.

```text
태그 그룹:
- 발동: 조건부
- 작동: 강화
- 운용: 이로운
- 속성: 화염
- 대상 유형: 구조체
- 역할: 수호
```

최종 특성 출력에서는 기본적으로 하나의 `태그` 필드로 합친다.

## 15. 태그 정규화 규칙

다음 표현은 표준 태그로 통일한다.

```text
패시브 → 상시
액티브 → 행동 또는 보너스 행동
쿨타임 → 재충전 또는 휴식 태그
버프 → 강화 또는 이로운
디버프 → 약화 또는 해로운
로봇 → 구조체 / 기계 생명 또는 기능성 로봇계 참조
안드로이드 → 구조체 / 인간형 기계체 / 인공 인격계 참조
사이보그 → 원래 크리처 유형 / 기계 개조
보스급 → 보스
레이드급 → 재해 또는 세계급
```

표준 태그가 의미를 충분히 담지 못하고 같은 개념이 반복적으로 발생할 때만 신규 태그를 추가한다. 신규 태그를 추가하면 이 문서와 관련 인덱스를 함께 갱신한다.
