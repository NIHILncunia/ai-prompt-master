# 3. 종족 시각 자료 자동 탐색 하드 게이트

## 목적

이미지 생성 요청에 종족명, 종족 별칭, 고유 생물 분류, 기계 종족명 또는 설정상 개체 분류가 포함된 경우, 범용 모델 지식으로 외형을 임의 해석하지 않고 프로젝트 내부 시각 자료를 먼저 확인한다.

이 절차는 외형을 쉽게 추정할 수 있는 경우에도 생략하지 않는다. `드로이드`, `아라코크라`, `엘-드로이드`처럼 명시적인 종족·분류어가 요청문에 존재하는 것 자체가 탐색 개시 조건이다.

## 적용 범위

- 1번 반실사 포트레이트 생성
- 3번 캐릭터 레퍼런스 시트 생성
- 애니 포트레이트를 포함한 캐릭터 이미지 생성 기능
- 종족 또는 설정 개체를 포함하는 기타 이미지 생성 기능

각 기능의 화풍과 출력 형식은 해당 기능 지침을 따른다. 이 문서는 외형 근거를 확보하는 절차만 정의한다.

## 탐색 개시 조건

다음 중 하나라도 충족하면 요구사항 확인서와 최종 영어 프롬프트를 작성하기 전에 탐색을 수행한다.

1. 요청문에 종족명 또는 종족 별칭이 직접 등장한다.
2. 요청문에 세계관 고유 생물·기계 생명체·용종·몬스터 분류가 등장한다.
3. 첨부 설정 문서나 캐릭터 문서에 종족 또는 개체 분류가 기록되어 있다.
4. 대상의 해부 구조, 골격, 피부, 외장 또는 얼굴 구조를 일반적인 인간형으로 판단하기 어렵다.
5. 사용자가 기존 디자인, 공식 이미지, 레퍼런스 또는 설정상의 외형을 암시한다.

판단이 서지 않을 때만 탐색하는 것이 아니다. 명시적인 분류명이 발견되면 판단 가능 여부와 관계없이 탐색한다.

## 기본 탐색 순서

다음 순서는 우선순위이자 폴백 순서다. 접근 도구가 허용하면 일부 단계를 병렬 검색할 수 있으나 최종 적용 우선순위는 유지한다.

1. 현재 대화에 첨부된 사용자 참고 이미지와 최신 수정 지시
2. `TRPG 데이터/12. 종족 이미지/`의 해당 종족 이미지와 가이드
3. `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/`의 해당 종족·성별·형태 레퍼런스
4. `TRPG 데이터/1. 프롬프트/공통/종족 데이터/데이터/<세계관>/<종족명>.md`
5. 종족 데이터 문서가 직접 지시하는 추가 이미지, 가이드 및 설정 문서
6. 해당 기능의 범용 종족 표현 라이브러리
7. 프로젝트 자료가 모두 없을 때만 일반적인 모델 지식과 합리적 추정

사용자가 요구한 폴백 흐름은 다음처럼 보장한다.

```text
종족 이미지 확인
→ 없으면 캐릭터 레퍼런스 이미지 확인
→ 없으면 공통/종족 데이터 확인
→ 전용 종족 데이터가 지시하는 추가 자료 확인
→ 그래도 없으면 범용 라이브러리와 일반 추정
```

## 검색어 확장

최초 검색에서는 요청문에 나온 원문 명칭을 그대로 사용한다. 결과가 없으면 다음 순서로 확장한다.

1. 한글명과 영문명
2. 하이픈·띄어쓰기 변형
3. 상위종·하위종·각성형 등 형태명
4. 성별형 또는 프레임명
5. 종족 데이터의 `canonical_name`, `korean_name`, 별칭
6. 설정 문서에서 사용하는 공식 명칭

예를 들어 `드로이드` 요청은 `드로이드`, `Droid`, `남성형 드로이드`, `드로이드 레퍼런스`를 검색 대상으로 삼는다.

## 자료 충돌 우선순위

자료가 충돌하면 다음 순서를 따른다.

1. 현재 대화에서 사용자가 내린 최신 명시 지시
2. 현재 대화에 첨부된 사용자의 참고 이미지와 교정 내용
3. 공통 종족 데이터의 전용 종족 파일
4. 전용 종족 파일이 직접 지정한 공식 종족 이미지와 레퍼런스
5. 세계관 설정 정본
6. 기능별 범용 종족 표현 라이브러리
7. 일반적인 모델 추정

사용자 참고 이미지가 단순 분위기 참고인지 공식 외형 기준인지 불명확하면 요구사항 확인서에 적용 범위를 명시한다.

## 요구사항 확인서 반영 의무

탐색을 수행한 경우 요구사항 확인서에 아래 항목을 반드시 포함한다.

- 인식한 종족 또는 개체 분류
- 확인한 종족 데이터 파일
- 확인한 공식 종족 이미지 또는 레퍼런스
- 외형에 반영한 핵심 시각 특징
- 사용자 요청으로 덮어쓴 특징
- 자료가 없어서 추정한 부분

자료를 찾지 못했다면 `관련 프로젝트 자료를 찾지 못함`을 명시하고 그때에만 일반 해석을 제안한다.

## 생성 금지 조건

다음 상태에서는 이미지 생성 도구를 호출하지 않는다.

- 명시적인 종족명이 있는데 탐색을 수행하지 않은 경우
- 종족 데이터가 참조 이미지를 지정했는데 해당 이미지의 존재 여부를 확인하지 않은 경우
- 요구사항 확인서에 자료 출처와 반영 특징이 누락된 경우
- 탐색 결과와 최종 영어 프롬프트의 외형이 충돌하는 경우

## 드로이드 적용 예시

요청문에 `남성형 드로이드`가 포함되면 다음 절차를 수행한다.

1. `TRPG 데이터/12. 종족 이미지/드로이드.webp` 확인
2. `TRPG 데이터/3. 캐릭터 레퍼런스 이미지/남성형 드로이드 레퍼런스.webp` 확인
3. `공통/종족 데이터/데이터/룩스테라/드로이드.md` 확인
4. 인간형 금속 골격, 기계식 목·척추 연결부, 흉부 코어, 교체식 군용 외부 장갑과 남성형 비례를 반영
5. 확인한 자료와 반영 특징을 요구사항 확인서에 기록
6. 범용 전투 로봇이나 임의의 안드로이드 디자인으로 대체하지 않음
