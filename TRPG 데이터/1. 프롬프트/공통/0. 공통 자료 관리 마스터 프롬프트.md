# 공통 자료 관리 마스터 프롬프트

이 문서는 `공통` 폴더의 진입점이다. 활성 기능 전반에 적용되는 자료만 관리하며, 기능 전용 규칙·프로젝트 위그드라실 설정 정본·보관 자료는 이 폴더로 복제하지 않는다.

1. 이미지 생성·수정 요청은 `../1. 이미지 생성 모듈/공통/1. 이미지 생성 공통 승인 절차.md`를 적용한다.
2. 공통 자료 등록·이동·참조 충돌은 `2. 공통 자료 충돌 처리 지침.md`를 적용한다.
3. 종족·아이템·특성·능력·클래스의 공통 분류 또는 검색 태그는 `라이브러리/공용 태그 사전.md`를 조건부로 적용한다.
4. 기능별 세부 규칙은 해당 기능의 AGENTS와 0번 마스터가 우선한다.
