# 7번 창작 지원의 클래스 제작기 프롬프트 적용 안내

## 문서 상태

이 폴더는 소설·세계관·게임식 설정에 사용할 범용 클래스 데이터를 제작하고 관리하는 정식 기능입니다.

현재 버전은 `1.0`입니다.

## 기능 목적

7번 창작 지원의 클래스 제작기는 다음 대상을 하나의 공통 규격으로 설계합니다.

- 기본 클래스
- 하위 클래스
- 전직·상위·히든 클래스
- 사회 직업과 전문직
- 전투 스타일과 아키타입
- 종족·혈통·조직 전용 클래스
- 시스템 클래스
- 비전투 생산·연구·관리 클래스

이 기능은 D&D 클래스 규칙 제작을 기본 목적으로 하지 않습니다. 명시적 요청 없이 레벨별 진행표, 히트 다이스, 숙련과 클래스 피쳐를 추가하지 않습니다.

## 핵심 개편

기존의 `유형 = 직접 공격 수단` 규칙을 폐기하고 `핵심 수행 유형`으로 확장했습니다.

```text
전투 - 검술
탐사 - 추적
사회 - 교섭
제작 - 연금
정보 - 시스템 침투
```

전투 수단은 필요한 클래스에만 별도 필드로 기록합니다.

## 계층 구조

다음 관계를 서로 분리합니다.

```text
직접 상위 클래스
조합 원형
하위 클래스
전직 대상
선행 클래스
연관 클래스
```

## 인접 기능과의 경계

- 특성·효과·로어 특성: 7번 창작 지원의 특성 제작기
- 개별 능력 전체 구조: 7번 창작 지원의 능력 제작기
- 클래스·직업·전직 구조: 7번 창작 지원의 클래스 제작기
- 세계관의 직업 제도와 역사 정본: 5번
- 종족 자체의 생리·문화·형태: 공통 종족 데이터

## 공용 태그

검색 태그는 `../../공통/라이브러리/공용 태그 사전.md`를 함께 사용합니다.

클래스 전용 구조 필드의 값을 태그로 반복하지 않습니다.

## 적용 원칙

Google Drive에는 직접 생성하거나 덮어쓰지 않습니다.

수정본과 신규 문서는 사용자가 수동 적용할 수 있는 로컬 파일 또는 ZIP으로 제공합니다.

## 변경 이력

### 1.0

- 웹 소설 클래스 템플릿을 TRPG 데이터 7번 창작 지원의 클래스 제작기 기능으로 정규화했습니다.
- D&D 클래스 규칙 제작을 기본 목적에서 제외했습니다.
- 전투·비전투 클래스를 같은 구조로 설명하도록 핵심 수행 유형을 확장했습니다.
- 직접 상위 클래스와 조합 원형을 분리했습니다.
- 주 기능 포지션과 활동 범위를 전투 외 역할까지 확장했습니다.
- 자원·제약·사회적 역할의 분류를 정리했습니다.
- 능력 제작기 데이터와 특성 제작기 데이터를 참조하는 연결 규칙을 추가했습니다.
- 클래스 데이터, 템플릿과 인덱스 구조를 추가했습니다.
- 8·12·16·7번 창작 지원의 능력 제작기 기능과의 경계를 확정했습니다.
