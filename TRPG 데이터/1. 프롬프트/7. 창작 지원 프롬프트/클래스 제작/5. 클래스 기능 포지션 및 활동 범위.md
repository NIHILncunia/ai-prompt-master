# 5. 클래스 기능 포지션 및 활동 범위

## 목적

이 문서는 클래스가 어떤 역할을 제공하고 어느 거리·규모·조직 범위에서 활동하는지를 정의한다.

기존의 전투 포지션과 전투 거리 중심 구조를 확장하여 비전투 클래스도 동일하게 설명할 수 있도록 한다.

## 1. 주 기능 포지션

주 기능 포지션은 클래스가 가장 우선적으로 수행하는 역할이다. 하나를 기본으로 선택한다.

### 공격

적대 대상을 제거하거나 손상시키는 것이 핵심이다.

### 방어

대상·지역·조직을 보호하고 피해를 받아내거나 차단한다.

### 지원

다른 대상의 능률, 안정성, 자원과 행동 가능성을 높인다.

### 회복

손상·질병·오염·상태 이상을 치료하고 정상 상태를 복원한다.

### 통제

이동·행동·정보·영역·관계를 제한하고 조절한다.

### 지휘

인물·군세·권속·조직의 행동을 조율하고 목표를 부여한다.

### 소환

소환체·권속·드론·분신·군세를 호출하고 운용한다.

### 탐사

미지 영역을 조사하고 생존·추적·항해·경로 개척을 수행한다.

### 정보

정보를 수집·분석·보호·전달·조작한다.

### 제작

도구·물품·시설·생명체와 기술 산출물을 만든다.

### 생산

생활·산업 자원을 지속적으로 생산·가공·보급한다.

### 교섭

상업·외교·중개·협상·사회 관계를 조정한다.

### 관리

시설·인력·재정·시스템·자원을 유지하고 배분한다.

### 운송

인물·물자·정보를 이동시키고 교통 수단을 운용한다.

### 연구

새 지식과 이론을 발견·검증하고 체계화한다.

### 복합

둘 이상의 포지션이 클래스의 핵심에서 분리 불가능하게 결합된다. 가능하면 대표 포지션 하나와 보조 포지션으로 먼저 표현한다.

## 2. 보조 기능 포지션

보조 포지션은 0~3개를 권장한다.

```text
공격 / 방어 / 지원 / 회복 / 통제 / 지휘 / 소환 / 탐사 / 정보 / 제작 / 생산 / 교섭 / 관리 / 운송 / 연구
```

주 포지션과 같은 값을 반복하지 않는다.

## 3. 전투 포지션

전투가 중요한 클래스에만 선택적으로 기록한다.

```text
딜러
탱커
브루저
서포터
힐러
컨트롤러
커맨더
서머너
스카우트
스페셜리스트
```

전투 포지션은 사회적 직업이나 핵심 수행 유형을 대체하지 않는다.

## 4. 활동 범위

### 자기 자신

자기 신체·정신·능력과 개인 활동이 중심이다.

### 접촉

대상과 직접 접촉해야 주된 역할을 수행할 수 있다.

### 근거리

개인 주변과 소규모 현장에서 활동한다.

### 중거리

하나의 전장·시설·거리 정도의 범위를 다룬다.

### 원거리

시야 밖 또는 상당한 거리에서 영향력을 행사한다.

### 초장거리

도시 밖, 장거리 통신망, 위성·포대·의식처럼 매우 먼 거리에서 개입한다.

### 영역

고정된 결계·시설·진지·작업장·던전 구역이 중요하다.

### 지역

마을·영지·숲·해역 등 하나의 지역 규모를 다룬다.

### 조직

길드·군대·교단·기업처럼 조직 단위에서 역할을 수행한다.

### 도시

도시 전체의 행정·경제·방어·정보망을 다룬다.

### 국가

국가 제도·군사·경제·외교 규모에서 작동한다.

### 세계

세계 전체의 법칙·교통·정보·재난에 관여한다.

### 네트워크

물리 거리보다 정보망과 접속 범위가 중요하다.

### 차원

다른 세계·차원·공간층을 넘나들며 활동한다.

### 복합

둘 이상의 활동 범위를 동등하게 사용한다.

## 5. 전투 거리

전투 클래스에 필요할 때만 기록한다.

```text
근거리
중거리
원거리
초장거리
접촉형
전환형
환경형
비전투형
```

`활동 범위`와 `전투 거리`는 다를 수 있다.

```text
지휘관
- 활동 범위: 조직
- 전투 거리: 근거리

해커
- 활동 범위: 네트워크
- 전투 거리: 비전투형 또는 초장거리
```

## 6. 규모 태그

필요하면 공용 태그로 다음 규모를 보완한다.

```text
개인
소규모 집단
부대
군단
조직
도시
국가
세계
```

규모는 핵심 수행 유형과 포지션을 대신하지 않는다.

## 7. 예시

```md
- 클래스: 레인저
  - 주 기능 포지션: 공격
  - 보조 기능 포지션: 탐사 / 정보
  - 활동 범위: 지역
  - 전투 포지션: 딜러
  - 전투 거리: 전환형

- 클래스: 상인
  - 주 기능 포지션: 교섭
  - 보조 기능 포지션: 관리 / 정보
  - 활동 범위: 도시 / 조직
  - 전투 포지션: 없음
  - 전투 거리: 비전투형

- 클래스: 왕실 행정관
  - 주 기능 포지션: 관리
  - 보조 기능 포지션: 교섭 / 정보
  - 활동 범위: 국가
  - 전투 포지션: 없음
```
