# 4. 클래스 기술 원천 및 테마 체계

## 목적

이 문서는 클래스가 무엇을 통해 능력과 역할을 획득하는지, 그리고 어떤 미학과 상징으로 표현되는지를 분리한다.

```text
기술 원천: 실제 숙련·지식·권한·혈통·장비의 출처
테마: 클래스의 이미지·분위기·상징과 반복 키워드
```

## 1. 기술 원천 선택 원칙

- 1~5개를 권장한다.
- 가장 본질적인 원천을 앞에 둔다.
- 직접 수행 내용은 핵심 수행 유형에 기록한다.
- 개별 능력의 세부 원천과 클래스 전체 원천을 구분한다.

## 13. 테마 선택 원칙

- 3~10개를 권장한다.
- 가장 핵심적인 이미지부터 기록한다.
- 테마는 구조 판정용 필드가 아니다.
- 동일한 테마를 가진 클래스도 수행 유형과 원천이 다를 수 있다.
- 설명을 장식하려고 관련 없는 테마를 늘리지 않는다.

## 15. 원천과 테마의 차이

```text
테마: 숲 / 달 / 사냥
기술 원천: 자연 교감 / 야생 경험 / 무기 숙련

테마: 기계 / 네트워크 / 침투
기술 원천: 데이터 / 해킹 기술 / 장비
```

숲 테마를 가진 클래스가 반드시 자연 교감을 원천으로 삼는 것은 아니다. 기계 테마를 가진 클래스가 반드시 기계 생명체인 것도 아니다.
