# 클래스 데이터

이 폴더는 검수와 확정을 마친 클래스 문서의 정식 저장 위치다.

## 기본 원칙

- 브레인스토밍 후보와 폐기안은 저장하지 않는다.
- 파일명은 확정 클래스명을 그대로 사용한다.
- 세계 전용 클래스는 문서 안의 `적용 세계` 필드로 구분한다.
- 동일 이름의 다른 클래스는 `클래스명 - 세계명.md`처럼 범위를 표시한다.
- 신규·개편 작업 전 `인덱스/클래스 인덱스.md`를 먼저 확인한다.
- 클래스 문서를 추가·이동·대체하면 인덱스를 함께 갱신한다.
- 대표 능력의 완전한 구조는 능력 제작기 데이터에 저장한다.
