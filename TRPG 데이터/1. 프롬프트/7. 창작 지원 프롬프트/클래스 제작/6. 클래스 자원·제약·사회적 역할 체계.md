# 6. 클래스 자원·제약·사회적 역할 체계

## 목적

이 문서는 클래스가 무엇을 관리하고 어떤 한계를 가지며 세계관 안에서 어떤 위치를 차지하는지를 정의한다.

## 1. 자원관리 원칙

- 0~5개를 권장한다.
- 자원이 없으면 `없음`으로 기록한다.
- 자원은 클래스의 모든 기능을 억지로 하나의 수치로 환원하기 위한 장치가 아니다.
- 같은 자원을 여러 성격으로 반복 기록하지 않는다.

## 5. 역할과 클래스명의 중복

`기사`, `마법사`, `상인`은 클래스명과 사회적 역할 양쪽에 나타날 수 있다.

```text
클래스명: 성기사
사회적 역할: 기사 / 성직자 / 교단원
```

이는 중복 오류가 아니다. 클래스명은 구조적 데이터의 이름이고 사회적 역할은 세계관 안의 직업적 위치다.

## 6. 자원·제약·역할 연결

세 필드는 서로 독립적이지만 자연스럽게 연결되어야 한다.

```text
클래스: 왕실 행정관
자원: 법적 권한 / 정보망 / 인맥
제약: 국가 통제 / 정치적 감시
사회적 역할: 관료 / 왕실 대리인 / 행정관
```

## 7. 금지 사항

- 명확한 필요 없이 모든 클래스에 전투 약점을 강제하지 않는다.
- 과열처럼 상태에 가까운 값을 소모 자원과 제약에 동시에 반복하지 않는다.
- 사회적 역할을 핵심 수행 유형 대신 사용하지 않는다.
- 신분·권한이 설정에서 확인되지 않았는데 임의로 부여하지 않는다.
- 강한 클래스를 제한하려고 관련 없는 수명·기억 소모를 장식처럼 추가하지 않는다.
