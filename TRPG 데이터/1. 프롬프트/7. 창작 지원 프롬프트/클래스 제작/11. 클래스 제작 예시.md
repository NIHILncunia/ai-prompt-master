# 11. 클래스 제작 예시 라이브러리

## 문서 역할

이 문서는 클래스 구조와 출력 방식을 보여 주는 설계 예시다. 예시는 자동으로 세계관 정본이나 완성 클래스 데이터로 간주하지 않는다.

## 1. 전투·탐사 복합 클래스

# 레인저

## 기본 정보

- 한 줄 정의: 야생 환경에서 표적을 추적하고 원거리와 근거리 전투를 전환하며 임무를 수행하는 사냥 전문가.
- 클래스 성격: 기본 클래스
- 직접 상위 클래스: 없음
- 조합 원형: 사냥꾼 / 척후병
- 하위 클래스: 비스트 마스터 / 글룸 스토커 / 헌터
- 전직 대상: 설정별 지정
- 선행 클래스: 없음
- 연관 클래스: 정찰병 / 괴물 사냥꾼
- 적용 세계: 공용

## 구조

- 핵심 수행 유형: 전투 - 궁술 / 탐사 - 추적
- 테마: 숲 / 활 / 쌍검 / 추적 / 사냥 / 정찰 / 야생
- 기술 원천: 자체 수련 / 무기 숙련 / 자연 교감 / 야생 경험
- 주 기능 포지션: 공격
- 보조 기능 포지션: 탐사 / 정보
- 활동 범위: 지역
- 전투 포지션: 딜러
- 전투 거리: 전환형
- 대표 전투 수단: 활 / 쌍검

## 운용

- 자원관리: 집중력 / 특수 탄약 / 야외 보급
- 제약·한계: 다수전 취약 / 광역 대응 약함 / 지형 정보 의존
- 획득 방식: 수련 / 현장 경험
- 상실·변경 조건: 없음
- 사회적 역할: 척후병 / 정찰병 / 괴물 사냥꾼 / 변경 수호자
- 태그: 야생 / 추적 / 정찰

## 설명

레인저는 활과 쌍검을 다루는 전투 능력만으로 정의되지 않는다. 표적의 흔적을 읽고 환경을 활용하며 미지의 지역에서 임무를 지속하는 탐사 구조가 전투와 동등하게 중요하다.

야외에서는 정찰과 추적, 기습과 생존을 연결해 행동한다. 직접 교전에서는 원거리 사격과 근거리 전환을 사용하지만 정면 방어와 대규모 광역전은 주 역할이 아니다.

세계관 안에서는 변경 수호자, 괴물 사냥꾼, 길잡이와 척후병으로 활동할 수 있다. 특정 조직과 세계에 적용할 때에는 해당 지역의 사냥 제도와 자연관을 5번 설정 정본에서 확인한다.

## 대표 능력

- 표적 추적
  - 역할: 대상의 흔적과 이동 방향을 찾아낸다.
  - 획득 관계: 기본 보유
  - 정본: 미작성
  - 상태: 개념만 확정
- 특수 사격
  - 역할: 상황에 맞는 사격 기술을 선택한다.
  - 획득 관계: 수련
  - 정본: 미작성
  - 상태: 개념만 확정
- 야생 은신
  - 역할: 자연 지형에 흔적을 숨긴다.
  - 획득 관계: 기본 보유
  - 정본: 미작성
  - 상태: 개념만 확정

## 2. 비전투 사회 클래스

# 상인

## 기본 정보

- 한 줄 정의: 물품·정보·신뢰와 거래망을 운용해 가치를 이동시키는 교섭·관리 전문직.
- 클래스 성격: 사회 직업 / 전문직
- 직접 상위 클래스: 없음
- 조합 원형: 중개인 / 관리자
- 하위 클래스: 대상에 따라 무역상 / 정보상 / 길드 상인
- 전직 대상: 거상 / 길드장
- 선행 클래스: 없음
- 연관 클래스: 외교관 / 행정관 / 정보상
- 적용 세계: 공용

## 구조

- 핵심 수행 유형: 사회 - 상업 / 관리 - 재정 관리
- 테마: 부 / 교섭 / 중개 / 명성 / 권위 / 정보망
- 기술 원천: 상업 지식 / 상업 네트워크 / 현장 경험 / 사회적 지위
- 주 기능 포지션: 교섭
- 보조 기능 포지션: 관리 / 정보
- 활동 범위: 조직 / 도시
- 전투 포지션: 없음
- 전투 거리: 비전투형
- 대표 전투 수단: 직접 공격 수단 없음

## 운용

- 자원관리: 골드 / 거래 신뢰도 / 인맥 / 정보망
- 제약·한계: 시장 접근 의존 / 법적 규제 / 신뢰 상실 위험
- 획득 방식: 교육 / 현장 경험 / 길드 가입
- 상실·변경 조건: 파산 / 면허 박탈 / 신뢰 붕괴
- 사회적 역할: 상인 / 중개인 / 길드원 / 외교관
- 태그: 교섭 / 경제 / 도시

## 설명

상인은 전투 능력의 부재로 정의되는 클래스가 아니다. 물품과 정보의 가치를 판정하고 거래 관계를 구축하며, 자본과 신뢰를 자원으로 시장과 조직을 움직이는 것이 핵심 수행이다.

개인 거래에서 출발할 수 있지만 성장하면 길드·도시·국가 규모의 유통망과 계약을 관리할 수 있다. 이 클래스의 힘은 단순한 재산이 아니라 신뢰와 정보, 법적 권리와 공급망을 연결하는 능력에서 발생한다.

## 대표 능력

- 가치 감정
  - 역할: 대상의 시장 가치와 거래 위험을 평가한다.
  - 정본: 미작성
  - 상태: 개념만 확정
- 거래망 관리
  - 역할: 물류·인맥·정보를 연결한다.
  - 정본: 미작성
  - 상태: 개념만 확정
- 신뢰 협상
  - 역할: 장기 계약과 관계를 구축한다.
  - 정본: 미작성
  - 상태: 개념만 확정

## 3. 기술·정보 클래스

# 해커

## 기본 정보

- 한 줄 정의: 코드와 네트워크 권한을 분석·침투·재구성하여 정보 시스템을 통제하는 기술 전문직.
- 클래스 성격: 전문직
- 직접 상위 클래스: 없음
- 조합 원형: 정보 분석가 / 기술자
- 하위 클래스: 넷러너 / 전자전 요원 / AI 조율자
- 전직 대상: 시스템 관리자 / 네트워크 지배자
- 선행 클래스: 설정별 지정
- 연관 클래스: 정보요원 / 공학자 / 첩보원
- 적용 세계: 공용

## 구조

- 핵심 수행 유형: 정보 - 시스템 침투 / 통제 - 정보 차단
- 테마: 해킹 / 데이터 / 네트워크 / 침투 / 시스템 / 인공지능
- 기술 원천: 데이터 / 네트워크 / 해킹 기술 / 장비 / 연산력
- 주 기능 포지션: 정보
- 보조 기능 포지션: 통제 / 지원
- 활동 범위: 네트워크
- 전투 포지션: 스페셜리스트
- 전투 거리: 초장거리 또는 환경형
- 대표 전투 수단: 기술 장비 또는 직접 공격 수단 없음

## 운용

- 자원관리: 연산력 / 네트워크 접근권 / 암호키 / 신호 강도
- 제약·한계: 사전 정보 필요 / 장비 의존 / 역추적 위험 / 접속망 의존
- 획득 방식: 학습 / 현장 경험 / 조직 교육
- 상실·변경 조건: 권한 박탈 / 장비 상실 / 신원 노출
- 사회적 역할: 해커 / 정보요원 / 첩보원 / 기술자
- 태그: 기술 / 정보 / 침투

## 대표 능력

- 취약점 탐색
