# 9. 클래스 품질 검수 체크리스트

## 1. 라우팅 검수

- [ ] 여러 능력·역할·원천을 묶는 클래스 데이터 요청인가?
- [ ] 개별 능력의 세부 구조라면 7번 창작 지원의 능력 제작기로 보내야 하지 않는가?
- [ ] 짧은 특성·효과·이력 단위라면 7번 창작 지원의 특성 제작기로 보내야 하지 않는가?
- [ ] 세계 전체의 직업 제도와 역사라면 5번 설정 요청이 아닌가?
- [ ] 종족 자체의 생리·문화라면 공통 종족 데이터가 필요한 항목이 아닌가?

## 2. 클래스 성격 검수

- [ ] 클래스 성격이 작품 안의 획득 방식과 관계를 설명하는가?
- [ ] 기본·하위·전직·상위 클래스를 혼동하지 않았는가?
- [ ] 사회 직업과 전투 스타일을 같은 기준으로 뭉개지 않았는가?
- [ ] 히든 클래스를 단순히 희귀하거나 강한 클래스라는 뜻으로 사용하지 않았는가?
- [ ] 종족·혈통·조직 전용 조건이 실제 설정과 연결되는가?

## 3. 계층 검수

- [ ] 직접 상위 클래스와 조합 원형을 구분했는가?
- [ ] 하위 클래스와 전직 대상을 구분했는가?
- [ ] 선행 클래스와 연관 클래스를 구분했는가?
- [ ] 양방향 관계가 필요한 경우 인덱스와 상대 문서에 반영했는가?
- [ ] 실제 관계 없이 이름이 비슷하다는 이유만으로 계층을 만들지 않았는가?

## 4. 핵심 수행 유형 검수

- [ ] 클래스가 주로 무엇을 수행하는지 설명하는가?
- [ ] 직접 공격 수단만으로 유형을 결정하지 않았는가?
- [ ] 비전투 클래스도 구체적인 수행 유형을 가졌는가?
- [ ] 기술 원천·테마·사회적 역할을 수행 유형에 넣지 않았는가?
- [ ] 복수 유형이 필요한 경우 핵심 순서가 명확한가?

## 5. 원천·테마 검수

- [ ] 기술 원천이 실제 숙련·지식·권한·혈통을 설명하는가?
- [ ] 테마가 미학·상징과 분위기를 설명하는가?
- [ ] 원천과 테마가 같은 목록을 반복하지 않는가?
- [ ] 개별 능력의 세부 원천과 클래스 전체 원천을 혼동하지 않았는가?
- [ ] 테마를 과도하게 늘려 정체성을 흐리지 않았는가?

## 6. 포지션·범위 검수

- [ ] 주 기능 포지션을 하나 판정했는가?
- [ ] 보조 기능 포지션이 실제 부가 역할을 설명하는가?
- [ ] 전투 포지션을 비전투 클래스에 강제하지 않았는가?
- [ ] 활동 범위와 전투 거리를 구분했는가?
- [ ] 사회적 영향 범위와 물리적 사거리를 혼동하지 않았는가?

## 7. 자원·제약 검수

- [ ] 자원의 성격이 소모·축적·유지·용량·사회·권한·환경 중 어디인지 이해 가능한가?
- [ ] 같은 자원을 여러 필드에 중복 기록하지 않았는가?
- [ ] 제약이 실제 클래스 구조에서 발생하는가?
- [ ] 강한 클래스를 제한하려고 관련 없는 비극적 대가를 붙이지 않았는가?
- [ ] 제약이 없는 클래스에 억지 약점을 만들지 않았는가?

## 8. 사회적 역할 검수

- [ ] 사회적 역할이 세계관 안의 직업적·제도적 위치를 설명하는가?
- [ ] 전투 포지션과 사회적 역할을 혼동하지 않았는가?
- [ ] 설정에 존재하지 않는 직책·면허·조직을 임의로 확정하지 않았는가?
- [ ] 클래스명과 사회적 역할이 같아도 각각의 의미를 구분했는가?

## 9. 능력·특성 연결 검수

- [ ] 대표 능력이 클래스 정체성을 보여 주는가?
- [ ] 대표 능력의 전체 구조를 클래스 문서에 중복 작성하지 않았는가?
- [ ] 미작성 능력은 `개념만 확정`으로 표시했는가?
- [ ] 하위·전직 클래스의 계승·강화·대체·신규 능력을 구분했는가?
- [ ] 재사용 가능한 특성은 7번 창작 지원의 특성 제작기 데이터와 연결했는가?

## 10. 설정 정합성 검수

- [ ] 특정 세계관이면 5번 정본을 확인했는가?
- [ ] 종족 전용 클래스면 공통 종족 데이터를 확인했는가?
- [ ] 관련 능력이 7번 창작 지원의 능력 제작기 데이터와 모순되지 않는가?
- [ ] 확정·추정·선택 제안을 구분했는가?
- [ ] 사용자의 최신 지시를 우선했는가?

## 11. 이름과 설명 검수

- [ ] 클래스명과 실제 역할이 연결되는가?
- [ ] 첫 문장에서 클래스의 핵심을 이해할 수 있는가?
- [ ] 필드 값을 자연스럽게 풀어 썼는가?
- [ ] 비전투 클래스를 열등한 구조처럼 서술하지 않았는가?
- [ ] 불필요한 추상어와 과장된 수식을 줄였는가?

## 12. 인덱스·중복 검수

- [ ] 동일한 이름의 기존 클래스를 검색했는가?
- [ ] 이름이 달라도 실질적으로 같은 구조가 존재하지 않는가?
- [ ] 기존 클래스의 하위·전직·변형으로 처리할 수 없는가?
- [ ] 정식 데이터라면 클래스 인덱스를 갱신했는가?
- [ ] 관련 능력·종족·조직·세계 링크를 기록했는가?

## 13. 최종 판정

다음 문장에 모두 답할 수 있어야 한다.

- 이 클래스가 무엇인지 알 수 있다.
- 이 클래스가 주로 무엇을 수행하는지 알 수 있다.
- 어떤 원천과 자원을 사용하는지 알 수 있다.
- 어떤 한계와 사회적 위치를 가지는지 알 수 있다.
- 어떤 능력과 계층 관계를 가지는지 알 수 있다.
