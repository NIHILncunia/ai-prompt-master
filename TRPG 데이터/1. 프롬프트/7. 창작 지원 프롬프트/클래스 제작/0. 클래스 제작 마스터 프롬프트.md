# 0. 클래스 제작 마스터 프롬프트

## 로컬 운영 진입점과 동기화

이 기능 폴더의 `AGENTS.md`와 `0. 클래스 제작 마스터 프롬프트.md`는 함께 운영 진입점으로 취급한다. 폴더를 직접 작업 공간으로 열었을 때에는 상위 `AGENTS.md`와 프로젝트 기본·통합 문서를 읽은 뒤 로컬 `AGENTS.md`를 확인하고, 이 마스터와 필요한 하위 지침·라이브러리를 이어서 읽는다.

폴더 ID, 정식 경로, 진입점, 필수 읽기 순서, 기능 경계, 외부 데이터 원천, 기본 산출물, 파일 작업 정책을 바꾸면 `AGENTS.md`와 이 마스터를 함께 점검한다. 실제 생성·분석·작성 절차와 세부 품질 규칙은 이 마스터와 하위 문서에 두며, 로컬 `AGENTS.md`에는 작업 시작과 유지보수에 필요한 라우팅 정보만 둔다.

전역 응답 규칙·파일 정책·공통 승인 절차를 바꾸면 `TRPG 데이터/AGENTS.md`, `TRPG 데이터/1. 프롬프트/AGENTS.md`, `00. TRPG 세션 매니저 프로젝트 기본 지침.md`, `0. TRPG 데이터 프롬프트 통합 마스터 프롬프트.md`를 함께 확인한다. 다른 기능이 소유한 정본 규칙은 이 폴더에 복제하지 않고 해당 기능을 참조한다.

## 미세단위 제작 기능과 저장 위치

7번 창작 지원의 클래스 제작기는 아이템 제작기, 특성 제작기, 능력 제작기, 7번 창작 지원의 인물 제작기와 함께 `미세단위 제작 기능`이다. 완성 클래스는 `프로젝트 위그드라실/데이터 창고/클래스/`에 저장하며, 기존 설정 메타데이터에 `series`를 추가해 소속 시리즈를 기록한다. `클래스 데이터/`는 기존 자료·작업 초안·호환성 참조로 유지하고, 새 정본은 데이터 창고에서 관리한다.

이 문서는 `TRPG 데이터/1. 프롬프트/7. 창작 지원 프롬프트/클래스 제작`의 진입점이다.

7번 창작 지원의 클래스 제작기는 판타지, SF, 무협, 현대 판타지, 초능력물, 게임식 세계관과 웹 소설에서 사용할 클래스·직업·전직·하위 클래스·전문직·아키타입을 하나의 공통 규격으로 설계하고 관리한다.

이 기능의 기본 목적은 D&D 클래스 규칙을 만드는 것이 아니다. 사용자의 명시적 요청 없이 레벨별 성장표, 히트 다이스, 숙련, 주문 슬롯, 클래스 피쳐와 같은 D&D 규칙을 임의로 추가하지 않는다.

## 클래스의 정의

클래스는 인물이나 집단이 무엇을 배우고 수행하며 어떤 역할과 성장 방향을 가지는지를 묶는 구조적 정체성이다.

클래스는 반드시 전투 직업일 필요가 없다. 상인, 장인, 학자, 외교관, 행정관, 의사, 파일럿, 정보 분석가와 같은 비전투 전문직도 클래스 데이터로 설계할 수 있다.

다음은 모두 클래스 제작 대상이 될 수 있다.

- 기본 클래스와 하위 클래스
- 전직·상위·히든 클래스
- 복합·융합 클래스
- 사회 직업과 전문직
- 전투 스타일과 아키타입
- 종족·혈통·조직 전용 클래스
- 시스템이 부여하는 클래스
- 비전투 생산·연구·관리 클래스

## 핵심 설계 원칙

1. 클래스명보다 구조적 정체성을 우선한다.
2. 클래스의 핵심 수행 유형, 기술 원천, 기능 포지션과 사회적 역할을 분리한다.
3. 전투 수단을 클래스 전체의 유형으로 오인하지 않는다.
4. 전투 클래스와 비전투 클래스를 같은 문법으로 설명한다.
5. 직접 상위 클래스, 조합 원형, 하위 클래스와 전직 관계를 분리한다.
6. 테마는 미학과 상징을 설명하며 구조 필드를 대신하지 않는다.
7. 대표 능력은 능력 제작기 데이터와 연결하고 완전한 내용을 중복 작성하지 않는다.
8. 클래스에 부착되는 짧은 특성과 효과는 특성 제작기 데이터를 참조할 수 있다.
9. 세계관 전체의 직업 제도와 역사 정본은 5번을 근거로 한다.
10. 특정 종족 전용 클래스는 공통 종족 데이터와 모순되지 않아야 한다.

## 7번 창작 지원의 능력 제작기와의 관계

- 클래스 문서는 대표 능력의 이름, 클래스 안에서의 역할과 습득 관계를 기록한다.
- 능력의 원천·작동·형태·효과·비용·리스크·진화 구조는 7번 창작 지원의 능력 제작기 정식 능력 데이터에서 관리한다.
- 능력 데이터가 아직 없으면 7번 창작 지원의 클래스 제작기에서 대표 능력의 개념과 이름만 제안할 수 있다.
- 사용자가 해당 능력을 확장하려 하면 7번 창작 지원의 능력 제작기로 라우팅한다.

## 7번 창작 지원의 특성 제작기와의 관계

- 클래스가 공통으로 부여하는 짧은 성질, 지속 효과, 칭호와 로어 단위는 특성 제작기로 분리할 수 있다.
- 클래스 문서 안에 필요한 특성을 요약할 수 있지만, 재사용 가능한 완성 특성은 7번 창작 지원의 특성 제작기 라이브러리를 참조한다.
- `기사의 명예`, `마도 회로`, `중갑 숙련`, `상인 길드원`처럼 클래스와 연결된 특성도 클래스 자체와 동일한 데이터가 아니다.

## 5번 설정 기능과의 관계

- 세계관의 직업 제도, 사회적 위상, 길드·교단·국가와의 관계는 5번 정본을 확인한다.
- 확인된 정본을 바탕으로 개별 클래스 데이터를 구조화하는 작업은 7번 창작 지원의 클래스 제작기가 담당한다.
- 7번 창작 지원의 클래스 제작기는 기존 세계에 없는 기관·역사·계급을 클래스 설명을 풍부하게 보이게 하려고 임의로 확정하지 않는다.

## 공통 종족 데이터와의 관계

- 종족 전용·혈통 전용 클래스는 공통 종족 데이터을 참조한다.
- 클래스가 종족의 생리와 문화를 대체 정의하지 않는다.
- 종족이 해당 클래스를 보유할 수 있는 이유와 제한만 연결한다.
