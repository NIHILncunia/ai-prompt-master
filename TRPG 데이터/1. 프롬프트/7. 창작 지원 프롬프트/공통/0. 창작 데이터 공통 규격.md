# 창작 데이터 공통 규격

모든 완성 데이터는 다음 필드를 사용한다.

```yaml
data_id: ''
doc_type: ''
series: ''
relations: []
```

`data_id`는 제목과 경로가 바뀌어도 유지하는 고유값이다. 형식은 `itm_`, `trt_`, `abl_`, `cls_`, `chr_` 뒤에 ULID를 붙인다.

특성과 능력은 효과를 다음처럼 기록한다.

```yaml
effect_rules:
  - target: 장착 대상 아이템
    property: 화염 속성 증가
    operation: 추가
    stage: 소
    condition: 강화 슬롯에 장착된 동안
```

단계값은 소=1, 중=2, 대=3, 특대=4다. 같은 항목은 값을 더하며 5 이상은 `[특대+]`로 표시한다. 실제 합산값은 유지한다.
