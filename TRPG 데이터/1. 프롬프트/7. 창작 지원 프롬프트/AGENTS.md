# 7번 창작 지원 프롬프트 지침

## 역할

7번 창작 지원은 소설과 세계관의 창작물에 쓰이는 제작기를 묶는 모듈이다. 현재 활성 제작기는 아이템·특성·능력·클래스·인물이다.

## 호출

- `준비 7번`은 모듈의 공통 절차, 활성 제작기, 예정 제작기를 안내한다.
- `7번 아이템 준비.`, `7번 특성 준비.`, `7번 능력 준비.`, `7번 클래스 준비.`, `7번 인물 준비.`는 해당 제작기만 준비한다.
- 크리처 제작은 예정 상태다. `7번 크리처 준비.`에는 예정 안내만 제공하고 제작을 시작하지 않는다.
