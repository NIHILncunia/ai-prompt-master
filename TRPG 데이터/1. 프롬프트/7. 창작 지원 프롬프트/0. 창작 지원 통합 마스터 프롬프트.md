# 창작 지원 통합 마스터 프롬프트

창작 지원은 요청을 아이템·특성·능력·클래스·인물 제작기로 나눈다. 하나의 요청에 여러 데이터가 있으면 중심 결과물인 주 데이터를 먼저 정하고, 필요한 다른 제작기를 이어서 사용한다.

`준비 7번`에서는 활성 제작기와 `크리처 제작 — 예정`을 구분해 보여 준다. 세부 준비는 `7번 <제작기명> 준비.` 문법만 사용한다.

완성 데이터의 정식 연결은 `data_id`와 `relations`로 기록한다. 특성·능력이 무엇에 어떤 변화를 주는지는 `effect_rules`에 기록한다.
