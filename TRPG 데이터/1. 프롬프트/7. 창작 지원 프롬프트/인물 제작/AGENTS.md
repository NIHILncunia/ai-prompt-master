# 7번 창작 지원의 인물 제작기 기능 지침

## 역할

7번 창작 지원의 인물 제작기는 아이템 제작기, 특성 제작기, 능력 제작기, 클래스 제작기와 함께 `미세단위 제작 기능`이다. 소설·설정용 인물을 욕망, 결핍, 신념, 관계, 선택, 변화가 이어지는 시트로 제작한다.

완성 인물은 `프로젝트 위그드라실/데이터 창고/인물/`에 저장하며 기존 설정 메타데이터에 `series`를 추가한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 기본·통합 마스터 프롬프트
3. `0. 인물 제작 마스터 프롬프트.md`
4. `1. 인물 제작 지침서.md`
5. `2. 인물 시트 점검 수칙.md`
6. 필요한 라이브러리와 템플릿
7. 5번 설정 정본, 공통 종족 데이터 및 7번 창작 지원의 특성·능력·클래스 제작기 데이터

## 기능 경계

- 세계관의 기존 인물·세력·사건 사실 확인과 수정은 5번이 담당한다.
- 종족은 공통 종족 데이터, 특성은 7번 창작 지원의 특성 제작기, 능력은 7번 창작 지원의 능력 제작기, 클래스는 7번 창작 지원의 클래스 제작기의 완성 데이터를 참조한다.
- 주연·조연은 상세 시트, 주변인물·단역은 간략 시트를 사용한다. 엑스트라는 개별 시트를 만들지 않는다.
- 대립자·선역·악역은 역할값이 아니라 태그와 서사적 기능으로 기록한다.
