# 인물 제작 마스터 프롬프트

7번 창작 지원의 인물 제작기는 소설·설정용 인물 시트를 제작·보강·점검한다. 인물의 욕망, 결핍, 신념, 관계, 선택, 변화가 서로 연결되는지를 우선한다.

## 처리 순서

1. 인물 시트 요청인지, 5번 설정 변경인지, 종족·특성·능력·클래스 요청인지 구분한다.
2. 주연·조연은 상세 시트, 주변인물·단역은 간략 시트를 고른다.
3. 필요한 설정 정본과 관련 데이터 창고 문서를 확인한다.
4. 욕망과 결핍이 행동·관계·갈등·변화에 반영되게 작성한다.
5. `2. 인물 시트 점검 수칙.md`으로 점검한다.
6. 완성 문서는 `프로젝트 위그드라실/데이터 창고/인물/`에 저장할 수 있는 형태로 출력한다.

## 저장 메타데이터

완성 문서는 기존 설정 메타데이터에 `series`를 추가한다. `type`은 `인물`, `subtype`은 `주연`, `조연`, `주변인물`, `단역` 중 하나다.
