# 7번 창작 지원의 능력 제작기 프롬프트 적용 안내

## 문서 상태

이 폴더는 소설·세계관·게임식 설정에 사용할 범용 능력 데이터를 제작하고 관리하는 정식 기능입니다.

현재 버전은 `1.0`입니다.

## 기능 목적

7번 창작 지원의 능력 제작기는 다음 대상을 하나의 공통 문법으로 설계합니다.

- 능력
- 기술
- 스킬
- 주문
- 무공
- 권능
- 초능력
- 패시브 능력
- 시스템형·지성형 능력
- 진화·파생·계승 능력

이 기능은 D&D 규칙 제작을 기본 목적으로 하지 않습니다. 명시적 요청 없이 피해 주사위, 행동 경제, 내성 DC와 레벨 진행을 추가하지 않습니다.

## 핵심 구조

```text
[층위/표현 권역:원천] - [작동 계통] - [발현 형태] -> [결과 효과]
```

구성 방식, 권한 성격과 계보 관계는 별도 축으로 관리합니다.

```text
구성 방식: 단일형 / 복합형 / 체계형
권한 성격: 일반형 / 권능형 / 시스템형
계보 관계: 독립형 / 파생형 / 진화형 / 계승형 / 융합형 / 분기형 / 퇴화형 / 봉인형
```

## 인접 기능과의 경계

- 특성·효과·로어 특성: 7번 창작 지원의 특성 제작기
- 개별 능력 전체 구조: 7번 창작 지원의 능력 제작기
- 클래스·직업·전직 구조: 7번 창작 지원의 클래스 제작기
- 세계관 전체의 능력 체계와 정본: 5번
- 종족 자체의 생리·문화·선천 구조: 공통 종족 데이터

패시브인지 액티브인지는 7번 창작 지원의 특성 제작기와 7번 창작 지원의 능력 제작기의 구분 기준이 아닙니다.

## 공용 태그

검색 태그는 `../../공통/라이브러리/공용 태그 사전.md`를 함께 사용합니다.

능력 전용 구조 필드의 값을 태그로 반복하지 않습니다.

## 적용 원칙

Google Drive에는 직접 생성하거나 덮어쓰지 않습니다.

수정본과 신규 문서는 사용자가 수동 적용할 수 있는 로컬 파일 또는 ZIP으로 제공합니다.

## 변경 이력

### 1.0

- 웹 소설 능력 템플릿의 핵심 구조를 TRPG 데이터 7번 창작 지원의 능력 제작기 기능으로 정규화했습니다.
- D&D 규칙 제작을 기본 목적에서 제외했습니다.
- 액티브·패시브를 모두 능력 데이터로 설계할 수 있도록 확정했습니다.
- 구성 방식·권한 성격·계보 관계를 서로 다른 축으로 분리했습니다.
- `계통` 명칭을 `작동 계통`으로 명확화했습니다.
- 지성형·시스템형 능력의 자동화·독립성·권한 범위 규칙을 추가했습니다.
- 능력 데이터, 템플릿과 인덱스 구조를 추가했습니다.
- 공통 설정·이미지 기능·클래스 제작기와의 경계를 확정했습니다.
