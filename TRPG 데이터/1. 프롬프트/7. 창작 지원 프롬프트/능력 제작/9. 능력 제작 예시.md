# 9. 능력 제작 예시 라이브러리

## 문서 역할

이 문서는 능력 구조와 출력 방식을 보여 주는 설계 예시다. 예시는 자동으로 세계관 정본이나 완성 능력 데이터로 간주하지 않는다.

## 1. 단일형 능력

# 화염창

## 기본 정보

- 한 줄 정의: 응축한 화염을 창 형태로 방출하여 지정한 대상을 관통하는 공격 능력.
- 구성 방식: 단일형
- 권한 성격: 일반형
- 계보 관계: 독립형
- 적용 세계: 공용

## 구조

- 대표 구조: `[물질층/마도형:화염] - [방출] - [투사체·창] -> [피해·관통]`
- 층위: 물질층
- 표현 권역: 마도형
- 원천: 화염 / 마력
- 작동 계통: 방출
- 발현 형태: 투사체 / 창
- 결과 효과: 피해 / 관통
- 대상: 단일 대상

## 운용

- 발동 방식: 즉발
- 지속 방식: 순간
- 비용: 마력
- 리스크: 없음
- 제약: 시야 필요
- 자동화 수준: 0단계
- 독립성: 도구형
- 권한 범위: 관측한 대상
- 태그: 화염 / 정밀 / 공격

## 설명

화염창은 열과 화염을 넓게 퍼뜨리는 대신 하나의 축으로 압축해 관통력을 높이는 능력이다. 사용자는 목표와 궤도를 직접 지정하며, 능력은 발사된 뒤 별도의 판단을 수행하지 않는다.

## 2. 상시형 생체 능력

# 초재생

## 기본 정보

- 한 줄 정의: 손상된 육체를 지속적으로 분석하고 본래 상태에 가깝게 복원하는 생체 능력.
- 구성 방식: 단일형
- 권한 성격: 일반형
- 계보 관계: 독립형

## 구조

- 대표 구조: `[생명층/생체형:세포·생명력] - [회복·재구성] - [신체변형·무형] -> [재생·안정화]`
- 층위: 생명층
- 표현 권역: 생체형
- 원천: 세포 / 생명력 / 대사 자원
- 작동 계통: 회복 / 재구성
- 발현 형태: 신체변형 / 무형
- 결과 효과: 재생 / 안정화
- 대상: 자신

## 운용

- 발동 방식: 상시 / 조건반응
- 지속 방식: 영구
- 비용: 대사 자원
- 리스크: 재생 한계 도달 / 세포 소모
- 제약: 완전히 소실된 정보는 복원 불가
- 자동화 수준: 3단계
- 독립성: 도구형
- 권한 범위: 자기 신체
- 태그: 재생 / 생체 / 상시

## 설명

초재생은 사용자가 매번 명령하지 않아도 신체 손상을 감지해 복구를 시작한다. 이 능력의 자동성은 지성에서 비롯된 것이 아니라 생체 반응에 가까우며, 육체의 원형 정보와 대사 자원이 남아 있는 범위에서 작동한다.

## 3. 복합 감각 능력

# 용안

## 기본 정보

- 한 줄 정의: 보이지 않는 힘과 허위를 간파하고 관측 대상을 분석하는 복합 시각 능력.
- 구성 방식: 복합형
- 권한 성격: 일반형
- 계보 관계: 계승형
- 하위 능력: 마력 시야 / 허위 간파 / 약점 분석

## 구조

- 대표 구조: `[정보층·정신층/초상형:시각·혈통] - [감지·해석] - [시선·투영] -> [가시화·탐지]`
- 층위: 정보층 / 정신층
- 표현 권역: 초상형
- 원천: 시각 / 혈통
- 작동 계통: 감지 / 해석
- 발현 형태: 시선 / 투영
- 결과 효과: 가시화 / 탐지
- 대상: 관측한 현상과 대상

## 운용

- 발동 방식: 상시 / 토글
- 지속 방식: 사용자 유지
- 비용: 집중력
- 리스크: 감각 과부하
- 제약: 시야 필요
- 자동화 수준: 2단계
- 독립성: 보조지성형이 아닌 감각 도구형
- 권한 범위: 관측한 현상
- 태그: 감각 / 분석 / 혈통

## 하위 능력

### 마력 시야

- 구조: `[정보층/초상형:마력 흔적] - [감지] - [시선] -> [가시화]`
- 역할: 마력과 능력의 흐름을 시각 정보로 변환한다.

### 허위 간파

- 구조: `[정신층·정보층/초상형:인식] - [해석] - [시선] -> [교란 해제]`
- 역할: 관측 정보의 모순과 인식 조작 흔적을 찾아낸다.

### 약점 분석

- 구조: `[정보층/초상형:관측 정보] - [해석] - [투영] -> [취약점 가시화]`
- 역할: 구조적 결함과 반복되는 행동 패턴을 분석한다.

## 4. 체계형 지성 능력

# 대현자

## 기본 정보

- 한 줄 정의: 사용자의 인식과 보유 능력을 분석하고 사고·학습·운용을 보조하는 내면 지성 체계.
- 구성 방식: 체계형
- 권한 성격: 시스템형
- 계보 관계: 독립형
- 하위 능력: 사고 가속 / 분석 감정 / 병렬 연산 / 능력 정리

## 구조

- 대표 구조: `[정보층·정신층/상징형:지식·기억] - [해석·재구성] - [무형·내면 인터페이스] -> [분석·최적화]`
- 층위: 정보층 / 정신층
- 표현 권역: 상징형
- 원천: 지식 / 기억 / 연산
- 작동 계통: 해석 / 재구성
- 발현 형태: 무형 / 내면 인터페이스
- 결과 효과: 분석 / 최적화
- 대상: 자기 정신 / 자기 보유 능력 / 인식 가능한 정보

## 운용

- 발동 방식: 상시 / 조건반응 / 명령 발동
- 지속 방식: 영구
- 비용: 정신력 / 연산 여유
- 리스크: 판단 의존 / 정보 편향
- 제약: 관측하거나 입력받은 정보만 분석 가능
- 자동화 수준: 2단계
- 독립성: 보조지성형
- 권한 범위: 자기 정신 / 자기 보유 능력 / 인식 가능한 정보
- 태그: 분석 / 지성형 / 시스템 / 보조

## 통합 규칙

- 사용자의 질문에 우선 반응한다.
- 위험 조건을 감지하면 경고를 제안한다.
- 하위 능력의 결과가 충돌하면 신뢰도가 높은 자료를 우선한다.
- 사용자 승인 없이 기억을 삭제하거나 능력 구조를 변경하지 않는다.

## 5. 능력과 특성의 병행 예시

```text
능력 제작기 데이터: 용안
- 전체 능력의 원천·구조·하위 기능·비용·리스크를 기록

특성 제작기 데이터: 마력 감지 / 허위 간파 / 약점 분석
- 인물이나 크리처에게 부착할 수 있는 짧은 기능 단위로 기록
```

두 데이터는 서로 대체하지 않는다.
