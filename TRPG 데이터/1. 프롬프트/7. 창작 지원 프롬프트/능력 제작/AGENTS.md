## 기능 경계와 연동

- 아이템 제작기, 특성 제작기, 능력 제작기, 클래스 제작기, 인물 제작기는 `미세단위 제작 기능`이다. 완성 능력은 `프로젝트 위그드라실/데이터 창고/능력/`에 두고 `series`로 시리즈 소속을 기록한다.

- 세계관 정본은 5번, 종족 생리·기관은 공통 종족 데이터를 참조한다.
- 짧고 재사용 가능한 특성은 7번 창작 지원의 특성 제작기, 클래스 구조는 7번 창작 지원의 클래스 제작기와 경계를 유지한다.
- 공용 태그는 `../../공통/라이브러리/공용 태그 사전.md`을 사용하며, 아이콘은 1번 이미지 생성 모듈 내부 7번, FVTT 구현은 6번으로 라우팅한다.
