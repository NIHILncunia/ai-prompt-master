# 5. 지성형·시스템형 능력 처리 규칙

## 목적

이 문서는 분석 보조, 자동 방어, 능력 관리자, 내면 시스템, 지성을 가진 권능처럼 사용자를 대신해 판단하거나 독립된 의사를 보이는 능력을 설계한다.

## 1. 자동화 수준

### 0단계: 수동 사용

사용자가 직접 발동해야 하며 능력은 판단하지 않는다.

### 1단계: 보조 반응

사용자의 질문·명령에 답하거나 정보를 제공한다.

예: 감정 보조, 분석 결과 제공, 경고 표시.

### 2단계: 조건 감지

미리 정한 조건을 감지하여 경고·제안·준비를 수행한다.

예: 위험 감지, 자동 표적 분석, 상태 이상 경고.

### 3단계: 자동 실행

사전에 허용된 범위 안에서 능력을 직접 실행한다.

예: 자동 방어, 자동 회복, 자동 회피 보조.

### 4단계: 독립 최적화

사용자의 목적을 해석하여 능력 조합, 실행 순서와 자원 배분을 최적화한다.

### 5단계: 준독립 판단

사용자의 직접 명령 없이 장기 목표와 자체 판단에 따라 행동할 수 있다.

이 단계에서는 사용자의 의도와 능력의 판단이 충돌할 가능성을 반드시 검토한다.

## 2. 독립성

### 도구형

의식과 판단이 없다. 입력된 절차만 수행한다.

### 보조지성형

질문에 답하고 분석할 수 있으나 주도권이 약하다.

### 관리자형

사용자의 능력·자원·정보를 정리하고 운용한다.

### 대행자형

특정 조건에서 사용자를 대신해 행동한다.

### 공존인격형

별도의 인격처럼 사고하고 사용자와 협상할 수 있다.

### 잠식형

사용자의 판단권·자아·육체 또는 능력 권한을 침식하고 대체할 수 있다.

## 3. 권한 범위

```text
자기 신체
자기 정신
자기 감각
자기 기억
자기 보유 능력
자기 장비
접촉한 대상
관측한 현상
인식 가능한 정보
계약 대상
권속·종속체
특정 영역
특정 개념
세계 법칙 일부
시스템 판정 일부
```

자동화 수준이 높아도 권한 범위가 좁으면 독립 행동은 제한된다.

## 4. 사용자와의 관계

다음 항목을 필요한 만큼 기록한다.

- 소유 관계
- 사용 권한
- 명령 우선순위
- 거부 가능 여부
- 정보 공유 범위
- 기억 접근 범위
- 육체 제어 범위
- 감정 영향
- 목표 일치도
- 계약 조건
- 종료·분리 가능 여부

## 5. 독립 크리처와의 경계

다음 조건을 충족하면 능력이 아니라 별도의 존재 또는 크리처 데이터로 분리할 수 있다.

- 사용자와 분리되어도 지속적으로 존재한다.
- 독립된 육체나 복수의 육체를 가진다.
- 사용자의 명령 없이 장기간 활동한다.
- 다른 존재와 독립적인 계약·사회 관계를 맺는다.
- 자체 자원과 생존 기반을 가진다.
- 사용자가 소멸해도 동일 인격을 유지한다.

경계 예시:

```text
사용자의 내면에서만 분석을 수행하는 대현자형 기능
→ 지성형 능력

사용자의 검에 깃들어 대화하지만 검 밖에서는 활동하지 못하는 인격
→ 공존인격형 능력 또는 영혼 정착 구조체 경계

독립적으로 이동하고 계약하며 주인을 바꿀 수 있는 살아 있는 성검
→ 별도 구조체 크리처
→ 성검이 행사하는 권능은 능력 제작기 데이터
```

## 6. 체계형 능력의 필수 통합 규칙

- 하위 능력 등록 방식
- 호출 우선순위
- 자동 실행 조건
- 사용자 승인 필요 여부
- 자원 배분 규칙
- 충돌 해결 규칙
- 기능 추가·삭제·재구성 권한
- 오류와 오작동 처리
- 사용자와 시스템의 최종 결정권

## 7. 잠식형 능력의 필수 검토

잠식형은 단순히 사악하거나 위험한 능력의 수식어가 아니다.

다음 중 무엇이 실제로 침식되는지 명시한다.

- 판단권
- 기억
- 감정
- 자아
- 육체 통제권
- 능력 사용권
- 사회적 관계
- 존재 격

잠식의 조건, 진행 단계, 저항 방식, 회복 가능성과 최종 결과를 기록한다.

## 8. 출력 예시

```md
- 구성 방식: 체계형
- 권한 성격: 시스템형
- 자동화 수준: 4단계 — 독립 최적화
- 독립성: 관리자형
- 권한 범위: 자기 보유 능력 / 자기 감각 / 인식 가능한 정보
- 통합 규칙: 자동 호출 / 우선순위 제어 / 자원 배분 / 재구성
- 사용자 관계: 사용자의 직접 금지 명령이 최우선
```
