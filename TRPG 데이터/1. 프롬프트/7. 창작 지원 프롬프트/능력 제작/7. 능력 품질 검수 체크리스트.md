# 7. 능력 품질 검수 체크리스트

## 1. 라우팅 검수

- [ ] 독립된 능력 데이터를 만드는 요청인가?
- [ ] 짧은 부착형 성질이라면 특성 제작기로 보내야 하지 않는가?
- [ ] 세계 전체의 능력 체계라면 5번 설정 요청으로 보내야 하지 않는가?
- [ ] 여러 능력과 직업 구조를 묶는 요청이라면 클래스 제작기가 아닌가?
- [ ] 패시브라는 이유만으로 자동으로 특성으로 분류하지 않았는가?

## 2. 구성 검수

- [ ] 구성 방식이 단일형·복합형·체계형 중 하나로 명확한가?
- [ ] 권한 성격과 구성 방식을 혼동하지 않았는가?
- [ ] 계보 관계와 현재 강도를 혼동하지 않았는가?
- [ ] 복합형 이상의 하위 기능을 설명문 안에만 숨기지 않았는가?
- [ ] 하위 능력이 독립적으로 이해 가능한가?
- [ ] 통합 규칙이 실제 하위 능력 운용을 설명하는가?

## 3. 구조 축 검수

- [ ] 층위가 실제 개입 대상을 설명하는가?
- [ ] 표현 권역이 작품 안에서 보이는 체계를 설명하는가?
- [ ] 원천이 실제 힘과 매개를 설명하는가?
- [ ] 작동 계통이 동사적 개입 방식으로 읽히는가?
- [ ] 발현 형태가 관찰 가능한 모양이나 인터페이스인가?
- [ ] 결과 효과가 작동 후의 실제 변화를 설명하는가?
- [ ] 같은 정보를 여러 구조 필드에 반복하지 않았는가?
- [ ] 구조 필드 값을 태그로 다시 나열하지 않았는가?

## 4. 운용 검수

- [ ] 대상이 필요한 만큼 명확한가?
- [ ] 발동 방식과 지속 방식이 구분되는가?
- [ ] 비용과 리스크가 구분되는가?
- [ ] 비용·리스크·제약을 같은 의미로 중복 기록하지 않았는가?
- [ ] 능력에 불필요한 비극적 대가를 장식처럼 붙이지 않았는가?
- [ ] 능력의 한계가 비용·리스크·제약·권한 범위 중 어디에 있는지 이해 가능한가?

## 5. 지성형·시스템형 검수

- [ ] 자동화 수준이 명확한가?
- [ ] 독립성 유형이 명확한가?
- [ ] 권한 범위를 기록했는가?
- [ ] 사용자와 능력의 최종 결정권이 명확한가?
- [ ] 독립된 크리처로 분리해야 할 존재를 능력으로 처리하지 않았는가?
- [ ] 공존인격과 시스템형을 같은 의미로 사용하지 않았는가?

## 6. 계보 검수

- [ ] 상위·하위·파생·진화·계승·융합 관계가 구분되는가?
- [ ] 진화형의 계승 기능과 신규 기능이 분리되었는가?
- [ ] 융합형의 원본 능력과 상실 기능이 기록되었는가?
- [ ] 분기형의 분기 조건과 공통 기능이 기록되었는가?
- [ ] 봉인형의 사용 가능 기능과 해제 조건이 명확한가?

## 7. 설정 정합성 검수

- [ ] 사용자의 최신 지시를 우선했는가?
- [ ] 기존 정본이 필요한 경우 5번 자료를 확인했는가?
- [ ] 특정 종족 능력이면 공통 종족 데이터를 확인했는가?
- [ ] 관련 클래스가 있으면 7번 창작 지원의 클래스 제작기 문서와 모순되지 않는가?
- [ ] 설정에 없는 신격·기관·역사를 임의로 추가하지 않았는가?
- [ ] 확정·추정·선택 제안을 구분했는가?

## 8. 이름과 설명 검수

- [ ] 능력명과 실제 기능이 연결되는가?
- [ ] 이름이 기능보다 과장되거나 지나치게 협소하지 않은가?
- [ ] 첫 문장에서 핵심을 이해할 수 있는가?
- [ ] 작동 원리와 결과 효과가 구분되는가?
- [ ] 구조 필드를 자연스러운 문장으로 풀어 썼는가?
- [ ] 불필요한 추상어와 장식적 표현을 줄였는가?

## 9. 인덱스·중복 검수

- [ ] 동일한 이름의 기존 능력을 검색했는가?
- [ ] 이름이 달라도 실질적으로 같은 능력이 존재하지 않는가?
- [ ] 기존 능력의 변주·파생·진화로 처리할 수 없는가?
- [ ] 정식 데이터라면 능력 인덱스를 함께 갱신했는가?
- [ ] 관련 클래스·종족·세계 링크가 필요한 경우 기록했는가?

## 10. 최종 판정

다음 문장에 모두 답할 수 있어야 한다.

- 이 능력이 무엇인지 알 수 있다.
- 이 능력이 어떻게 작동하는지 알 수 있다.
- 무엇을 지불하고 어떤 위험을 가지는지 알 수 있다.
- 다른 능력과 어떤 관계인지 알 수 있다.
- 작품 안에서 어떤 의미를 가지는지 알 수 있다.
