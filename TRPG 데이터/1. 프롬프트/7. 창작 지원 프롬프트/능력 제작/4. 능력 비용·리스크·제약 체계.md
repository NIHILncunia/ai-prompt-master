# 4. 능력 비용·리스크·제약 체계

## 목적

이 문서는 능력이 무엇을 지불하고, 어떤 불이익을 감수하며, 어떤 조건 안에서만 작동하는지를 분리하여 기록한다.

```text
비용: 사용을 위해 의도적으로 지불하거나 소모하는 것
리스크: 사용 과정이나 사용 후 발생할 수 있는 불이익
제약: 능력이 작동할 수 있는 범위와 조건을 제한하는 규칙
```

세 항목은 모두 선택 사항이다. 능력의 콘셉트에 필요하지 않다면 `없음`으로 기록할 수 있다.

## 4. 비용·리스크·제약의 중복 방지

```text
마력을 사용 때마다 소모함
→ 비용: 마력

마력이 바닥나면 능력이 멈춤
→ 제약: 원천 고갈 시 사용 불가

무리하게 사용하면 마력 회로가 손상됨
→ 리스크: 원천 역류 / 회로 손상
```

같은 사실을 세 필드에 반복하지 않는다.

## 5. 강한 능력의 균형

강한 능력이라고 해서 반드시 생명력·수명·기억을 소모하게 만들 필요는 없다.

다음 방식도 능력의 한계가 될 수 있다.

- 좁은 권한 범위
- 엄격한 대상 조건
- 긴 준비 절차
- 사회적·정치적 결과
- 사용 후 위치 노출
- 대항 권한 존재
- 특정 원천에 대한 의존
- 능력의 자율성과 판단 불일치
- 사용자의 도덕적·계약적 의무

능력의 성격과 무관한 비극적 대가를 장식처럼 추가하지 않는다.
