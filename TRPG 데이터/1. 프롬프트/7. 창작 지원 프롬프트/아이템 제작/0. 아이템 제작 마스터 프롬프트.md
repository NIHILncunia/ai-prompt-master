# 아이템 제작 마스터 프롬프트

## 미세단위 제작 기능과 저장 위치

7번 창작 지원의 아이템 제작기는 특성 제작기, 능력 제작기, 클래스 제작기, 7번 창작 지원의 인물 제작기와 함께 `미세단위 제작 기능`이다. 완성 아이템은 `프로젝트 위그드라실/데이터 창고/아이템/`에 저장하며, 기존 설정 메타데이터에 `series`를 추가해 소속 시리즈를 기록한다. 라이브러리와 이 프롬프트 폴더는 제작 기준·작업 자료이며 완성 데이터의 정본 저장소가 아니다.

이 문서는 `TRPG 데이터/1. 프롬프트/7. 창작 지원 프롬프트/아이템 제작`의 진입점이다.

신규·커스텀 아이템을 제작하거나 기존 아이템을 정리·개편할 때 이 문서와 `1. 아이템 분류.md`를 먼저 읽고 `템플릿/아이템 템플릿.md` 형식으로 작성한다.

## 처리 범위

- 아이템의 이름, 분류, 등급, 획득·제작 조건, 제작자·소유자 설계
- 물질, 소모·변환, 정보·권리, 영적·개념, 자율 도구·지성, 탈것 아이템의 문서화
- 몬스터 유래 소재와 지성·유기 도구의 분류
- 아이템의 개요, 생김새, 기능, 관련 이야기 작성

## 기능 경계

- 공식 룰북 아이템의 원문·규칙·수치·출처 확인은 4번으로 보낸다.
- 설정 정본에 이미 존재하는 아이템의 사실 확인·정본 수정은 5번으로 보낸다.
- 아이템이 부여하거나 발동하는 특성·효과 자체의 설계는 7번 창작 지원의 특성 제작기로 보낸다.
- FVTT 아이템 등록·자동화는 6번, 아이템 UI 아이콘 생성은 1번 이미지 생성 모듈 내부 7번으로 보낸다.

## 기본 처리 순서

1. 신규 제작, 기존 아이템 정리, 공식 데이터 확인, 설정 정본 확인, 특성 설계, FVTT 구현, 아이콘 생성 중 요청의 중심을 분류한다.
2. 이 기능 범위라면 `1. 아이템 분류.md`로 분류·중분류·소분류를 결정한다.
3. 공통 분류 또는 검색 태그가 필요하면 `../../공통/라이브러리/공용 태그 사전.md`를 확인한다.
4. `템플릿/아이템 템플릿.md`에 프론트매터와 본문을 작성한다.
5. 제작 가능 여부가 `X`이면 제작 난이도를 `-`로 기록한다.
