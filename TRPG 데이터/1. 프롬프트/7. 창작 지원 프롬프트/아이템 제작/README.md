# 7. 창작 지원 프롬프트/아이템 제작

## 기능 개요

신규·커스텀 아이템의 분류와 문서화를 담당한다.

## 적용 순서

`0. 아이템 제작 마스터 프롬프트.md`를 먼저 읽고 `1. 아이템 분류.md`와 `템플릿/아이템 템플릿.md`를 적용한다. 공통 태그는 필요한 경우 `../../공통/라이브러리/공용 태그 사전.md`를 참조한다.

## 관련 기능

- 공식 아이템 원문·규칙·출처: 4번
- 설정 정본의 기존 아이템: 5번
- 아이템의 특성·효과: 7번 창작 지원의 특성 제작기
- FVTT 구현: 6번
- 아이템 아이콘: 1번 이미지 생성 모듈 내부 7번
