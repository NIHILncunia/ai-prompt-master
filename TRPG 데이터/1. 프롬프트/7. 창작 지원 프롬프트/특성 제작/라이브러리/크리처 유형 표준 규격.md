# 7. 크리처 유형 표준 규격

## 목적

이 문서는 평범한 인간부터 자연 생물, 신화적 존재, 외계 생명, 기계 생명, 인공 생명, 생체병기, 자율 병기, 영체와 군체 의식까지 모든 창작 존재를 일관된 방식으로 설명하기 위한 크리처 유형 규격이다.

크리처 유형은 특성 제작의 기반 자료다. 대상의 기원, 육체, 생태, 존재 기반과 사회적 위치를 먼저 파악하면 그 대상에게 필요한 기원·신체·감각·이동·전투·방어·자원·약점 특성을 중복 없이 설계할 수 있다.

## 분류 대상

다음 중 하나 이상을 충족하면 크리처 분류 대상으로 볼 수 있다.

- 독립적인 판단이나 행동이 가능하다.
- 자아·의식·본능·프로그램에 따라 하나의 행위 주체로 움직인다.
- 독립적인 생명 활동이나 자기 유지 체계를 가진다.
- 스탯블록 또는 캐릭터 정보로 표현할 수 있다.

조종자가 없으면 아무 행동도 하지 못하는 일반 무기·차량·건축물은 크리처가 아니다. 자율 판단하는 전차, 지성을 가진 검, 살아 있는 성채와 독립 인공지능은 구조체 크리처가 될 수 있다.

## 분류 축

- 유형 대분류: 현재 존재의 가장 핵심적인 본질. 원칙적으로 하나만 지정한다.
- 기원 중분류: 무엇으로부터 유래했거나 어떤 계통에서 태어났는가.
- 발생 방식: 출생, 제작, 감염, 승천, 사령화처럼 현재 상태에 도달한 과정.
- 외형 태그: 현재 어떤 신체 구조와 형태를 가졌는가.
- 존재 기반 태그: 무엇으로 생명과 활동을 유지하는가.
- 지성 구조 태그: 자아와 의식이 어떤 방식으로 존재하는가.
- 사회성·역할 태그: 어떤 공동체와 역할을 가지는가.
- 성질·위상 태그: 속성, 능력, 성장 단계와 위협 규모.

역할은 기원이 아니다. `수호자`, `병기`, `상인`, `심판자`와 같은 정보는 중분류로 만들지 않고 공용 태그로 기록한다.

## 상위 유형 판정 원칙

- 상위 유형은 원칙적으로 하나만 지정한다.
- 과거의 출신보다 현재 존재를 유지하는 본질을 우선한다.
- 외형이 닮았다는 이유만으로 같은 유형으로 분류하지 않는다.
- 직업, 역할, 도덕성, 크기와 강함은 상위 유형을 결정하지 않는다.
- 일시적인 변신과 강화는 원래 유형을 유지한다.
- 영구적인 변질로 존재 기반 자체가 바뀌었다면 현재 유형을 변경할 수 있다.

# 15개 유형 대분류

## 1. 이형체

이형체는 현재 세계의 정상적인 생명·정신·현실 법칙으로 완전히 설명하기 어려운 이질적 존재다.

### 기원 중분류

- 외계 법칙계: [설명] 현재 세계와 다른 생명·물리 법칙 아래에서 발생하여 존재 방식 자체가 이질적인 계통 [예시: 우주에서 온 색채 — H. P. 러브크래프트 《우주에서 온 색채》 / 미고 — H. P. 러브크래프트 《어둠 속의 속삭임》]
- 이차원 토착계: [설명] 다른 차원이나 현실층의 생태에서 자연적으로 태어난 존재 [예시: 마인드 플레이어 — D&D 5e 《Monster Manual》 / 아미그달라 — 블러드본]
- 심상 구현계: [설명] 꿈, 공포, 기억이나 집단 무의식이 실체를 얻어 발생한 존재 [예시: 피라미드 헤드 — 사일런트 힐 2, 유사 사례]
- 기생 생명계: [설명] 다른 생명체의 정신 또는 육체를 숙주로 삼아 성장하고 활동하는 이질 생명 [예시: 페이스허거 — 영화 《에이리언》 / 헤드크랩 — 하프라이프]
- 감염·동화계: [설명] 다른 생물을 감염·변이시키거나 자신의 생명 구조로 동화하며 증식하는 계통 [예시: 플러드 — 헤일로 시리즈 / 네크로모프 — 데드 스페이스]
- 집단지성계: [설명] 여러 육체가 하나의 초월 의식이나 중앙 정신에 종속되는 계통 [예시: 그레이브마인드 — 헤일로 2 / 오버마인드 — 스타크래프트]
- 인공 이형계: [설명] 실험이나 인공 조작으로 만들어졌지만 정상적인 생물·구조체 분류로 설명하기 어려운 존재 [예시: 타이라ント — 바이오하자드, 괴수와의 경계 사례]

### 주요 외형 태그

인간형 / 야수형 / 기생체형 / 촉수형 / 다기관형 / 무정형 / 기하학형 / 군체형 / 거대형

### 주요 존재 기반 태그

이질 생물 / 정신 생명 / 정보 생명 / 차원 에너지 / 숙주 의존 / 분산 의식

### 경계 원칙

다른 행성에서 왔다는 사실만으로 이형체가 되지는 않는다. 정상적인 생물학과 문명을 가진 외계 종족은 인간형이나 야수로 분류할 수 있다.

## 2. 야수

야수는 자연적인 생물 계통과 생태 활동을 중심으로 살아가는 비인공 생명체다.

### 기원 중분류

- 자연 생태계: [설명] 일반적인 번식과 생태 순환을 통해 유지되는 자연 생물 [예시: 다이어 울프 — D&D 5e 《Monster Manual》 / 자이언트 이글 — D&D 5e 《Monster Manual》]
- 고대 생존계: [설명] 멸종 생물이나 원시 생물 계통이 현재까지 살아남은 존재 [예시: 티라노사우루스 — D&D 5e 《Monster Manual》 / 매머드 — D&D 5e 《Monster Manual》]
- 외계 생태계: [설명] 다른 행성에서 자연적으로 진화하여 독립적인 생태를 이루는 동물 [예시: 반타 — 스타워즈 / 톤톤 — 영화 《스타워즈: 제국의 역습》]
- 마력 생태계: [설명] 마력이 자연환경의 일부인 세계에서 정상적인 생물 종으로 진화한 존재 [예시: 파오우르무 — 몬스터 헌터: 월드, 유사 사례]
- 인공 육종 정착계: [설명] 인공적으로 육종되었으나 이후 독립적인 번식과 자연 생태를 형성한 계통 [예시: 인도미누스 렉스 — 영화 《쥬라기 월드》, 독립 종 정착 전의 경계 사례]

### 주요 외형 태그

포유류 / 조류 / 파충류 / 양서류 / 어류 / 곤충류 / 갑각류 / 협각류 / 다족류 / 연체류 / 기타 무척추류

### 주요 존재 기반 태그

자연 생물 / 마력 생물 / 군체 생물 / 기생 생물 / 공생 생물

### 경계 원칙

지능이 높거나 말을 할 수 있어도 자연 생태가 본질이면 야수로 남을 수 있다. 사람형·수인형 신체와 언어·사회·세대 계승이 종족 정체성의 중심이라면 인간형을 검토한다.

## 3. 천상체

천상체는 천상 세계, 신성한 힘, 신격 또는 천상의 질서와 연결된 본질을 지닌 존재다.

### 기원 중분류

- 천사계: [설명] 신격이나 천상의 질서를 수행하도록 창조되거나 태어난 인격적 천상체 [예시: 솔라 — D&D 5e 《Monster Manual》 / 플래니터 — D&D 5e 《Monster Manual》 / 티리엘 — 디아블로 시리즈]
- 천상 태생계: [설명] 천상 세계의 생태와 문명 안에서 태어날 때부터 천상체였던 토착 주민. 천사나 신격의 분신이 아니라 가족·공동체·직업과 문명을 이루는 일반 천상 생명도 포함한다 [예시: 아자타 — Pathfinder Roleplaying Game 《Bestiary》]
- 신성 야수계: [설명] 동물 또는 환상 생물의 신체 계통과 천상적 본질을 함께 지닌 존재 [예시: 코아틀 — D&D 5e 《Monster Manual》 / 유니콘 — D&D 5e 《Monster Manual》]
- 신격 분신계: [설명] 신격의 의지나 권능 일부가 독립된 육체와 인격을 얻은 존재 [예시: 티아마트의 아바타 — D&D 5e 《Fizban's Treasury of Dragons》]
- 천체 발생계: [설명] 태양, 달, 별과 성좌의 힘에서 발생하거나 천체의 본질이 생명을 얻은 존재 [예시: 솔가레오 — 포켓몬스터 썬·문, 유사 사례 / 루나아라 — 포켓몬스터 썬·문, 유사 사례]
- 신앙 발생계: [설명] 집단의 신앙, 기도와 종교적 관념이 응집되어 탄생한 존재 [예시: 프라이멀 — 파이널 판타지 XIV, 유사 사례]
- 승천자계: [설명] 필멸자나 다른 생명체가 신성한 변화와 승천을 거쳐 천상체가 된 계통
- 인공 천상계: [설명] 신격이나 천상 문명이 신성한 기술과 의식으로 제작한 천상체]
- 타락 천상계: [설명] 천상적 본질을 유지하지만 원래의 질서와 신격의 사명에서 이탈한 존재 [예시: 자리엘 — D&D 5e 《Mordenkainen's Tome of Foes》 / 이주알 — 디아블로 시리즈]

### 주요 외형 태그

인간형 / 유익 인간형 / 야수형 / 조류형 / 장신형 / 다수족형 / 영체형 / 기하학형 / 물체형 / 군체형 / 거대형

### 주요 존재 기반 태그

신성 생물 / 천상 생태 / 신성 영혼 / 신앙 에너지 / 천체 에너지 / 신격 권능

### 경계 원칙

전투·수호·심판·인도·치유는 역할 태그다. 천상 세계에 이주해 산다는 이유만으로 다른 유형의 존재가 천상체로 바뀌지는 않는다.

## 4. 구조체

구조체는 제작, 조립, 설계, 프로그램, 인공 핵, 영혼 정착 또는 기계적 증식을 통해 존재하는 인공적·기계적 생명과 자율 행위자다.

### 기원 중분류

- 기계 생명계: [설명] 처음부터 기계적 육체와 생명 구조를 가진 종족. 독자적인 세대·공동체·문명을 형성할 수 있다 [예시: 사이버트로니안 — 트랜스포머 / 머신 라이프폼 — 니어: 오토마타]
- 인공 인격계: [설명] 자아, 감정과 학습 능력을 갖도록 개별 제작된 기계 인격 [예시: X — 록맨 X 시리즈 / 2B — 니어: 오토마타 / 월-E — 영화 《월-E》]
- 기능성 로봇계: [설명] 노동, 경비, 전투와 정찰 같은 기능을 수행하도록 제작된 자율 기계 [예시: 배틀 드로이드 — 스타워즈 / 프로텍트론 — 폴아웃 시리즈]
- 마도기계계: [설명] 기계 구조와 마법 회로 또는 마력 동력이 결합한 존재 [예시: 드웨머 센추리온 — 엘더스크롤 V: 스카이림 / 아케인 골렘 — 월드 오브 워크래프트]
- 재료 조형계: [설명] 돌, 금속, 점토와 목재 같은 재료를 빚거나 조립한 뒤 인공 동력을 부여한 존재 [예시: 돌 골렘 — D&D 5e 《Monster Manual》 / 철 골렘 — D&D 5e 《Monster Manual》]
- 자동인형계: [설명] 인간이나 동물의 관절 구조를 모방한 인형형 육체에 동력과 행동 체계를 부여한 존재 [예시: 마리오네트 솔저 — 엘든 링]
- 생체기계계: [설명] 생물 조직과 기계 장치가 처음부터 하나의 인공 육체로 설계된 존재 [예시: 에반게리온 — 《신세기 에반게리온》, 유사 사례]
- 영혼 정착계: [설명] 영혼이나 정신이 인공 육체, 갑주 또는 기계에 정착해 활동하는 존재 [예시: 알폰스 엘릭 — 《강철의 연금술사》]
- 복제 인격계: [설명] 기존 인물의 기억·성격·행동 또는 전투 데이터를 복제해 제작한 존재 [예시: 메탈 소닉 — 소닉 더 헤지혹 시리즈]

- 군체 기계계: [설명] 수많은 소형 기계나 나노머신이 하나의 의식과 생명 단위를 이루는 계통 [예시: 리플리케이터 — 스타게이트]

## 5. 천룡종

천룡종은 태어날 때부터 용의 본질과 자체적인 신성을 지닌 진정한 드래곤 계통이다. D&D의 `Dragon` 유형은 룩스테라에서 천룡종에 대응한다.

### 기원 중분류

- 원초 천룡계: [설명] 특정 외부 속성보다 순수한 용의 본질과 혈통이 중심인 천룡 [예시: 레드 드래곤 — D&D 5e 《Monster Manual》 / 알두인 — 엘더스크롤 V: 스카이림]
- 원소 천룡계: [설명] 용의 본질과 특정 원소가 혈통 단계에서 결합한 천룡 [예시: 블루 드래곤 — D&D 5e 《Monster Manual》 / 화이트 드래곤 — D&D 5e 《Monster Manual》]
- 정신 천룡계: [설명] 정신, 의식과 초능력이 혈통적 본질에 결합한 천룡 [예시: 에메랄드 드래곤 — D&D 5e 《Fizban's Treasury of Dragons》]
- 천체 천룡계: [설명] 태양, 달, 별과 우주적 에너지가 용의 본질에 결합한 계통 [예시: 아스트랄 드래곤 — D&D 5e 《Spelljammer: Adventures in Space》]

- 혼합 혈통계: [설명] 복수의 천룡 혈통이나 본질이 안정적으로 결합한 계통]

사족유익형 / 이족유익형 / 무익 육상형 / 장신형 / 수생형 / 등갑형 / 다두형 / 다익형 / 다수족형 / 영체형

### 주요 존재 기반 태그

용의 신성 / 생물학적 육체 / 원소 기관 / 천체 에너지 / 차원 에너지

### 경계 원칙

천룡종은 용종의 상위 단계가 아니다. 용종이 아무리 오래 성장해도 천룡종으로 바뀌지 않는다. 용의 혈통을 가진 사람형 종족은 인간형의 용혈계다.

## 6. 정령

정령은 원소, 자연현상, 지형, 물질과 생명력의 흐름이 의식과 형상을 얻은 존재다.

원소 공격을 사용한다는 이유만으로 정령이 되지는 않는다. 원소나 자연현상 자체가 존재 본질일 때 정령으로 분류한다.

## 8. 악마

악마는 지옥, 심연, 마계, 죄악, 욕망, 타락과 영혼 변질을 존재 기반으로 삼는 존재다.

## 9. 거인

용종은 천룡종이 아닌 생물이 용성 또는 동등한 용의 힘에 적응하여 안정된 종과 생태를 이룬 존재다.

# 공통 경계 판정

## 구조체와 사이보그

- 기계로 태어나거나 제작되어 기계 구조가 존재의 본질이면 구조체다.
- 생물학적 존재가 기계를 이식받은 경우 원래 유형을 유지한다.
- 생물학적 두뇌나 영혼이 원래 인격의 연속성을 유지하면 원래 유형을 우선한다.
- 기억과 성격만 복제한 별도의 기계는 구조체다.
- 완전한 정신 업로드는 세계관의 인격 연속성 기준에 따라 판정하되 기본값은 구조체다.

## 구조체와 인공 생물

- 기계·인공 재료·동력핵·프로그램이 본질이면 구조체다.
- 완전히 생물학적인 육체와 생명 활동이 본질이면 인간형·야수·괴수 등을 사용한다.
- 생물학적 인공 인간은 인간형이 될 수 있다.
- 생체병기는 살아 있는 생물성이 중심이면 괴수, 인공 설계체가 중심이면 구조체다.

## 언데드와 영혼 정착 구조체

- 죽음과 사령 에너지가 현재 존재를 유지하면 언데드다.
- 영혼이 사령적 성질 없이 인공 육체의 인격과 동력으로 사용되면 구조체다.
- 인공 육체가 파괴되어도 영혼이 언데드로 계속 존재하면 언데드를 우선한다.

## 야수와 인간형

- 동물 생태와 본능이 중심이면 야수다.
- 사람형·수인형 신체, 언어, 사회와 세대 계승이 종족의 본질이면 인간형이다.
- 지능 하나만으로 유형이 바뀌지는 않는다.

## 괴수와 야수

- 자연 생태의 정상적인 종이면 야수다.
- 합성, 저주, 오염, 초자연적 변이와 생체병기성이 핵심이면 괴수다.
- 단순히 강하거나 거대하다는 이유만으로 괴수가 되지는 않는다.

## 천룡종과 용종

- 태어날 때부터 용의 본질과 신성을 지닌 드래곤은 천룡종이다.
- 다른 생물이 용성에 적응하여 형질과 생태가 변한 경우 용종이다.
- 용의 혈통을 가진 인간형 종족은 인간형의 용혈계다.
- 용과 닮은 기계는 구조체다.
- 용의 시체가 되살아난 존재는 언데드다.
