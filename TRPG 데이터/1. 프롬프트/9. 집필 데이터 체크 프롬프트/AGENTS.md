# 9. 집필 데이터 체크 프롬프트 작업 지침

## 역할

이 기능은 마스터의 집필 원문을 수집하고 문체를 재현 가능한 기준으로 정리한다. 생성형 집필 대행이나 첨삭 기능이 아니라, 과제 발급·원문 보관·문체 분석을 담당하는 독립 기능이다.

## 정본과 필수 읽기 순서

1. `TRPG 데이터/PROJECT AGENTS.md`
2. `TRPG 데이터/AGENTS.md`
3. `TRPG 데이터/1. 프롬프트/AGENTS.md`
4. 이 `AGENTS.md`
5. `README.md`
6. `0. 집필 데이터 체크 마스터 프롬프트.md`
7. 요청 유형에 따른 세부 지침
8. `TRPG 데이터/19. 집필 데이터/0. 집필 데이터 운영 지침.md`
9. 필요한 장르·주제·장면 소재 데이터베이스와 과제 이력·문체 프로필

## 직접 호출어

| 호출 | 처리 |
| --- | --- |
| `집필 데이터 체크.` | 기능과 절차를 설명하고 시작 여부를 확인한다. |
| `집필 데이터 체크 소설.` | 장르 1개와 주제 1개로 된 소설 과제를 발급한다. |
| `집필 데이터 체크 장면 묘사.` | 한 장면 묘사 과제를 발급한다. |
| `집필 데이터 제출.` | 현재 발급 과제에 대한 원문을 보관하고 문체 프로필을 갱신한다. |
| `문체 프로필.` | 현재 누적 문체 프로필을 조회한다. |

## 기능 경계

- 원문을 작성하거나 첨삭·윤문·평가·요약하지 않는다.
- 소설 과제에는 장르와 주제 외의 줄거리, 등장인물, 시점, 문체 조건을 덧붙이지 않는다.
- 장면 묘사 과제에는 내부 선택 태그나 설계 과정을 노출하지 않는다.
- 룩스테라가 선택된 장면은 현재 설정 정본으로 확인 가능한 사실만 사용한다.
- 원문·과제 이력·프로필 같은 지속 데이터는 생성·수정 직후 19번 데이터 정본에 Drive 반영한다.

## 관련 기능

- 5번 설정 관련 요청: 룩스테라 장면의 사실 근거가 필요할 때만 참조한다.
- 7번 창작 지원: 설정·인물·능력 데이터를 만드는 기능으로, 집필 원문 보관과 혼용하지 않는다.
- 9번의 문체 프로필은 이후 마스터가 요청한 창작 작업에서 문체 적용 기준으로만 제공한다.
