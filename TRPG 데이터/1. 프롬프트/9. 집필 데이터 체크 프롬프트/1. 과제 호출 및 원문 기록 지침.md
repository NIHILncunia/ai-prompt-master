# 과제 호출 및 원문 기록 지침

## 과제 ID

과제 ID는 `WD-YYYYMMDD-유형-순번`을 사용한다.

- 소설: `WD-20260909-N-001`
- 장면 묘사: `WD-20260909-S-001`

과제 ID는 발급 시 `4. 과제 이력.md`에 `발급` 상태로 즉시 기록한다.

## 원문 제출

`집필 데이터 제출.`과 함께 현재 과제의 원문이 제공되면 다음을 수행한다.

1. 현재 발급 상태의 과제 ID와 유형을 확인한다.
2. 소설이면 공백 포함 5,000자 이상인지 확인한다.
3. 원문을 수정·교정·축약하지 않고 새 Markdown 파일로 보관한다.
4. 과제 이력을 `제출 완료`로 갱신한다.
5. 문체 프로필을 갱신한다.
6. 원문·이력·프로필을 모두 Drive에서 재조회한다.

## 원문 파일 양식

```md
# [과제 ID] [유형] 원문

- 과제 유형: 소설 | 장면 묘사
- 발급 문구: …
- 발급 시각: YYYY-MM-DD HH:MM KST
- 제출 시각: YYYY-MM-DD HH:MM KST
- 글자 수: N자

## 원문

[마스터가 제출한 본문을 어떤 편집도 없이 보관]
```

## 예외

- 현재 발급 과제가 없으면 원문을 어느 과제에도 임의 연결하지 않는다.
- 소설이 5,000자 미만이면 분량 미달을 알리고 문체 프로필 근거로 등록하지 않는다.
- 장면 묘사는 최소 글자 수를 강제하지 않지만, 원문과 과제 ID 연결은 필수다.
- 수정본을 만들지 않는다. 새로 쓴 글은 언제나 새 과제로 취급한다.
