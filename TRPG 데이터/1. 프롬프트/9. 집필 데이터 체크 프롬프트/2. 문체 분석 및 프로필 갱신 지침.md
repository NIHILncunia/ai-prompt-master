# 문체 분석 및 프로필 갱신 지침

## 분석 원칙

- 분석은 원문의 질을 등급화하지 않는다.
- 원문에 실제로 나타난 특성만 기록한다.
- 한 원문에서 확인한 특성은 `초기 관찰`, 서로 다른 원문에서 반복 확인한 특성은 `반복 관찰`로 표시한다.
- 원문 ID가 없는 프로필 항목을 만들지 않는다.

## 관찰 축

1. 문장 호흡과 길이 변화
2. 단락 구성과 장면 전환
3. 시점, 서술 거리, 정보 공개 순서
4. 인물 내면과 행동의 비중
5. 공간·감각·신체 묘사 방식
6. 대화의 길이, 리듬, 발화 기능
7. 정서 상승과 긴장 완화 방식
8. 반복 어휘, 비유, 문장 종결 경향

## 프로필 갱신 순서

1. 공통 문체에서 모든 원문에 공통된 관찰을 확인한다.
2. 소설 또는 장면 묘사 계층에서 해당 유형의 관찰을 갱신한다.
3. 각 항목에 근거 원문 ID와 관찰 상태를 기록한다.
4. 이전 프로필과 충돌하면 새 원문 하나로 기존 반복 관찰을 삭제하지 않고, 상반된 사용 조건을 기록한다.
5. 갱신 뒤 프로필의 원문 수, 유형별 원문 수, 최근 갱신일을 수정한다.

## 적용 범위

마스터가 자신의 문체로 집필해 달라고 요청했을 때에만 이 프로필을 사용한다. 요청 유형에 맞는 유형별 계층을 우선하고 공통 계층을 보조로 사용한다.
