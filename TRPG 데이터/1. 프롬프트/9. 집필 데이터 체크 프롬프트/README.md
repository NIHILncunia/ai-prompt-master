# 집필 데이터 체크

마스터의 집필 원문을 과제 단위로 축적하고, 매 제출의 문체 분석을 이후 집필 지원에 재사용하기 위한 9번 독립 기능이다.

## 시작 명령

- `집필 데이터 체크.`
- `집필 데이터 체크 소설.`
- `집필 데이터 체크 장면 묘사.`
- `집필 데이터 제출.`
- `문체 프로필.`

새 흐름의 첫 응답은 소설 과제·장면 묘사 과제, 원문 기록, 문체 프로필 갱신 절차를 먼저 안내하고 시작 여부를 묻는다.

## 핵심 계약

- 소설 과제는 장르와 주제만 제시하며, 제출 원문은 최소 5,000자다.
- 장면 묘사 과제는 간결한 장면만 제시한다. 룩스테라 여부는 50:50 무작위로 정한다.
- 제출 원문은 수정·교정·재작성하지 않고 그대로 보관한다.
- 매 제출마다 문체 분석을 수행해 공통·소설·장면 묘사 프로필을 갱신한다.
- 기존 과제의 교정본을 만들지 않는다. 다음 집필은 새 과제로 발급한다.
