# 과제 데이터베이스 선택 지침

## 데이터베이스 우선순위

1. `1. 장르 데이터베이스.md`
2. `2. 주제 데이터베이스.md`
3. `3. 장면 소재 데이터베이스.md`
4. `4. 과제 이력.md`

## 소설 과제 선택

- `상태: 활성`인 장르와 주제만 후보로 사용한다.
- 동일 장르·주제 조합은 후보가 소진되기 전 재발급하지 않는다.
- 최근 5개 과제에 사용한 핵심 장르 및 주제 축은 우선순위를 낮춘다.
- 장르와 주제의 적용 가능 장르가 명백히 충돌하면 다른 후보를 선택한다.

## 장면 묘사 선택

- 범용과 룩스테라 범위를 균등 확률로 선택한다.
- 룩스테라 선택 시 현재 설정 정본에서 확인 가능한 지역·세력·인물·사건 요소만 사용한다.
- 필요한 설정 근거가 없으면 같은 범위 안에서 근거 가능한 다른 장면 소재를 재선택한다.
- 최근 5개 장면과 같은 공간 축·관계 축·갈등 축이 반복되면 우선순위를 낮춘다.

## 노출 규칙

과제를 받을 때 마스터에게 내부 ID, 원본 키워드, 선택 가중치, 제외 사유, 조합 과정을 노출하지 않는다.
