# 3. NPC 설계 지침

## 역할

이 문서는 세션에서 사용할 NPC를 빠르게 이해하고 연기하며, 이후 포트레이트 제작에 활용할 수 있도록 설계하는 규칙을 정의한다.

NPC는 세션 진행을 고정하는 장치가 아니라 목적과 가치에 따라 반응하는 인물로 작성한다.

## NPC 분류

### 주요 NPC

사건의 핵심 갈등, 정보, 관계, 선택, 결말에 직접 영향을 주는 인물이다.

### 조우 NPC

특정 장면이나 조우에서 중요한 역할을 맡는 인물이다.

### 단역 NPC

분위기, 현장감, 간단한 정보, 짧은 갈등을 제공한다.

단역에게 주요 NPC와 같은 분량을 강제하지 않는다.

## 스탯블록 정책

NPC는 필요에 따라 `스탯블록 불필요 / 기존 스탯블록 재사용 / 전용 스탯블록 제작`으로 분류한다.

일반 경비, 병사, 사제, 상인, 용병, 주민처럼 고유 전투 능력이 핵심이 아닌 NPC는 역할에 맞는 기존 NPC용 스탯블록을 우선 검토한다. 기존 스탯을 사용하면 스탯블록명과 출처를 기록한다.

사용자가 중요하다고 강조한 NPC, 고유한 전투 능력이 필요한 NPC, 이야기상 특별한 힘이 중요한 NPC는 자동으로 일반 스탯에 치환하지 않는다. 전용 스탯블록이 필요한지 사용자에게 확인하고, 전용 제작 시 원하는 전투·운용 컨셉을 한 결정 단위씩 묻는다. 이미 제공된 컨셉은 다시 묻지 않는다.

실제 스탯 수치와 형식은 4번 룰북 기능의 자료를 확인한다. 별도의 `[NPC명] 스탯블록.md` 파일은 만들지 않는다. 스탯블록이 필요한 경우 `NPC 및 몬스터/[NPC명].md`에서 기본 정보, 외형·장비, 마스터용 묘사 다음에 `스탯블록 정책`과 `스탯블록`을 두고 같은 파일 안에 기록한다. 기존 스탯블록을 재사용하는 경우에도 같은 위치에 스탯블록명, 출처, 사용 방침을 기록한다.


## 통합 NPC 파일 원칙

세션 자산용 NPC 상세 파일은 `NPC 및 몬스터/[NPC명].md` 하나를 정본으로 사용한다.

파일의 권장 순서는 다음과 같다.

```markdown
# NPC명

## 기본 정보
## 외형 및 장비
## 마스터용 묘사
## 스탯블록 정책
## 스탯블록
## 성격과 행동 원리
## 등장 관계
## 이미지 및 토큰
```

- `스탯블록 불필요`라면 `## 스탯블록 정책`에 그 이유를 기록하고 `## 스탯블록`은 생략할 수 있다.
- `기존 스탯블록 재사용`이라면 `## 스탯블록`에 원문 수치를 복제하지 않고 스탯블록명, 출처, 사용 방침을 기록한다.
- `전용 스탯블록 제작`이라면 4번 룰북 기능과 스탯블록 지침에 따라 작성한 실제 스탯블록을 `## 스탯블록` 아래에 직접 삽입한다.
- 외형 문서와 스탯블록 문서를 분리 생성하지 않는다.

## 기본 정보

필요한 범위에서 다음 정보를 갖는다.

- 이름
- 성별
- 나이대
- 종족
- 직업 또는 사회적 역할
- 소속
- 세션 내 역할
- 현재 위치
- 플레이어와의 기존 관계

정확한 나이가 중요하지 않다면 나이대로 작성한다.

## 외형 정보

NPC 이미지를 제작할 수 있을 정도로 구체적인 외형 정보를 제공한다.

- 성별 표현
- 나이대
- 종족적 특징
- 키와 체격
- 피부색과 피부 상태
- 얼굴형
- 눈 색과 눈매
- 머리카락 색, 길이, 형태
- 복장
- 장비
- 액세서리
- 상처, 문신, 흉터, 의체
- 눈에 띄는 소품
- 전체적인 인상

모든 NPC를 같은 미형 기준으로 만들지 않는다.

직업, 생활 환경, 경제적 여건, 지역 문화, 종족 특성이 외형에 반영되어야 한다.

## 마스터용 묘사

세션용 NPC 정본에는 기본적으로 `## 마스터용 묘사`를 포함한다. 이 섹션은 외형 데이터의 요약이 아니라, GM이 실제 플레이에서 그대로 읽거나 최소한만 다듬어 사용할 수 있는 **플레이 전달용 등장 묘사**다.

- 기본 분량은 1~2문단이며, 각 서술 문단은 반드시 3~4개의 완결된 문장으로 작성한다. 한 문장짜리 서술 문단은 허용하지 않으며, 5문장 이상이면 의미와 호흡을 기준으로 각각 3~4문장인 복수 문단으로 나눈다.
- 플레이어가 그 장면에서 실제로 감지할 수 있는 외형, 자세, 움직임, 목소리 인상, 장비, 마력 연출, 위압감 등을 중심으로 쓴다.
- 문체는 마스터가 플레이어에게 장면을 설명하는 **정중체 기반의 상황 설명체**를 기본으로 한다.
- 반말, 소설 독백체, 감상문체, 내면 서술 중심 문체는 사용하지 않는다. 특별한 사용자 지시가 없는 한 `~보입니다`, `~드러납니다`, `~느껴집니다`, `~하고 있습니다`처럼 실제 진행에 바로 읽을 수 있는 설명형 종결을 우선한다.
- 능력치, CR, 숨겨진 정체, 비공개 목적, 아직 드러나지 않은 설정처럼 플레이어가 알 수 없는 정보는 묘사문에 선행 공개하지 않는다.
- 객관적 외형 항목을 그대로 나열하지 않고, 장면에서 처음 보았을 때 무엇이 먼저 눈에 들어오는지와 어떤 인상을 주는지를 GM 서술의 호흡으로 재구성한다.
- 위장/본색, 평상시/전투 시처럼 외형과 인상이 크게 달라지는 인물은 `### 위장 상태`, `### 본색 상태`처럼 상황별 하위 묘사를 둘 수 있다.
- 이미 확정된 외형·장비·설정과 충돌하는 새로운 시각 요소를 묘사문에서 임의로 추가하지 않는다.
- 확정된 이미지가 있는 대상은 최신 확정 이미지의 색, 실루엣, 장비, 노출 범위, 표정과 분위기를 우선 기준으로 삼아 묘사와 이미지가 어긋나지 않게 한다.

## 성격 설계

성격을 한두 개의 형용사로 끝내지 않는다.

- 겉으로 드러나는 태도
- 실제 내면
- 중요하게 여기는 가치
- 현재 원하는 것
- 두려워하는 것
- 양보하지 않는 기준
- 숨기고 싶은 약점
- 내면의 모순
- 압박받았을 때의 반응
- 신뢰를 얻었을 때의 변화

## 가치와 욕망

가치는 장기적으로 중요하게 여기는 기준이다.

예:

- 공동체의 생존
- 명예
- 자유
- 가족
- 지식
- 질서
- 자연의 균형
- 약속
- 복수
- 신앙

욕망은 현재 사건에서 얻고 싶은 구체적인 결과다.

가치와 욕망은 충돌할 수 있으며, 이 충돌이 인물의 입체적인 행동을 만든다.

## 두려움과 약점

두려움은 단순 공포증보다 상실 가능성과 연결한다.

- 공동체에서 버림받는 것
- 과거의 실패가 드러나는 것
- 존경한 인물이 틀렸다는 사실
- 통제할 수 없는 힘을 다시 사용하는 것
- 가족이 자신의 선택 때문에 피해를 입는 것

약점은 판단을 흔들거나 관계를 어렵게 하는 요소로 작성한다.

## 내면의 모순

내면의 모순은 억지 반전이 아니다.

인물이 동시에 중요하게 여기는 두 가치가 충돌하는 상태를 만든다.

- 공동체를 사랑하지만 공동체를 위해 개인을 희생할 수 있다.
- 진실을 중시하지만 사랑하는 사람의 죄는 숨기고 싶어 한다.
- 용감하게 행동하지만 자신이 지휘하는 사람의 죽음을 감당하지 못한다.
- 자유를 원하지만 책임을 타인에게 넘긴다.

## 행동 판단 기준

주요 NPC에는 미래 행동을 확정하지 않고 판단 기준을 제공한다.

- 무엇을 얻으면 협력하는가
- 무엇을 잃으면 물러나는가
- 어떤 행동을 배신으로 보는가
- 어떤 증거를 신뢰하는가
- 누구의 안전을 우선하는가
- 시간 압박에서 무엇을 포기하는가
- 어느 선을 넘으면 공격하거나 도주하는가

## 플레이어에 대한 태도

- 초기 태도
- 신뢰가 생기는 조건
- 경계가 깊어지는 조건
- 적대하는 조건
- 도움을 요청하는 조건
- 관계가 회복되는 조건

모든 NPC가 플레이어를 즉시 신뢰하거나 특별하게 대하지 않는다.

## 말투와 행동 특징

고정 대사문보다 연기 지침을 제공한다.

- 문장 길이
- 존댓말 여부
- 자주 쓰는 표현
- 감정을 숨기는 방식
- 거짓말할 때의 습관
- 긴장할 때의 몸짓
- 상대를 부르는 방식
- 침묵을 사용하는 방식

대표 대사는 한두 줄 예시로만 사용할 수 있다.

## 주요 NPC 작성 형식

```markdown
#### NPC명

- 성별:
- 나이대:
- 종족:
- 역할:
- 소속:
- 외형:
- 겉으로 보이는 성격:
- 실제 내면:
- 중시하는 것:
- 현재 원하는 것:
- 두려워하는 것:
- 내면의 모순:
- 초기 태도:
- 신뢰 조건:
- 적대 조건:
- 말투와 행동:
- 절대로 하지 않을 행동:
- 변화 가능한 영역:
```

## 조우 NPC 작성 형식

```markdown
#### NPC명

- 기본 정보:
- 외형:
- 현재 목적:
- 행동 원리:
- 플레이어에 대한 태도:
- 압박받았을 때의 반응:
```

## 단역 NPC 작성 형식

```markdown
- NPC명: 종족·성별·나이대·역할을 포함한 한두 문장 설명. 제공할 정보 또는 장면에서의 반응.
```

## NPC 정보 배치

상세 정보는 처음 등장하는 장면에 둔다.

세션 앞부분의 `주요 NPC`에는 이름, 역할, 핵심 목적을 짧게 요약한다.

이후 장면에서는 현재 태도, 이전 장면에서 달라진 점, 이번 장면의 목적, 새롭게 드러나는 면모만 적는다.

## 이미지 및 토큰 제작과의 관계

세션 자산 단계에서는 NPC의 외형과 역할이 확정되면 해당 이미지 생성 기능을 사용해 필요한 이미지를 실제로 제작한다.

외형 정보는 포트레이트 또는 기타 인물 이미지를 만들 수 있을 정도로 구체적이어야 한다. 이미지 기능의 스타일·비율·승인 절차는 해당 이미지 기능 지침을 따른다.

맵에 배치되는 NPC는 전투 여부와 관계없이 기본적으로 토큰 제작 대상이다. 토큰 제작도 기존 토큰 기능 지침을 사용하며, 세션의 NPC 목록에는 이미지·토큰 제작 상태와 결과 참조를 기록한다.

## 금지 사항

- 모든 NPC가 비슷한 미형 외모
- 모든 NPC가 같은 말투
- 성격을 한 단어로 종료
- 비밀을 숨긴다는 이유로 모든 질문을 거부
- 플레이어 선택과 무관하게 정해진 행동만 반복
- 이유 없이 목숨을 걸고 싸움
- 주요 NPC가 GM의 정답을 대신 말함
- 설정상 종족·지역 문화와 무관한 외형
- 과거사 전체를 세션 문서에 과도하게 삽입
