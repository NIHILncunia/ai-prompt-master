# 7. 세션 품질 검수 체크리스트

## 설계 계단

- [ ] 처음부터 설계한 경우 한 줄 이야기를 먼저 확정했는가
- [ ] 핵심 이야기 골격이 시작 상황·중심 문제·핵심 변화·종료 지점을 포함하는가
- [ ] 핵심 사건 흐름이 장면 상세보다 먼저 확정되었는가
- [ ] 사용자가 이미 제공한 흐름을 임의로 재설계하지 않았는가
- [ ] 처음부터 설계한 경우 한 번에 하나의 결정 단위로 충분히 질문했는가
- [ ] 장면 목록 확정 전에 장면별 상세 파일을 만들지 않았는가
- [ ] `세션 프롤로그`와 `세션 에필로그`가 장면 목록의 정식 항목으로 포함되어 있는가
- [ ] 프롤로그가 이전 상황·현재 출발점·첫 본편 장면 진입을 연결하는가
- [ ] 에필로그가 마지막 사건의 결과·여파·다음 연결을 정리하는가
- [ ] 장면 기능과 묘사가 정리되기 전에 맵·스탯블록을 성급하게 확정하지 않았는가

## 패키지와 경로

- [ ] `2. 로그/세션 설계/[스토리명]/[세션 이름] 기획/` 경로인가
- [ ] `01. 시나리오`, `02. 장면 목록`, `03. 등장인물 및 몬스터`가 있는가
- [ ] `장면/` 폴더에 장면 목록과 일치하는 장면별 파일이 있는가
- [ ] `장면/00. 세션 프롤로그.md`와 마지막 번호의 `세션 에필로그.md`가 존재하는가
- [ ] 필요한 경우 `맵/`, `NPC 및 몬스터/` 하위 구조가 생성되었는가
- [ ] 아크 개요는 연속 세션일 때만 스토리 폴더의 `00. 세션 아크 개요.md`인가

## 장면 목록과 파일 동기화

- [ ] `02. 장면 목록`이 장면 순서·추가·삭제의 기준 원장으로 사용되는가
- [ ] 장면 번호와 장면별 파일명이 일치하는가
- [ ] 장면 목록의 장면명과 장면 파일 제목이 일치하는가
- [ ] 추가·삭제·통합된 장면의 이전·다음 연결이 동기화되었는가
- [ ] 장면의 맵 참조와 `맵/00. 맵 목록`이 일치하는가
- [ ] 고아 장면이나 고아 맵 참조가 없는가

## 장면 기능 확장

- [ ] 각 장면의 목적과 종료 조건이 분명한가
- [ ] 필요한 공개·발견·숨겨진 정보와 획득 경로가 구분되는가
- [ ] 능력 체크가 의미 있는 지점에만 배치되었는가
- [ ] 내성 체크가 의미 있는 위험과 연결되는가
- [ ] 한 번의 판정 실패가 핵심 진행을 완전히 막지 않는가
- [ ] 장면 묘사가 플레이어가 현재 인지할 수 있는 정보만 제공하는가
- [ ] 진행 묘사에 필요한 경우 사용 조건이 명확한가
- [ ] 등장 묘사가 공통 프로필이나 스탯블록을 불필요하게 복제하지 않는가

## 맵 산정과 배틀맵

- [ ] 전투 여부가 아니라 토큰 배치와 공간 관계의 필요성으로 맵을 판정했는가
- [ ] 장면 수와 맵 수를 기계적으로 1:1로 만들지 않았는가
- [ ] 같은 장소의 맵 재사용 가능성을 검토했는가
- [ ] 한 장면에 복수 맵이 필요하면 명확히 할당했는가
- [ ] 각 맵의 논리 그리드 가로·세로 수가 정해졌는가
- [ ] 권장 가로·세로 비율과 해상도가 정해졌는가
- [ ] 주요 구조물·출입 지점·토큰 활동 범위가 설계되었는가
- [ ] 필요한 배틀맵 이미지가 해당 이미지 기능 지침에 따라 준비되었는가

## NPC·몬스터와 스탯블록

- [ ] 세션에 실제 등장하는 NPC·몬스터 목록이 확정되었는가
- [ ] 각 대상이 `스탯블록 불필요 / 기존 재사용 / 전용 제작` 중 하나로 분류되었는가
- [ ] 일반 NPC에 불필요한 전용 스탯블록을 남발하지 않았는가
- [ ] 사용자가 강조한 주요 NPC를 임의의 일반 스탯에 치환하지 않았는가
- [ ] 강조 NPC의 전용 제작 여부와 컨셉이 모호할 때 사용자에게 확인했는가
- [ ] 전용 몬스터의 일반·정예·보스 등급이 명확한가
- [ ] 등급이나 전투 컨셉이 비어 있으면 사용자에게 확인했는가
- [ ] 실제 스탯을 작성하거나 재사용할 때 4번 룰북 자료를 확인했는가
- [ ] 각 세션용 NPC·몬스터 정본에 실제 플레이용 `마스터용 묘사`가 포함되어 있는가
- [ ] 마스터용 묘사가 1~2문단의 플레이 전달용 서술이며, 외형 목록의 단순 복제나 미공개 정보의 선행 공개가 아닌가
- [ ] 마스터용 묘사가 반말·독백체·소설 내면 묘사가 아니라, 마스터가 플레이어에게 읽어 주는 정중체 기반 상황 설명으로 작성되었는가
- [ ] 확정 이미지가 있는 대상은 묘사가 최신 확정 이미지의 외형·색상·장비·분위기와 일치하는가
- [ ] 위장/본색 등 상태 변화가 큰 대상은 필요한 경우 상황별 묘사가 구분되어 있는가
- [ ] 스탯블록이 필요한 대상은 `NPC 및 몬스터/[이름].md` 통합 파일의 기본 정보·외형 다음에 같은 문서 안에서 관리되는가

## 이미지와 토큰

- [ ] 필요한 NPC·몬스터 이미지가 준비되었는가
- [ ] 맵에 배치되는 NPC·몬스터의 토큰이 전투 여부와 관계없이 준비되었는가
- [ ] 이미지·토큰이 대상의 확정된 외형·장비·역할과 일치하는가
- [ ] 이미지 생성 세부 규칙은 해당 이미지 기능의 지침을 따랐는가

## 장면 결과 조건과 자산 연결

- [ ] 결과 판정이 필요한 장면에 성공 조건이 기록되어 있는가
- [ ] 결과 판정이 필요한 장면에 실패 조건과 실패 후 진행이 기록되어 있는가
- [ ] 실패가 세션 중단이 아니라 불리한 상태·대가를 남기고 다음 장면으로 이어지는가
- [ ] 공간 배치가 필요한 장면은 관련 맵을 참조하는가
- [ ] 장면이 참여자의 `NPC 및 몬스터/[이름].md` 통합 파일을 참조하고 스탯 수치를 불필요하게 복제하지 않았는가
- [ ] 핵심 정보에 둘 이상의 획득 경로가 있는가

## FVTT 경계

- [ ] 세션 제작에서 이미지와 스탯 데이터까지 준비했는가
- [ ] Actor·Scene·Journal·Compendium·JSON 등 실제 FVTT 데이터 변환을 세션 제작 단계에서 수행하지 않았는가
- [ ] 실제 FVTT 변환이 필요하면 6번 기능으로 넘길 대상이 명확한가
- [ ] 4번 룰북 기능에서 확인된 `[[...]]`, `@...`, `@UUID[...]` 문법을 임의로 제거하거나 고정 숫자로 바꾸지 않았는가
- [ ] 새 인라인 문법 작성·변수 경로·활동 연결 검증이 필요하면 6번의 `2. 피트 및 아이템 인라인 문법과 변수 사용 가이드.md`로 넘겼는가

## 제공

- [ ] 문서 파일이 UTF-8 Markdown인가
- [ ] 저장 경로가 표준 구조와 일치하는가
- [ ] 신규 파일은 프로젝트 기본 정책에 따라 Google Drive에 직접 저장했는가
- [ ] 기존 파일 변경은 사용자의 명시적 요청 범위 안에서 수행했는가
