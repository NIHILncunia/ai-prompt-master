# 19. 세션 제작

## 기능 개요

룩스테라 세계관을 기준으로 실제 플레이 전에 사용할 세션을 설계하고, 장면이 확정된 뒤 필요한 배틀맵·NPC·몬스터 스탯블록·이미지·토큰까지 준비합니다.

실제 Foundry VTT Actor·Scene·Journal·Compendium·JSON 변환과 피트·아이템 설명의 인라인 문법·롤 데이터 경로 검증은 6번 FVTT 기능에서 수행합니다.

## 기본 설계 흐름

`한 줄 이야기 → 핵심 이야기 골격 → 핵심 사건 흐름 → 장면 목록 → 장면별 파일 → 장면 기능 확장·묘사·성공/실패 조건 → 맵 산정·할당 → 배틀맵 설계·제작 → NPC·몬스터 목록 → 스탯 정책·스탯블록 → 이미지·토큰 → 진행 시트·스탯블록 모음 → 장면 결과 조건·자산 연결 검증`

사용자가 이미 흐름을 제공했다면 그 흐름을 보존하고, 처음부터 시작하는 경우에는 한 번에 하나의 큰 결정을 질문합니다.

## 맵

배틀맵은 전투 전용이 아닙니다. 토큰의 위치와 공간 관계가 플레이에 의미가 있다면 비전투 장면도 맵 대상으로 봅니다.

장면 전체를 검토해 필요한 맵 수를 산정하고 같은 장소의 재사용 여부를 판단합니다. 각 맵에는 논리 그리드 가로·세로 수와 권장 이미지 규격을 정합니다.

## NPC·몬스터와 스탯

모든 NPC·몬스터에 새 스탯블록을 만들지는 않습니다.

- 기존 스탯블록 재사용
- 전용 스탯블록 제작

**세션에 등장하는 모든 NPC와 몬스터는 전투 여부와 관계없이 스탯블록이 필수입니다.** 개체별 정본은 별도 `[이름] 스탯블록.md`를 만들지 않고 `NPC 및 몬스터/[이름].md` 안에 직접 기록합니다. 세션 완성 단계에서는 모든 대상의 스탯블록을 모은 `05. [세션 이름] 스탯블록 모음.md`를 플레이용 파생본으로 생성합니다.

중 하나로 판정합니다.

일반 NPC는 적절한 기존 NPC 스탯을 사용할 수 있습니다. 사용자가 강조한 주요 NPC는 전용 스탯블록 필요성이 모호하면 확인 후 제작합니다. 전용 몬스터는 필요한 경우 일반·정예·보스 등급과 전투 컨셉을 사용자에게 확인합니다.

맵에 배치되는 NPC와 몬스터는 전투 여부와 관계없이 기본적으로 토큰을 준비합니다.

## 파일 구성

- `0. 세션 제작 마스터 프롬프트.md`: 실행 진입점
- `1~7. 세션 제작 지침`: 기본·장면·NPC·장면 내 조우 결과·연속성·출력·검수
- `8. 세션 제작 예시.md`: 필요 시 참고 예시
- `9. 세션 자산 및 VTT 준비 지침.md`: 맵·스탯블록·이미지·토큰 제작 절차와 FVTT 경계
- `템플릿/`: 세션 패키지 출력 레이아웃

## 출력 구조

```text
[세션 이름] 기획/
├─ 01. [세션 이름] 시나리오.md
├─ 02. [세션 이름] 장면 목록.md
├─ 장면/
├─ 맵/
│  ├─ 00. 맵 목록.md
│  └─ ...
├─ 03. [세션 이름] 등장인물 및 몬스터.md
├─ 04. [세션 이름] 진행 시트.md
├─ 05. [세션 이름] 스탯블록 모음.md
└─ NPC 및 몬스터/
   └─ [이름].md  # 기본 정보·외형·스탯블록 통합
```

`03`은 상위 등장인물·몬스터 요약 인덱스 역할을 유지합니다. NPC·몬스터의 상세 프로필과 스탯블록은 `NPC 및 몬스터/[이름].md` 하나에 통합합니다. `04`는 장면 묘사와 능력·내성 체크포인트를 장면 순서대로 모은 GM 진행용 파생본이며, `05`는 실제 사용 스탯블록을 모은 GM 참조용 파생본입니다. 두 파일은 정본이 바뀌면 함께 동기화합니다. 조우의 성공·실패 조건은 해당 장면 파일에 직접 기록하며 별도 조우 설계 파일이나 `조우/` 폴더는 만들지 않습니다.

## 관련 기능

- 3번: 로그 분석
- 4번: 룰북 및 스탯 원문 확인
- 5번: 설정 정본
- 6번: 실제 FVTT 데이터 변환과 `[[...]]`·`@...` 문법 검증

세션 스탯블록에 4번 룰북 기능에서 확인된 인라인 문법이 포함되어 있으면 그대로 보존합니다. 새 문법 작성이나 변수·활동 연결 검증은 6번의 `2. 피트 및 아이템 인라인 문법과 변수 사용 가이드.md`를 따릅니다.
- 이미지 생성 모듈: 배틀맵·인물/몬스터 이미지·토큰 실제 생성

## 저장

신규 세션 문서 산출물은 해당 Google Drive 세션 설계 경로에 직접 저장하는 것이 기본입니다. 기존 파일의 수정·삭제·이름 변경은 사용자의 명시적 요청이 있을 때만 수행합니다.
