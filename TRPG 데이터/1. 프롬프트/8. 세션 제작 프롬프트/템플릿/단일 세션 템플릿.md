## 표준 폴더 구조

```text
[세션 이름] 기획/
├─ 01. [세션 이름] 시나리오.md
├─ 02. [세션 이름] 장면 목록.md
├─ 장면/
│  ├─ 00. 세션 프롤로그.md
│  ├─ NN. [장면명].md
│  └─ NN. 세션 에필로그.md
├─ 맵/
│  ├─ 00. 맵 목록.md
│  └─ NN. [맵명].md
├─ 03. [세션 이름] 등장인물 및 몬스터.md
├─ NPC 및 몬스터/
│  └─ [이름].md
├─ 04. [세션 이름] 조우 설계.md
└─ 조우/
   ├─ 00. 조우 목록.md
   └─ [조우명].md
```

장면별 파일은 장면 목록이 확정된 뒤에만 만든다. 맵과 스탯블록은 장면 기능·묘사가 충분히 정리된 뒤 만든다.


마스터용 묘사는 외형 목록을 그대로 반복하지 않고 실제 장면에서 먼저 보이는 요소와 인상을 중심으로 작성한다. 숨겨진 정체·목적·기계 수치를 선행 공개하지 않는다.

스탯블록이 불필요한 경우 `## 스탯블록`은 생략할 수 있다. 별도의 `[이름] 스탯블록.md` 파일은 생성하지 않는다.
