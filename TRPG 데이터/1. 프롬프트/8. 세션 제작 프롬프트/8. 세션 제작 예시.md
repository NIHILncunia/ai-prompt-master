# 8. 세션 제작 예시 라이브러리

## 역할

이 문서는 완성 세션을 복사하기 위한 모음이 아니다.

세션 제작 지침을 실제 문장과 구조로 적용하는 짧은 품질 예시를 제공한다.

## 독립 사건 도입 예시

### 나쁜 예시

```markdown
플레이어들은 새로운 마을에 도착한다. 마을의 역사와 주변 국가에 대한 설명을 들은 뒤 수상한 사건을 조사하기로 한다.
```

문제점:

- 세계와 캠페인을 처음부터 소개한다.
- 플레이어가 조사할 이유가 약하다.
- 현재 움직이는 사건이 없다.

### 좋은 예시

```markdown
오리진 외곽의 보급 창고에서 세 번째 화재가 발생한다. 불길은 진압됐지만 창고 안의 물자는 타지 않았고, 바닥에 남은 발자국은 모두 창고 안쪽을 향해 있다. 관리인은 화재를 사고로 처리하려 하지만, 오늘 밤 출항할 탐사대의 식량이 통째로 사라졌다.
```

장점:

- 이미 진행 중인 세계에서 사건이 시작된다.
- 즉시 확인할 이상 현상이 있다.
- 시간 압박과 이해관계가 있다.

## 연속 사건 도입 예시

```markdown
이전 세션에서 구조한 연구원은 끝내 자신이 운반하던 표본의 정체를 밝히지 않았다. 다음 날 새벽, 표본이 보관된 연맹 지하 창고의 경보가 울린다. 문은 안에서 잠겨 있으며, 연구원은 흔적 없이 사라졌다.
```

## 전체 진행 흐름 예시

```text
지하 창고 봉쇄
→ 내부 흔적 조사
→ 연구원의 목적 확인
→ 표본을 노리는 세력과 접촉
→ 연구원 구조 또는 추적
→ 표본 처리 방식 선택
→ 연맹과 상대 세력의 관계 변화
```

## 장면 예시

```markdown
## 장면 2. 안쪽으로 향한 발자국

### 장면 목적

화재가 침입을 감추기 위한 위장이며, 범인이 창고 안에서 출발했다는 사실을 드러낸다.

### 장소와 분위기

젖은 재 냄새가 남은 돌바닥. 벽의 마법등은 일정한 간격으로 꺼졌다 켜지며, 창고 중앙의 금속 상자는 겉면만 검게 그을려 있다.

### 시작 상황

연맹 경비 둘이 창고 관리인을 붙잡고 있다. 관리인은 자신이 마지막으로 문을 잠갔다고 주장하지만, 손에는 안쪽 잠금장치에서만 묻을 수 있는 푸른 윤활제가 남아 있다.

### 공개 정보

- 물자는 불에 타지 않았다.
- 외부 문은 강제로 열린 흔적이 없다.
- 발자국은 상자에서 입구 쪽으로 이어진다.

### 숨겨진 정보

- 관리인은 범인이 아니며, 새벽에 안쪽에서 들린 신호음을 확인하려다 잠금장치를 만졌다.
- 금속 상자 아래에는 배수로로 통하는 작은 틈이 있다.

### 다음 장면 연결

- 관리인을 설득하면 배수로의 오래된 도면을 얻는다.
- 상자를 조사하면 틈과 비늘 조각을 발견한다.
- 경비 기록을 확인하면 새벽에 지하 수로 수위가 비정상적으로 변한 사실을 알 수 있다.
```

## 주요 NPC 예시

```markdown
#### 세라드 벤

- 성별: 남성
- 나이대: 40대 후반
- 종족: 인간
- 역할: 오리진 보급 창고 관리인
- 외형: 작고 마른 체격. 햇볕에 그을린 얼굴과 깊은 눈가 주름, 잿빛 수염. 낡았지만 깨끗하게 손질한 연맹 작업복을 입는다.
- 겉으로 보이는 성격: 신경질적이고 책임을 피하려 한다.
- 실제 내면: 자신의 실수로 탐사대가 위험해지는 것을 누구보다 두려워한다.
- 중시하는 것: 맡은 물자가 필요한 사람에게 제때 도착하는 것.
- 현재 원하는 것: 자신이 잠금장치를 건드린 사실을 숨기면서 물자를 되찾는 것.
- 두려워하는 것: 관리 자격을 잃고 과거의 밀수 전력이 드러나는 것.
- 내면의 모순: 규칙을 중시하지만, 물자가 부족한 탐사대에는 장부를 조작해 더 나눠주곤 했다.
- 초기 태도: 플레이어를 감찰자로 생각해 방어적으로 반응한다.
- 신뢰 조건: 공개 처벌보다 물자 회수를 우선한다.
- 적대 조건: 과거의 밀수 기록을 경비 앞에서 공개한다.
- 말투와 행동: 짧고 퉁명스럽게 답하며, 거짓말할 때 오른손 엄지로 단추를 문지른다.
- 절대로 하지 않을 행동: 탐사대의 식량을 고의로 빼돌리지 않는다.
- 변화 가능한 영역: 플레이어가 자신을 보호하면 물류망의 비공식 정보를 제공할 수 있다.
```

## 협상 조우 예시

```markdown
#### 닫힌 부두의 협상

- 유형: 협상
- 목적: 밀수선에 실린 표본의 행방을 확인하고 출항을 막는다.
- 참여자:
  - 플레이어: 표본 회수 또는 안전한 처리
  - 선장 하르바: 선원 생존과 거래 대금 확보
  - 연맹 경비: 공개 체포와 증거 확보
- 공개 정보: 선장은 출항 준비를 마쳤고 경비가 접근하면 밧줄을 끊으라고 지시했다.
- 숨겨진 정보: 선장은 표본이 생물이라는 사실을 모르며, 화물칸에서 들리는 소리를 선원들에게 숨기고 있다.
- 가능한 접근:
  - 거래 대금을 보장한다.
  - 표본의 위험성을 증명한다.
  - 선원들의 공포를 이용해 선장을 고립시킨다.
  - 경비를 물리고 비공개 협상을 제안한다.
- 상황 변화: 화물칸에서 두 번째 충격음이 들리면 선원들이 동요하고, 세 번째 충격음 뒤에는 표본이 탈출한다.
- 성공 결과: 선장이 화물칸을 열고 선원들을 대피시킨다.
- 부분 성공 결과: 표본 위치는 알지만 선장이 배를 출항시킨다.
- 실패 결과: 경비와 선원 사이에 충돌이 발생하며 표본이 혼란 속에서 탈출한다.
```

## 조사 조우 예시

```markdown
#### 불에 타지 않은 창고

- 유형: 조사
- 핵심 질문: 물자는 어떻게 외부 침입 없이 사라졌는가?
- 반드시 얻어야 할 정보:
  - 화재는 위장이다.
  - 내부에서 배수로가 사용됐다.
- 정보 경로:
  - 발자국 방향
  - 상자 밑의 틈
  - 경비 기록의 수위 변화
  - 관리인의 증언
- 실패 후 진행:
  - 조사가 늦어지면 배수로의 물이 올라 흔적 일부가 사라진다.
  - 대신 배수로에서 빠져나온 생물이 시장에서 목격되어 다음 장면이 열린다.
```

## 전투 조우 예시

```markdown
#### 부서지는 저장고

- 유형: 전투·구조
- 적의 목표: 플레이어를 죽이는 것이 아니라 표본이 탈출할 시간을 번다.
- 적의 행동:
  - 앞줄은 통로를 막는다.
  - 후열은 지지대를 파괴한다.
  - 지휘자는 표본이 빠져나가면 즉시 퇴각한다.
- 환경:
  - 흔들리는 철제 발판
  - 깨지기 쉬운 유리 저장조
  - 닫히는 방화문
- 전투 외 해결:
  - 지휘자에게 표본이 통제를 벗어났음을 증명한다.
  - 방화문을 먼저 닫아 목표를 차단한다.
  - 냉각 장치를 작동해 표본을 진정시킨다.
```

## 부분 성공 예시

```markdown
플레이어는 실종자를 구하지만, 실종자가 지키려던 지도는 적대 세력에게 넘어간다. 구조된 인물은 다음 목적지를 알고 있으나 즉시 추적하면 치료할 시간을 잃는다.
```

## 실패 후 진행 예시

```markdown
플레이어가 협상에 실패하면 선장은 출항한다. 세션은 끝나지 않는다. 항구 감시탑, 소형 추격선, 수로 출구 중 하나를 이용해 추적 장면으로 전환한다.
```

## 결말 분기 예시

```markdown
- 표본을 연맹에 넘긴다: 연맹은 연구를 시작하지만 생물의 기원은 비공개로 분류한다.
- 표본을 원래 서식지로 돌려보낸다: 지역 생태는 안정되지만 연맹과의 관계가 악화될 수 있다.
- 표본을 파괴한다: 즉각적인 위험은 사라지지만 배후 세력의 목적을 확인할 증거를 잃는다.
- 배후 세력과 거래한다: 단기 보상과 정보를 얻지만 이후 협박의 여지를 남긴다.
```

후속 요소를 모두 다음 세션의 중심 사건으로 사용할 필요는 없다.
