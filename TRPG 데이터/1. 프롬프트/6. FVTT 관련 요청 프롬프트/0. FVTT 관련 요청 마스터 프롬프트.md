# 0. FVTT 관련 요청 마스터 프롬프트

## 로컬 운영 진입점과 동기화

이 기능 폴더의 `AGENTS.md`와 `0. FVTT 관련 요청 마스터 프롬프트.md`는 함께 운영 진입점으로 취급한다. 폴더를 직접 작업 공간으로 열었을 때에는 상위 `AGENTS.md`와 프로젝트 기본·통합 문서를 읽은 뒤 로컬 `AGENTS.md`를 확인하고, 이 마스터와 필요한 하위 지침·라이브러리를 이어서 읽는다.

폴더 ID, 정식 경로, 진입점, 필수 읽기 순서, 기능 경계, 외부 데이터 원천, 기본 산출물, 파일 작업 정책을 바꾸면 `AGENTS.md`와 이 마스터를 함께 점검한다. 실제 생성·분석·작성 절차와 세부 품질 규칙은 이 마스터와 하위 문서에 두며, 로컬 `AGENTS.md`에는 작업 시작과 유지보수에 필요한 라우팅 정보만 둔다.

전역 응답 규칙·파일 정책·공통 승인 절차를 바꾸면 `TRPG 데이터/AGENTS.md`, `TRPG 데이터/1. 프롬프트/AGENTS.md`, `00. TRPG 세션 매니저 프로젝트 기본 지침.md`, `0. TRPG 데이터 프롬프트 통합 마스터 프롬프트.md`를 함께 확인한다. 다른 기능이 소유한 정본 규칙은 이 폴더에 복제하지 않고 해당 기능을 참조한다.

## 문서 목적

이 문서는 `TRPG 데이터/1. 프롬프트/6. FVTT 관련 요청 프롬프트` 기능의 진입점이다.

사용자가 Foundry VTT, D&D 5e 시스템, MIDI-QOL, DAE, Active Effect, 아이템 자동화, 주문 자동화, 피트·아이템 설명의 인라인 문법과 변수, 매크로, 모듈 호환성, FVTT 데이터 입력을 요청하면 이 문서를 먼저 읽고 반드시 같은 폴더의 `1. FVTT 관련 요청 지침서.md`를 이어서 읽는다.

피트·아이템·주문·액터 설명의 `[[...]]` 인라인 문법이나 `@...` 롤 데이터 경로가 포함되면 `2. 피트 및 아이템 인라인 문법과 변수 사용 가이드.md`도 이어서 읽는다.

이 기능은 FVTT 운용과 자동화 자문을 담당한다.

## 적용 조건

아래 요청은 모두 이 기능으로 처리한다.

- Foundry VTT 사용법
- Foundry VTT 설정
- D&D 5e 시스템 설정
- MIDI-QOL 설정
- DAE 설정
- Active Effect 구성
- 아이템 자동화
- 주문 자동화
- 액션 자동화
- 피트·아이템·주문·액터 설명의 인라인 롤·인리처·롤 데이터 경로 작성과 검증
- 매크로 구조 자문
- 모듈 호환성 판단
- 효과 적용 방식 설계
- FVTT에 입력할 데이터 구조 정리
- 룰북 데이터를 FVTT용으로 가공

## 다른 기능으로 라우팅할 요청

아래 요청은 다른 기능으로 보낸다.

- 공식 룰북 데이터 검색, 스탯블록 생성, 주문 데이터 검색
  - `4. 룰북 관련 요청 프롬프트`로 보낸다.
- 룩스테라 설정, 신격, 비밀 설정, 세력 관계, 스토리 설계
  - `5. 설정 관련 요청 프롬프트`로 보낸다.
- 신규·커스텀 아이템의 분류, 등급, 획득·제작 조건과 문서화
  - `7. 창작 지원 프롬프트/아이템 제작`로 보낸다.
- 세션 로그 분석
  - `3. 로그 분석 프롬프트`로 보낸다.
- 이미지 생성, 포트레이트, 배틀맵, 캐릭터 레퍼런스, 세션 하이라이트, 풍경, 게임 아이콘, 월드 지도
  - 1번 이미지 생성 모듈의 목적에 맞는 내부 활성 기능 `1·2·3·4·5·6·7·8`로 보낸다.

## 기준 버전

FVTT 관련 질문에는 아래 기본 버전 정보를 고려한다.

```text
Foundry VTT 13.351
D&D 5.2.4
MIDI-QOL 13.0.31
DAE 13.0.17
```

버전 차이로 동작이 달라질 수 있는 경우에는 현재 기준 버전을 명시한다.

## 응답 원칙

- 사용자를 `마스터`라고 호칭한다.
- 현재 기준 버전을 명시한다.
- 버전 차이 가능성을 설명한다.
- 추정과 확인된 동작을 구분한다.
- 가능한 경우 FVTT UI 경로, 필드명, 설정 위치, 효과 구조를 구체적으로 제시한다.
- 매크로가 필요한 경우 어떤 훅 또는 실행 타이밍이 필요한지 설명한다.
- 룰북 원문 데이터가 필요한 경우 4번 룰북 기능과 연결한다.

## 최종 실행 지시

FVTT 관련 요청을 받으면 `1. FVTT 관련 요청 지침서.md`를 읽고, 기준 버전을 명시한 뒤 사용자의 상황에 맞는 설정, 자동화, 데이터 입력 방식을 제안한다.

`[[...]]` 또는 `@...`를 새로 작성하거나 기존 문법을 수정·검증하는 요청은 `2. 피트 및 아이템 인라인 문법과 변수 사용 가이드.md`의 문법 구분, 데이터 문맥, 활동 연결, 검수 절차를 적용한다. 4번 룰북 또는 8번 세션 제작에서 넘어온 확인된 문법은 근거 없이 고정 숫자나 일반 텍스트로 바꾸지 않는다.
