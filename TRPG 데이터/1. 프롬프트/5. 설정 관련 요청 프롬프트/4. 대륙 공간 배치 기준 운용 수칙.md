# 4. 대륙 공간 배치 기준 운용 수칙

## 문서 목적

이 문서는 5번 설정 관련 요청 기능에서 대륙의 공간상 사실을 작성·수정·점검할 때 적용하는 실행 절차다. 상세 격자·표기·범례 규칙의 정본은 `프로젝트 위그드라실/대륙 공간 배치 기준 작성 지침.md`이며, 이 문서는 그 지침을 5번 기능의 라우팅·탐색·검증 흐름에 연결한다.

대륙 공간 배치 기준은 개별 대륙·국가·지형·도시국가 문서의 정본성을 대체하지 않는 인덱스형 내부 참조 자료다. 정본에서 확인한 위치·인접·연결 관계를 다섯 레이어로 비교하며, 근거 없는 좌표나 경로를 정설로 승격하지 않는다.

## 적용 조건

다음 가운데 하나라도 해당하면 이 수칙을 추가로 읽고 적용한다.

- 대륙 정본의 신규 작성·보강·개편·재작성·수정
- 대륙에 속한 지형·수계·권역·국가·정치 영역·정착지·항구·거점·이동경로의 위치, 범위, 인접 관계, 소속 권역, 연결 관계 변경
- 대륙의 지면·수역, 권역, 지형지물, 문명·거점, 이동경로 배치 또는 상호 정합성 점검

단순 문체 윤문처럼 공간상 사실을 바꾸지 않는 작업에는 이 수칙의 다섯 레이어 갱신을 강제하지 않는다.

## 필수 자료와 읽기 순서

1. `0. 설정 관련 요청 마스터 프롬프트.md`
2. `1. 설정 관련 요청 지침서.md`
3. 이 수칙
4. 프로젝트 설정 루트 `AGENTS.md`
5. 프로젝트 설정 루트 `문서 작성 및 수정 지침.md`
6. 프로젝트 설정 루트 `대륙 공간 배치 기준 작성 지침.md`
7. 대상 시리즈 `AGENTS.md`
8. 대상 시리즈의 대륙 공간 배치 기준 템플릿
9. 대상 대륙 정본과 직접 연결된 국가·지형·도시국가·세력 관계 문서
10. 대상 시리즈의 관련 인덱스와 대상 대륙 공간 배치 기준
11. `설정 정비/설정 정비 현황.md`와 같은 대상의 미완료 정비 문서

템플릿 구조를 새로 적용하거나 변경하면 `3. 설정 문서 템플릿 구조 점검 수칙.md`를, 대륙 정본의 문체·밀도·정합성 점검을 수행하면 `2. 설정 문서 점검 및 밀도 분석 수칙.md`를 함께 적용한다.

## 실행 절차

1. 대상 시리즈와 대륙을 판정하고, 대륙 설정 변경인지 이미지 지도 제작인지 먼저 구분한다.
2. 정본에서 바뀌었거나 새로 추가될 공간상 사실을 `지면·수역`, `권역`, `지형지물`, `문명·거점`, `이동경로` 가운데 어느 레이어에 영향을 주는지 기록한다.
3. 대상 대륙의 공간 배치 기준과 관련 인덱스로 기존 좌표·인접·연결 관계를 확인하고, 실제 근거는 연결된 정본에서 다시 검증한다.
4. 변경 대상이 한 레이어뿐이어도 다섯 레이어의 격자 크기, 수역 마스크, 권역 코드, 객체 위치, 항구·수운 접속, 경로 연속성을 모두 대조한다.
5. 정본에서 확인된 사실만 대륙 정본과 공간 배치 기준에 반영한다. 근거가 부족한 좌표·경계·경로는 `추정` 또는 `임시`로 표시한다.
6. 추정·충돌·보강 필요 사항은 정본에 섞지 않고 대상 시리즈의 설정 정비에 근거, 영향 범위, 승인 필요 여부를 기록한다.
7. 변경 뒤에는 범례의 좌표·상태·근거 정본·연결 관계, 위키 링크, 관련 인덱스, 설정 정비 현황을 검증한다.

## 정본과 설정 정비의 경계

- 대륙·국가·지형·도시국가·세력 관계 문서는 개별 사실의 최종 근거다.
- 공간 배치 기준은 그 사실을 좌표계에서 비교하는 인덱스이며, 빈칸을 추정으로 채워 정본을 바꾸지 않는다.
- 정본과 공간 배치 기준이 충돌하면 정본을 우선하고, 공간 배치 기준을 정본에 맞춰 갱신한다.
- 어느 쪽의 근거도 부족하거나 정본끼리 충돌하면 임의로 합치지 않고 설정 정비에 문제와 선택지를 기록한다.

## 1번 이미지 생성 모듈 내부 8번 월드 지도 기능과의 경계

1번 이미지 생성 모듈 내부 8번은 세계·대륙 지도를 시각적으로 제작하는 기능이다. 이미지 생성 또는 지도 화질 개선 자체는 1번 이미지 생성 모듈 내부 8번으로 라우팅한다.

다만 대륙 설정의 위치·권역·지형·거점·항로를 확정하거나 수정해야 하는 요청은 5번에서 이 수칙으로 먼저 처리한다. 1번 이미지 생성 모듈 내부 8번은 확정된 대륙 공간 배치 기준을 시각 지도 제작의 입력으로 사용할 수 있지만, 이미지 결과만으로 정본의 공간상 사실을 새로 확정하거나 변경하지 않는다.

## 완료 판정

- 적용 조건과 대상 대륙을 분명히 판정했는가
- 필요한 정본, 인덱스, 공간 배치 기준, 설정 정비를 읽었는가
- 한 요소의 변경에 대해 다섯 레이어 전체를 교차 검증했는가
- 범례의 좌표·상태·근거·연결 관계가 실제 정본과 맞는가
- 추정과 충돌을 정본에서 분리하고 설정 정비에 기록했는가
- 1번 이미지 생성 모듈 내부 8번 지도 기능의 시각 결과를 정본 근거로 오인하지 않았는가
