# D&D 룰북 소유 리스트

## 문서 목적

이 문서는 현재 보유·공유 중이며 실제 룰북 수량으로 집계하는 D&D 5e 자료의 정본입니다.
룰북 관련 요청에서는 이 문서를 먼저 확인하여 주분류, 소유 여부, D&D Beyond 존재 여부와 상세 인덱스 대상을 판단합니다.

수집 룰북은 같은 파일 안에서 `데이터북`, `시나리오북`, `설정북`의 독립 표로 관리합니다.
D&D Beyond 비교 전용 항목은 수집 룰북 집계와 분리합니다.

`5.5e 호환성`의 상세 판정과 Legacy 운용은 `0. 룰북/문서/16. D&D 5.5e 호환성 비교 및 레거시 기준.md`를 정본으로 합니다. 이 문서의 상태 열은 빠른 조회용입니다.

## 집계 규칙

- 모든 수집 룰북은 주된 사용 목적과 목차 구조에 따라 세 주분류 중 정확히 한 곳에만 둡니다.
- 연속된 모험 진행이 중심이면 시나리오북, 세계·지역·세력·문화 설명이 중심이면 설정북, 재사용 가능한 규칙·옵션·스탯블록·목록이 중심이면 데이터북으로 분류합니다.
- 경계가 비슷하면 서문의 목적과 목차의 주된 장 구성을 우선하고, 필요할 때만 장별 페이지 비중을 보조 기준으로 사용합니다.
- `원본 확인`은 대응하는 실제 파일 행이 모두 `Y`일 때만 `Y`입니다.
- 상세 인덱스는 데이터북에만 만들며, 시나리오북과 설정북은 전 페이지 검증 뒤 장르·주제·데이터 유형만 기록합니다.
- `기존 목록 기준 —` 표기는 전 페이지 원본 검증 전의 기존 분류 정보를 보존한 값이며 확정된 원본 검증 결과가 아닙니다.
- Beyond 비교 전용 항목은 대조용이며 실제 수집 룰북 수량에 포함하지 않습니다.
- `5.5e 호환성` 열은 파일명 변경·삭제 여부가 아니라 인덱싱 시 출처의 우선순위와 판본 분리 방식을 나타냅니다.
- `Legacy`는 엄격히 Volo's Guide to Monsters와 Mordenkainen’s Tome of Foes에만 사용합니다. 세부 기준은 16번 문서를 따릅니다.
- `개정·대체 관계`는 특정 구판·신판의 직접 개정, 정식 통합, 부분 대체 또는 개별 항목 재수록 범위를 나타냅니다. 관계가 없는 출처는 `—`로 둡니다.

## 관리 규칙

- 세 수집 표 사이의 중복 배치는 허용하지 않습니다.
- 새로운 수집 룰북은 주분류를 판정한 뒤 해당 표의 연도 순서에 추가합니다.
- 분할 파일은 이 문서에서 한 논리 룰북 행으로 묶고, 실제 파일별 검증은 `FVTT 룰북 검증 및 갱신 현황.md`에서 관리합니다.
- 합본·상위 룰북에 여러 논리 항목이 수록된 경우 동일한 실제 PDF를 여러 논리 행에 연결할 수 있습니다. 실제 고유 파일 수를 셀 때에는 같은 파일명을 한 번만 셉니다.
- `0. 룰북` 직계 룰북 원본은 PDF만 사용합니다. `0. 룰북/문서`의 Markdown은 운영 지침이며 룰북 원본 수량에 포함하지 않습니다.
- 시나리오북·설정북의 장르, 핵심 주제, 데이터 유형은 전 페이지 검증이 끝난 경우에만 확정합니다.
- 데이터북 상세 인덱스 번호는 데이터북 표 순서를 따르며 1부터 연속으로 유지합니다.
- 비교 전용 항목을 수집 룰북으로 승격할 때에는 세 주분류 중 하나를 먼저 확정합니다.
- 5.5e 상태의 신규·변경 판정은 16번 기준 문서를 먼저 갱신한 뒤 이 문서와 01번 레지스트리에 같은 값을 반영합니다.

## 에이전트 해석 규칙

- 실제 보유량 질문에는 세 수집 표의 합계 96을 사용합니다.
- 상세한 항목명·페이지 위치가 필요하면 데이터북의 활성 상세 인덱스만 검색합니다.
- 시나리오·설정북은 장르·주제·확인된 데이터 유형까지만 인용하고, 아카이브된 상세 인덱스를 현행 근거로 사용하지 않습니다.
- `원본 확인=N`인 행의 `기존 목록 기준 —` 값은 보조 정보로만 설명하며 원본 검증 완료로 표현하지 않습니다.
- 5.5e 호환성, Legacy, 동일 항목의 구판·신판 우선순위 또는 개정·대체 관계가 질문의 핵심이면 16번 기준 문서를 함께 확인합니다.
