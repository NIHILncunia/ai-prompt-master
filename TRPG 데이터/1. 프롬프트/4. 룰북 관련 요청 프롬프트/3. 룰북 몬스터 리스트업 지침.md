# 룰북 몬스터 리스트업 지침

## 1. 목적

사용자가 특정 룰북(예: Volo's Guide to Monsters, Monster Manual 등)을 지정하여 몬스터 목록을 요구하면, 해당 룰북의 몬스터 데이터를 탐색하여 정해진 양식에 맞춰 리스트업합니다.

## 2. 작업 절차

- Step 1 (탐색): 지정된 룰북 파일 내에서 `Bestiary`, `Monsters`, `Appendix` 등의 목차 및 본문을 스캔하여 몬스터의 목록을 수집합니다.
- Step 2 (분석): 각 몬스터의 이름, 크기(Size), 유형(Type), 그리고 해당 룰북 내에 실제 스탯블록(Stat Block)이 존재하는지 여부를 확인합니다.
- Step 3 (출력): 수집된 데이터를 토큰 제한이 허용하는 선까지 [템플릿/룰북 몬스터 리스트업 출력 템플릿.md](<템플릿/룰북 몬스터 리스트업 출력 템플릿.md>)의 양식에 맞춰 제공합니다. 데이터가 너무 많을 경우 알파벳 순서대로 분할하거나 특정 CR·유형으로 좁혀 출력합니다.

## 3. 항목 판정 규칙

- 크기(Size): 초소형, 소형, 중형, 대형, 거대형, 초대형으로 표기합니다. 요청이 있으면 영어 표기를 병기합니다.
- 유형(Type): 야수, 인간형, 핀드, 언데드, 괴물 등으로 표기합니다. 요청이 있으면 영어 표기를 병기합니다.
- 스탯블록 존재 여부: 해당 룰북 본문에 전투에 사용할 수 있는 전체 스탯블록이 있으면 `O`, 이름이나 설정만 언급되고 스탯블록이 없으면 `X`로 표기합니다.
