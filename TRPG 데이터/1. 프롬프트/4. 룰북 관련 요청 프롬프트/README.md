# 4. 룰북 관련 요청

## 기능 개요

D&D 룰북의 공식 규칙·데이터·스탯블록을 확인하고, 수집 룰북의 주분류와 원본 검증·상세 인덱스 상태를 관리한다.

## 적용 대상

- 룰북 탐색과 소유 여부 확인
- 공식 규칙·주문·아이템·몬스터·스탯블록 확인
- 커스텀 몬스터 스탯블록 제작
- 특정 룰북의 몬스터 목록과 CSV 데이터 정리

## 주요 사용 사례

- 특정 몬스터의 공식 수록 여부와 출처 확인
- FVTT 임포트용 스탯블록 작성
- 특정 룰북의 몬스터 목록 추출
- 보유 룰북과 데이터 목록 비교
- 데이터북·시나리오북·설정북 주분류 확인
- 분류별 원본 검증 진행과 데이터북 상세 인덱스 확인

## 파일 구성

- `AGENTS.md`: 기능 라우팅과 조건부 읽기 규칙
- `0. 룰북 관련 요청 마스터 프롬프트.md`: 기능 실행 진입점
- `1. 룰북 관련 요청 지침서.md`: 룰북 탐색·근거 확인·요청 분류
- `2. 몬스터 스탯블록 지침.md`: 몬스터 스탯블록 규칙
- `3. 룰북 몬스터 리스트업 지침.md`: 몬스터 목록 추출 규칙
- `9999. D&D 룰북 소유 리스트.md`: 데이터북·시나리오북·설정북 독립 표와 Beyond 비교 전용 목록의 정본
- `템플릿/`: 스탯블록과 목록의 출력 레이아웃
- `라이브러리/`: 기능 전용 재사용 자료를 둘 공간

## 숫자 문서 적용 순서

1. `0. 룰북 관련 요청 마스터 프롬프트.md`
2. `1. 룰북 관련 요청 지침서.md`
3. 요청에 따라 2번 스탯블록 지침 또는 3번 몬스터 목록 지침
4. 필요한 출력 템플릿

`9999. D&D 룰북 소유 리스트.md`는 실행 순서가 아닌 조건부 색인이다.

## 공통 라이브러리 의존성

현재 공통 라이브러리 의존성은 없습니다.

## 템플릿

- `템플릿/몬스터 스탯블록 출력 템플릿.md`
- `템플릿/룰북 몬스터 리스트업 출력 템플릿.md`

## 입력 자료

- `TRPG 데이터/0. 룰북`의 룰북 원문
- `9999. D&D 룰북 소유 리스트.md`

## 출력 결과

- 출처와 확실성을 구분한 룰북 답변
- 시나리오북·설정북의 검증된 장르·핵심 주제·데이터 유형 요약
- 데이터북의 항목별 상세 위치 인덱스
- SBI Import Package: 영문 스탯블록과 LOCALIZATION JSON을 합친 단일 복사 블록
- 일반 한국어 번역과 창작/조정의 기반 몬스터 원본 스탯블록
- 룰북 몬스터 목록과 필요 시 CSV 형태의 데이터

## 관련 기능

- 5번 설정 관련 요청
- 6번 FVTT 관련 요청

## 유지보수 주의사항

- README는 사람용 안내이며, 일반 실행의 필수 읽기 문서가 아닙니다.
- `9999.` 색인은 실행 문서 번호 연속성에서 제외합니다.
- 상세 위치 인덱스는 데이터북에만 만들며, 시나리오북·설정북은 유형 요약까지만 관리합니다.
- 아카이브된 비데이터북 인덱스는 현행 검색과 집계에 사용하지 않습니다.
- 스탯블록 템플릿의 FVTT 임포트용 레이아웃은 임의로 변경하지 않습니다.
- 기존 별도 FVTT 한국어 번역은 Import Package의 LOCALIZATION으로 통합했습니다. 기존 `스탯블록 임포터` 매크로에 패키지 전체를 넣으며, 순수 SBI에는 STATBLOCK 영역만 입력합니다.
- JSON 형식 확인과 실환경 자동화 검증은 구분합니다. 주문·복수 Activity 등 확인이 필요한 범위는 스탯블록 전용 지침을 따릅니다.
