# 4번 룰북 관련 요청 기능 지침

- 폴더 ID: `1euaEeTya1cl6f397AOjNzrJQs5VnPxfa`

## 역할

공식 룰북 자료를 탐색·검증하고 규칙·데이터·스탯블록의 근거를 정리한다.

## 룰북 주분류와 인덱스 경계

- `9999. D&D 룰북 소유 리스트.md`의 데이터북·시나리오북·설정북 독립 표를 주분류 정본으로 사용한다.
- 하나의 수집 룰북은 주된 사용 목적과 목차 구조에 따라 한 주분류에만 둔다.
- 상세 위치 인덱스는 데이터북에만 작성한다.
- 시나리오북과 설정북도 원본 전체를 검증하지만 장르·핵심 주제·확인된 데이터 유형까지만 기록하고 개별 항목명·페이지 인덱스를 만들지 않는다.
- 실제 파일별 검증과 데이터북별 상세 인덱스 진행은 `작업 정비/룰북 인덱싱 및 FVTT 컴펜디움 이관 체계/FVTT 룰북 검증 및 갱신 현황.md`의 분리 표를 따른다.
- 아카이브된 비데이터북 상세 인덱스는 현행 검색·집계·후속 인덱싱 입력으로 사용하지 않는다.

요청과 무관한 예시·라이브러리·데이터 폴더는 무조건 전부 읽지 않는다. 마스터가 지정하거나 현재 작업에 필요한 자료만 추가로 확인한다.

요청별 추가 읽기 문서는 아래와 같다.

- 룰북 소유 여부 확인·비교: `9999. D&D 룰북 소유 리스트.md`
- 룰북 주분류·원본 검증·상세 인덱스 상태: `9999. D&D 룰북 소유 리스트.md`, `작업 정비/룰북 인덱싱 및 FVTT 컴펜디움 이관 체계/FVTT 룰북 검증 및 갱신 현황.md`
- 공식·커스텀 몬스터 스탯블록: `2. 몬스터 스탯블록 지침.md`, `템플릿/몬스터 스탯블록 출력 템플릿.md`
- 특정 룰북의 몬스터 목록: `3. 룰북 몬스터 리스트업 지침.md`, `템플릿/룰북 몬스터 리스트업 출력 템플릿.md`

`README.md`는 사람용 구조 안내이며 일반 실행의 필수 읽기 문서가 아니다. `9999. D&D 룰북 소유 리스트.md`는 조건부 색인·레지스트리이므로 0번 이후 실행 문서의 연속 번호 규칙에서 제외한다.

## 기능 경계와 연동

- 룰북 원문은 Google Drive의 `TRPG 데이터/0. 룰북`에서 검색하고, 먼저 이 기능 폴더의 `9999. D&D 룰북 소유 리스트.md`를 확인한다. Codex CLI에서는 Git 로컬 작업 폴더에서 이 자료를 조회한다.
- 요청 대상에 맞는 기본 룰북을 직접 훑는다. 기본 룰북은 `D&D 5e 2024 Player’s Handbook`, `D&D 5e 2024 Dungeon Master’s Guide`, `D&D 5e 2025 Monster Manual`이며, 몬스터·스탯블록은 `Monster Manual`, 플레이어 규칙·주문·장비는 `Player’s Handbook`, 판정·보상·운영 규칙은 `Dungeon Master’s Guide`를 우선한다. 요청 범위가 둘 이상에 걸치거나 불명확하면 세 기본 룰북을 이 순서대로 확인한다.
- Google Drive 룰북 자료 검색은 웹검색, 검색 엔진, 외부 웹사이트, Google Drive 커넥터 사용을 뜻하지 않는다. 룰북 자료에 없는 내용은 추정하거나 웹에서 보완하지 않고 확인 불가로 보고한다.
- FVTT 구현은 6번, 세계관 설정 반영은 5번으로 라우팅한다.
- 몬스터 스탯블록 출력은 전용 스탯블록 지침과 FVTT 임포트용 출력 템플릿을 우선한다.
- 메인 스탯블록의 기본 산출물은 영문 데이터와 LOCALIZATION JSON을 한 `text` 코드블록에 담은 SBI Import Package다. 일반 한국어 번역과 창작/조정의 기반 몬스터 원본은 별도로 유지하며 상세 규격은 전용 지침과 템플릿을 따른다.
- `라이브러리/`은 기능 전용 재사용 자료만 수용한다. 룰북 원문과 보유 목록은 이 폴더로 옮기지 않는다.

## 동기화 원칙

- 이 `AGENTS.md`와 `0. 룰북 관련 요청 마스터 프롬프트.md`는 함께 기능 진입점으로 취급한다.
- 폴더 ID·경로·진입점·읽기 순서·기능 경계·외부 데이터 원천·기본 산출물·파일 정책이 바뀌면 두 문서를 함께 점검한다.
- 세부 실행 절차와 품질 규칙은 마스터와 하위 지침에 둔다. 상위 전역 규칙이나 다른 기능이 소유한 정본을 이 폴더에 복제하지 않는다.
- 전역 라우팅이나 파일 정책이 바뀌면 TRPG 데이터 루트·프롬프트 루트 `AGENTS.md`, 프로젝트 기본 지침, 통합 마스터를 함께 갱신한다.
- 새 하위 문서가 진입점·필수 로드 파일·정본 데이터 원천이 되면 이 문서와 마스터의 파일 목록 및 읽기 순서를 함께 수정한다.

## 파일 작업 원칙

- Google Drive에 파일을 직접 생성·업로드·덮어쓰기·삭제·이름 변경하지 않는다.
- 수정본은 실제 적용 경로와 원래 파일명을 유지한 로컬 파일 또는 ZIP으로 제공한다.
- 기존 문서를 교체할 때에는 ZIP 내부 경로에 따라 덮어쓰고, 삭제가 필요한 파일은 별도 목록으로 명시한다.
