# 6. 풍경 생성 AGENTS

## 역할

실내·실외·특수 환경 풍경 생성을 담당한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 풍경 생성 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 풍경 생성 공통 지침.md`와 요청 환경에 맞는 `2. 실내 풍경.md`, `3. 실외 풍경.md`, `4. 특수 환경 풍경.md`
6. `5. 풍경 생성 실패 방지 체크리스트.md`, `라이브러리/풍경 앵커 호출 규칙.md`, 필요 시 `라이브러리/풍경 유형 및 구도 라이브러리.md`

상위 모듈의 공통 붓터치 마감 적용 대상·자동 예외와 이미지 승인 하드 게이트를 먼저 판정한다.

## 그림체 적용 경계

- 별도 정식 스타일 지정이 없는 풍경 생성은 환경 중심의 사용자 지정 스타일·기능성 예외다. 이 기본 모드에서는 `라이브러리/풍경 앵커 호출 규칙.md`의 기존 풍경 05~09를 장소에 맞는 최소 조합으로 사용한다.
- 정식 인물 스타일의 얼굴·나이·전신 앵커를 풍경에 자동 적용하지 않는다.
- 마스터가 `붓터치 반실사` 또는 `애니 페인팅`의 회화적 마감을 명시적으로 요청한 경우에는 `../라이브러리/스타일/정식 스타일 호출 규칙.md`의 해당 비인물 풍경 규칙을 따른다.
- 마스터가 `라인 웹툰`을 명시적으로 선택한 풍경은 예외적으로 정식 스타일 적용 모드로 전환한다. `../라이브러리/견본/라인 웹툰/`의 `04. 라인 마감 앵커.png`와 13~17 환경 앵커를 중앙 호출 규칙에 따라 최소 조합으로 사용하고, `라인 웹툰.md`의 고정 영어 그림체 블록 전체를 원문 그대로 한 번 삽입한다.
- 라인 웹툰 풍경에는 `공통 붓터치 마감 규칙.md`를 적용하지 않으며, 기존 `견본/풍경 앵커/` 05~09와 라인 웹툰 13~17을 자동 혼합하지 않는다.
- 순수 환경 장면에서는 라인 웹툰 01~09 인물 앵커와 10~12 전문 체형 앵커를 자동 적용하지 않는다. 환경 마감 기준인 04와 실제 장소 위험에 필요한 13~17만 사용한다.
- 별도 표면 마감은 장소성·랜드마크·원근을 포함한 환경 아트 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.

## 기능 경계

- 기본 산출물은 장소성·랜드마크·원근을 갖춘 독립 환경 아트다.
- true top-down 배틀맵, 격자, 전술용 토큰 배치는 이 기능의 산출물이 아니다.

## 공용 맵 풍경 저장

- 공용 맵 공간을 위한 확정 풍경은 `11. 맵/<환경>/`에 `<map_code>_<map_title>_풍경.webp`로 저장한다.
- 같은 공간의 공용 맵 문서와 `map_uuid`를 사용하며, 독립 감상용 풍경은 이 저장 규칙의 대상이 아니다.
