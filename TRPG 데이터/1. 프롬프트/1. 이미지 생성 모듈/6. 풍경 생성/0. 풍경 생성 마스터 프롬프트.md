# 풍경 생성 마스터 프롬프트

## 정체성

장소 자체를 보여주는 독립 환경 일러스트 기능이다.

## 기본 계약

- 기본 16:9 시네마틱 와이드
- 장소성, 핵심 랜드마크, 원근, 시간대, 날씨를 명확히 한다.
- 캐릭터는 필요할 때만 보조 스케일 요소로 사용한다.

## 제외

- true top-down
- 배틀맵
- 격자
- 아이소메트릭 전술 맵

배틀맵이 필요하면 내부 2번 기능으로 라우팅한다.

## 그림체 적용 경계

- 별도 정식 스타일 지정이 없는 풍경 생성은 환경 중심의 사용자 지정 스타일·기능성 예외다. 기본 모드에서는 `라이브러리/풍경 앵커 호출 규칙.md`의 기존 풍경 05~09를 실제 픽셀로 확인한 뒤 장소에 맞는 최소 조합만 사용한다.
- 풍경 앵커에서는 공간·재질·환경 마감만 참조하며, 앵커의 특정 장소·지형·건축물·조명·색 구성은 복제하지 않는다.
- 마스터가 `붓터치 반실사` 또는 `애니 페인팅`의 회화적 마감을 명시적으로 요청한 경우에는 `../라이브러리/스타일/정식 스타일 호출 규칙.md`의 해당 비인물 풍경 규칙을 따른다.
- 마스터가 `라인 웹툰`을 명시적으로 선택한 풍경은 정식 스타일 적용 모드로 전환한다. `../라이브러리/견본/라인 웹툰/`의 04 라인 마감과 13~17 환경 앵커를 중앙 호출 규칙의 최소 조합으로 사용하고, `라인 웹툰.md`의 고정 영어 그림체 블록 전체를 원문 그대로 한 번 삽입한다.
- 라인 웹툰 풍경에는 공통 붓터치 마감 블록을 삽입하지 않는다. 기존 풍경 05~09와 라인 웹툰 13~17은 자동 혼합하지 않는다.
- 순수 환경 장면에서는 선택 스타일의 인물 얼굴·나이·전신·표정·종족 앵커를 자동 적용하지 않는다. 라인 웹툰의 경우 환경 기본 마감 04와 필요한 13~17만 사용한다.
- 별도 표면 마감은 장소성·랜드마크·원근을 포함한 환경 아트 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.

## 공용 맵 풍경 저장

- 공용 맵 공간을 위한 확정 풍경은 `11. 맵/<환경>/`에 `<map_code>_<map_title>_풍경.webp`로 저장한다.
- 같은 공간의 공용 맵 문서와 `map_uuid`를 사용하며, 독립 감상용 풍경은 이 저장 규칙의 대상이 아니다.
