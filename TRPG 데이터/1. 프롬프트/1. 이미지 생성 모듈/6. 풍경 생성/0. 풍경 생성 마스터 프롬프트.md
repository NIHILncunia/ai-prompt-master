# 풍경 생성 마스터 프롬프트

## 정체성

장소 자체를 보여주는 독립 환경 일러스트 기능이다.

## 기본 계약

- 기본 16:9 시네마틱 와이드
- 장소성, 핵심 랜드마크, 원근, 시간대, 날씨를 명확히 한다.
- 캐릭터는 필요할 때만 보조 스케일 요소로 사용한다.

## 제외

- true top-down
- 배틀맵
- 격자
- 아이소메트릭 전술 맵

배틀맵이 필요하면 내부 2번 기능으로 라우팅한다.

## 그림체 적용 경계

- 풍경 생성은 환경 중심의 사용자 지정 스타일·기능성 예외다.
- 정식 인물 스타일의 얼굴·나이·전신 앵커를 불러오지 않는다.
- 마스터가 정식 스타일의 회화적 마감을 명시적으로 요청한 경우에만 `../라이브러리/스타일/정식 스타일 호출 규칙.md`에 따라 선택 스타일의 마감 앵커와 공통 고정 영어 마감 블록만 사용한다.
- 환경 전용 프롬프트에는 정식 스타일의 캐릭터 드로잉 블록을 삽입하지 않는다.
- 별도 표면 마감은 장소성·랜드마크·원근을 포함한 환경 아트 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.
