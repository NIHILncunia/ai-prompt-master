# 3. 풍경 일러스트 실패 방지 체크리스트

## 사용 목적

이미지 생성 전 프롬프트와 생성 결과를 점검한다. 하나라도 핵심 항목이 실패하면 수정 프롬프트를 작성하고 다시 승인받는다.

## 1. 기능 라우팅

- [ ] 배틀맵, FVTT, 탑다운, 격자, 전술 공간, scenic prompt yml이 목적이 아닌가?
- [ ] 특정 인물 한 명의 외형과 포즈가 목적이 아닌가?
- [ ] 사건, 전투, 갈등, 감정선이 목적이 아닌가?
- [ ] 장소와 환경 자체가 최종 산출물인가?

배틀맵 전환이 목적이면 2번, 인물 중심이면 1번, 사건 중심이면 5번으로 다시 라우팅한다.

## 2. 산출물

- [ ] 기본 생성 수량이 1장인가?
- [ ] 기본 비율이 16:9 가로인가?
- [ ] 사용자 요청이 있을 때만 세로, 정사각형, 초광각으로 변경했는가?
- [ ] scenic prompt yml, Scene Manifest, Scene Package, 배틀맵을 불필요하게 만들지 않았는가?

## 3. 풍경 중심성

- [ ] 풍경이 이미지에서 가장 먼저 읽히는가?
- [ ] 인물이나 생물이 없어도 완성된 이미지로 성립하는가?
- [ ] 인물과 생물은 규모와 생활상을 보여주는 작은 보조 요소인가?
- [ ] 얼굴, 의상, 무기, 포즈가 주요 초점이 아닌가?
- [ ] 모든 인물이 카메라를 바라보지 않는가?
- [ ] 영웅 포즈나 전투 동작이 없는가?

## 4. 장소 정체성

- [ ] 장소를 한 문장으로 설명할 수 있는가?
- [ ] 기억 가능한 핵심 랜드마크가 하나 있는가?
- [ ] 지형과 건축 양식이 서로 일관적인가?
- [ ] 재료와 풍화가 기후에 맞는가?
- [ ] 도시나 정착지라면 실제 생활과 이동 흔적이 있는가?
- [ ] 종족 풍경이라면 주거와 시설이 종족의 체형·문화·생업에 맞는가?

## 5. 구도와 깊이

- [ ] 전경, 중경, 후경이 분리되는가?
- [ ] 시선이 핵심 랜드마크로 자연스럽게 이동하는가?
- [ ] 스케일 기준 요소가 있는가?
- [ ] true top-down, battlemap, isometric map처럼 보이지 않는가?
- [ ] 분할 패널, 시트, 콜라주, 컨셉 보드 형태가 아닌가?
- [ ] 화면 가장자리에서 핵심 구조물이 어색하게 잘리지 않는가?

## 6. 조명과 가시성

- [ ] 시간대와 날씨가 장소의 성격을 강화하는가?
- [ ] 중요한 지형과 건축이 어둠에 묻히지 않는가?
- [ ] 과도한 안개가 장소 구조를 숨기지 않는가?
- [ ] 발광 입자, 렌즈 플레어, 마법 효과가 화면을 덮지 않는가?
- [ ] 강조색이 핵심 랜드마크에 집중되는가?

## 7. 렌더링과 재질

- [ ] 돌, 나무, 금속, 천, 물, 얼음, 식생의 재질이 구분되는가?
- [ ] 미니어처 디오라마나 장난감 세트처럼 보이지 않는가?
- [ ] 사용자가 요청하지 않은 애니, 카툰, 셀 셰이딩, 평면 2D 스타일이 아닌가?
- [ ] 디테일이 많아도 시각적 노이즈가 과하지 않은가?
- [ ] 서로 다른 원근과 화풍을 붙인 콜라주처럼 보이지 않는가?

## 8. 풍경 앵커 적용

- [ ] `라이브러리/풍경 앵커 호출 규칙.md`을 읽고 실제 사용할 앵커의 픽셀을 확인했는가?
- [ ] 공간감에는 05, 자연·유기 재질에는 06, 건축·실내 재질에는 07, 대기·광원에는 08, 기후·계절 변화에는 09를 장소에 맞게 최소 조합으로 선택했는가?
- [ ] 인물 정식 스타일의 얼굴·연령·체형·표정·종족 앵커와 캐릭터 드로잉 블록을 제외했는가?
- [ ] 앵커의 산악 풍경·폭포·성채 홀·배너·가구·고정 팔레트와 구도를 복제하지 않았는가?
- [ ] 08에서는 색온도·광원·공기 원근만, 09에서는 날씨·계절이 남긴 물리적 환경 변화만 참조했는가?

## 9. 설정 정합성

- [ ] 사용자의 최신 지시를 최우선으로 반영했는가?
- [ ] 기존 세계관 장소라면 5번 정본과 충돌하지 않는가?
- [ ] 공식 D&D 정보가 필요하면 4번 근거를 확인했는가?
- [ ] 종족 풍경이라면 공통 종족 데이터의 시각 표현 데이터와 충돌하지 않는가?
- [ ] 확인되지 않은 설정을 공식 사실처럼 추가하지 않았는가?

## 10. 금지 요소

- [ ] 텍스트, 자막, 라벨, 로고가 없는가?
- [ ] UI, 프레임, 테두리, 워터마크가 없는가?
- [ ] 보이는 격자와 토큰 표시가 없는가?
- [ ] 캐릭터 시트나 지도 아이콘이 없는가?
- [ ] 현대 물품과 기술이 설정에 맞지 않게 섞이지 않았는가?

## 최종 판정

다음 문장을 만족해야 승인 가능한 결과다.

```text
이 이미지는 인물이나 전술 공간이 아니라 장소 자체를 보여주는 완성된 풍경 일러스트이며, 한눈에 장소의 정체성·스케일·문화·기후가 읽힌다.
```
