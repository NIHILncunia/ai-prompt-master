# 풍경 앵커 호출 규칙

## 목적과 범위

이 문서는 내부 6번 풍경 생성의 환경 앵커 역할·선택 규칙을 정한다. 기본 풍경 모드는 기존 환경 앵커 05~09를 사용하고, 정식 스타일 `라인 웹툰`이 명시된 풍경은 별도의 라인 웹툰 환경 앵커 04·13~17을 사용한다.

- 인물의 얼굴·연령·체형·표정·종족 앵커는 풍경 생성에 사용하지 않는다.
- 풍경 앵커는 화풍·재질·공간 처리만 참조한다. 앵커 속 산악 지형, 폭포, 성채 홀, 배너, 가구, 시간대, 팔레트, 카메라, 구도를 복제하지 않는다.
- 사용자 제공 장소 레퍼런스와 확정된 세계관·건축·기후 정보가 앵커보다 우선한다.
- 최종 영어 프롬프트 공개 전, 선택한 앵커의 실제 픽셀을 확인하고 요구사항 확인서에 사용·제외 앵커와 사유를 기록한다.

라인 웹툰 환경에서는 04를 기본으로 유지하고 13~17 중 직접 필요한 역할만 추가한다. 01~09의 인물 앵커와 10~12 전문 체형 참고는 순수 환경 요청에 자동 적용하지 않는다.

## 선택 규칙

### 기본 풍경 모드

- 별도 정식 스타일 지정이 없으면 기존 `견본/풍경 앵커/` 05~09 체계를 사용한다.
- 넓은 실외·도시 전경·원거리 지형은 05를 사용한다.
- 자연 지형과 식생·물·암석이 주된 장소는 05와 06을 함께 사용한다. 근접 자연 디테일처럼 원근이 주제가 아닌 경우에는 06만 사용할 수 있다.
- 건축 외관·정착지 전경은 05와 07을 사용한다. 실내 또는 건축 재질이 핵심인 장소는 07을 사용하며, 넓은 실내의 공간감까지 필요할 때만 05를 더한다.
- 시간대·광원 방향·색온도 대비·공기 원근이 장소의 판독성과 분위기를 좌우하면 08을 추가한다.
- 계절·비·눈·바람·습기·먼지와 그에 따른 젖음·침적·흔들림·표면 변화가 장소 상태를 결정하면 09를 추가한다.

### 라인 웹툰 풍경 모드

마스터가 정식 스타일 `라인 웹툰`을 명시한 경우 아래 조합을 사용한다.

- 넓은 실외·도시 전경·광역 지형: `04 + 13`
- 자연 지형·숲·계곡·수변: `04 + 13 + 14`
- 근접 자연 재질이 핵심이고 광역 원근이 중요하지 않음: `04 + 14`
- 건축 외관·정착지 전경: `04 + 13 + 15`
- 실내·건축 재질이 핵심: `04 + 15`
- 넓은 실내에서 공간감과 건축 재질이 모두 핵심: `04 + 13 + 15`
- 시간대·광원 방향·색온도·안개/시정거리 변화가 핵심: 위 장소 조합 + `16`
- 비·눈·바람·습기·계절·적설·결빙이 장소 상태를 결정: 위 장소 조합 + `17`
- 대기·광원과 기후·계절이 모두 핵심일 때만 16과 17을 함께 사용한다.

두 모드 모두 필요 이상의 앵커를 넣지 않는다. 사용자 제공 장소 레퍼런스와 확정 세계관·건축·기후 정보가 앵커보다 우선하며, 실제 사용할 모든 앵커의 픽셀을 최종 프롬프트 공개 전에 확인한다. 기본 풍경 05~09와 라인 웹툰 13~17은 서로 다른 스타일 체계이므로 자동 혼합하지 않는다.

라인 웹툰 풍경에서는 `라인 웹툰.md`의 고정 영어 그림체 블록 전체를 한 번 삽입하고 공통 붓터치 마감 블록은 삽입하지 않는다. 기본 풍경 모드는 기존 기능성 예외 규칙을 따른다.

## 마감 기준과 금지

- 읽기 쉬운 형태와 재질을 먼저 확보한다. 기본 풍경 모드에서는 초점·재질·거리별로 크기와 밀도가 달라지는 통제된 붓터치를 적용하고, 라인 웹툰 모드에서는 선 계층·2~3단 셀식 명암·그래픽 색면으로 같은 역할을 수행한다.
- 전체 화면을 같은 크기의 두꺼운 임파스토, 팔레트 나이프 질감, 균일한 거친 붓결로 덮지 않는다.
- 사진, CGI, 미니어처 디오라마, 콜라주, 콘셉트 보드, 지도, 격자·텍스트·라벨로 바꾸지 않는다.
- 원근·랜드마크·기후·장소성을 흐리게 하는 과도한 안개·발광 효과를 사용하지 않는다.
