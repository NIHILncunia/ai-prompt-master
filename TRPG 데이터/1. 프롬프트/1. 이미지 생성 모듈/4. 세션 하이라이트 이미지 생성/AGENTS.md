# 4. 세션 하이라이트 이미지 생성 AGENTS

세션 하이라이트 이미지를 담당한다.

읽기 순서:
1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 세션 하이라이트 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 세션 하이라이트 공통 지침.md`
6. 장면 유형 문서 선택
7. `../라이브러리/스타일/정식 스타일 호출 규칙.md`에서 그림체 적용 방식, 주 프레이밍과 참조 예산 판정
8. 정식 스타일 적용 시 선택 스타일 계약과 실제 앵커 픽셀 확인

상위 모듈의 제공 이미지 그림체 보존 규칙, 정식 스타일 앵커 하드 게이트와 이미지 승인 절차를 먼저 판정한다.

핵심 계약:

- 이미지 생성은 공통 승인 절차를 적용하고 마스터의 명시적 승인을 받은 뒤에만 실행한다.
- 별도 스타일 변경 지시가 없으면 서로 호환되는 모든 확인된 캐릭터 레퍼런스의 그림체와 마감을 보존한다.
- 여러 핵심 레퍼런스의 그림체가 충돌하면 임의로 혼합하지 않고 마스터에게 장면 전체에 사용할 단일 기준 그림체 하나를 확인한다.
- 정식 스타일 변경이 명시된 경우 레퍼런스는 디자인 기준, 정식 앵커는 스타일 전용 기준으로 분리하고 디자인 기준 이미지를 스타일 앵커보다 먼저 배정한다.
- 장면의 지배적 프레이밍을 얼굴 중심 또는 전신·행동 중심으로 분류하고 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 반환한 앵커 목록을 사용한다.
- 여러 캐릭터 레퍼런스가 참조 예산을 차지해 활성 앵커를 줄이면 제외한 모든 앵커와 각 제외 사유를 요구사항 확인서에 기록한다.
- 스타일 앵커의 의상·팔레트·포즈·카메라·배경·장면 구성은 가져오지 않는다.
