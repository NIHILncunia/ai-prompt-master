# 세션 하이라이트 이미지 생성

세션의 핵심 장면이나 분위기를 압축적으로 보여주는 이미지 기능이다.

단일 장면형, 인물 중심형, 단체 장면형, 정보 포함형으로 분기할 수 있다.

확인된 캐릭터 레퍼런스 이미지가 있으면 별도 스타일 변경 지시가 없는 한 서로 호환되는 모든 그림체와 마감을 보존한다. 핵심 레퍼런스의 그림체가 충돌하면 장면 전체에 사용할 단일 기준 그림체 하나를 확인한 뒤 진행한다.

정식 스타일 변환이 명시되면 디자인 기준 이미지를 스타일 앵커보다 먼저 배정하고, 장면의 지배적 프레이밍을 얼굴 중심 또는 전신·행동 중심으로 분류하여 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 반환한 앵커 목록을 사용한다. 참조 예산으로 빠진 모든 앵커와 사유는 요구사항 확인서에 기록한다.
