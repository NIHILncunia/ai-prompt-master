# 이미지 생성 공통 AGENTS

## 최우선 실행·저장·진행 정책

이 섹션은 전역 지침과 하위 기능 문서에 남아 있는 이전 파일 정책, `다음` 해석, 로컬·ZIP 제공 규칙과 충돌할 때 최우선으로 적용한다.

### 최신 정본

- 실행 규칙과 자료 구조는 Google Drive의 최신 정본을 기준으로 한다.
- 프로젝트 소스 사본, 오래된 로컬 사본, 캐시된 파일 ID는 읽기 전용 참고 자료일 뿐 현재 정본을 대체하지 않는다.
- 캐시된 경로나 ID가 실제 Drive 구조와 다르면 실제 폴더·파일 조회 결과를 우선하고, 현재 구조에 맞춰 라우팅한다.

### 데이터 생성·수정의 즉시 Drive 반영

- 이미지, 토큰, 레퍼런스 시트, 풍경, 배틀맵, 지도, 아이콘, 세션 문서, 설정 문서, 룰북 인덱스, Highlight Card, 스탯블록, 아이템, 특성, 능력, 클래스, 인물 데이터와 같이 **지속 보관할 데이터**를 새로 생성하거나 수정하면, 생성·수정 직후 해당 정본 경로에 Drive 직접 생성·업로드·갱신을 먼저 시도한다. 이후 검수·확정으로 내용이 바뀌면 같은 정본 파일을 다시 갱신한다.
- 기존 정본 파일을 갱신하는 경우에는 원본 파일명과 Drive 파일 ID를 유지하는 교체 업로드를 우선한다. 신규 정본이면 기능별 기본 경로에 새 파일을 만든다.
- 실제 Drive 쓰기 결과를 확인하기 전에는 반영 완료라고 보고하지 않는다.

### 비데이터 결과의 업로드

- 준비 안내, 채팅 답변, 조회 결과, 검토 의견, 선택지, 작업 중간 설명처럼 지속 보관 데이터가 아닌 결과는 자동 업로드하지 않는다.
- 마스터가 업로드·저장·반영·교체를 요청하면, 해당 결과도 Drive 직접 업로드를 먼저 시도한다.

### Drive 업로드 실패 시 대체 산출물

- Drive 직접 생성·업로드·갱신이 도구 또는 권한 문제로 실패하면, 같은 상대 경로와 원본 파일명을 보존한 ZIP을 제공한다.
- ZIP은 Drive 직접 반영의 대체 수단이며 기본 산출물이 아니다.
- Drive 반영이 실패했을 때에는 실패 사실과 ZIP 제공 사실을 구분해 보고한다.

### `다음`의 전역 의미

- 마스터의 `다음`은 언제나 **직전에 제시된 현재 단계의 결과·판단·초안을 확정하고, 다음 정의된 프로세스로 즉시 진행하라**는 뜻이다.
- 확인서, 최종 프롬프트, 설계 골격, 장면 목록, 데이터 초안, 검수 결과처럼 확정 가능한 결과가 제시된 직후의 `다음`에는 추가 확인 질문을 하지 않는다.
- 이미지 확인서와 최종 영어 프롬프트가 제시된 뒤의 `다음`은 해당 생성 배치 승인으로 처리한다. 생성·검수 뒤의 `다음`은 생성 결과를 채택하고 다음 산출물 또는 다음 처리 단계로 진행한다.
- 아직 확정 대상으로 제시된 결과가 없는 상태에서의 `다음`도 현재 절차를 가능한 다음 필수 단계로 진행한다. 다만 대상명·파일 경로처럼 현재 자료만으로 안전하게 판정할 수 없는 필수 정보는 임의로 발명하지 않고, 확인 가능한 범위까지 진행한 뒤 정확한 차단 지점만 표시한다.
- 하위 문서의 `다음` 해석이 이 정책과 다르면 이 정책을 우선한다.


## 역할

모든 이미지 하위 기능에서 공유하는 승인·확인·자료 탐색·생성 후 자가검수·결과 보고 규칙을 관리한다.

## 읽기 순서

0. 이미지 생성 공통 운영 지침
1. 이미지 생성 공통 승인 절차
2. 요구사항 확인서 작성 규칙
3~5번은 요청 조건에 따라 읽는다.
6. `6. 이미지 생성 프롬프트 점검 및 교정 지침.md`는 요구사항 확인서와 최종 영어 프롬프트를 공개하기 직전에 반드시 읽고 적용한다.

## 생성 전 공통 의무

- 요구사항 확인서 초안과 최종 영어 프롬프트 초안을 작성한 뒤 6번 지침의 P01~P10을 검사한다.
- 실패 항목은 승인 요청 전에 자동 교정하고 처음부터 다시 검사한다.
- `프롬프트 점검 결과: 통과`가 아니면 문안을 확정하거나 생성을 승인받지 않는다.

## 생성 후 공통 의무

- 생성 결과만 제시하고 종료하지 않는다.
- 생성 직후 공통 승인 절차의 자가검수를 수행하고, 사용 권고 또는 재생성 권고를 근거와 함께 마스터에게 제시한다.
- 재생성이 필요해도 자동으로 다시 생성하지 않는다. 수정 요구사항 확인서와 최종 영어 프롬프트를 다시 공개한 뒤 마스터의 명시적 승인을 받는다.
- 자가검수 통과 여부와 무관하게 결과 응답의 최하단에 `SESSION PROGRESS`를 표시한다.

## 금지

기능별 산출물 규격이나 화풍 세부 규칙을 이 폴더에 복제하지 않는다. 6번 지침은 해당 정본을 다시 읽고 대조하는 절차만 소유한다.
