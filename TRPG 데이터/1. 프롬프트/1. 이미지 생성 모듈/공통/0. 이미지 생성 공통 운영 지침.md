# 0. 이미지 생성 공통 운영 지침

## 적용 범위

이미지 생성 모듈의 모든 하위 기능에 적용한다.

## 기본 흐름

요청 해석 → 기능 선택 → 필요한 자료 확인 → 요구사항 확인서·최종 영어 프롬프트 초안 → 프롬프트 점검·자동 교정 → 통과본 공개 → 승인(`다음` 포함) → 생성 직전 재확인 → 생성 → 자가검수 → 결과 보고·판정 → 필요 시 재생성 재승인

기능 고정 계약과 공통 승인 절차를 분리한다. 공통 절차는 승인 상태만 관리하고, 출력 수·비율·레이아웃은 각 기능 계약이 관리한다.

`다음`은 요구사항 확인서와 최종 영어 프롬프트 공개 직후에는 생성 승인으로, 그 이전에는 절차 진행으로, 생성 완료 후에는 새 산출물 요청으로 해석한다.

요구사항 확인서와 최종 영어 프롬프트는 `6. 이미지 생성 프롬프트 점검 및 교정 지침.md`의 모든 필수 항목을 통과한 뒤에만 공개한다. 실패한 문안은 정본을 다시 읽어 자동 교정하고 처음부터 재검사한다.

생성 뒤에는 결과를 요구사항·산출물 계약·시각 품질 기준으로 자가검수한다. 통과 여부와 무관하게 검사 근거와 사용 또는 재생성 권고를 공개하며, 결과 응답의 최하단에는 `SESSION PROGRESS`를 표시한다. 재생성 권고는 자동 재생성이 아니라 수정 확인서·최종 영어 프롬프트의 재공개와 마스터 재승인을 요구한다.
