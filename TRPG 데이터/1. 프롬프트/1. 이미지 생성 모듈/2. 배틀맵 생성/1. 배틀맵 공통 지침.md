# 배틀맵 공통 지침

- true top-down 시점을 유지한다.
- 원근감 때문에 벽이나 오브젝트가 전투 공간을 가리는 표현을 피한다.
- 이동 가능/불가 영역, 엄폐물, 문, 통로, 고저차가 읽혀야 한다.
- 장식보다 실제 전투 배치와 이동 동선을 우선한다.
- 기본은 gridless이며, 격자가 필요할 때만 추가한다.
- 사전 풍경의 분위기는 계승하되 카메라 시점은 배틀맵 계약을 따른다.

- 배틀맵은 정식 스타일 앵커 자동 호출 대상이 아니다. `라인 웹툰` 01~17도 자동 적용하지 않으며, 스타일 요청이 있어도 true top-down 전술 판독성을 해치지 않는 표면 언어만 제한적으로 반영한다.
- 스타일 표현 때문에 벽 높이, 원근, 오브젝트 외곽, 대기 효과가 이동 가능 영역·엄폐·통로·고저차 판독을 가리면 스타일 표현을 버리고 기능 계약을 우선한다.
