# 3. 캐릭터 레퍼런스 생성 AGENTS

캐릭터 레퍼런스 시트 생성을 담당한다.

읽기 순서:
1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 캐릭터 레퍼런스 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 캐릭터 레퍼런스 공통 지침.md`
6. `2. 레퍼런스 시트 구성 규칙.md`
7. `3. 정보 영역 규칙.md`
8. `../라이브러리/스타일/정식 스타일 호출 규칙.md`에서 그림체 적용 방식과 소스별 앵커 조합 판정
9. 정식 스타일 적용 시 선택 스타일 계약과 실제 앵커 픽셀 확인

상위 모듈의 제공 이미지 그림체 보존 규칙, 정식 스타일 앵커 하드 게이트와 이미지 승인 절차를 먼저 판정한다.

핵심 계약:

- 이미지 생성은 공통 승인 절차를 적용하고 마스터의 명시적 승인을 받은 뒤에만 실행한다.
- 제공 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 디자인과 그림체를 그대로 따른다.
- 제공 이미지 없이 새로 만들 때에는 마스터가 지정한 화풍을 사용한다. 화풍도 기준 이미지도 없으면 임의로 정식 스타일을 선택하지 않고 요구사항 확인 단계에서 확인한다.
- 명시적으로 `애니 페인팅` 또는 `붓터치 반실사`로 바꾸는 경우 제공 이미지는 디자인 기준, 정식 앵커는 스타일 전용 기준으로 분리한다.
- 신규 생성 또는 명시적 정식 스타일 변환에서는 메인 흉상 소스를 얼굴·흉상, 정면·후면 전신 소스를 반신·전신으로 분류하고, 각 생성의 실제 앵커 목록을 `../라이브러리/스타일/정식 스타일 호출 규칙.md`에서 받는다.
- 디자인 기준 이미지가 있으면 스타일 앵커보다 우선 배정하고, 참조 예산으로 제외한 모든 앵커와 사유를 요구사항 확인서에 기록한다.
- 생성한 캐릭터 레퍼런스 시트는 대상의 자산 폴더에 `<대상> 레퍼런스 시트 V1.webp`로 저장한다. V2부터는 동일 대상 폴더에서 버전만 올리며, 기존 파일은 덮어쓰지 않는다.
