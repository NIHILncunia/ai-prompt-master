# 캐릭터 레퍼런스 마스터 프롬프트

## 고정 출력 계약

- 가로 16:9 시트
- 정확히 3개의 캐릭터 표현
  1. 좌측 소개 영역의 메인 흉상
  2. 우측 정면 전신
  3. 우측 후면 전신
- cm 단위 키 기준선을 포함한다.

## 목적

동일 캐릭터의 외형을 재사용할 수 있도록 정보 중심의 레퍼런스 시트를 만든다.

## 그림체 기준

- 사용자 제공 이미지 또는 이전 확정 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 그림체와 마감을 그대로 따른다.
- 기준 이미지가 여러 장이고 그림체가 충돌하면 임의로 혼합하지 않고 마스터에게 기준을 확인한다.
- 제공 이미지 없이 새로 만드는 경우 마스터가 지정한 화풍을 사용한다. 화풍 지정도 없으면 요구사항 확인 단계에서 확인한다.
- `애니 페인팅` 또는 `붓터치 반실사`로 변경하라는 명시가 있으면 제공 이미지는 디자인 기준으로만 사용하고 선택 스타일의 정식 앵커와 고정 영어 블록을 적용한다.
- 신규 생성 또는 명시적 정식 스타일 변환에서는 메인 흉상 소스를 얼굴·흉상, 정면·후면 전신 소스를 반신·전신으로 분류한다.
- 각 소스 생성은 그림체 적용 방식, 선택 정식 스타일, 산출물 구도 분류, 디자인 기준 이미지 수와 도구 전체 이미지 참조 한도를 `../라이브러리/스타일/정식 스타일 호출 규칙.md`에 전달하고 반환된 앵커 목록을 사용한다.
- 디자인 기준 이미지가 있으면 스타일 앵커보다 우선 배정한다. 참조 예산으로 제외한 모든 앵커와 각 제외 사유는 요구사항 확인서에 기록한다.
- 최종 시트 조립은 생성한 세 소스의 그림체와 마감을 일치시키며, 별도 정식 스타일 패스를 다시 적용하지 않는다.

## 저장

완료된 캐릭터 레퍼런스 시트는 대상의 자산 폴더에 `<대상> 레퍼런스 시트 V1.webp`로 저장한다. 후속 시트는 같은 폴더에서 V2부터 순차로 올리며, 기존 파일은 덮어쓰지 않는다.
