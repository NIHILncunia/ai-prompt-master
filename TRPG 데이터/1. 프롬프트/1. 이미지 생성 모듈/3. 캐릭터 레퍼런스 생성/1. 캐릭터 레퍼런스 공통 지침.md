# 캐릭터 레퍼런스 공통 지침

- 배경 연출보다 캐릭터 정보 전달을 우선한다.
- 동일 인물의 얼굴·의상·신체 특징을 세 표현에서 일치시킨다.
- 제공 이미지의 그림체·선 처리·채색·재질 마감을 세 표현에서 일치시킨다. 별도 스타일 변경 지시가 없으면 공통 마감이나 정식 스타일을 덧씌우지 않는다.
- 스타일 변경이 명시된 경우 캐릭터 디자인은 제공 이미지에서, 그림체와 마감은 선택 스타일 계약에서 가져오며 두 역할을 섞지 않는다.
- 종족 고유 신체 구조는 설정 문서나 대상 라이브러리의 사실 정보를 따른다.
- 시트는 장면 이미지가 아니라 제작·재현용 자료다.
