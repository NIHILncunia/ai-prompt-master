# 캐릭터 레퍼런스 생성

캐릭터 레퍼런스는 설정 확인과 재사용을 위한 시트형 결과물이다.

기본적으로 16:9 시트를 중심으로, 바이오·흉상·정면·후면·키 정보를 포함한다.

제공 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 그림체와 마감을 기본 보존한다. 다른 정식 스타일로 변경할 때에만 제공 이미지를 디자인 기준으로 두고 선택 스타일의 정식 앵커를 스타일 전용으로 적용한다.

신규 생성 또는 명시적 정식 스타일 변환에서는 메인 흉상과 전신 소스를 각각 얼굴·흉상 또는 반신·전신으로 분류하고, `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 반환한 앵커 목록을 사용한다.
