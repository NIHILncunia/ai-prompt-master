# 7. 게임 아이콘 생성 AGENTS

## 역할

게임용 아이콘 생성을 담당한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 게임 아이콘 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 게임 아이콘 공통 지침.md`, `2. 아이콘 스타일 규칙.md`, `3. 출력 구성 규칙.md`, `4. 용도별 아이콘 분기.md`, `5. 게임 아이콘 실패 방지 체크리스트.md`
6. 필요 시 `라이브러리/아이콘 유형 및 시각 언어 라이브러리.md`와 상위 `../라이브러리/레이아웃/`

상위 모듈의 공통 붓터치 마감 적용 대상·자동 예외와 이미지 승인 하드 게이트를 먼저 판정한다. 게임 아이콘은 공통 붓터치 마감의 자동 적용 예외다.

## 그림체 적용 경계

- 게임 아이콘 기능 자체는 일반 인물·환경 정식 스타일의 `사용자 지정 스타일·기능성 예외`에 속한다.
- `붓터치 반실사`, `애니 페인팅`, `라인 웹툰` 등 일반 정식 스타일 앵커는 게임 아이콘에 자동 적용하지 않는다.
- 비아이템 스킬·주문·액션·특성·버프·디버프·상태·속성·자원 아이콘은 기능 예외 내부의 정식 `게임 스킬 아이콘` 계약을 기본 적용한다.
- 정식 계약은 `../라이브러리/스타일/게임 스킬 아이콘.md`이며, 역할별 앵커는 `../라이브러리/견본/게임 스킬 아이콘/`에서 최소 조합으로 호출한다.
- 1:1 구성, 64×64 판독성, 단일 핵심 개념, 실루엣, 아이콘과 배경의 분리 등 기능 전용 계약이 모든 표면 스타일보다 우선한다.
- 사용자가 `라인 웹툰풍 게임 아이콘`처럼 별도 스타일을 명시하면 `게임 스킬 아이콘`의 기능 계약은 유지하되, 선명한 외곽선·평면 색 분리·제한된 셀식 명암처럼 작은 크기에서 유지되는 표면 언어만 덧씌운다. 라인 웹툰 01~17 앵커와 고정 영어 블록은 자동 삽입하지 않는다.
- 특정 일반 스타일 앵커를 직접 참조하라는 명시 지시가 있을 때에만 기능 계약과 충돌하지 않는 범위에서 개별 참조를 검토하고 요구사항 확인서에 공개한다.
- 실제 예외 판정과 기능 전용 정식 스타일 호출은 `../라이브러리/스타일/정식 스타일 호출 규칙.md`를 따른다.

## 핵심 계약

- 기본 산출물은 프레임 없는 1:1 게임 아이콘이며, 다중 생성은 **3×3 슬롯 시트**를 기본 단위로 사용한다.
- 3×3 시트의 실제 아이콘은 좌상단부터 행 우선 순서로 채우고, 9개를 초과하면 같은 배치에서 3×3 시트를 여러 장 생성한다.
- 생성 도구가 반환한 3×3 시트는 슬롯 구조가 정상이라면 **그 이미지 자체를 최종 정본으로 보존**한다. 고정 512×512 슬롯 또는 1536×1536 시트 크기를 강제하지 않는다.
- 생성된 3×3 시트를 자동으로 슬롯 분할·크롭·리사이즈·재합성하지 않으며, 낱개 아이콘 파일을 자동 저장하지 않는다. 개별 아이콘 추출은 마스터가 별도로 요청한 후속 파생 작업에서만 수행한다.
- 모든 **실제 아이콘 슬롯**은 비투명 배경색 또는 비투명 추상 배경면을 캔버스 전체에 반드시 채운다. 배경은 피사체의 속성·주색·명도·발광과 조화되는 명확한 색감을 가져야 하며, 순수 검정·거의 검정·검정/차콜을 기본 배경으로 사용하는 것을 금지한다. 반대로 **빈 슬롯만 예외적으로 순수 검정 배경**을 사용한다. 투명 픽셀·알파 홀·무채움 영역·의도되지 않은 빈 캔버스를 허용하지 않는다.
- 아이템·소비품·재료·무기·방어구·장비 아이콘은 공통 비투명 배경 계약 위에서 피사체의 주색·명도·발광에 맞춘 추상 배경을 사용한다. 배경은 흐린 색면, 가우시안 블러, 절제된 안개를 허용하되 풍경·바닥·실내 장면으로 만들지 않는다.
- 아이템 세트는 아이템별 배경색을 대비에 맞게 조정하되, 흐림 정도·안개 밀도·조명 방향·여백·렌더링 밀도는 공통으로 유지한다. 스킬·상태·UI 아이콘에는 이 아이템 전용 계약을 적용하지 않는다.
- 캐릭터가 포함된 완성형 VTT 토큰 요청은 내부 1번 반실사 포트레이트로 라우팅한다.

- 다중 시트는 `생성 → 3×3 구조·수량·슬롯 순서·경계 침범·64px 판독성 검수 → 원본 시트 저장` 순서로 처리한다. 구조 실패를 후처리 분할·재합성으로 숨기지 않고 재생성 권고 대상으로 판정한다.
- 게임 아이콘 배치 정본은 `TRPG 데이터/22. 아이콘 생성`에 저장한다. 스킬 배치는 `TRPG 데이터/22. 아이콘 생성/스킬 아이콘`, 아이템 배치는 `TRPG 데이터/22. 아이콘 생성/아이템 아이콘`을 사용한다.
- 배치마다 `<YYYY MMDD> <상위 폴더명> <NN>` 폴더를 만들고 같은 이름의 `.md` 인덱스를 둔다. 예: `2026 0912 스킬 아이콘 01/2026 0912 스킬 아이콘 01.md`.
- 한 배치의 시트가 1장이면 `<배치명>.png`, 여러 장이면 `<배치명>-1.png`, `<배치명>-2.png`처럼 저장한다. MD에는 모든 이미지 파일명과 각 3×3 슬롯의 행 우선 내용을 기록한다.
