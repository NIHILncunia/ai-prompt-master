# 게임 아이콘 공통 지침

- 작은 크기 판독성을 가장 우선한다.
- 한 아이콘에 여러 핵심 개념을 동시에 넣지 않는다.
- 배경과 아이콘 경계가 명확해야 한다.
- 프레임 없는 형태를 기본으로 한다.
- 다중 생성의 최종 패키징은 **3×3 슬롯 시트**를 사용한다.
- 시트와 슬롯의 픽셀 크기는 생성 도구의 원본을 보존하며 512×512 / 1536×1536로 자동 정규화하지 않는다.
- 실제 아이콘은 좌상단부터 행 우선 순서로 채운다.
- 빈 슬롯은 **검정 배경**으로 둔다.
- 실제 아이콘 슬롯에는 피사체의 속성·주색·명도·발광과 조화되는 비투명 유색 배경색 또는 유색 추상 배경면을 반드시 넣고 캔버스 가장자리까지 완전히 채운다. 순수 검정·거의 검정·검정/차콜 기본 배경은 금지한다. 투명 픽셀·알파 홀·무채움 영역·의도되지 않은 빈 캔버스를 남기지 않는다.
- 9개를 초과하는 다중 생성은 3×3 시트를 여러 장으로 분할한다.
- 일반 인물·환경 정식 스타일 앵커는 자동 적용하지 않는다. `라인 웹툰` 01~17도 게임 아이콘의 기본 참조가 아니다.
- 스킬·주문·액션·특성·버프·디버프·상태·속성·자원 등 비아이템 아이콘은 `../라이브러리/스타일/게임 스킬 아이콘.md`의 정식 기능 스타일과 역할별 최소 앵커 조합을 적용한다.
- `라인 웹툰풍`이 요청되면 게임 스킬 아이콘 기능 계약을 유지한 채 64×64 판독성을 해치지 않는 선명한 외곽선·평면 색 분리·제한된 셀식 명암만 선택적으로 반영하고, 라인 웹툰 고정 영어 그림체 블록이나 01~17 앵커 세트를 자동 호출하지 않는다.
- 아이템·소비품·재료·무기·방어구·장비는 공통 비투명 배경 계약 위에서 피사체 대비에 맞춘 추상 배경을 사용한다. 배경은 단색일 필요가 없으며, 흐린 색면·가우시안 블러·절제된 안개를 사용할 수 있다.
- 다중 아이템 세트에서는 선 굵기, 재질 표현, 명암, 흐림 정도, 안개 밀도, 조명 방향, 여백을 잠근다. 배경색은 개별 아이템의 색과 명도에 맞춰 달라질 수 있다.
- 아이템이 아닌 스킬·상태·UI 아이콘도 속성과 효과에 맞춘 유색 비투명 배경을 사용한다. `컷아웃 친화적`은 투명 배경을 뜻하지 않고, 피사체 외곽이 배경에서 명확히 분리되어 후처리가 쉬워야 한다는 의미다.
- 생성된 3×3 시트는 구조가 정상이라면 원본 이미지 자체를 최종 정본으로 사용한다. 자동 슬롯 분할·리사이즈·재합성·낱개 저장을 하지 않는다.
- 구조 실패는 후처리 보정 대상이 아니라 재생성 권고 대상이다. 검수용 축소 미리보기는 허용하지만 정본을 변경하지 않는다.
- 배치 정본은 `TRPG 데이터/22. 아이콘 생성/스킬 아이콘` 또는 `TRPG 데이터/22. 아이콘 생성/아이템 아이콘` 아래에 `<YYYY MMDD> <상위 폴더명> <NN>` 폴더 단위로 저장한다. 배치 내부에 동명의 `.md`와 3×3 시트 이미지를 함께 둔다.
- 시트가 1장이면 `<배치명>.png`, 여러 장이면 `<배치명>-1.png`, `<배치명>-2.png`처럼 번호를 붙인다.
