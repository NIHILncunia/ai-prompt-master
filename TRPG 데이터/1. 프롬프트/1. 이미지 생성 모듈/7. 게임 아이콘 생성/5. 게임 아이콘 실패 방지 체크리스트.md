# 3. 게임 아이콘 실패 방지 체크리스트

## 사용 방법

최종 영어 프롬프트를 공개하기 전과 생성 결과를 검수할 때 각각 한 번씩 확인한다. 하나라도 실패하면 해당 항목을 수정하고, 수정 요구사항 확인서와 최종 영어 프롬프트를 다시 공개해 마스터의 명시적 승인을 받은 뒤에만 다시 생성한다.

## A. 라우팅

- [ ] 게임 UI에서 사용할 아이콘 이미지가 목적이다.
- [ ] 규칙 데이터, 스탯블록, 주문 설명 요청이 아니다.
- [ ] FVTT 자동화나 액티브 이펙트 설정 요청이 아니다.
- [ ] 캐릭터가 포함된 완성형 VTT 토큰 요청이 아니다.
- [ ] 캐릭터 포트레이트, 풍경, 배틀맵, 하이라이트 장면 요청이 아니다.

## B. 캔버스

- [ ] 1:1 정사각형이 명시되어 있다.
- [ ] 한 이미지에 아이콘 하나만 있다.
- [ ] 피사체가 캔버스의 약 70~85%를 차지한다.
- [ ] 사방에 8~12% 안전 여백이 있다.
- [ ] 끝부분, 불꽃, 파편, 날개, 무기 날이 잘리지 않는다.

## C. 프레임

- [ ] 아이콘 프레임이 없다.
- [ ] 원형 테두리, 배지 림, 카드 베젤이 없다.
- [ ] 캔버스 외곽을 따라 닫힌 발광 링이 없다.
- [ ] 마법진이나 고리가 있다면 중앙의 핵심 대상이며 외곽 프레임이 아니다.
- [ ] 완성형 VTT 토큰용 원형 프레임이 없다.

## D. 배경

- [ ] 아이템·소비품·재료·무기·방어구·장비는 비투명 배경을 포함한다.
- [ ] 아이템 배경색은 피사체의 주색·명도·발광과 가장자리 대비를 기준으로 선택했다.
- [ ] 아이템 배경은 흐린 색면, 부드러운 그라데이션, 가우시안 블러, 절제된 국소 안개 중 필요한 처리만 사용한다.
- [ ] 아이템이 아닌 아이콘은 회색 또는 검은색 계열의 단순 무광 배경 계약을 유지한다.
- [ ] 풍경, 바닥, 방, 탁자, 벽, 하늘이 없다.
- [ ] 투명 체크무늬를 그리지 않았다.
- [ ] 어두운 피사체가 어두운 배경에 묻히지 않았으며, 필요하면 저채도 대비 배경과 절제된 림라이트를 사용했다.
- [ ] 피사체와 배경의 가장자리 대비가 충분하다.
- [ ] 배경 처리나 안개가 피사체 외곽을 가리거나 캔버스 끝까지 번지지 않는다.

## E. 중심 대상

- [ ] 핵심 개념이 하나다.
- [ ] 보조 요소는 0~2개다.
- [ ] 작은 크기에서 무엇인지 알아볼 수 있다.
- [ ] 캐릭터 전신이나 복잡한 장면이 들어가지 않았다.
- [ ] 긴 물체는 전체 형태가 읽히는 대각선 또는 수직 구도다.
- [ ] 상태와 스킬은 방향성과 효과의 중심이 명확하다.

## F. 재질과 효과

- [ ] 금속, 유리, 가죽, 목재, 돌, 보석의 재질이 구분된다.
- [ ] 모든 부분이 동일하게 발광하지 않는다.
- [ ] 과도한 블룸과 렌즈 플레어가 없다.
- [ ] 연기와 입자가 캔버스 끝까지 퍼지지 않는다.
- [ ] 큰 투영 그림자나 바닥 접지 그림자가 없다.
- [ ] 피사체 외곽이 효과에 묻히지 않는다.

## G. 텍스트와 UI

- [ ] 텍스트가 없다.
- [ ] 숫자가 없다.
- [ ] 라벨, 로고, 워터마크가 없다.
- [ ] 수량 숫자나 등급 글자가 없다.
- [ ] 모바일 앱 버튼이나 완성된 UI 슬롯처럼 보이지 않는다.

## H. 다중 아이콘

- [ ] 요청 수량과 생성 수량이 일치한다.
- [ ] 각 아이콘이 별도의 1:1 이미지다.
- [ ] 사용자가 시트를 요청하지 않았다면 그리드나 합성 시트가 아니다.
- [ ] 배경 질감, 조명 방향, 여백, 점유율, 렌더링이 통일되어 있다.
- [ ] 속성별 아이콘이 색상뿐 아니라 실루엣과 효과 형태도 다르다.

## I. 최종 프롬프트 필수 문구

- [ ] `1:1 square image`가 포함되어 있다.
- [ ] 단일 중심 대상과 명확한 실루엣이 명시되어 있다.
- [ ] 아이템이면 피사체의 색·명도·발광에 맞춘 비투명 추상 배경이 명시되어 있다.
- [ ] 아이템이 아니면 회색 또는 검은색 계열의 단순 무광 배경과 컷아웃 친화적 가장자리 분리가 명시되어 있다.
- [ ] 프레임·테두리·배지·UI 링 금지가 명시되어 있다.
- [ ] 텍스트·숫자·로고 금지가 명시되어 있다.
- [ ] 풍경·바닥·복잡한 배경 금지가 명시되어 있다.

## 자주 발생하는 실패와 수정법

### 실패 1: 자동으로 원형 프레임이 생김

원인:
- `game icon`, `ability icon`만 적고 프레임 금지를 명시하지 않음
- `badge`, `emblem`, `medallion` 같은 단어를 사용함

수정:

```text
no icon frame, no border, no badge rim, no circular UI ring, no card bezel
```

### 실패 2: 어두운 무기가 배경에 묻힘

원인:
- 아이템의 명도와 발광을 보지 않고 배경색을 고정함
- 림라이트와 명도 분리를 지시하지 않음

수정:

```text
isolated against an intentionally visible non-transparent abstract background: a softly blurred pale low-saturation blue-gray field with restrained localized violet mist, crisp edge separation, and restrained rim light; no scenery, no floor, no table, and no environmental context
```

### 실패 3: 아이템이 테이블이나 방 안에 놓임

원인:
- `product shot`, `still life`, `on a table` 같은 표현을 사용함

수정:

```text
isolated subject, no scenery, no room, no floor, no table, no environmental context
```

### 실패 4: 스킬 아이콘이 전투 장면이 됨

원인:
- 사용자 행동 전체를 서술함
- 여러 인물과 적을 프롬프트에 포함함

수정:
- 행동의 결정적 상징 하나로 압축한다.
- 캐릭터 전신 대신 손, 무기 일부, 눈, 심장, 발자국 같은 부분만 사용한다.

### 실패 5: 여러 아이콘이 한 장의 격자로 합쳐짐

원인:
- `set of four icons`만 적고 개별 출력 조건을 누락함

수정:

```text
generate each icon as a separate 1:1 image, one icon per image, not a contact sheet, not a grid, and not a multi-panel composition
```

### 실패 6: 효과나 안개가 배경 전체로 번져 아이템이 흐려짐

원인:
- `dramatic smoke`, `explosive particles`, `cinematic atmosphere`를 과도하게 사용함

수정:

```text
keep all glow, smoke, sparks, and particles tightly contained around the subject; no effects touching the canvas edges
```

### 실패 7: 아이콘이 너무 복잡함

원인:
- 여러 개념을 동시에 표현함
- 작은 장면을 축소해 넣음

수정:
- 핵심 대상 1개와 보조 요소 최대 2개로 축소한다.
- 64×64 축소 상태를 기준으로 실루엣을 다시 설계한다.
