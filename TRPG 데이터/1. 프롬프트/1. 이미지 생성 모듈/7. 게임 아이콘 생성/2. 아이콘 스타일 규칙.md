# 아이콘 스타일 규칙

## 1. 기능 전용 정식 스타일

비아이템 게임플레이 아이콘의 기본 스타일은 `게임 스킬 아이콘`이다.

정본:
- `../라이브러리/스타일/게임 스킬 아이콘.md`
- `../라이브러리/견본/게임 스킬 아이콘/`

적용 대상:
- 스킬·주문·액션
- 특성·패시브
- 버프·디버프·상태이상
- 속성·저항·취약
- 자원·충전·게이지 개념

핵심 문법:
- 고채도·고대비 판타지 RPG 아이콘
- 한 슬롯 하나의 핵심 개념
- 64×64 / 128×128에서 읽히는 굵은 실루엣
- 중앙 집중형 또는 명확한 대각선 운동형
- 페인터리와 그래픽 사이의 중간 렌더링 밀도
- 선택적 림라이트와 국소 글로우
- 실제 슬롯 전체를 속성·주색과 조화되는 유색 비투명 추상 배경으로 충전
- 실제 슬롯의 검정·거의 검정·차콜 기본 배경 금지
- 프레임·배지 림·토큰 링 기본 금지

## 2. 역할별 앵커 호출

- 동적 공격·베기·폭발: `01. 동적 원소 공격 앵커.png`
- 장축 투사체: `01 + 02. 장축 투사체 앵커.png`
- 번개·빔·고에너지: `01 + 03. 고에너지 발광 앵커.png`
- 치유·신성·지원: `04. 치유·지원 앵커.png`
- 방어·장벽·갑주형 효과: `05. 방어·재질 앵커.png`
- 대시·회피·도약·물리 기동: `06. 물리 기동 앵커.png`
- 순간이동·위상전이·공간 도약: `07. 공간 전이 앵커.png`
- 속박·봉인·침묵·행동 차단: `08. 제어·속박 앵커.png`
- 저주·공포·정신 약화·오염: `09. 저주·정신 약화 앵커.png`
- 이동 방해·중력 제어: `06 + 08`
- 공간 봉쇄·차원 구속: `07 + 08`
- 복합 제어·저주 디버프: `08 + 09`

기본 상한은 스타일 앵커 2장이다. 하나로 충분하면 두 번째 앵커를 넣지 않는다.

## 3. 일반 정식 스타일과의 경계

게임 아이콘은 일반 정식 스타일 자동 적용의 기능성 예외다. `붓터치 반실사`, `애니 페인팅`, `라인 웹툰`의 일반 앵커를 자동 호출하지 않는다.

사용자가 별도 표면 스타일을 요구하면 기능 계약을 유지하면서 작은 크기 판독성과 양립하는 표현만 설명형으로 반영한다. 일반 스타일 앵커를 섞는 것은 마스터가 직접 참조를 지시한 경우에만 검토한다.

## 4. 아이템 스타일 확장 상태

아이템·소비품·재료·무기·방어구·장비·도구·장신구 등 아이템 계열은 현재 공통 아이템 배경·패키징 계약을 사용한다. 신규 정식 후보는 하나의 상위 스타일인 `게임 아이템 아이콘 스타일`로 개발하며, 개발 정본은 `TRPG 데이터/20. 그림 스타일 분석/게임 아이템 아이콘 스타일/`에 둔다.

스타일 최상위 폴더에는 `dev_`를 붙이지 않고 내부 개발 자산에만 `dev_`를 사용한다. 무기·장비·재료·소모품 등은 필요할 때 `게임 아이템 아이콘 스타일` 내부의 검증 축 또는 하위 분기로 다룬다. 별도의 `무기 아이콘 스타일`, `장비 아이콘 스타일`을 기본 전제로 병렬 생성하지 않는다.

정식 승격 전에는 개발 자산을 일반 게임 아이콘 런타임에서 자동 호출하지 않으며, 스킬 스타일의 에너지 효과 중심 구도를 아이템 계열에 기계적으로 복제하지 않는다.

### 4.1. 무기 아이콘 개발 기본값

- 별도 속성·마법·희귀도·특수 효과가 명시되지 않은 무기는 **일반 무기**로 해석한다.
- 일반 무기의 우선순위는 `무기 종류 실루엣 → 구조 → 재질 → 보조 장식 → 배경`이다.
- 일반 무기에는 화염·냉기·번개·암흑 오라·거대한 마력 소용돌이·과도한 발광을 자동 추가하지 않는다.
- 일반 무기의 배경은 **회색조(grayscale) 비투명 추상 배경으로 고정**한다. 회색의 명도 변화는 허용하지만 청색·갈색·녹색·보라색 등 색조가 느껴지는 배경은 사용하지 않는다.
- 순수 검정 배경은 기본값으로 사용하지 않는다. 어두운 무기는 회색조 배경의 명도 차와 제한적인 림라이트로 분리한다.
- 금속·목재·가죽·뼈·결정 등 재질 차이가 64×64에서 읽히도록 재질 표현을 효과보다 우선한다.
- 일반 무기도 사실적 제품 사진처럼 만들지 않는다. **참고 무기 아이콘과 같은 선명한 게임 아이템풍 그래픽-페인터리 렌더링, 장식적 판타지 디자인, 과감한 실루엣**을 유지한다.

### 4.2. 효과가 존재하는 무기 조건부 분기

- 다음 중 하나가 명시될 때만 효과 무기 분기를 활성화한다.
  1. 화염·냉기·번개·독·신성·암흑·비전 등 속성
  2. 마법 무기·저주받은 무기·유물·전설급 등 마법/희귀도 성질
  3. 사용자 또는 테스트 명세가 특정 특수 효과를 직접 요구
- 효과 무기의 배경은 **회색조를 금지**하고 명시된 속성·마법 성질에 맞는 비회색 유색 배경을 사용한다.
- 마법 효과는 검날, 룬, 보석, 마석, 총구, 지팡이 머리 등 **발생 지점 근처의 국소 효과**로 제한한다.
- 속성·마법 효과가 무기 본체 외곽선·손잡이·날·활대·총열·장축 끝점을 가리면 실패다.
- 희귀도는 색 테두리나 슬롯 프레임으로 표현하지 않고 구조적 특이성, 보조 재질, 룬, 보석, 제한적 발광으로 표현한다.
- `일반 / 희귀 / 전설`이 달라도 무기 종류 판독성이 먼저 유지되어야 한다.
