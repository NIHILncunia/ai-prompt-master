# 2. 아이콘 유형 및 시각 언어 라이브러리

## 문서 목적

이 문서는 게임 아이콘의 종류를 분류하고, 각 개념을 작은 정사각형 안에서 어떻게 시각화할지 정의한다.

## 공통 시각 문법

모든 아이콘은 다음 구조를 공유한다.

```text
핵심 대상 1개
+ 개념을 설명하는 보조 요소 0~2개
+ 통제된 속성 효과
+ 실제 슬롯은 유형과 무관하게 피사체·속성과 조화되는 비투명 유색 추상 배경 / 빈 3×3 슬롯만 순수 검정
+ 프레임 없음
```

아이콘의 메시지는 `무엇인가`, `무엇을 하는가`, `어떤 상태인가` 중 하나를 우선한다.

## 사용자 입력을 시각 언어로 변환하는 규칙

사용자 문장은 최종 프롬프트 문구가 아니라 의미 시드다. 먼저 아래 슬롯으로 분해하고, 필요한 슬롯만 남겨 해당 유형의 시각 문법으로 다시 조립한다.

| 의미 슬롯 | 질문 | 예시 |
|---|---|---|
| 기능 역할 | 게임에서 무엇을 하는가 | 공격, 방어, 회복, 이동, 강화, 약화, 제어, 소환 |
| 핵심 변화 | 대상에 어떤 변화가 생기는가 | 밀침, 끌어당김, 관통, 붕괴, 흡수, 봉인, 가속 |
| 방향성 | 어느 방향으로 읽혀야 하는가 | 전진, 방사, 수렴, 상승, 낙하, 회전 |
| 강도 | 얼마나 강하고 급격한가 | 약함, 집중, 폭발적, 압도적 |
| 속성·재질 | 어떤 물성/원소인가 | 화염, 냉기, 번개, 그림자, 돌, 금속, 역장 |
| 핵심 상징 | 어떤 단일 기호가 가장 잘 읽히는가 | 눈, 손, 사슬, 균열, 발자국, 결정, 파동 |
| 분위기·색감 | 어떤 정서를 남겨야 하는가 | 날카로움, 불길함, 안정감, 신성함, 독성 |

원문의 표현이 과격하거나 서사적이어도 그대로 묘사하지 않는다. 아래처럼 시각적 성질만 보존한다.

- `몸을 분쇄한다` → 압도적 충격, 방사형 균열, 파쇄되는 추상 물질, 높은 에너지 밀도
- `심장을 꿰뚫는다` → 정밀 관통, 한 점으로 집중된 장축 궤적, 중심 코어 관통
- `목을 벤다` → 빠르고 결정적인 초승달형 참격, 끊어지는 추상 선이나 문양
- `피를 빨아먹는다` → 생명력 흡수, 적색·자홍색 에너지의 수렴/이동 흐름
- `뼈를 박살낸다` → 무거운 둔격, 갈라지는 갑주·석재·추상 구조, 방사형 충격 균열

이 변환은 표현 강도를 약화시키기 위한 것이 아니다. 잔혹성 대신 형태, 운동, 대비, 에너지 밀도와 파괴 패턴으로 강도를 유지한다.

## A. 아이템·소비품·재료

### 핵심 목표

실물 오브젝트의 형태와 용도를 즉시 알아보게 한다.

### 권장 구도

- 단일 오브젝트 3/4 시점
- 전체 실루엣 노출
- 중앙 또는 약간 비대칭 배치
- 병, 열쇠, 두루마리, 보석은 약한 대각선

### 시각 앵커

- 치유 물약: 투명한 병, 붉은 액체, 코르크, 약한 따뜻한 발광
- 마나 물약: 푸른 액체, 내부 소용돌이, 차가운 발광
- 해독제: 녹색 액체, 허브 잎, 작은 기포
- 고대 열쇠: 낡은 금속, 독특한 이빨, 룬 홈
- 마도서: 닫힌 책, 금속 모서리, 중앙 보석 또는 봉인
- 제작 재료: 광석, 가죽 조각, 이빨, 결정, 기계 부품

### 피해야 할 요소

- 손에 들고 있는 캐릭터
- 테이블 위 정물화
- 여러 물건이 가득한 인벤토리 장면
- 상점 배경

## B. 무기·방어구·장비

### 핵심 목표

종류, 재질, 위계, 속성을 한 번에 읽게 한다.

### 권장 구도

- 검·도끼·창·활: 30~45도 대각선
- 방패·투구·흉갑: 중앙 정렬 또는 약한 3/4 회전
- 장신구: 확대된 단일 오브젝트

### 시각 앵커

- 화염검: 검신의 붉은 열, 짧은 불꽃 꼬리, 검은 금속
- 냉기도끼: 서리 낀 날, 청백색 얼음 균열, 무거운 실루엣
- 독 단검: 짧고 날카로운 날, 녹색 독방울, 비대칭 곡선
- 성스러운 방패: 밝은 금속, 중앙 태양 문양, 절제된 금빛
- 흑룡린갑: 겹친 검은 비늘, 푸른 가장자리 광택, 무거운 질감

### 피해야 할 요소

- 캐릭터 전신
- 전투 장면
- 무기를 둘러싼 거대한 원형 프레임
- 날과 손잡이 일부가 잘리는 구도

## C. 스킬·주문·액션

### 핵심 목표

행동의 방향과 속성의 성격을 즉시 전달한다.

### 구성 방식

1. 발사형: 중앙 핵에서 한 방향으로 뻗는 투사체
2. 폭발형: 압축된 중심과 바깥으로 터지는 파편
3. 방어형: 막아내는 곡면, 방패, 장벽
4. 물리 기동형: 발·부츠·발자국·잔상·운동 궤적으로 사용자의 위치 변화 자체를 표현
5. 공간 전이형: 서로 떨어진 위치, 전이점, 공간 왜곡을 사용해 순간이동·위상전이를 표현
6. 강화형: 무기, 심장, 눈, 팔을 감싸는 오라
7. 소환형: 문, 손, 발톱, 실루엣이 나타나는 순간

물리 기동과 공간 전이는 같은 `이동`으로 평탄화하지 않는다. 대시·회피·도약은 `06. 물리 기동 앵커.png`, 순간이동·위상전이는 `07. 공간 전이 앵커.png`를 기본 역할 기준으로 사용한다.

### 시각 앵커

- 화염구: 압축된 불꽃 구체와 짧은 불꽃 꼬리
- 번개 창: 날카로운 번개 한 줄과 창끝 형태
- 얼음 방벽: 갈라진 반투명 얼음 판
- 그림자 걸음: 검은 발자국과 짧은 보라색 잔상
- 치유의 손길: 빛나는 손바닥과 작은 금빛 생명 입자
- 사령 폭발: 검보라 핵과 짧은 영혼 파편

### 피해야 할 요소

- 여러 마법사가 싸우는 장면
- 넓은 전장
- 작은 캐릭터 전신
- 화면 전체를 덮는 안개
- 외곽을 감싸는 원형 스킬 버튼 프레임

## D. 특성·재주·패시브

### 핵심 목표

지속적인 성향, 훈련, 체질, 전투 습관을 하나의 은유로 표현한다.

### 대표 은유

- 강인함: 금이 갔지만 버티는 방패 또는 돌 심장
- 민첩함: 겹쳐진 발자국 또는 날카로운 깃털
- 광폭화: 붉게 타는 심장 또는 이빨을 드러낸 짐승 입
- 치명타: 갈라진 표적이 아니라 두 겹으로 파고든 칼날
- 재생: 상처를 덮는 초록 잎 또는 다시 붙는 뼈
- 야간 시야: 어둠 속에서 빛나는 단일 눈
- 전술 지휘: 검과 깃발 대신 명확한 지휘 손짓 또는 전술 말 하나
- 용의 혈통: 비늘 심장 또는 작은 용의 눈

### 피해야 할 요소

- 문장형 배지
- 텍스트 약어
- 클래스 로고 복제
- 너무 많은 상징의 조합

## E. 버프·디버프·상태이상

### 핵심 목표

플레이 중 즉시 위험 또는 이득을 구분하게 한다.

### 버프 시각 언어

- 위로 향하는 흐름
- 단단하게 닫힌 형태
- 선명한 중심광
- 정돈된 대칭 또는 상승 방향

예시:

- 공격력 증가: 붉게 달아오른 검날
- 방어력 증가: 겹쳐진 단단한 방패면
- 가속: 앞으로 겹치는 발자국과 짧은 잔상
- 재생: 봉합되는 녹색 심장
- 집중: 하나로 모이는 빛과 선명한 눈

### 디버프 시각 언어

- 아래로 처지는 흐름
- 끊기거나 금이 간 형태
- 비대칭 긴장
- 압박, 속박, 오염

디버프 안에서도 역할을 분리한다.

- 속박·봉인·침묵·행동 차단처럼 **외부 힘이 행동을 제한하는 효과**는 `08. 제어·속박 앵커.png`를 기본으로 한다.
- 저주·공포·정신 약화·오염처럼 **대상의 상태 자체가 부정적으로 변질되는 효과**는 `09. 저주·정신 약화 앵커.png`를 기본으로 한다.
- 둔화·중력 제어처럼 이동과 제어가 동시에 핵심이면 `06 + 08`, 공간 봉쇄·차원 구속은 `07 + 08`, 복합 저주·제어는 `08 + 09`를 사용한다.

예시:

- 중독: 독방울과 이빨
- 출혈: 갈라진 붉은 칼날
- 기절: 충격받은 투구와 깨지는 빛
- 속박: 팽팽한 사슬
- 실명: 눈을 가리는 검은 천 또는 손
- 공포: 뒤틀린 눈과 검은 손가락
- 침묵: 봉인된 입 대신 끊어진 음파와 봉인 매듭

## F. 속성·저항·취약

### 속성 형태 언어

- 화염: 날카롭고 상승하는 불꽃
- 냉기: 각지고 갈라지는 결정
- 번개: 지그재그로 뻗는 직선 에너지
- 독: 둥근 방울과 뱀형 곡선
- 산성: 녹아내리는 점성과 기포
- 신성: 정돈된 광선과 밝은 중심
- 사령: 찢긴 영혼 조각과 검보라 안개
- 정신: 겹친 눈, 파동, 왜곡된 결정
- 역장: 투명하고 단단한 기하학 면
- 대지: 무거운 암석과 균열
- 바람: 가늘고 빠른 나선
- 물: 부드러운 곡선과 방울

### 저항

속성 대상 앞에 단단한 방패나 막아내는 곡면을 결합한다. 단, 방패가 아이콘 외곽 프레임이 되지 않게 한다.

### 취약

속성 대상이 갈라지거나 관통되는 순간을 표현한다. 붉은 X나 텍스트 기호에 의존하지 않는다.

## G. 자원·화폐·제작 재료

### 자원

- 마나: 푸른 결정 또는 압축된 액체 구체
- 분노: 붉은 심장, 이빨, 달아오른 금속
- 스태미나: 단단한 폐, 발자국, 녹색 에너지 매듭
- 신성력: 작은 금빛 성화 또는 빛의 결정
- 룬 충전: 빛나는 돌판 또는 에너지 홈
- 탄약: 대표 탄환 2~3개 또는 화살촉 묶음

### 화폐

- 코인 한두 개와 대표 문양만 사용한다.
- 코인 산더미나 상자 가득한 장면을 피한다.
- 실제 글자 대신 추상 문양을 사용할 수 있다.

### 제작 재료

- 원재료의 표면 질감을 강조한다.
- 광석, 가죽, 뼈, 비늘, 약초, 부품을 서로 다른 실루엣으로 만든다.
- 수량 표시는 넣지 않는다.

## H. 퀘스트·업적·시스템 표식

### 퀘스트

- 봉인된 편지
- 지도 조각
- 특이한 열쇠
- 목표 물품

느낌표나 물음표 문자를 기본적으로 사용하지 않는다.

### 업적

- 달성 내용을 대표하는 단일 상징을 사용한다.
- 메달이나 배지 프레임을 기본으로 만들지 않는다.
- 왕관, 월계수, 별은 업적 내용과 직접 관련될 때만 사용한다.

### 시스템 표식

- 상호작용, 제작, 잠금, 경고 등의 기능을 단순 오브젝트로 표현한다.
- 현대 앱 아이콘이나 플랫 모바일 UI로 자동 변환하지 않는다.

## 아이템 배경 선택 매트릭스

| 피사체 특성 | 권장 배경 | 이유 |
|---|---|---|
| 밝은 금속·금색·흰색 | 어두운 저채도 색면과 국소 안개 | 밝은 가장자리와 금속 반사를 분리 |
| 발광 마법·불·번개 | 광원과 충돌하지 않는 어두운 색상 대비 배경 | 광원 형태와 색 번짐을 분리 |
| 일반 금속·가죽·목재 | 재질보다 한 단계 어둡거나 색상 대비가 나는 흐린 배경 | 재질과 그림자를 함께 읽게 함 |
| 흑색 무기·갑주 | 밝은 저채도 색면, 흐린 안개, 절제된 림라이트 | 검은 실루엣과 세부 재질 보존 |
| 그림자·암흑·검은 불꽃 | 밝거나 색상 대비가 나는 저채도 배경 | 효과가 배경에 묻히지 않게 함 |
| 검보라·남색 중심 | 보색 또는 인접색과 명도 차를 둔 흐린 배경 | 어두운 색상 뭉침 방지 |
| 중간 명도 다색 대상 | 주색과 충돌하지 않는 저채도 색면 | 범용 대비와 색 분리 확보 |

아이템 배경은 항상 비투명하게 보이도록 한다. 부드러운 색면, 흐린 그라데이션, 가우시안 블러, 국소 안개는 허용하지만, 풍경·바닥·탁자·실내·하늘과 같은 환경 맥락이나 캔버스 끝까지 번지는 효과는 넣지 않는다.

## 프롬프트용 공통 문구

### 프레임 금지

```text
no icon frame, no border, no badge rim, no circular UI ring, no card bezel
```

### 아이템용 적응형 배경

```text
isolated against an intentionally visible non-transparent abstract background: a softly blurred low-saturation color field with restrained localized mist, chosen from the item's dominant color, luminance, and glow for clear silhouette separation; no scenery, no floor, no table, no room, and no environmental context
```

### 비아이템 게임플레이용 유색 추상 배경

```text
fill the entire square with an opaque colored abstract background harmonized with the gameplay effect, dominant hue, luminance, and glow, with strong silhouette separation; no pure-black, near-black, or charcoal default background for an occupied slot, no scenery, and no transparency
```

### 작은 크기 가독성

```text
clear readable silhouette and compact detail that remains legible at 64x64 and 128x128 UI sizes
```

### 다중 개별 출력

```text
generate each requested icon as a separate 1:1 image, one icon per image, not a contact sheet and not a grid
```
