# 게임 아이콘 마스터 프롬프트

## 기본 계약

- 기본 캔버스 1:1
- 단일 핵심 개념
- 64×64에서도 식별 가능한 실루엣
- 완성형 VTT 토큰용 프레임 없음
- 아이템·소비품·재료·무기·방어구·장비는 피사체의 주색·명도·발광을 기준으로 선택한 비투명 추상 배경
- 아이템 배경에는 부드러운 색면, 흐린 그라데이션, 가우시안 블러, 절제된 국소 안개를 허용하되 풍경·바닥·실내 맥락은 금지
- 스킬·상태·UI 아이콘은 단순한 검정·차콜·회색 계열 배경과 컷아웃 친화적 가장자리 계약을 유지

## 출력 구성

- 단일 아이콘
- 개별 아이콘 세트
- 격자 시트
- 스프라이트 시트

단일 아이콘은 레이아웃 문서를 불러오지 않는다. 다중 배열에서만 필요한 레이아웃을 조립한다.

## 그림체 적용 경계

- 그림체 적용 방식은 사용자 지정 스타일·기능성 예외다.
- 정식 인물 스타일의 얼굴·나이·전신 앵커를 자동으로 불러오지 않는다.
- 기능 전용 판독성·시점·레이아웃 계약이 우선한다.
- 사용자가 별도 표면 마감을 요청하면 기능 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.
- 실제 예외 판정은 `../라이브러리/스타일/정식 스타일 호출 규칙.md`를 따른다.
