# 용도별 아이콘 분기

## 1. 비아이템 게임플레이 아이콘

대상:
- 스킬·주문·액션
- 특성·패시브
- 버프·디버프·상태이상
- 속성·저항·취약
- 자원·충전·게이지

기본 스타일:
- `게임 스킬 아이콘` 정식 계약
- 역할별 정식 앵커 최소 조합
- 유색 비투명 추상 배경
- 검정·차콜 기본 배경 금지

## 2. 아이템·소비품·재료

- 비투명 추상 배경을 반드시 포함한다.
- 배경색은 피사체의 주색·명도·발광을 먼저 판정하고 가장자리와 재질이 분명히 읽히도록 선택한다.
- 어두운 피사체에는 더 밝고 저채도의 대비 배경과 절제된 림라이트를 사용한다.
- 밝거나 강하게 발광하는 피사체에는 더 어둡거나 색상 대비가 나는 유색 배경을 사용한다.
- 흐린 색면·부드러운 그라데이션·가우시안 블러·국소 안개를 허용한다.
- 투명 체크무늬, 바닥, 탁자, 방, 풍경은 배경으로 사용하지 않는다.

## 3. 무기 아이콘

현재 상태: `게임 아이템 아이콘 스타일` 내부 무기 검증 축 개발 중.

검·대검·도끼·창·폴암·활·석궁·총기·지팡이·단검·곡도·둔기·사슬무기 등은 다음 우선순위를 사용한다.

`무기 종류 실루엣 → 실제 구조 → 재질 → 조건부 마법 성질 → 희귀도 장식 → 배경/효과`

### 3.1. 일반 무기 — 기본 분기

- 사용자가 속성·마법·희귀도·특수 효과를 명시하지 않으면 일반 무기로 해석한다.
- 철·강철·목재·가죽·뼈 등 구조와 재질을 우선하며 마법 발광을 자동 추가하지 않는다.
- **회색조(grayscale) 비투명 추상 배경을 고정한다.** 회색 명도 변화는 허용하지만 색조가 느껴지는 배경은 금지한다.
- 무기 자체는 실사·사진풍이 아니라 선명한 게임 인벤토리 아이콘풍 그래픽-페인터리 렌더링과 장식적 판타지 디자인을 유지한다.
- 검·대검·도끼는 날과 손잡이 비율, 창·폴암은 날끝부터 자루 끝까지, 활은 활대와 시위, 석궁은 활대·본체·방아쇠, 총기는 총열·개머리판/손잡이, 지팡이는 장축과 머리 구조가 함께 읽혀야 한다.
- 사람·손·착용자는 기본적으로 넣지 않는다.

### 3.2. 효과가 존재하는 무기 — 조건부 분기

- 화염·냉기·번개·독·신성·암흑·비전 등 속성, 마법·저주·유물·전설급 성질, 특수 효과가 명시된 경우에만 활성화한다.
- **회색조 배경은 사용하지 않는다.** 명시된 효과와 조화되는 비회색 유색 배경과 룬·보석·마석·국소 발광·원소 효과를 사용할 수 있다.
- 무기 본체의 그림체·디자인 밀도·재질 표현은 일반 무기와 동일한 게임 아이템풍으로 유지한다.
- 효과는 본체 구조를 보조하며 무기 외곽 실루엣을 가리지 않는다.
- 슬롯 테두리 색으로 희귀도를 표시하지 않는다.
- 모든 무기를 자동으로 속성 무기로 만드는 것을 금지한다.

현재 무기 검증은 별도 정식 `무기 아이콘 스타일`을 병렬 생성하는 작업이 아니라 상위 `게임 아이템 아이콘 스타일`의 무기 분기를 검증하는 단계다.

## 4. 장비 아이콘

현재 상태: 무기 스타일 안정화 후 개발.

갑옷·의복·투구·방패·장갑·부츠·벨트·망토·목걸이·반지·장신구는 착용 부위와 물체 종류가 64×64에서 먼저 읽혀야 한다. 세트 문양·등급 장식·마법 효과는 실루엣과 재질 판독을 해치지 않는 범위에서만 추가한다.

## 5. 지역·시설 및 시스템 UI

지역·시설·상호작용·제작·잠금·경고·시스템 기능은 작은 정사각형에서 단순한 장소 기호 또는 오브젝트 기호로 압축한다. 현대 앱 아이콘이나 완성된 버튼 UI로 자동 변환하지 않는다.

모든 분기는 `3. 출력 구성 규칙.md`의 **3×3 원본 시트 보존·배치 저장 계약**을 공유한다. 생성된 시트는 자동 분할·512 정규화·1536 재합성을 하지 않는다.
