# 용도별 아이콘 분기

- 지역/시설 아이콘
- 아이템 아이콘
- 상태/속성 아이콘
- UI 버튼 또는 시스템 아이콘

용도에 따라 장식 강도와 읽기 방식을 조절한다.

## 아이템 아이콘 배경

- 아이템·소비품·재료·무기·방어구·장비는 비투명 배경을 반드시 포함한다.
- 배경색은 피사체의 주색, 명도, 발광을 먼저 판정한 뒤 가장자리와 재질이 분명히 읽히도록 선택한다.
- 어두운 피사체에는 더 밝고 저채도의 대비 배경과 절제된 림라이트를, 밝거나 강하게 발광하는 피사체에는 더 어둡거나 색상 대비가 나는 배경을 사용한다.
- 배경은 흐린 색면, 가우시안 블러, 국소 안개처럼 추상적으로만 처리한다. 투명 체크무늬, 바닥, 탁자, 방, 풍경은 배경으로 사용하지 않는다.
