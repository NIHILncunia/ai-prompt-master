# V2 산출물 검수 규칙

생성 후 먼저 요구사항 확인서에 명시된 모드를 확인하고 해당 체크리스트를 적용한다.

## 공통 검수

1. 최종 캔버스가 정확히 `1916 × 821 px`인가.
2. 별도 배경 지시가 없다면 상단 이미지 영역이 흰색 단색인가.
3. 하단 데이터 바가 전체 검은색인가.
4. 데이터 바에는 사용자가 제공한 정보만 존재하는가.
5. 미제공 항목을 `불명`, `???`, 추정값으로 임의 생성하지 않았는가.
6. 라벨과 값이 위·아래 세로 쌍으로 명확히 대응하는가.
7. 전투 장면·환경 배경·계약 밖 추가 컷·불필요한 UI 장식이 없는가.

## 인간형 V2 검수

1. 정면·정확한 측면·후면이 모두 존재하는가.
2. 최종 전신 3면에 머리와 얼굴이 표시되지 않았는가.
3. 전신 3패널의 너비가 정확히 동일한가.
4. 세 전신의 체형·복식·장식·색상·소재가 동일 개체로 일치하는가.
5. 측면이 3/4이 아니라 정확한 측면인가.
6. 우측 얼굴 패널이 정면·중앙 정렬인가.
7. 얼굴과 헤어스타일 핵심 구조가 판독되는가.
8. 얼굴 패널이 흉상처럼 어깨·가슴·상반신을 넓게 포함하지 않았는가.
9. 외부 무기가 있으면 독립 패널에만 존재하는가.
10. 외부 무기가 없으면 빈 무기 패널이 없는가.
11. 전체 외곽선과 패널 구획이 한 줄짜리 단일선 공유 그리드인가.
12. 인접 영역 경계가 이중선으로 보이지 않는가.
13. 카드형 프레임·장식형 외곽선이 없는가.

## 몬스터형 V2 검수

1. 정면·정확한 측면·후면이 모두 존재하는가.
2. 세 방향 모두 머리부터 발끝까지 전체 실루엣이 보이는가.
3. 세 방향의 체형·비율·기관·장식·재질·발광부가 동일 개체로 일치하는가.
4. 측면이 3/4이 아니라 정확한 측면인가.
5. 머리·등·날개·꼬리·촉수·뿌리 등 비인간 구조가 방향별로 일관되는가.
6. 핵심 디테일 패널이 사용자 지정 부위를 반영했는가.
7. 사용자 지정이 없다면 가장 중요한 식별 구조가 선택되었는가.
8. 핵심 디테일이 시네마틱 연출이 아니라 구조 판독 중심인가.
9. 외부 무기가 있으면 본체와 분리된 독립 패널에 존재하는가.
10. 외부 무기가 없으면 빈 무기 패널이 생성되지 않았는가.
11. 발톱·뿔·꼬리·촉수 등 신체 무기를 별도 무기 패널로 분리하지 않았는가.
12. 상단 이미지 영역에 격자선·구획선·외곽선이 없는가.
13. 각 시각 영역이 충분한 여백으로 명확히 구분되는가.
14. 원본 몬스터의 전체 실루엣과 핵심 구조가 재현 가능한 수준으로 보존되었는가.

핵심 계약 항목 하나라도 실패하면 완성으로 판정하지 않는다. 특정 패널만 실패한 경우 전체를 처음부터 다시 생성하기보다 해당 패널을 재생성·교체한 뒤 다시 합성하는 것을 우선한다.

패널 재생성·교체·재합성을 포함한 모든 새 생성 전에는 공통 승인 절차를 다시 적용한다. 수정 범위와 방향을 반영한 요구사항 확인서·최종 영어 프롬프트를 공개하고 마스터의 명시적 승인을 받은 뒤에만 실행한다.
