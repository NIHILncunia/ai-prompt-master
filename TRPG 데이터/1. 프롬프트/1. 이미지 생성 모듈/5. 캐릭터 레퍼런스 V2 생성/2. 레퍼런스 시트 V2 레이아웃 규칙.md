# 레퍼런스 시트 V2 레이아웃 규칙

## 공통 캔버스

- 전체 해상도는 `1916 × 821 px`로 고정한다.
- 상단은 이미지 영역, 하단은 검은색 데이터 바로 구성한다.
- 별도 지시가 없으면 상단 이미지 영역은 흰색 단색이다.
- 최종 시트는 패널별 생성 결과물을 고정 좌표로 합성하는 방식을 기본으로 한다.
- 이미지 모델에게 최종 레이아웃을 자율 설계하게 하지 않는다.

## 인간형 레이아웃

### 상단 구조

무기 없음:
`[정면|측면|후면|대형 얼굴+헤어스타일 클로즈업]`

외부 무기 있음:
`[정면|측면|후면|외부 무기|대형 얼굴+헤어스타일 클로즈업]`

### 단일선 공유 그리드

- 인간형 V2에는 테두리와 구획선을 반드시 그린다.
- 전체는 하나의 연속된 표처럼 읽히는 단일선 공유 그리드다.
- 외곽선은 한 줄짜리 단일 외곽선이다.
- 인접 패널 사이는 하나의 공유 세로선으로만 구분한다.
- 상단과 하단 데이터 바 사이는 하나의 공유 수평선이다.
- 데이터 항목 사이는 하나의 공유 세로선이다.
- 이중선, 카드형 독립 프레임, 장식형 모서리 프레임은 금지한다.

### 전신 3면

- 순서는 정면, 정확한 측면, 후면이다.
- 세 패널은 동일 폭이다.
- 최종 시트에서는 머리와 얼굴을 표시하지 않는다.
- 칼라·후드·목선 등 복식 구조는 필요한 범위에서 남길 수 있다.
- 3/4·반측면·사선 시점은 허용하지 않는다.

### 얼굴 패널

- 반드시 정면이며 패널 중앙에 둔다.
- 흉상 패널이 아니다.
- 얼굴과 헤어스타일의 핵심 구조가 판독되는 범위까지 포함한다.
- 정수리·앞머리·옆머리·묶음 시작점·포니테일 베이스·주요 헤어 장식을 우선 보존한다.
- 어깨·가슴·상반신은 최소화한다.

## 몬스터형 레이아웃

### 상단 구조

외부 무기 없음:
`정면 전체    정확한 측면 전체    후면 전체    핵심 디테일`

외부 무기 있음:
`정면 전체    정확한 측면 전체    후면 전체    외부 무기    핵심 디테일`

### 무격자 상단

- 몬스터형 상단에는 격자선·구획선·외곽선을 사용하지 않는다.
- 각 시각 영역은 충분한 흰색 여백으로만 구분한다.
- 인간형의 단일선 공유 그리드 규칙을 몬스터형 상단에 적용하지 않는다.

### 전신 3면

- 정면, 정확한 측면, 후면 순서다.
- 머리부터 발끝까지 전체 실루엣을 표시한다.
- 머리·등·날개·꼬리·촉수·뿌리 등 주요 비인간 구조를 임의 생략하지 않는다.
- 세 방향의 전체 비율·기관·장식·재질·발광부·색상을 동일 개체로 유지한다.
- 3/4·반측면·사선 시점은 허용하지 않는다.

### 핵심 디테일 패널

- 우측 대형 영역으로 유지한다.
- 사용자 지정 부위가 있으면 최우선으로 사용한다.
- 미지정 시 자동 선택 우선순위:
  1. 얼굴·머리 구조
  2. 코어·기관·발광부
  3. 구강·눈·뿔
  4. 날개·꼬리·촉수·등판
  5. 기타 가장 강한 식별 구조
- `머리 + 흉부 코어`처럼 연결된 핵심 구조를 함께 보여줄 수 있다.
- 시네마틱 초상이 아니라 구조 판독용 패널이다.

## 하단 데이터 바

- 두 모드 모두 하단은 반드시 전체 검은색이다.
- 각 항목은 `라벨 위 / 값 아래`의 세로 쌍이다.
- 제공된 데이터만 표시한다.
