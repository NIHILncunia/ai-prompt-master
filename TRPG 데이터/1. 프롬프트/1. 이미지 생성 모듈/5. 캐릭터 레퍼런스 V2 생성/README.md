# 캐릭터 레퍼런스 V2 생성

`1916 × 821 px` 고정 캔버스의 프로덕션형 레퍼런스 시트를 생성한다.

## 모드

### 인간형 V2
얼굴·헤어스타일·복식 재현이 핵심인 사람형 캐릭터용 모드다.

### 몬스터형 V2
전체 실루엣·비인간 해부 구조·핵심 기관이 중요한 대형 또는 비인간 몬스터용 모드다.

세부 판정, 레이아웃, 무기, 데이터 바, 검수 규칙은 아래 문서를 따른다.

제공 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 그림체와 마감을 기본 보존한다. 신규 생성 또는 다른 정식 스타일로 변경할 때에는 얼굴·두상 소스와 정면·측면·후면 전신 소스를 각각 얼굴·흉상 또는 반신·전신으로 분류하고 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 반환한 앵커 목록을 사용한다.

최종 시트 합성에서는 생성된 패널 소스의 그림체를 그대로 유지하며 충돌하는 두 번째 정식 스타일 패스를 적용하지 않는다. 캔버스, 모드별 패널 배치, 외부 무기·신체 무기 구분과 전체 검은색 하단 데이터 바 계약은 그대로 유지한다.

- `0. 캐릭터 레퍼런스 V2 마스터 프롬프트.md`
- `1. 캐릭터 레퍼런스 V2 공통 지침.md`
- `2. 레퍼런스 시트 V2 레이아웃 규칙.md`
- `3. 텍스트 바 및 무기 패널 규칙.md`
- `4. V2 산출물 검수 규칙.md`
