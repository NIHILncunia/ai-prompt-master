# 텍스트 바 및 무기 패널 규칙

## 하단 데이터 바

- 모든 V2 시트에 필수다.
- 배경색은 항상 전체 검은색으로 고정한다.
- 마스터가 제공한 데이터만 사용한다.
- 제공되지 않은 필드나 값을 추정하여 추가하지 않는다.
- 미제공 값을 `불명`, `???`, 추정값으로 자동 채우지 않는다.
- 제공된 정보를 임의로 생략·요약·번역·재명명하지 않는다.
- 각 항목은 `라벨 위 / 값 아래`로 세로 정렬한다.
- 데이터 바를 카드형 UI나 다른 색 배경으로 재해석하지 않는다.

### 몬스터형 기본 후보 필드

- 이름
- 종족/유형
- 크기
- 등급
- 소속

위 항목은 후보일 뿐 자동 생성하지 않는다. 실제 시트에는 사용자가 제공한 항목만 표시한다.

## 외부 무기 패널

본체와 분리 가능한 장비만 독립 무기 패널을 사용한다.

예:
- 검
- 창
- 완드
- 총기
- 방패
- 기타 장착 해제 가능한 장비

- 무기 전체 형태와 상대 비율을 보존한다.
- 패널에 맞추기 위해 특정 부위만 줄이거나 늘리지 않는다.
- 무기가 없으면 빈 패널이나 자리표시자를 만들지 않는다.

## 신체 무기

다음은 본체 일부로 취급하며 독립 무기 패널을 만들지 않는다.

- 발톱
- 송곳니
- 뿔
- 꼬리
- 촉수
- 독침
- 날개 칼날
- 기타 본체와 분리할 수 없는 공격 구조

신체 무기는 전신 3면 또는 몬스터형 핵심 디테일 패널에서 판독되도록 한다.
