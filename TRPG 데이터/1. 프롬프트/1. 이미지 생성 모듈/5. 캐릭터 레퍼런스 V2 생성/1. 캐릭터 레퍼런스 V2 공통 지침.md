# 캐릭터 레퍼런스 V2 공통 지침

- 시트는 장면 이미지가 아니라 제작·재현용 시각 데이터다.
- 사용자 제공 이미지나 이전 확정 이미지가 있으면 정체성, 전체 구조, 색상, 재질, 장식, 장비를 우선 보존한다.
- 종족·고유 개체의 공식 외형 자료가 있으면 범용 지식보다 해당 설정 자료를 우선한다.
- 사용자 제공 이미지나 이전 확정 이미지가 있으면 별도 화풍 변경 지시가 없는 한 해당 이미지의 그림체·선 처리·채색·재질 마감을 그대로 따른다.
- 기준 이미지도 화풍 지정도 없으면 임의로 정식 스타일을 선택하지 않고 요구사항 확인 단계에서 확인한다.
- 스타일 변경이 명시된 경우 캐릭터 디자인은 제공 이미지에서, 그림체와 마감은 선택 스타일 계약에서 가져오며 두 역할을 섞지 않는다.
- `라인 웹툰`을 선택하면 정식 `01~12` 인물·형태 앵커 중 패널 목적과 직접 맞는 최소 조합만 사용하고, 공통 붓터치 마감은 적용하지 않는다.
- `라인 웹툰` V2에는 환경 앵커 `13~17`을 자동 적용하지 않는다. 상단 흰색 제작 배경과 구조 판독 계약이 환경 연출보다 우선한다.
- 몬스터형에서 강한 비인간 전신 해부가 핵심이면 `03. 전신 비례 앵커.png`로 인간형 비례를 강제하지 않는다. 이 경우 디자인 기준 이미지가 실루엣·기관·사지 구조를 소유하고 `04`와 필요한 `09`가 그림 언어를 담당한다.
- 10~12 전문 성인 여성 체형 앵커는 특정 체형 비교가 직접 목적일 때만 사용하며 일반 캐릭터 V2에 자동 삽입하지 않는다.
- 상단 배경은 별도 지시가 없으면 흰색 단색을 사용한다.
- 정면·정확한 측면·후면은 동일 개체의 비율과 구조를 유지한다.
- 세 방향은 정적인 제작용 기준 자세를 사용하고 행동 연출을 하지 않는다.
- 최종 시트는 패널별 시각 소스를 고정 규격으로 합성한 프로덕션 결과물로 취급한다.
- 최종 합성에서는 생성된 소스의 선택 그림체를 그대로 보존하며 두 번째 스타일 패스나 환경 스타일 패스를 추가하지 않는다.

## 인간형 공통 원칙

- 얼굴·헤어스타일 정보와 체형·복식 정보를 분리한다.
- 전신 3면은 체형·복식·착용 장비 구조 재현을 우선한다.
- 얼굴 패널은 얼굴 정체성과 헤어스타일 구조의 정본이다.
- 소스 생성 단계에서 동일성 확보를 위해 머리까지 포함할 수 있으나 최종 전신 3면에서는 머리·얼굴을 크롭한다.

## 몬스터형 공통 원칙

- 전체 실루엣과 비인간 해부 구조 자체가 정체성 정보다.
- 정면·측면·후면의 머리·등판·날개·꼬리·촉수·뿌리·기관·발광부가 동일 구조로 이어져야 한다.
- 몬스터형에서는 전신 3면에서 머리를 제거하지 않는다.
- 얼굴이 항상 정체성의 중심이라고 가정하지 않는다. 코어·구강·뿔·날개 관절·등판 등 핵심 구조가 정본이 될 수 있다.
- 핵심 디테일 패널은 구조 판독을 우선하며 시네마틱 연출을 하지 않는다.
