# 5. 캐릭터 레퍼런스 V2 생성 AGENTS

캐릭터 레퍼런스 V2 시트 생성을 담당한다. 인간형 V2와 몬스터형 V2를 모두 포함한다.

읽기 순서:
1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 캐릭터 레퍼런스 V2 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 캐릭터 레퍼런스 V2 공통 지침.md`
6. `2. 레퍼런스 시트 V2 레이아웃 규칙.md`
7. `3. 텍스트 바 및 무기 패널 규칙.md`
8. `4. V2 산출물 검수 규칙.md`
9. `../라이브러리/스타일/정식 스타일 호출 규칙.md`에서 그림체 적용 방식과 소스 생성 단계별 앵커 조합 판정
10. 정식 스타일 적용 시 선택 스타일 계약과 실제 앵커 픽셀 확인
11. `라인 웹툰` 선택 시 `../라이브러리/스타일/라인 웹툰.md`와 정식 `../라이브러리/견본/라인 웹툰/01~17` 역할을 확인하고, V2 모드와 패널 소스 종류를 중앙 호출 규칙에 전달한다.

상위 모듈의 제공 이미지 그림체 보존 규칙, 정식 스타일 앵커 하드 게이트와 이미지 승인 절차를 먼저 판정한다.

핵심 계약:
- 캔버스는 정확히 `1916 × 821 px`이다.
- 요구사항 확인서에서 `인간형 V2` 또는 `몬스터형 V2` 모드를 명시한다.
- 사용자 모드 지정이 자동 판정보다 우선한다.
- 인간형은 머리 제거 전신 3면 + 얼굴/헤어스타일 클로즈업 + 단일선 공유 그리드를 사용한다.
- 몬스터형은 머리 포함 전체 전신 3면 + 핵심 디테일을 사용하며 상단 격자·구획선·외곽선을 사용하지 않는다.
- 몬스터형 핵심 디테일은 사용자 지정 우선, 미지정 시 자동 선택한다.
- 외부 무기만 독립 패널을 사용하고 신체 무기는 본체에 포함한다.
- 하단 데이터 바는 두 모드 모두 반드시 전체 검은색이다.
- 데이터 바에는 사용자가 제공한 항목만 사용한다.
- 제공 이미지가 있으면 별도 스타일 변경 지시가 없는 한 그 이미지의 디자인과 그림체를 그대로 따른다.
- 제공 이미지 없이 새로 만들 때에는 마스터가 지정한 화풍을 사용하며, 화풍도 기준 이미지도 없으면 요구사항 확인 단계에서 확인한다.
- 신규 생성 또는 명시적 정식 스타일 변환에서는 얼굴·두상 소스를 얼굴·흉상 경로로, 정면·측면·후면 전신 소스를 반신·전신 경로로 분류하고 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 반환한 앵커 목록을 사용한다.
- 정식 스타일은 `붓터치 반실사`, `애니 페인팅`, `라인 웹툰`을 지원한다. `라인 웹툰`은 `라인 웹툰.md`의 고정 영어 그림체 블록과 정식 01~12 인물·형태 앵커를 필요 역할에 따라 최소 조합하며, `공통 붓터치 마감 규칙.md`의 고정 영어 마감 블록은 적용하지 않는다.
- `라인 웹툰` 인간형 V2의 얼굴·헤어 클로즈업 소스는 기본적으로 `01. 핵심 얼굴 앵커.png + 04. 라인 마감 앵커.png`, 전신 3면 소스는 `03. 전신 비례 앵커.png + 04. 라인 마감 앵커.png`를 사용한다. 얼굴 정체성 오차가 전신 소스에서도 핵심 위험이면 `01`을 추가한다. 02·05~09는 해당 위험이 실제로 있을 때만 조건부로 추가한다.
- `라인 웹툰` 몬스터형 V2는 `04. 라인 마감 앵커.png`를 기본 마감 기준으로 사용한다. 비인간 두상·귀·뿔·엄니·비늘·털·깃털·갑각 등 형태가 핵심이면 `09. 판타지 종족 형태 앵커.png`를 추가한다. `03. 전신 비례 앵커.png`는 인간형 골격과 비례를 실제로 따르는 몬스터에만 사용하며, 강한 비인간 체형을 인간 비례로 교정하기 위해 사용하지 않는다.
- V2는 흰색 제작 시트이므로 `13~17` 환경 앵커를 자동 적용하지 않는다. 10~12 전문 성인 여성 체형 앵커도 해당 체형 비교가 직접 목적일 때만 사용한다.
- 디자인 기준 이미지는 스타일 앵커보다 우선 배정하며, 참조 예산으로 제외한 모든 앵커와 사유를 요구사항 확인서에 기록한다.
- 최종 시트 합성은 생성된 소스의 그림체를 보존하며 충돌하는 두 번째 정식 스타일 패스를 추가하지 않는다.
- 인간형 V2 시트는 해당 NPC·PC·신격 대상 폴더에 `<대상> 레퍼런스 시트 V2.webp`로 저장한다.
- 몬스터형 V2 시트는 `TRPG 데이터/10. 몬스터/<유형>/<대상>/`에 `<대상> 레퍼런스 시트 V2.webp`로 저장하며 `몬스터 이미지 분류 및 저장 지침.md`의 유형별 구조를 따른다.
- 용종 V2 시트는 `TRPG 데이터/14. 용종/<유형>/<대상>/`에 저장하며 몬스터형 규칙을 따른다.
- 몬스터 이미지의 `10. 인간형`은 적성 인간형 전용이며, 절지동물형은 `16. 곤충류`, 유형 미확정 대상은 `커스텀`에 둔다.
- 기존 파일은 덮어쓰지 않는다.

라우팅:
- `캐릭터 레퍼런스 V2`, `레퍼런스 시트 V2`, `버전 2 레퍼런스`는 이 기능으로 들어온다.
- `몬스터 레퍼런스`, `몬스터형 레퍼런스`, `대형 비인간 레퍼런스`는 이 기능의 `몬스터형 V2` 모드로 라우팅한다.
