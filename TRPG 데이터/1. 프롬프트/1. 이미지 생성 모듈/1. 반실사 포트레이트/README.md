# 반실사 포트레이트

## 개요

반실사 포트레이트는 단일 대상의 전신·흉상·완성형 VTT 토큰을 생성한다. 기본 스타일은 `붓터치 반실사`이며, `애니 페인팅`을 정식 스타일로 선택할 수 있다. 과거 명칭 `세미리얼 애니 페인팅`은 레거시 별칭이다.

## 출력 흐름

1. 전신 9:16 1장 생성
2. 전신 확정
3. 확정 전신 기반 흉상 9:16 또는 완성형 VTT 토큰 1:1 생성

사용자가 이미지를 업로드하면 전신 단계 없이 해당 이미지를 기준으로 완성형 VTT 토큰 1:1을 직접 생성할 수 있다.

완성형 토큰은 캐릭터가 포함된 투명 WebP 한 장이며, 유형 기반 계열 자동 선택과 일반·엘리트·보스 장식 규칙을 적용한다.

## 스타일 직접 호출

`애니 페인팅 포트 준비`라고 호출하면 이 기능의 준비 절차로 직접 진입하며 선택 스타일을 `애니 페인팅`으로 바인딩한다. 준비 호출 자체는 이미지를 생성하지 않는다.

실제 생성 준비에서는 먼저 `../라이브러리/스타일/정식 스타일 호출 규칙.md`에서 그림체 적용 방식과 구도별 앵커 조합을 판정한다. 신규 얼굴·흉상은 `붓터치 반실사` 선택 시 `01 + 02 + 04`, 신규 반신·전신은 `01 + 02 + 03 + 04`를 기본 호출하되 실제 조합과 참조 예산 축소는 중앙 호출 규칙이 결정한다. 최종 영어 프롬프트는 선택 스타일의 고정 그림체 블록과 공통 마감 블록을 그대로 사용하며, 캐릭터·포즈·카메라·배경은 요구사항에 따라 별도로 정한다.

완성형 VTT 토큰은 확정 전신 또는 사용자 업로드 기준 이미지의 그림체와 캐릭터 본체를 보존하며, 캐릭터 스타일 앵커를 추가해 다시 그리지 않는다.
