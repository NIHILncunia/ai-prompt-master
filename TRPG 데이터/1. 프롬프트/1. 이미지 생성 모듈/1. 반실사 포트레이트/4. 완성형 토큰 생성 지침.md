# 완성형 토큰 생성 지침

## 정의

완성형 토큰은 캐릭터가 포함된 VTT용 최종 파생 산출물이다. 포트레이트 전신 확정본 또는 사용자가 업로드한 기준 이미지를 보존한 채 원형 배치·자동 프레임·원형 바깥 투명 처리를 적용한다. 프레임은 토큰 내부의 시각 규칙이며, 빈 프레임 WebP나 중앙 빈 원형은 만들지 않는다.

## 두 입력 경로

### 포트레이트 전신 확정본

- 같은 포트레이트 작업에서 전신 9:16이 생성·확정되어 있어야 한다.
- 확정 전신을 직접 기준 이미지로 사용한다.
- 확정 전신이 없으면 이 경로로는 토큰을 생성하지 않고 전신 단계부터 진행한다.

### 사용자 업로드 이미지

- 사용자가 제공한 이미지는 토큰 생성의 직접 기준 이미지가 될 수 있다. 포트레이트 전신 생성·확정을 선행 조건으로 요구하지 않는다.
- 단일 대상이 식별되고 원형 토큰 안에 배치 가능한지 먼저 확인한다.
- 전신·반신·흉상·정사각형 등 입력 비율은 허용한다.
- 여러 대상, 식별 불가 대상, 토큰 안에서 판독하기 어려운 장면이면 생성 전에 기준 대상을 확인한다.

## 출력

- 캐릭터를 포함한 1:1 정사각형 WebP 1장
- 원형 VTT 토큰 구성
- 원형 토큰 바깥 영역은 투명 배경
- 저장 파일명: `<액터> 토큰.webp`
- 저장 위치: `TRPG 데이터/15. 이미지 생성 결과/캐릭터/`

## 자동 계열·등급 판정

- 기준 이미지와 관련 설정에서 대상의 유형·종족·분류, 세력·소속·역할·위계를 확인한다.
- 기존 토큰 계열 프로필이 있으면 유형·종족·분류 → 세력·소속·역할·위계 → 시각 일치도 순으로 가장 적합한 계열을 자동 적용한다.
- 일치하는 계열이 없거나 기존 계열과 충돌하면 새 기본 계열로 생성하고, 결과를 이후 재사용할 기준 토큰으로 보관한다.
- 마스터가 계열·색상·분위기를 명시하면 자동 판정보다 우선한다.
- `엘리트`, `정예`, `강화 개체`는 엘리트 토큰으로 처리한다.
- `보스`, `중간보스`, `최종보스`, `표적`, `토벌 대상`은 보스 토큰으로 처리한다.
- 등급 정보가 없으면 일반 토큰으로 처리한다. 이름·외형·추측만으로 보스나 엘리트로 격상하지 않는다.

## 프레임과 구도

- 기준 이미지의 캐릭터 본체를 그대로 사용한다. 캐릭터 자체를 새로 생성하거나 다시 그리지 않는다.
- 토큰 작업의 주 대상은 원형 배치, 자동 프레임, 원형 바깥 투명 처리다.
- 작은 VTT 표시 크기에서도 식별되도록 기준 이미지를 크롭·확대·축소·위치 이동할 수 있다.
- 캐릭터의 포즈와 실루엣은 유지하며, 원형에 맞춘 새 포즈 구성은 하지 않는다.
- 프레임 본체는 기하학적으로 완전한 원형이어야 한다. 일반·엘리트·보스의 프레임 본체 두께는 동일하다.
- 일반 토큰은 대표 색·재질을 반영한 절제된 링과 최소 문양을 사용한다.
- 엘리트 토큰은 같은 두께의 링에 더 뚜렷한 문양·보석·제한적 외곽 장식을 사용한다.
- 보스 토큰은 같은 두께의 링에 가장 높은 장식 밀도, 대칭적 위계 장식, 강한 대비의 표적 표현을 사용한다. 표적성은 캐릭터를 덮는 조준선이나 UI 마커가 아니라 프레임 주변의 대칭적 표식·대비색·위협성 있는 장식 구조로 표현한다.
- 프레임 장식은 캐릭터와 기준 이미지의 핵심 요소를 과도하게 가리지 않는다. 일부 요소가 캐릭터 앞뒤로 자연스럽게 겹치는 정도만 허용한다.
- 프레임과 장식의 재질·색상·문양·외곽 실루엣은 적용 계열 프로필을 따른다.

## 보존·허용

### 반드시 보존

- 동일 개체의 정체성
- 얼굴·머리 또는 비인간형 헤드 구조
- 종족·신체 구조
- 의상·장비
- 대표 색상
- 핵심 발광·재질 특징
- 전체적인 위계와 역할 인상

### 허용

- 기준 이미지의 크롭, 확대·축소, 위치 이동
- 원형 토큰에 맞춘 배치 조정
- 가장자리 마스킹과 자연스러운 블렌딩
- 원본 캐릭터를 바꾸지 않는 아주 미세한 밝기·대비·색 균형 보정
- 배경의 최소 정리 또는 원형 내부에 맞춘 단순화
- 계열·등급 규칙에 맞춘 원형 경계·통합 프레임 구성
- 원형 바깥 투명 처리

## 금지

- 기준 이미지의 캐릭터 본체를 새 이미지로 다시 생성하거나 다시 그리기
- 얼굴·신체 구조·포즈·실루엣·의상·장비·발광 특징을 새롭게 재해석하기
- 기준 이미지와 다른 신규 캐릭터로 재설계
- 기준 이미지에 없던 핵심 장비·의상·종족 특징 추가
- 일반 대상을 임의로 엘리트·보스로 격상
- 프레임 본체를 타원형 또는 찌그러진 원형으로 제작
- 프레임 장식으로 캐릭터나 기준 이미지의 핵심 요소를 과도하게 가리기
- 캐릭터를 덮는 조준선, UI 마커, 텍스트로 보스 표적성을 표현
- 중앙이 비어 있는 프레임만 제작하거나 캐릭터 없는 결과 만들기
- 빈 중앙 마스크, `#FFFFFF` 빈 원형, 별도 프레임 WebP를 산출물 계약으로 사용

## 승인과 검수

완성형 토큰은 전신·흉상·다른 토큰의 기존 승인 상태를 재사용하지 않는다. 기준 이미지 유형, 대상 유형, 자동 적용 계열, 적용 등급, 자동 프레임 요약, 단일 1:1 투명 WebP 산출물을 포함한 요구사항 확인서와 최종 영어 프롬프트를 새로 공개하고 마스터의 명시적 승인 후 생성한다.

생성 후에는 캐릭터 포함 여부, 완전한 원형 프레임, 바깥 투명도, 캐릭터 가림 여부, 계열 일관성, 일반·엘리트·보스 장식 차이를 검수한다.
