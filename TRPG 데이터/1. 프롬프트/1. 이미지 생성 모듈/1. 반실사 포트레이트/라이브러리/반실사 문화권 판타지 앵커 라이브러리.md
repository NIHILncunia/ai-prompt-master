# 9. 반실사 문화권 판타지 앵커 라이브러리

## Purpose

A cultural fantasy anchor controls the visual tradition before style, class, race, and theme are applied.

It prevents unwanted genre drift.

The anchor decides:

- whether D&D wording is appropriate
- what cultural visual language should be used
- what motifs are forbidden
- what materials, clothing, architecture, and mythic references are appropriate
- how to avoid replacing the requested concept with a generic Western fantasy version

## 스타일 상속

이 라이브러리는 `../../라이브러리/스타일/붓터치 반실사.md`를 스타일 정본으로 참조한다. 이 문서는 대상·문화권·프리셋·클래스·테마 데이터만 제공하며 독립적인 렌더링 화풍을 강제하지 않는다.

## Anchor Resolution Rule

Resolve the cultural anchor before writing or generating.

If the user explicitly provides a culture, mythology, sacred beast, martial tradition, court, sect, deity, folklore source, or non-Western fantasy direction, follow that anchor.

If the user gives no explicit direction, use Western Medieval Fantasy.

## Anchor Output Rule

Do not output internal anchor IDs as comma-separated bracket tags.

Correct natural phrasing:

```text
Resolved cultural direction: Western medieval high fantasy, D&D-compatible TRPG interpretation, realistic semi-realistic painterly fantasy character rendering.
```

## Anchor: Western Medieval Fantasy

Use when:

- no culture is specified
- D&D, TRPG, adventurer, knight, elf, dwarf, or Western fantasy is implied
- medieval fantasy equipment and archetypes are appropriate

Visual tradition:

- Western medieval high fantasy
- D&D-compatible TRPG interpretation
- castles, ruins, taverns, forests, cathedrals only when appropriate
- plate armor, mail, leather, cloaks, robes, staffs, swords, axes, bows
- grounded mythic fantasy materials

Style phrase:

```text
Create a realistic semi-realistic painterly Western medieval high fantasy TRPG portrait with D&D-compatible visual language, grounded fantasy materials, and high-end painterly fantasy illustration presentation.
```

Avoid:

- anime, manga, comic, cel-shaded, or any other 2D rendering
- East Asian martial robes unless requested
- cyberpunk or science fiction drift
- automatic holy imagery for paladins or clerics

## Anchor: East Asian Mythological Fantasy

Use when:

- the user requests East Asian mythic fantasy
- sacred beasts, divine beasts, mythic court, celestial animals, ancient eastern kingdoms, or mythological spirits are explicit
- terms such as 황룡, 청룡, 주작, 현무, 백호, 기린, 용왕, 선녀, 도깨비, 구미호, 봉황 are used

Visual tradition:

- semi-realistic East Asian mythological fantasy
- mythic court robes
- ceremonial armor
- jade, silk, lacquer, bronze, gold, cloud patterns, talismans, sacred mountains
- temple, palace, shrine, misty mountains, celestial clouds

Style phrase:

```text
Create a realistic semi-realistic painterly East Asian mythological fantasy portrait with ceremonial mythic visual language, refined sacred materials, and high-end painterly fantasy illustration presentation.
```

Avoid:

- Western D&D wording
- crusader armor
- gothic cathedral framing
- random samurai armor unless Japanese direction is explicit
- generic Western dragon anatomy for East Asian dragons

## Anchor: Original Hybrid Fantasy

Use when:

- the user requests a deliberate fusion
- the concept mixes Western D&D with East Asian mythic elements
- the user asks for a unique original setting

Style phrase:

```text
Create a realistic semi-realistic painterly original hybrid fantasy portrait that combines the specified cultural bases in a coherent realistic semi-realistic painterly TRPG style, with controlled material language and no random cultural drift.
```

Hybrid rule:

- The prompt must say which culture is the base and which elements are secondary.

## Sacred Beast Handling

### East Asian Dragon

Use:

- long serpentine body
- horns
- whiskers
- mane
- clawed limbs
- cloud or water association
- sacred, imperial, or elemental presence depending on concept

Avoid:

- Western winged lizard default unless requested

### Huanglong / Yellow Dragon

Use:

- imperial yellow, gold, earth, central direction, sacred authority
- cloud, jade, old court, celestial earth symbolism

### Azure Dragon

Use:

- blue-green scales
- spring, east, wood, storm, cloud motifs

### Vermilion Bird

Use:

- red, flame, feathers, southern direction, sacred bird form
- do not turn into a generic phoenix unless intended

### Black Tortoise

Use:

- tortoise and serpent symbolism
- black, water, north, winter, endurance, protection

### White Tiger

Use:

- white tiger, metal, west, autumn, warlike sacred pressure

### Qilin / Kirin

Use:

- deer-like or horse-like sacred beast
- scales, antlers, mane, gentle divine majesty
- auspicious atmosphere

## Anchor Conflict Resolution

User request wins.

If the user says "D&D 동양 판타지", resolve as Original Hybrid Fantasy unless one side is clearly dominant.

If the user says "무협 팔라딘", use East Asian Martial Fantasy for culture and paladin only as oath-bound armored or martial archetype. Do not add crusader imagery.

If the user says "서양식 구미호", use Original Hybrid Fantasy and specify Western fantasy base with fox-spirit traits.
