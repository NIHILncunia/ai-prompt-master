# 토큰 계열 프로필 운영 지침

## 목적

토큰 계열 프로필은 기준 완성형 토큰의 프레임 시각 언어를 보존하고, 같은 유형 또는 관련 설정을 가진 새 대상의 완성형 토큰에 자동 적용하기 위한 Markdown 기록이다. 빈 프레임 파일을 보관하거나 재사용하지 않는다.

## 보존 구조

```text
토큰 계열
├─ 기준 완성형 토큰 PNG
└─ 계열 프로필 Markdown
```

프로필에는 아래 필드를 기록한다.

- 계열명
- 기준 토큰 파일
- 적용 유형·종족·분류
- 관련 세력·소속·지역·역할
- 프레임 공통 두께
- 주·보조 색상
- 재질
- 문양
- 외곽 실루엣
- 대칭 방식
- 일반·엘리트·보스별 장식 밀도
- 보스 표적 표현
- 캐릭터 본체 적용 금지 요소

## 자동 선택

새 대상의 계열은 다음 순서로 자동 선택한다.

1. 유형·종족·분류 일치
2. 세력·소속·지역·역할·위계 일치
3. 기준 토큰의 색·재질·문양·외곽 실루엣과 새 대상 설정의 시각 일치도

- 같은 유형의 계열이 여러 개면 세력·소속·지역·역할·위계가 더 일치하는 계열을 우선한다.
- 일치하는 계열이 없거나 기존 계열과 충돌하면 새 기본 계열로 생성한다.
- 마스터가 계열·색상·분위기를 명시하면 자동 선택보다 우선한다.
- 자동 선택 결과와 판단 근거는 토큰 생성 요구사항 확인서에 공개한다.

## 적용 범위

- 계열 프로필은 프레임의 색상·재질·문양·장식·외곽 실루엣·대칭·등급별 밀도만 재사용한다.
- 기존 캐릭터의 얼굴·머리·신체 구조·의상·장비·포즈·실루엣은 새 대상에 복제하지 않는다.
- 일반·엘리트·보스는 같은 계열의 시각 언어를 공유하고 장식 밀도와 보스 표적성만 달리한다.
- 보스 표적성은 캐릭터를 덮는 조준선이나 UI 마커가 아니라 프레임 주변의 대칭적 표식·대비색·위협성 있는 장식 구조로 표현한다.
