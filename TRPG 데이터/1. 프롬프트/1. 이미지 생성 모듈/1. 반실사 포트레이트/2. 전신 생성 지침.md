# 전신 생성 지침

## 출력

- 9:16 세로 이미지 1장
- 머리부터 발끝까지 완전한 전신
- 단일 대상
- 저장 파일명: `<액터>.webp`
- 접미 없는 기본 액터 파일명은 전신 확정본을 의미한다. `전신` 접미사는 붙이지 않는다.

## 구성

- 머리, 손, 발, 주요 장비와 장식이 불필요하게 잘리지 않아야 한다.
- 포즈는 대상의 역할과 성격을 읽을 수 있어야 한다.
- 전신 실루엣과 복식 구조를 확인할 수 있는 구도를 우선한다.
- 배경은 캐릭터를 보조하되 전신 가독성을 해치지 않는다.

## 완료 조건

- 얼굴과 정체성을 식별할 수 있음
- 의상·장비의 전체 구조를 확인할 수 있음
- 색상 체계가 확정 가능함
- 흉상 또는 완성형 VTT 토큰 생성의 기준 이미지로 사용할 수 있음
