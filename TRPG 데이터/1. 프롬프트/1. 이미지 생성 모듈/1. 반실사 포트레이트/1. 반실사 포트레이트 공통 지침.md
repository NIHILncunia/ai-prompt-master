# 반실사 포트레이트 공통 지침

## 기본 계약

- 단일 대상만 다룬다.
- 전신과 흉상의 기본 비율은 세로 9:16이다. 완성형 토큰은 1:1 정사각형을 사용한다.
- 선택된 스타일 계약을 따른다. 별도 지정이 없으면 `붓터치 반실사`, `애니 페인팅`이 명시되면 정식 스타일 `애니 페인팅`을 적용한다. 과거 표현 `세미리얼 애니 페인팅`도 같은 스타일로 정규화한다.
- 대상의 종족·개체 고유 형태가 중요한 경우 관련 설정 문서와 시각 자료를 먼저 확인한다.

## 기준 이미지

- 포트레이트 전신이 확정되면 흉상과 완성형 토큰의 기준 이미지로 사용할 수 있다.
- 사용자가 업로드한 단일 대상 이미지는 완성형 토큰의 직접 기준 이미지가 될 수 있으며, 전신 생성·확정을 요구하지 않는다.
- 사용자 이미지가 보존 기준이면 명시적으로 바꾸라고 한 요소만 변경한다. 단, 사용자가 `그림체 변경`, `현재 스타일로 적용`, `애니 페인팅으로 변환`처럼 스타일 변환을 명시한 경우에는 캐릭터 디자인을 보존하고 원본 그림체·렌더링 방식은 보존 대상에서 제외한다.

## 스타일과 디자인 분리

- 스타일 계약과 캐릭터 디자인 계약을 분리한다.
- 스타일 변환 요청에서 우선 보존하는 것은 정체성, 연령·성별·종족, 얼굴 특징, 헤어, 의상 구조, 장비, 대표 색상, 설정상 핵심 마법·재질 특징이다.
- 원본 이미지의 선화, 셀 셰이딩, 포토리얼 렌더링, 붓터치, 조명 방식은 선택 스타일과 충돌하면 그대로 유지하지 않는다.
- 선택 스타일만을 이유로 고딕·금장·모피·대성당·파랑/흰색 계열을 자동 추가하지 않는다.
- 스타일 앵커에서는 그림체·채색·재질 표현·마감만 참조한다. 앵커의 인물·얼굴 생김새·헤어·의상·장비·팔레트·포즈·카메라·배경·구성을 복제하지 않는다.
- 신규 얼굴·흉상은 `붓터치 반실사` 선택 시 `01 + 02 + 04`, 신규 반신·전신은 `01 + 02 + 03 + 04`를 기본 호출한다.
- 실제 사용할 앵커 조합과 참조 예산 축소는 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 결정하며, 이 기능이 별도의 최대 수량이나 축소 조합을 정하지 않는다.
- 표정과 포즈는 사용자가 지정한 성격을 적극적으로 반영하며, 순한 표정이나 동일한 3/4 앵글을 기본값으로 강제하지 않는다.

## 단계 경계

- 전신은 캐릭터 전체 디자인과 후속 산출물의 기준본이다.
- 흉상과 전신 기반 완성형 토큰은 확정 전신의 파생 결과물이다.
- 업로드 이미지 기반 완성형 토큰은 업로드 원본의 파생 결과물이다.
- 완성형 토큰은 기준 이미지의 캐릭터 본체를 그대로 사용하며 캐릭터를 새로 생성하거나 다시 그리지 않는다.
- 완성형 토큰은 기준 이미지의 기존 그림체를 보존하며 캐릭터 스타일 앵커를 적용하지 않는다.
- 토큰 단계의 주 작업은 크롭·확대·축소·위치 이동 같은 미세 배치, 계열·등급에 맞는 프레임 구성, 원형 바깥 투명 처리다.
- 캐릭터 본체에 허용되는 변경은 가장자리 블렌딩, 마스킹, 아주 미세한 밝기·대비·색 균형 보정처럼 원본 형상을 바꾸지 않는 수준에 한정한다.
- 완성형 토큰은 캐릭터를 포함한 최종 토큰이며, 빈 프레임이나 별도 프레임 WebP가 아니다.

## 보존 우선순위

- 정체성
- 얼굴·머리 또는 비인간형 헤드 구조
- 종족·신체 구조
- 의상·장비
- 대표 색상
- 핵심 발광·재질 특징
- 전체적인 위계와 역할 인상

## 금지

- 선택 스타일 계약과 다른 화풍으로 이탈
- `붓터치 반실사` 선택 시 명백한 애니풍·셀 셰이딩·웹툰풍으로 이탈
- `애니 페인팅` 선택 시 반실사 인물화·현실적인 컨셉 아트 얼굴·평면 셀 셰이딩·치비·웹툰식 평면 채색으로 이탈
- 사진 같은 포토리얼
- AAA 3D CGI 캐릭터 렌더 인상
- 기준 이미지와 흉상·완성형 토큰의 정체성 불일치
- 완성형 토큰에서 캐릭터 본체를 재생성·재디자인
- 캐릭터 없이 프레임만 만드는 결과
