# 반실사 포트레이트 품질 및 금지 규칙

## 목적

구 `반실사 생성 제한 규칙 라이브러리`에서 스타일 변경 후에도 유효한 품질·안정성 규칙만 이관한다.
포트레이트의 화풍 판정은 선택된 스타일 계약을 따른다. 기본은 `../라이브러리/스타일/붓터치 반실사.md`이며, `애니 페인팅`이 선택되면 `../라이브러리/스타일/애니 페인팅.md`를 사용한다. 과거 표현 `세미리얼 애니 페인팅`은 레거시 별칭으로만 받아들인다. 이 문서는 두 스타일에 공통인 구조·안정성·가독성 규칙만 소유하며 스타일별 얼굴 비례와 렌더링 문법을 중복 정의하지 않는다. 구 포토리얼·3D CGI·AAA 렌더링 강제 규칙은 폐기한다.

## 단일 대상·단일 화면

- 일반 포트레이트는 하나의 연속된 캔버스와 하나의 요청 프레이밍만 사용한다.
- 분할 화면, 콜라주, 인셋, 전신과 흉상의 동시 배치를 금지한다.
- 사용자가 복수 대상을 명시하지 않은 경우 불필요한 제2 인물·배경 인물을 추가하지 않는다.

## 텍스트 및 UI 금지

- 일반 포트레이트에는 읽을 수 있는 글자, 숫자, 로고, 워터마크, UI 패널을 넣지 않는다.

## 얼굴·머리·센서 우선

- 얼굴, 머리, 가면, 주둥이, 부리, 해골, 센서, 모노아이 등 정체성 중심부가 선명하게 읽혀야 한다.
- 눈·센서의 방향, 개수, 형태를 보존한다.
- 과도한 발광으로 홍채·센서 구조를 지우지 않는다.
- 인간형은 설정된 연령이 얼굴 구조와 체형으로 읽혀야 하며, 성인을 미소년·미소녀화하거나 아동·청소년을 성인 체형으로 만드는 결과를 피한다.
- 성향은 눈매·눈썹·입꼬리·시선·고개 방향으로 구분하며 모든 캐릭터를 순하고 선한 기본 표정으로 수렴시키지 않는다.
- 선택 스타일이 `애니 페인팅`이어도 얼굴형과 눈매를 개체별로 달리하여 동일 얼굴 수렴을 방지한다.

## 스타일 드리프트 방지

- 선택 스타일의 정본 문서를 우선하고, 다른 스타일의 금지 규칙을 교차 적용하지 않는다.
- `붓터치 반실사`에서는 설득력 있는 현실 구조와 일러스트 중심의 형태 단순화를 함께 유지한다. 사진·하이퍼리얼·CGI 또는 애니풍으로 이탈하지 않는다.
- `애니 페인팅`에서는 애니메이션형 얼굴 구조를 기본으로 하며 반실사 인물화, 현실적인 패션 초상화, 서구권 리얼리즘 컨셉 아트 얼굴, 치비·SD, 평면 셀 채색, 웹툰식 단순 채색, 포토리얼, CGI 인상을 피한다.
- 어느 스타일에서도 특정 샘플에서 반복된 고딕·금장·모피·후드·성당·파랑/흰색 팔레트를 스타일 자체의 필수 요소로 복제하지 않는다.
- 앵커의 포즈·카메라·크롭·배경·조명 상황·장면 구성을 스타일 요소로 복제하지 않는다.

## 해부학 안정성

- 팔다리 수, 관절 방향, 손·발·발톱·기계 관절을 대상에 맞게 유지한다.
- 비인간형 대상에 인간 비율을 억지로 적용하지 않는다.
- 임의의 꼬리·날개·뿔·귀를 추가하지 않는다.

## 손·장비

- 전신에서 손이 보이면 손가락·그립·장비 접촉 관계를 명확히 한다.
- 전신의 주무기와 핵심 장비는 실루엣과 장착 위치를 보존한다.
- 흉상은 얼굴 우선이다. 사용자가 명시하지 않은 경우 무기, 방패, 손잡이, 칼집 등이 흉상 프레임에 억지로 들어오지 않게 한다.

## 실루엣과 FX

- 장식, 망토, 사슬, 파티클이 신체 구조를 가리지 않게 한다.
- FX는 대상의 실제 능력·상태를 보조하는 범위로 제한한다.
- 과도한 폭발, 번개, 연기, 글로우가 얼굴·장비·외곽선을 가리면 실패로 본다.

## 배경

- 배경은 대상을 보조하며 주 피사체보다 강하게 튀지 않는다.
- 머리 뒤의 과도한 광원, 배경 인물, 얼굴처럼 보이는 우연한 형상을 피한다.

## 문화권·클래스 드리프트 방지

- 문화권을 임의로 다른 문화권의 상징으로 치환하지 않는다.
- 팔라딘=자동 신성광, 워록=자동 악마화, 레인저=자동 녹색 마법, 수도사=자동 동아시아풍처럼 직업명을 고정 클리셰로 변환하지 않는다.
- 사용자가 명시한 문화, 종교, 계급, 능력 원천을 우선한다.

## 기계형

- 완전 기계형에 인간 피부·입술·유기적 얼굴을 임의로 추가하지 않는다.
- 장갑판, 관절, 센서, 볼트, 피스톤, 마모 등 기계적 구조를 읽을 수 있게 유지한다.

## 비율

- 본 기능의 출력은 세로 9:16이다.
- 전신에서는 머리부터 발끝까지, 흉상에서는 얼굴과 상반신 정체성을 안정적으로 담는다.
