# 1. 반실사 포트레이트 AGENTS

## 역할

이 폴더는 이미지 생성 모듈 내부 1번 기능인 `반실사 포트레이트`를 담당한다. 전신·흉상·완성형 VTT 토큰을 생성하며, 완성형 토큰의 두 입력 경로를 소유한다.

## 직접 준비 호출

- `포트레이트 준비`, `포트레이트 준비.`는 이 기능의 처리 프로세스 안내 요청이다. 별도 스타일 지정이 없으면 기존 기본 스타일을 사용한다.
- `애니 페인팅 포트 준비`, `애니 페인팅 포트 준비.`, `애니 페인팅 포트레이트 준비`, `애니 페인팅 포트레이트 준비.`는 이 기능의 처리 프로세스 안내 요청이며 선택 스타일을 `애니 페인팅`으로 고정한다. `애니 페인팅`은 정식 스타일명이다. 과거 명칭 `세미리얼 애니 페인팅`은 레거시 별칭으로만 받아들인다.
- 준비 호출이 아니더라도 포트레이트 요청에서 `애니 페인팅`, `애니 페인팅으로 전환`, `애니 페인팅 스타일`, `세미리얼 애니 페인팅`을 명시하면 같은 스타일을 선택한다.
- 직접 준비 호출에서는 요구사항 확인서 작성, 프롬프트 공개, 생성·수정·외부 실행을 시작하지 않는다.

## 핵심 계약

- `애니 페인팅`과 `붓터치 반실사` 생성은 정식 시각 앵커의 실제 이미지 픽셀 확인이 완료되어야 준비 완료로 본다. 파일명·메타데이터 확인만으로 대체하지 않는다.
- 요구사항 확인서와 최종 영어 프롬프트 검토에는 선택 스타일과 실제로 사용한 앵커의 전체 파일명을 기록한다.
- 최종 영어 프롬프트에는 선택 스타일의 고정 영어 그림체 블록과 공통 고정 영어 마감 블록을 문장 변경 없이 넣는다.
- 스타일 앵커의 인물·의상·팔레트·포즈·카메라·배경·구성은 참조하지 않는다.
- 신규 얼굴·흉상은 `붓터치 반실사` 선택 시 `01 + 02 + 04`, 신규 반신·전신은 `01 + 02 + 03 + 04`를 기본 호출한다. 실제 조합과 참조 예산 축소는 `../라이브러리/스타일/정식 스타일 호출 규칙.md`가 결정한다.
- 요구사항 확인서와 최종 영어 프롬프트는 공통 프롬프트 점검의 P01~P10을 모두 통과한 뒤 공개한다.

- 전신 9:16을 생성·확정한 뒤 동일 개체의 흉상 또는 완성형 토큰을 후속 산출물로 선택할 수 있다.
- 사용자가 이미지를 업로드하면 전신 생성을 선행하지 않고 해당 이미지를 기준으로 완성형 토큰을 직접 생성할 수 있다.
- 완성형 토큰은 기준 이미지의 캐릭터 본체를 그대로 사용하며, 원형 배치·미세 보정·자동 프레임·투명 처리만 적용한다.
- 완성형 토큰은 기준 이미지의 기존 그림체를 보존하며 캐릭터 스타일 앵커로 다시 그리지 않는다.
- 완성형 토큰은 캐릭터가 들어간 최종 토큰이며, 빈 프레임 또는 별도 프레임 PNG가 아니다.
- 토큰 계열은 대상 유형과 설정을 근거로 자동 선택하며, 등급은 일반·엘리트·보스로 처리한다. 등급이 없으면 일반 토큰이다.
- 각 이미지 생성은 공통 승인 절차를 개별 적용하고 마스터의 명시적 승인을 받은 뒤에만 실행한다.
