# 월드 지도 마스터 프롬프트

## 기본 계약

- 16:9
- 컬러풀 양피지 지도
- 종이 바깥은 무광 검정
- 종이 안쪽 바다는 파란색
- 지도 상하좌우에 약 200px 상당의 바다 여백을 확보
- 장식보다 지도 판독성을 우선

## 4모드

1. 랜덤 세계 전도
2. 사용자 지정 세계 전도
3. 랜덤 대륙 지도
4. 사용자 지정 대륙 지도

사용자 자료가 있으면 임의 재배치보다 제공된 지리 관계를 우선한다.

## 그림체 적용 경계

- 그림체 적용 방식은 `사용자 지정 스타일·기능성 예외`다.
- 정식 스타일 앵커는 종류를 불문하고 자동으로 불러오지 않는다. `라인 웹툰` 01~17도 월드 지도에는 자동 적용하지 않는다.
- 양피지 카토그래피, 해안선·지형·수계·라벨 판독성, 약 200px 바다 안전 여백, 종이 바깥 무광 검정 계약이 모든 스타일 계약보다 우선한다.
- `라인 웹툰풍 월드 지도` 요청도 기능성 예외로 유지한다. 선명한 해안선과 지형선, 정돈된 평면 색 분리 같은 카토그래피 친화적 요소만 설명형으로 반영하고 라인 웹툰 고정 영어 그림체 블록이나 01~17 앵커를 자동 삽입하지 않는다.
- 13~17 환경 앵커는 원근 환경 일러스트용 역할이므로 월드 지도에서 자동 사용하지 않는다. 지형·기후·수계 표현은 월드 지도 전용 규칙과 라이브러리를 따른다.
- 특정 스타일 앵커의 직접 참조는 마스터가 명시적으로 요청한 경우에만 검토한다.
- 실제 예외 판정은 `../라이브러리/스타일/정식 스타일 호출 규칙.md`를 따른다.
