# 6. 사용자 지정 세계 전도 생성 규칙

## 목적

사용자가 제공한 세계 지도, 배치 스케치, 여러 대륙 이미지, 텍스트 구조를 바탕으로 세계 전도를 만든다.

## 우선 보존 대상

1. 대륙 간 상대 위치
2. 대륙별 상대 크기
3. 북·남·동·서 방향 관계
4. 대륙 사이 거리
5. 내해, 해협, 대양의 연결
6. 주요 군도 위치
7. 각 대륙의 핵심 지형 배치
8. 세계적 랜드마크

## 외곽선 처리

- 원본의 대륙 실루엣과 방향성을 유지한다.
- 인공적으로 둥글거나 네모난 해안선은 자연스럽게 보정한다.
- 만, 곶, 반도, 하구, 해협, 연안 섬을 추가해 설득력을 높일 수 있다.
- 외곽선 보정으로 대륙의 정체성이 달라지면 안 된다.
- 원본에 없는 거대한 대륙이나 바다를 임의로 추가하지 않는다.

## 여러 이미지 결합

여러 대륙 이미지를 제공한 경우 다음을 먼저 정리한다.

- 각 이미지가 어느 대륙인지
- 북쪽 방향
- 상대 크기
- 세계 내 배치
- 대륙 사이 최소 거리
- 중복된 해안 또는 바다 영역
- 공통 렌더링 스타일

모든 대륙을 동일한 양피지 지도 스타일로 통합한다.

## 불완전한 자료 처리

- 텍스트와 이미지가 충돌하면 사용자의 최신 텍스트 지시를 우선한다.
- 이미지에 일부 지형만 보이면 보이는 구조를 유지하고 나머지를 자연스럽게 연결한다.
- 방향 정보가 없으면 추가 질문이 필수적인 경우에만 짧게 확인한다.
- 사소한 공백은 지리적 일관성을 우선해 보완한다.

## 금지 사항

- 대륙 위치를 임의로 재배열하지 않는다.
- 사용자 제공 대륙을 하나로 합치지 않는다.
- 원본의 내해를 육지로 막지 않는다.
- 내부 지형을 장식적 이유로 반대편에 옮기지 않는다.
