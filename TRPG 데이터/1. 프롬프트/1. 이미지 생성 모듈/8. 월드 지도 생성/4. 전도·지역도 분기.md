# 전도·지역도 및 생성 모드 분기

## 1. 범위 판정

- 세계 전체: 세계 전도
- 단일 대륙: 대륙 지도

## 2. 생성 방식 판정

- 사용자가 구체적 배치·이미지·스케치를 주지 않은 경우: 랜덤 생성
- 사용자 배치·이미지·스케치·텍스트 구조를 기준으로 삼는 경우: 사용자 지정

## 3. 최종 네 모드

1. 랜덤 세계 전도 → `5. 랜덤 세계 전도 생성 규칙.md`
2. 사용자 지정 세계 전도 → `6. 사용자 지정 세계 전도 생성 규칙.md`
3. 랜덤 대륙 지도 → `7. 랜덤 대륙 지도 생성 규칙.md`
4. 사용자 지정 대륙 지도 → `8. 사용자 지정 대륙 지도 생성 규칙.md`

최종 프롬프트 조립은 `9. 월드 지도 최종 프롬프트 조립기.md`를 사용한다.
