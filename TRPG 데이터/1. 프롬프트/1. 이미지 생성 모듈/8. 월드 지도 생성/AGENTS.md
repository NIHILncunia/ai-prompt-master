# 8. 월드 지도 생성 AGENTS

## 역할

월드 지도 및 지역도 생성을 담당한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 월드 지도 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 월드 지도 공통 지침.md`, `2. 양피지 스타일 규칙.md`, `3. 라벨링 및 표기 규칙.md`, `4. 전도·지역도 분기.md`
6. 요청 모드에 맞는 `5. 랜덤 세계 전도 생성 규칙.md`부터 `8. 사용자 지정 대륙 지도 생성 규칙.md`까지의 문서와 `9. 월드 지도 최종 프롬프트 조립기.md`
7. 필요 시 `라이브러리/지형·기후·수계 배치 라이브러리.md`

상위 모듈의 공통 붓터치 마감 적용 대상·자동 예외와 이미지 승인 하드 게이트를 먼저 판정한다. 양피지 지도는 공통 붓터치 마감의 자동 적용 예외다.

## 그림체 적용 경계

- 그림체 적용 방식은 사용자 지정 스타일·기능성 예외다.
- 정식 인물 스타일의 얼굴·나이·전신 앵커를 자동으로 불러오지 않는다.
- 기능 전용 판독성·시점·레이아웃 계약이 우선한다.
- 사용자가 별도 표면 마감을 요청하면 기능 계약과 충돌하지 않는 범위만 요구사항 확인서에 공개한다.
- 실제 예외 판정은 `../라이브러리/스타일/정식 스타일 호출 규칙.md`를 따른다.

## 핵심 계약

- 세계 전도·대륙 지도는 랜덤/사용자 지정의 4모드로 분기한다.
- 대륙의 정본 위치·권역·항로를 새로 확정하거나 변경하는 요청은 설정 관련 기능에서 먼저 처리한다.
