# 8. 월드 지도 생성 AGENTS

## 역할

월드 지도 및 지역도 생성을 담당한다.

## 읽기 순서

1. 상위 `../AGENTS.md`
2. 상위 `../0. 이미지 생성 모듈 마스터 프롬프트.md`
3. `0. 월드 지도 마스터 프롬프트.md`
4. `../공통/1. 이미지 생성 공통 승인 절차.md`
5. `1. 월드 지도 공통 지침.md`, `2. 양피지 스타일 규칙.md`, `3. 라벨링 및 표기 규칙.md`, `4. 전도·지역도 분기.md`
6. 요청 모드에 맞는 `5. 랜덤 세계 전도 생성 규칙.md`부터 `8. 사용자 지정 대륙 지도 생성 규칙.md`까지의 문서와 `9. 월드 지도 최종 프롬프트 조립기.md`
7. 필요 시 `라이브러리/지형·기후·수계 배치 라이브러리.md`

상위 모듈의 공통 붓터치 마감 적용 대상·자동 예외와 이미지 승인 하드 게이트를 먼저 판정한다. 양피지 지도는 공통 붓터치 마감의 자동 적용 예외다.

## 그림체 적용 경계

- 그림체 적용 방식은 `사용자 지정 스타일·기능성 예외`다.
- 정식 스타일 앵커는 종류를 불문하고 자동으로 불러오지 않는다. `라인 웹툰`의 01~17 인물·형태·환경 앵커도 월드 지도에는 자동 적용하지 않는다.
- 16:9 양피지 카토그래피, 해안선·대륙 실루엣 판독성, 지형·수계·라벨 계층, 바다 안전 여백 등 지도 기능 계약이 모든 정식 스타일 계약보다 우선한다.
- 사용자가 `라인 웹툰풍 월드 지도`처럼 스타일을 명시해도 `정식 스타일 적용`으로 전환하지 않는다. 선명한 해안선·지형 경계, 제한된 평면 색 분리, 정돈된 도식선처럼 지도 판독성과 양립하는 그래픽 특성만 기능성 예외 안에서 설명형으로 반영하고, 라인 웹툰 고정 영어 그림체 블록이나 01~17 앵커를 자동 삽입하지 않는다.
- 지도는 인물·장면 일러스트가 아니므로 13~17 환경 앵커도 기본 참조로 사용하지 않는다. 기후·지형 정보는 월드 지도 전용 지형·기후·수계 규칙으로 해결한다.
- 사용자가 특정 스타일 앵커 이미지를 직접 참조하라고 명시한 경우에만 지도 기능 계약과 충돌하지 않는 범위에서 개별 참조를 검토하고 요구사항 확인서에 공개한다.
- 실제 예외 판정은 `../라이브러리/스타일/정식 스타일 호출 규칙.md`를 따른다.

## 핵심 계약

- 세계 전도·대륙 지도는 랜덤/사용자 지정의 4모드로 분기한다.
- 대륙의 정본 위치·권역·항로를 새로 확정하거나 변경하는 요청은 설정 관련 기능에서 먼저 처리한다.
