# 8. 사용자 지정 대륙 지도 생성 규칙

## 목적

사용자가 제공한 풍경화, 쿼터뷰 전경, 손그림, 외곽선, 기존 지도, 텍스트 배치를 대륙 지도 형식으로 변환한다.

## 핵심 보존 원칙

- 내부 지형은 최대한 유지한다.
- 산맥과 강의 방향 관계를 유지한다.
- 숲, 정글, 사막, 화산, 설원, 늪, 수정 대지 등 생태권 위치를 유지한다.
- 중심 수정핵, 거대 산, 세계수, 분화구 같은 주요 랜드마크를 유지한다.
- 생태권 사이의 이웃 관계를 바꾸지 않는다.
- 대륙의 전반적인 방향과 비율을 유지한다.

## 해안선과 외곽선

외곽선은 원본을 기계적으로 복사하지 않는다.

다음을 허용한다.

- 부자연스러운 직선 해안 완화
- 지나치게 둥근 해안의 굴곡 추가
- 만, 곶, 반도, 하구 추가
- 산맥이 바다에 닿는 구간의 절벽화
- 강 하구와 삼각주 정리
- 작은 연안 섬과 암초 추가
- 반복되는 톱니 모양 제거

다음을 금지한다.

- 대륙의 방향을 뒤집는 변경
- 주요 반도를 삭제하는 변경
- 내부 생태권 크기를 전면 재배분하는 변경
- 원본에 없는 두 번째 대륙 추가
- 중심 랜드마크를 다른 지역으로 이동

## 풍경화에서 지도화할 때

- 원근으로 가려진 후면 지형은 앞쪽 지형과 설정 설명을 근거로 보완한다.
- 쿼터뷰의 과장된 높이는 지도 기호형 고저 표현으로 변환한다.
- 풍경의 조명과 날씨는 지도의 영구 지형으로 오인하지 않는다.
- 구름, 용, 인물은 기본적으로 지형 데이터가 아니므로 지도에 남기지 않는다.
- 사용자가 요청한 토템, 도시, 성소는 지도 랜드마크로 단순화할 수 있다.

## 화질 개선 재생성

기존 지도의 화질 개선이 목적이면 편집을 반복하지 않고 고해상도 신규 렌더링을 우선한다.

- 원본 구성과 색상 체계를 재현한다.
- 흐릿해진 해안선과 지형 경계를 다시 그린다.
- 작은 구조물은 과밀하게 복사하지 않는다.
- 양피지와 바다 여백 규칙을 새로 정확히 적용한다.
